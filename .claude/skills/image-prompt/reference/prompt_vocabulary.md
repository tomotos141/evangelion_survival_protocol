## §Quality Tags — 品質タグ（使用注意）

### 効果あり（モデル依存）
| 対象 | タグ |
|------|-----|
| フォトリアル | `professional photography`, `8k uhd`, `sharp focus` |
| Danbooru 系 | `masterpiece`, `best quality` |
| コンセプトアート | `concept art`, `highly detailed` |

### カーゴカルト（効果不明 — 使わない）
`trending on artstation`, `award winning`, `ultra realistic`, `hyper detailed`

### 原則
- **2-3 個まで**に絞る
- ベース SDXL では品質タグの効果は限定的
- モデルのドキュメント（モデルカード）の推奨に従う
