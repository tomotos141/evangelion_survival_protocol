## 6. Ghost / Lie / Want / Need チェーン (内面の因果構造)
> Weiland の Character Arc 理論に基づく。Ghost が Lie を生み、Lie が Want を駆動し、Need が Lie の克服を要求する。

- **Ghost（幽霊）**: このキャラクターが「嘘」を信じるに至った**過去の決定的出来事**。
- **Wound（傷）**: Ghost が残した心理的傷跡。日常のどんな場面で症状が出るか。
- **Lie（嘘）**: Ghost のせいで信じ込んでいる**誤った信念**。（例: 「人を信じれば裏切られる」）
- **Want（欲しいもの）**: Lie に基づいて本人が自覚している目標。
- **Need（必要なもの）**: Lie を克服した先にある本当の課題。
- **Truth（真実）**: Need を満たすために受け入れるべき真実。Arc の到達点と対応する。
