# Consistency Check Skill

## Overview
このスキルは、執筆された小説のドラフトを、既存のキャラクター設定資料や世界観設定資料と照らし合わせ、矛盾や違和感がないかを体系的にチェックするためのものです。

## Prerequisites
このスキルを効果的に使用するためには、以下の情報が整理されていることが望ましいです。
- **キャラクター設定**: 名前、性格、口調、一人称/二人称、動機、過去の経歴など。
- **世界観設定**: 地理、魔法/科学のルール、文化、歴史、固有名詞など。
- **過去の経緯**: 物語のこれまでの展開（時系列、重要な出来事、キャラクターの状態）。

## Capabilities

### 1. Character Consistency (キャラクターの整合性)
- **Voice & Tone**: 台詞がキャラクターの口調（語尾、使用する語彙）と合っているか。
    - **碇シンジ**: 
        - 口調は内向的で丁寧語崩れ（～だよ、～だよね）。
        - **【重要】独白（モノローグ）の禁止事項**:
            - 「分析的・批評的すぎる思考」（例：「物理法則を無視した～」「軍の配置が～」といった冷静な観察）。
            - 「冷笑的・ニヒルな態度」（例：「～のがオチだ」「茶番だ」）。
        - **【重要】推奨される描写**:
            - 生理的な嫌悪感、恐怖、痛み（PTSD反応）。
            - 「必死さ」「余裕のなさ」。知識は持っているが、それを活用するのにも精神的なコストが伴う描写。
    - **葛城ミサト**: 明るく振る舞うが、大人の余裕と脆さが同居している。
    - **アスカ**: 高圧的だが、その裏にある承認欲求を滲ませる。
- **Personality & Motivation**: 行動や決断が、そのキャラの性格や確立された動機と矛盾していないか。
- **Relationships**: 他のキャラクターへの呼び方や態度が、現在の関係性を反映しているか。
- **Status**: 肉体的な状態（怪我、疲労）や所持品の状態が一貫しているか。

### 2. World Building Consistency (世界観の整合性)
- **Rules & Mechanics**: 魔法、技術、超常現象などが、定義済みのルールに従っているか。
- **Setting Details**: 地理的な移動、天候、時間経過、文化的習慣などが設定通りか。
- **Fact Checking**: 固有名詞の表記揺れや、過去に提示された事実との食い違いがないか。

### 3. Plot & Timeline Continuity (プロットと時系列の連続性)
- 直前のシーンからの続き具合に矛盾がないか。
- 時間の経過が論理的か。
- 伏線や伏線回収の整合性。

## Instructions for the Agent

整合性チェックを行う際は、以下の手順に従ってください。

1.  **Generate Context (コンテキストの把握)**
    - まず、チェック対象となる本文（ドラフト）を確認します。
    - 次に、関連する設定ファイル（`characters/`, `world/` などのディレクトリにあるMarkdownファイル）を `view_file` で読み込みます。
    - 必要であれば、直前の章やシーンも参照して文脈を補完します。

2.  **Analyze (分析)**
    - 本文を段落やシーンごとに読み解き、設定資料と照合します。
    - 特に「台詞」「重要なアクション」「環境描写」に注目します。

3.  **Report (レポート作成)**
    - 発見された矛盾や違和感をリストアップします。
    - 各指摘には、以下の要素を含めてください：
        - **場所**: 該当する行番号や文。
        - **問題点**: 何が矛盾しているか。
        - **根拠**: どの設定（または過去の記述）と食い違っているか。
        - **改善案**: どう修正すべきかの提案。

## Reporting Format Example

```markdown
### 整合性チェックレポート

#### 1. キャラクター: アリス
- **場所**: 15行目 「俺、腹減ったな」
- **問題点**: 一人称の不一致。
- **根拠**: `characters/alice.md` によると、アリスの一人称は「私」です。
- **改善案**: 「私、お腹空いたかも」に変更。

#### 2. 世界観: 魔法使用
- **場所**: 42行目 詠唱なしで火球を放っている。
- **問題点**: ルール違反。
- **根拠**: `world/magic_system.md` の「初級魔術でも詠唱は必須」というルールに反しています。
- **改善案**: 短い詠唱を追加するか、魔法具を使用した描写に変更する。
```
