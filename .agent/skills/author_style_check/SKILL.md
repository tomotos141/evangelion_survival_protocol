# Author Style Check Skill

## Overview
このスキルは、作品の品質や整合性（Quality/Consistency）のチェックとは別に、**「著者の個人的な嗜好（Taste/Aesthetics）」**に合致しているかを判定するためのものです。
技術的に正しくても、著者の「美学」に反する表現は修正対象となります。

## Core Aesthetics (著者の美学)

### 1. Emotional Tone: "Dry & Cold" (ドライで冷徹)
- **OK**: 諦念、ニヒリズム、静かな絶望、業務的な対応、皮肉（ただし経験則に基づくもの）。
- **NG**: 過剰な熱血、根拠のない希望、ウェットな友情・恋愛描写、幼稚なはしゃぎ方。
- **Guideline**: 感情は「吐露」するものではなく、「滲み出る」ものとして描く。
- **Restriction**: 「脚本」「演出」「フラグ」などのメタ的な比喩表現は禁止。あくまで「世界（現実）の理不尽さ」として描くこと。

### 2. Atmosphere: "Beautiful Ruin" (美しい破滅)
- **OK**: 静寂、廃墟、結晶、赤い海、無機質な輝き、終末感。
- **NG**: 生活感あふれる温かい日常、ごちゃごちゃした騒がしさ（意図的な演出を除く）。
- **Guideline**: どんなに平和なシーンでも、どこかに「世界の終わり」の予感や「死の匂い」を漂わせる。

### 3. Character Appeal: "Competence & Mask" (有能さと仮面)
- **OK**:
    - **Competence Porn**: 熟練した手つき、無駄のない所作、プロフェッショナルな思考。
    - **The Mask**: 完璧な演技、本音を隠した腹の探り合い、精神的なすれ違い。
- **NG**: 無能な善人、ただ守られるだけの存在、簡単に本音をさらけ出す展開。
- **Guideline**: キャラクターの魅力は「強さ」と「孤独」から生まれる。馴れ合いはさせない。

### 4. Plot Mechanics: "Hopeless Hard Mode" (絶望的ハードモード)
- **OK**: 敵の学習、通用しない切り札、裏切られる予知、ギリギリの綱渡り（薄氷の勝利）。
- **NG**: 「愛」や「奇跡」による安易な解決、ご都合主義的なパワーアップ。
- **Guideline**:
    - **Tightrope Walk**: 完全な無双（俺TUEEE）は禁止。「あと一歩で破滅していた」という冷や汗をかくような、紙一重の勝利を描く。
    - 読者を安心させない。「このままでは詰む」という緊張感を常に維持する。

### 5. Adaptation Policy: "Original Expansion" (原作のなぞり排除)
- **Policy**: 原作アニメのエピソードをそのままなぞる（Retelling）ことは極力避ける。
- **Direction**:
    - 世界観やキャラクター設定は維持しつつ、独自解釈に基づいた**完全オリジナルストーリー**を展開する。
    - 既知のイベント（例：使徒襲来）であっても、展開や結末を劇的に変化させ、「全く別の物語」として再構築する。

## Check List (チェックリスト)

原稿レビュー時は、以下の観点でチェックを行ってください。

### Taste Check
- [ ] **甘さの排除**: セリフや独白から、不要な「甘え」や「幼さ」を削除したか？
- [ ] **不穏さの混入**: 一見ポジティブなシーンに、ノイズや違和感（「毒」）を混ぜたか？
- [ ] **プロ意識**: 主人公や登場人物は、感情よりも目的を優先して動いているか？

### Visual & Sensory Check
- [ ] **色彩**: 「赤」「黒」「銀」「無機質」などのキーワードが効果的に使われているか？
- [ ] **感覚**: 「冷たい」「硬い」「痛い」「人工的な」といった、著者好みの感覚描写はあるか？

## Feedback Example

- **Bad**: 「大丈夫、僕たちが力を合わせればなんとかなるよ！」（根拠のない熱血）
- **Good Adjustment**: 「……確率の低い賭けだけど、ゼロじゃない。やるしかないね」（計算ずくの諦念）

- **Bad**: 「ミサトさんの料理、美味しいですね！」（平凡な日常）
- **Good Adjustment**: 「……味はする。少なくとも、栄養価の計算は合っているはずだ」（分析的・ドライ）
