# Story Editor Skill

## Overview
このスキルは、執筆された原稿に対して「面白さ（エンターテインメント性）」の観点から分析を行い、具体的な修正案やリライトを提供します。これまでの修正方針（ハードボイルドな文体、予定調和の打破、能ある鷹は爪を隠す主人公像）を反映し、大人の読者が楽しめる深みのある物語へ昇華させます。

## Capabilities

### 1. Hardboiled & Mature Tone (文体とトーンの調整)
- **ドライな描写**: 過剰な感嘆符（！）や、「がーん」「ドキドキ」といった直接的なオノマトペを排除します。代わりに、具体的な身体感覚や乾いた心理描写を用います。
- **ニヒリズムと知性**: 主人公の独白に、諦念、皮肉、そして状況を冷静に分析する知性を織り交ぜます。
- **メタ発言・比喩の排除**: 
    - 「これはアニメだ」「脚本家の都合」といったメタ視点の単語は厳禁です。
    - たとえ中身が大人でも、14歳の少年が自然に使う語彙の範囲で思考させてください。「人生2周目」の感覚は、「既視感」や「経験則」として処理し、ゲーム用語や創作用語では語らせないこと。
- **固有名詞と専門用語の抑制**: 
    - 主人公が「まだ知っているはずのない情報（敵の名前、組織の裏事情）」を独白で語らないようチェックします。不自然な知識は「奴」「あれ」「組織」などの一般名詞に置き換えます。
    - 一般人（または子供）の視点では理解できない専門用語（「VTOL」「識別信号」など）は、「見慣れない編隊」「無骨な機体」といった感覚的な表現に修正します。

### 2. Dual Nature of Protagonist (二面性の演出)
- **「演技」と「本音」のギャップ**: ループものや転生ものにおいて、主人公が「無害な一般人」を演じつつ、内面では「冷徹な策士」として動く構造を強化します。
- **情報の隠蔽**: 主人公が未来知識を持っていることを、周囲（特に鋭い他者）に悟られないように立ち回る緊張感を描きます。
- **種明かしの禁止**: 「演技成功」「バレてない」といった安心感を誘う独白を減らし、行動だけで演技であることを示唆します。

### 3. Destruction of Predictability (予定調和の破壊)
- **イレギュラーの導入**: 主人公の計画通りに進む展開（俺TUEEE）に、必ず「計算外の要素」や「不穏な綻び」を混入させます。
- **謎の提示**: 全てを解決するのではなく、主人公自身にも理解できない異変（身体の変質、敵の行動パターンの変化など）を残し、サスペンスを持続させます。

### 4. Pacing & Reaction (ペース配分とリアクション)
- **周囲の畏怖**: 主人公の異常な能力に対し、周囲が単に賞賛するのではなく、理解不能なものへの「恐怖」「警戒」「戸惑い」を抱く様子を描きます。
- **五感への訴求**: 
    - 痛み、臭い、温度などの生理的な感覚を重視し、戦闘時のリアリティを高めます。
    - 食事や日常の場面でも、「人工的すぎる甘さ」「冷たすぎる空気」など、不快感や違和感を通して世界の敵意（ハードモード感）を表現します。
    - 危機に気づくだけでなく、それに対してどう対処したか（脈拍を操作する、視線を意図的に逸らすなど）を描くことで、主人公の技術と「綱渡り」のスリルを強調します。
- **文章量と描写密度 (Volume & Density)**:
    - 1話あたり**最低200〜250行（5,000文字以上）**を維持することを基本とする。
    - 単なる行動の羅列（あらすじ化）を避け、1つの行動に対して「それがもたらす予兆（音、影、殺気）」「実行時の感触（衝撃、抵抗）」「結果としての残響（火花、沈黙）」を多層的に描写する。
    - 会話文だけの応酬を避け、沈黙の間の心理描写や、周囲の風景の細部（錆びた手すりの冷たさ、ひび割れたアスファルトの質感）を差し込む。

### 5. Reader Engagement Check (読者没入度チェック)
- **Page Turner Quality**:
    - 「ここで読むのをやめられない」「続きが気になる」と思わせるフック（引き）が章の終わりにあるか？
    - クリフハンガー（宙ぶらりんの結末）や不穏な予兆で終わらせることを推奨します。
- **Emotional Rollercoaster**:
    - 緊張（Tension）と緩和（Release）のバランスは適切か？ ずっと緊張しっぱなし、あるいは弛緩しっぱなしになっていないか？
- **Subversion of Expectations**:
    - 読者が「あるある」と予測する展開を、良い意味で裏切れているか？
    - 「助かると思ったが、代償が大きすぎた」「勝ったと思ったが、新たな謎が出た」などのツイストがあるか？

## Workflow

### Step 1: Tone & Style Check (文体チェック)
- [ ] 幼稚な表現、過度な感嘆詞はないか？
- [ ] **Density Check**: 描写が「あらすじ」になっていないか？ 特に「場所」「時間」などを記号的に処理せず、地の文として溶け込ませているか？
- [ ] **Volume Check**: 本文が200行（5,000文字）を大きく下回っていないか？ 下回っている場合、描写の「ため」や「余白」が不足していないか？
- [ ] 説明過多な独白（「計画通りだ」と自分で言ってしまう等）になっていないか？
- [ ] メタ的な知識（敵の名前など）や、不自然な専門用語を使っていないか？
- [ ] ターゲット層（30代以上など）に適した語彙が選択されているか？

### Step 2: Plot Twist & Engagement Analysis (展開・没入度チェック)
- [ ] 主人公にとって都合が良すぎる展開になっていないか？
- [ ] 「演技」が見破られそうになるスリルはあるか？
- [ ] 読者の予想を裏切る「不気味さ」や「謎」が含まれているか？
- [ ] 章のラストは「続きを読みたくなる」引き（クリフハンガー等）になっているか？
- [ ] 読後の感情は「スッキリ」よりも「ザワザワする（不穏）」になっているか？

### Step 3: Rewrite Proposal (リライト提案)
- 分析に基づき、具体的なリライト案を提示します。
- 修正案は、単なる指摘ではなく「実際に書き換えたパラグラフ」として提示し、ユーザーが文体の変化を直感的に理解できるようにします。

## Instructions for Agent
- **辛口かつ具体的な編集**: 「雰囲気を暗くして」ではなく、「ここのセリフを削除し、無言でタバコの煙を吐く描写に変えましょう」のように具体的に指示してください。
- **「Show, Don't Tell」の徹底**: 悲しみを「悲しい」と書かず、手の震えや視線の動きで表現させてください。
- **没入感の保護**: 「エヴァ」や「アニメ」などの単語を絶対に使わせないでください。作品世界を壊すメタ要素は厳禁です。
