# Metaphor Reference — battousai（濁刃）

> 著者の実作品（第1〜4話）から抽出した比喩パターン集。
> Writer/Editor は新しい比喩を設計する際、素材圏と構造の手触りをここから参照する。

## 第3層（構造比喩）— 全話に通底するもの

### 鉄の匂い = 侵食
- 「鉄錆のような何かが滲んでいる」（1話: 初出、錯覚かもしれない段階）
- 「消える時間が長くなっている」（1話: 侵食の進行を時間で計測）
- 「湯気の中に、鉄錆が混じった」（1話: 食事という日常の侵食）
- 「舌の上に鉄の膜が張っているような」（1話: 味覚の喪失）
- 「鉄の匂いと白梅の残り香が重なって——鉄だけが残った」（2話: 鉄が白梅に勝つ）
- 「袖口の白梅の残り香が鉄気にゆっくり沈んでいく」（4話: 沈没イメージ）

**進行**: 錯覚 → 蓄積 → 日常侵食 → 味覚喪失 → 他の匂いに勝つ → 他の匂いを沈める

### 白梅 = 記憶 / 喪失
- 「和紙に染み込み、巴の指に移り、着物の懐に移り、巴自身の匂いの一部になっていた」（3話: 記憶が身体化する）
- 「血の匂いを突き破るようにして、甘く清冽な香りが鼻腔を洗った」（3話: 戦闘動詞で香りを描写）
- 「甘さの底を鉄が掻き、鉄の膜を白梅が突き破り、破れた端からまた鉄が滲む」（3話: 二つの匂いの戦争）
- 「白梅だけが、ここではないどこかの記憶を運んでいた」（3話: 香りが空間の運搬者）

## 第2層（人物比喩）— キャラクター間の鏡像

### 手の震え
| キャラ | 文脈 | 意味 |
|---|---|---|
| 抜刀斎 | 「震えは腕を伝って肩に届き…鳩尾の奥から脊椎を駆け上がり」（2話） | 剣の美しさへの戦慄 / 渇望 |
| 巴 | 「指が震えていることに気づいた。あの男の手と同じだ——思ってから、その比較を自分の中で潰した」（3話） | 恐怖 + 無意識の共感 |

### 拭う動作
| キャラ | 対象 | 意味 |
|---|---|---|
| 抜刀斎 | 「拭う必要のない刀を、拭っていた」（1話） | 強迫的反復。拭いても消えない「何か」 |
| 巴 | 「膳を拭き始めた。木目に沿って」（4話） | 暮らしの手順。だが仇の膳を拭いている |

### 手が知っている / 手が迷う
| 文脈 | 引用 |
|---|---|
| 抜刀斎×刀 | 「指は柄に吸いつくように嵌まり、力を入れる必要すらない」（4話） |
| 抜刀斎×斧 | 「手がどこを握ればいいのか迷う。人の骨を断てる手が、薪一本割れない」（4話） |
| 巴×台所 | 「手が勝手に動く。薪を割る男の手とは逆だ」（4話） |

### 沈黙の質
| 文脈 | 引用 |
|---|---|
| 一人の沈黙 | 「空洞だった。自分の呼吸と老婆の咳だけが満たす、薄い沈黙」（4話） |
| 二人の沈黙 | 「音がある沈黙だった。温度がある沈黙だった」（4話） |

## 第1層（表面比喩）— シーン単位の一発

### 感覚越境型
- 「何かの残響のように鼻の奥にこびりついて」（1話: 匂い→音の語彙）
- 「血の匂いが、雨の匂いを塗り潰していた」（1話: 匂い→絵画の動詞）
- 「鉄の気配が消えるまでに三十歩を要した」（3話: 匂い→距離の単位）

### 物質比喩型
- 「信頼という名の縄は、ほどこうとすれば締まる種類のものだった」（2話: 抽象→具体。桂の「君でなければ」の重さ）
- 「夕餉の記憶は琥珀の中の虫のように固まっている。温かいが、動かない。触れられない」（3話: 記憶→琥珀。三拍で展開）
- 「戦闘終了の句読点」（1話: 鍔鳴り→文法。短い暗喩）

### 否定形型
- 「怪物は手を震わせない」（3話: 否定で巴の世界観に罅を入れる）
- 「何も残さない剣」（2話: 灰堂の定義。不在が存在を作る）
- 「人を三人斬ったことなど、この川は知らない」（1話: 自然の無関心＝絶対的孤独）

### メタテクスト型
- 「『怪物を探している』という一文の中に、小さな罅が入った」（3話: 思考→テクスト→物質的損傷）
- 「慣れない外国語を読み上げるような」（4話: 日常語の異物化。殺人者にとっての「ごちそうさま」）
