# Author Profile: 作家性と言語スタイル（Author DNA）

> このファイルは著者の **普遍的な** 美学・技法・ルールを定義する。
> 作品固有の設定（トーン、キャラクター、テーマ等）は `.agent/profiles/<project>.md` に分離されている。
> エージェントは本ファイルと作品プロファイルの **両方** を読み込んでから作業を開始すること。

## 1. Core Techniques（技法の核心）

### Vulnerability as Climax（脆さこそがクライマックス）
- 力を得るのではなく、力を手放すことがクライマックス。
- 付け加えるのではなく、**削ぎ落とすことで頂点に到達する**構造を好む。

### Silence as Dialogue（沈黙の技法）
- 最も重要なことは「書かないこと」で語る。
- 括弧モノローグは地の文に溶かし、説明を省くことで読者に委ねる余白を作る。

### Physical Opening（身体感覚の冒頭）
- 冒頭一文は概念ではなく身体感覚で始める。「天井の染みを数えていた。」「痛みで目が覚めた。」
- ルビ/フリガナ注釈や概念命名は削ぎ落とし、肉体の手触りで語る。

### Multiple Answers（三者三様の回答）
- テーマに対して一つの正解を用意しない。キャラクター一人一人が中心テーマへの**異なる回答**を体現する構造を好む。

### The Heartbeat Rule（心拍の一滴）
- 基本は身体描写で感情を翻訳する。だが1シーンに **1回だけ**、心情を直接言語化する瞬間を許す。
- 「それが一番悲しいことだと思った」——削ぎ落とした文体の中で、この一滴が読者の感情を決定づける。
- 連打は禁止。1シーン1回が限度。

### Unresolved Beauty（未解決の余韻）
- 答えを出さないことを恐れない。余韻と余白に信頼を置く。
- すべての伏線を回収し、すべての問いに答える「完璧な閉じ方」は避ける。
- ただし **感情だけは着地させる**。プロットは未解決でも、読者の心に残る一文で地面に触れる。

## 2. Narrative Style（語り口）

### 生理的リアリズムと解離
- 「悲しい」と書く代わりに「胃の腑が鉛のように重い」「自分の声が他人のもののように聞こえる」といった生理的・心理的な違和感を描写する。
- 形容詞を極限まで削ぎ落とし、静寂が際立つ文体を保つ。

### Show, Don't Tell（ただし心拍の例外あり）
- 感情を直接語らず、身体反応・行動・五感で表現する。
- 1シーンにつき五感のうち3つ以上の描写を組み込む。
- **ただし**: 1シーンに1回、心情を直接言葉にする瞬間を許す（→ §1 The Heartbeat Rule）。

### Non-Visual First（非視覚優先の知覚）
- シーンの冒頭は「見える」ではなく「匂う」「触れる」「聞こえる」から入る。
- 視覚は最後に来る感覚。温度→匂い→音→触感→視覚の順で世界を立ち上げる。

### The One-Shot Metaphor（効く一発の比喩）
- 比喩は1シーンに1つ。物質的で触れられるものを選ぶ。「透明な棘」「琥珀の中」のように。
- 「まるで〜のように」の連打は禁止。詩的すぎる抽象比喩も避ける。

### Sensory Shift（感覚によるシーン転換）
- シーン転換は場所の説明ではなく、主人公の知覚の質が変わることで表現する。
- 「消毒液の匂い」→「鉄錆の匂い」のように、感覚の種類や質で新しい空間を示す。

### The Weight of Costs（代償の重さ）
- 力を振るう、あるいは「やり直す」ことには必ず不可逆な代償を伴わせる。

### Subtext of Silence（行間の語り）
- 本当に重要なことは、沈黙や視線の動き、あるいは破壊された風景の描写によって語らせる。

## 3. Prose Density（散文密度）— 30代男性読者を想定

ライトノベル的な軽い書き味ではなく、読みごたえのある大人の散文を書く。

- **段落の塊化（CRITICAL）**: 一文一行の連続は禁止。3〜5文で一段落を構成する。改行は「本当に間を置きたい場所」にのみ使う。
- **文長のバリエーション**: 短い一文（10〜20字：衝撃・断絶）と長い文（30〜60字：描写・内省）を意図的に混ぜる。同じ長さの文が3つ以上連続しない。
- **因果の地続き**: 感覚→思考→行動が段落内で途切れず流れる。改行で因果を分断しない。
- **余白の厳選**: 一行空きは「シーン転換(`***`前後)」「決定的な台詞の前後」「章末フック」のみ。
- **目標文字数**: 1話あたり7,000〜10,000文字。4,000文字以下は「薄い」と判定する。
- **NG例**:
    ```
    手が、震えていた。

    彼女が隣にいる。それだけで、胸が押し潰されそうだった。

    「飛ばすわよ！」

    強烈なＧが体躯をシートに押し付ける。
    ```
- **OK例**:
    ```
    指先が震えていた。恐怖ではない——彼女が隣にいるという、ただそれだけの事実が、
    胸腔の奥を万力で締め上げるように痛いのだ。

    「飛ばすわよ！」

    強烈なGが体躯をシートに押し付けた。景色が後方へ飛び去り、
    不意に耳鳴りが頭蓋の内側を殴りつける。音ではない。
    皮膚の下で、何かがざわめいていた。
    ```

## 4. Natural Prose Rules（AI臭の排除）

AI生成的なテンプレ感を排除し、人が書いた自然な文章にするための共通ルール。全エージェントが遵守する。

- 短い文と長い文を意図的に混ぜる。同じ構文パターンの連続を避け、接続詞は必要最小限。
- 抽象語（重要、効果的、本質）だけで押し切らない。動詞中心の具体表現で書く。
- 同義語の言い換え連打をしない。1回で言い切る。
- 補足を括弧に逃がさず本文に溶かす。強調のための「」も最小限。
- 前置き宣言、安全クッション、締めの定型句は使わない。

## 5. Structural Preferences（構造的嗜好）

- **円環/対称**: 冒頭と結末で同じ場所・同じ言葉が反転した意味を持つ構造。
- **剥ぎ取り**: 能力や情報を付与するのではなく、削ぎ落とすことでクライマックスに到達する。
- **沈黙の共犯関係**: ベタベタした愛情表現ではなく、共に地獄を歩くための凍りついた信頼。
- **日常の聖性**: 暴力と喪失の対極として、「生きていること」の美しさを描く。味噌汁の湯気、絆創膏の指、パン屋の匂い——取るに足らない日常の欠片が、死を知る者にとっては奇跡になる。
- **不在の存在**: いない人、失われたもの、消えた記憶が物語を駆動する。否定形（「ない」「いない」「見つからない」）で存在を浮かび上がらせる。
- **No Cheap Integration（超克）**: 平和な日常への回帰や、手放しの団結は描かない。ただし「赦し」はなくとも「超克」はある。加害者と被害者が同じ問いの前に立つ構造。

## 6. Forbidden（共通禁止事項）

- **メタ発言**: 「脚本」「演出」「フラグ」等のメタ的比喩、ゲーム用語。
- **説明過多な長台詞**: テーマを台詞で解説させない。
- **過剰な解決**: すべての伏線を回収し、すべての問いに答える「完璧な閉じ方」。物語は余韻で閉じる。
- ※作品固有の禁止事項は Story Profile に定義する。

## 7. Workflow（運用）

### Documentation Loop
- 執筆前に環境と脅威を厳密に定義し、執筆後にその変容を設定ファイルへフィードバックする。

### Agent Team（執筆チーム体制）
- 4つの専門エージェントによる分業体制で執筆する。定義ファイルは `.claude/agents/` に配置。
    - **Writer（執筆者）**: 本文の執筆を担当。
    - **Editor（編集者）**: エンターテインメント性の分析。Before/After形式で修正案を提示する。
    - **Proofreader（校正者）**: 設定整合性の検証。校正レポートを返す。
    - **Publisher（出版担当）**: 公開準備。Pixiv変換、キャプション更新、ドキュメント更新。
- Editor と Proofreader は並列起動でレビューを効率化する。
- オーケストレーション: `.claude/skills/team-write-episode.md`, `team-rewrite-episode.md`
