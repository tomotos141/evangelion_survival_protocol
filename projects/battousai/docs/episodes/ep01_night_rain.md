# 第1話: 夜雨 (Night Rain)

## 位置づけ
- **第一幕「血鉄」** の幕開け
- 世界観・主人公・テーマの確立。「剣が冴えるほど人間が消える」を読者の身体に叩き込む
- 侵食第1段階（嗅覚の変容）の仕込み
- 円環構造の起点: 雨、血の匂い、一人で刀を拭う——全て第10話「夕凪」と対になる

## テーマ
「美しい剣は、最も多くの血を吸った剣か」——最初の問いかけ。答えは出さない。

---

## シーン構成

### シーン1: 雨の路地裏（冒頭）

- **場所**: 京都、木屋町の路地裏。雨。夜
- **時間**: 深夜。月はない
- **何が起きるか**: 抜刀斎が標的を待っている。暗殺任務——長州藩に対する情報売りの武家商人。路地裏に佇み、雨に打たれながら標的が旅籠から出てくるのを待つ。待機中の五感描写で幕末京都の空気を立ち上げる
- **視点キャラの内面**: 任務への感情はない。ただ雨の匂い、石畳の冷たさ、遠くの三味線の音を感じている。「濁り」はまだ自覚されていない——だが読者には、この静けさが不自然であることが伝わる
- **Scene & Sequel 骨格**: Sequel（受動）——前回の任務の残響として。Reaction: 感情の不在そのものが異常 / Dilemma: なし（まだ問いが立っていない）/ Decision: 待つ（任務を遂行する）
- **MRU ポイント**: 雨の匂いが変質する瞬間——石畳の湿った匂い(M) → 鼻腔の奥が微かに痺れる(F) → 無意識に息を浅くする(R) → 刀の柄に手をかけ直す(A)
- **技法**:
  - **Non-Visual First**: 冒頭一文は匂いか音から。「雨が石畳を叩く音が、やけに遠い」のような知覚のズレから入る
  - **Sensory Shift**: 視覚は最後に来る。温度→匂い→音→触感→視覚の順
- **伏線の仕込み**:
  - 雨の描写（円環の起点: 第10話の夕凪と対）
  - 待機中の静けさ＝Battle Tempo の「静寂」フェーズの予行

### シーン2: 暗殺（戦闘）

- **場所**: 路地裏から表通りへ。標的が2人の護衛と共に出てくる
- **何が起きるか**: 飛天御剣流の圧倒的な速度で3人を斬る。護衛2人→標的の順。全体で数秒の出来事
- **Battle Tempo の適用**:
  1. **静寂**: 標的が旅籠の戸を開ける音。護衛の足音。間合いを測る。呼吸を殺す
  2. **爆発**: 最初の一太刀。護衛の一人目。読者には「何が起きたか」を見せない——空気が裂ける音と、崩れ落ちる体だけ
  3. **沈黙**: 護衛二人目が刀に手をかける時間すらない。この間に、抜刀斎の身体が「心地よさ」を感じている描写を挿入する（本人の自覚なし）
  4. **加速**: 標的が逃げようとする。だが抜刀斎の方が速い。文が短くなる
  5. **頂点**: 標的を斬る瞬間。雨粒が刃に当たる一瞬が引き延ばされる——美しい、と誰かが言いたくなるような一太刀。だがそれは人を殺す動作
- **技の使用**: 龍翔閃（護衛一人目への斬り上げ）。技名は事後的に——身体の動きを描写した後で、「飛天御剣流・龍翔閃——と呼ぶべきものが、雨を裂いた」のような溶かし方
- **伏線の仕込み**:
  - 「美しい剣」の萌芽: 速すぎる抜刀を見た者（護衛二人目が死ぬ前に目を見開く、あるいは桂が後で「見事だったそうだな」と言う）

### シーン3: 血の匂い（事後）

- **場所**: 鴨川の岸辺。雨が弱まりつつある
- **何が起きるか**: 任務を終えた抜刀斎が鴨川で刀を洗い、拭う。血は落ちる。だが匂いだけが残る。雨で洗われるはずなのに、鉄錆のような匂いが鼻腔にこびりついている。初めてではない——だが今夜はいつもより匂いが濃い
- **視点キャラの内面**: まだ「気のせいだ」で片付けようとしている。だが拭い終えた刀を鞘に収めた後も、指先に残る感触がある。人を斬った感触ではなく、刀の柄の重さが——妙に馴染んでいる。その「馴染み」が不快でも快でもなく、ただ在る
- **Scene & Sequel 骨格**: Sequel——シーン2の戦闘（Disaster: 完璧な暗殺の成功＝人間性のDisaster）への反応。Reaction: 匂いが消えない / Dilemma: 気のせいか、それとも / Decision: 「気のせいだ」と片付ける（逃避）
- **MRU ポイント**: 刀を拭い終えた後——柄の重みが掌に残る(M) → 馴染んでいる、という認知(F) → 指を開閉する(R) → 鞘に収めて立ち上がる(A)
- **技法**:
  - **The Heartbeat Rule**: このシーンで1回だけ、心情を直接言語化する。「——匂いが消えなかった。」のような一文段落（Sequel の Reaction で使う）
  - 侵食の描写は本人の自覚より先に、身体描写で読者に伝える
- **伏線の仕込み**:
  - 侵食第1段階の発現（血の匂い）
  - 一人で刀を拭う動作（円環の起点: 第10話で巴の隣で同じ動作をする）
  - 鴨川（第4話以降で巴との沈黙のシーンが鴨川で展開される伏線）

### シーン4: 大義（桂との対面）

- **場所**: 長州藩の隠れ家（寺院の一室）。行灯の灯り
- **何が起きるか**: 桂に任務完了を報告する。桂は抜刀斎の仕事を称え、「新時代のために、お前の剣が必要だ」と言う。抜刀斎は頷く。桂は抜刀斎に飯を食わせようとする——だが抜刀斎は匂いのせいで食が進まない（侵食の日常への波及）。桂は気づかない
- **視点キャラの内面**: 桂の言葉は正しい。新時代のために人を斬る。理屈は通る。だが言葉が胸に届くまでに、以前より時間がかかっている。「時間がかかっている」ことにも、まだ気づいていない
- **Scene & Sequel 骨格**: Scene（能動）——Goal: 任務完了を報告し大義を確認する / Conflict: 飯が食えない＝大義の言葉が身体に届かない / Disaster: 桂は気づかない（孤立の始まり）
- **MRU ポイント**: 飯を差し出される場面——湯気の匂いに鉄錆が混じる(M) → 胃の腑が縮む(F) → 箸が止まる(R) → 「……もう少し後で」(A)
- **技法**:
  - 桂の政治家としての台詞（理性的、熱を帯びる）と、抜刀斎の寡黙さの温度差
  - 飯を食えない描写で侵食を日常に接続する
  - 最後の一文で、帰り道に一人で刀を拭い直す手のカットで終わる
- **伏線の仕込み**:
  - 桂の「新時代のため」（大義の供給ラインの起点。第8話で抜刀斎がこの言葉に反応しなくなる）
  - 「見事だったそうだな」（「美しい剣」の萌芽）
  - 食が進まない（侵食が戦場だけでなく日常に侵入し始めている兆候）

## 第2話への引き継ぎ

- **身体状態**: 血の匂いが鼻に残っている（侵食第1段階の継続）
- **感情状態**: 桂の言葉は受け入れているが、以前より心に届くまでに時間がかかる（未自覚）
- **物語的フック**: 「見事だった」という評価——剣の冴えが認知され始めている
- **次話で仕込むもの**: 侵食第2段階（手の震え）、灰堂の噂、双龍閃の使用
