# 第2話: 残心 (Zanshin)

## 位置づけ
- **第一幕「血鉄」** の第2話。戦闘中心（戦闘2/日常1の配分の「戦闘」側）
- 侵食第2段階（運動感覚の乱れ）の発現
- 「美しい剣」の自覚——剣が冴えていることを初めて意識し、それが「喜び」に近いことへの恐怖
- 灰堂の存在を噂として初めて導入（第5話への伏線）
- 第1話「夜雨」の引き「四日後に、次の名前が来る」を受ける

## テーマ
「恐怖と歓喜の区別がつかない——手の震えは、何に対する反応なのか」

---

## シーン構成

### シーン1: 名前（任務の受領）

- **場所**: 長州藩の隠れ家（前話と同じ寺院）。早い夜
- **時間**: 第1話の4日後。日が落ちた直後
- **何が起きるか**: 桂から新たな暗殺任務を告げられる。今度の標的は佐幕派の剣術指南役——前回の武家商人とは格が違う。護衛も腕が立つ。桂が「お前でなければ、この任務は果たせない」と言う。この言葉は信頼であり、同時に縛鎖でもある
- **視点キャラの内面**: 4日間、血の匂いは薄れたが消えていない。任務を受けること自体に迷いはない。だが桂の「お前でなければ」という言葉が、以前なら何も感じなかったはずなのに、今夜は妙に重い。なぜ重いのかは、わからない
- **Scene & Sequel 骨格**: Scene（能動）——Goal: 任務の詳細を受け取る / Conflict: 桂の「お前でなければ」が胸に刺さる——信頼なのか、逃げ場を塞いでいるのか / Disaster: 任務を引き受ける＝さらに深く沈む道を選ぶ（本人の自覚なし）
- **MRU ポイント**: 桂の「お前でなければ」(M) → 胸の奥が締まる(F) → 畳の目に視線を落とす(R) → 「……わかった」(A)
- **技法**:
  - **Non-Visual First**: 冒頭は触覚から。4日経っても右手に残る「何かの感触」——掌が柄の鮫皮を覚えている。あるいは掌に薄い膜が張ったような違和感
  - 桂の言葉の「隙間」の描写——第1話では「胸に届くまでに長い隙間がある」だったが、ここでは「言葉自体は届いているのに、何かが引っかかる」という微妙な変化
  - 第1話で匂いに侵された味噌汁との対比：今回は茶を飲める（匂いは薄れている）。だが掌の感触は消えていない——侵食の軸が嗅覚から触覚へ移行する予兆
- **伏線の仕込み**:
  - 桂の「お前でなければ」（大義への依存構造の強化。替えの利かない道具としての固定化）
  - 標的の格上げ（より強い相手を斬る→剣の冴えが際立つ構造）
  - 嗅覚の侵食の残存（第1段階はまだ続いている）

### シーン2: 戦闘（双龍閃）

- **場所**: 祇園の裏手、料亭の裏口に続く路地。月が出ている夜
- **何が起きるか**: 標的（佐幕派の剣術指南役）と護衛3人を相手にする。護衛2人は第1話と同程度だが、1人は剣士——抜刀斎と刃を合わせる者が初めて現れる。だがその剣士ですら、抜刀斎には敵わない。双龍閃で決着をつける。問題は「どれほど容易に勝ったか」——前話より明らかに冴えている自分に気づく
- **Battle Tempo の適用**:
  1. **静寂**: 料亭の裏口。酒宴の音が壁越しに漏れている。標的が出てくるのを待つ。月光が路地の入口を白く照らし、その外は闇。今度は雨がない——視界がある分、匂いが鮮明
  2. **爆発**: 護衛2人をほぼ同時に斬る。第1話と似た展開だが、速い。自分でも驚くほど速い。身体が先行し、意識が追いつかない
  3. **沈黙**: 残った護衛の剣士と対峙する。間合いを測る。ここで初めて「相手の剣」を見る——構えには隙がない。だが抜刀斎の目には、相手の呼吸の底が見えている。「見えてしまう」ことへの一瞬の違和感
  4. **加速**: 護衛の剣士が仕掛けてくる。受ける。弾く。踏み込む。相手も速い——だが遅い。一合、二合。三合目で抜刀斎は確信する——勝てる。勝てるという確信が、胸の奥で光る
  5. **頂点**: 双龍閃。最初の抜刀を囮にし、鞘で相手の腕を打ち、体勢が崩れた瞬間に真の一太刀。二つの衝撃が一瞬のうちに起こる。技の完成度に、抜刀斎自身が驚く。これほど滑らかに、これほど正確に双龍閃を放てたことが、ない
- **技の使用**: 双龍閃（護衛の剣士への決め技）。身体の動きを描写した後に技名を置く。「右手が柄を握り、鯉口を切った。抜刀——だがこれは囮。左手に持った鞘が相手の前腕を打つ。」→ 結果 → 「双龍閃。」
- **伏線の仕込み**:
  - 「冴え」の自覚: 自分の剣が前回より明らかに速く、正確になっていることに気づく
  - 「見えてしまう」: 相手の呼吸の底、動きの癖——全てが「見える」。この能力の伸びが、後の灰堂との対比に繋がる
  - 双龍閃の技術的完成度: 技名が出る最初の「冴え」の証明

### シーン3: 残心（手の震え）

- **場所**: 戦闘後の路地裏。月光が刀身を照らしている
- **何が起きるか**: 標的を含む4人を斬った後、抜刀斎は刀を構えたまま動けない。「残心」——斬った後も構えを崩さない、飛天御剣流の教え。だが今夜の残心は教えのためではない。身体が構えを解くことを拒んでいる。手が刀を離さない。そして——手が震えている。震えが止まるまでの時間が、前回より長い。だがこの震えが恐怖なのか、それとも高揚の余韻なのか、区別がつかなくなっている。鼓動が速い。呼吸が浅い。身体が熱い。それは恐怖の反応と同じだ。だが——恐怖とは違う何かが混じっている
- **視点キャラの内面**: 「美しい剣」を自覚する瞬間。双龍閃が完璧だったこと、4人を斬るのに息一つ乱れなかったこと。それが「良いこと」なのか「悪いこと」なのか、判断がつかない。ただ、手の中に残る剣の軌跡の正確さが——冷たい確信として指先に宿っている
- **Scene & Sequel 骨格**: Sequel——シーン2の戦闘への反応。Reaction: 手が震える。止まらない / Dilemma: この震えは恐怖か高揚か。自分は何を感じているのか / Decision: 「考えるな」——無理に手を開き、刀を鞘に収める。答えを出さない逃避
- **MRU ポイント**: 月光が刀身を白く照らす(M) → 指が痺れるような熱を帯びている(F) → 柄を握る指が開かない(R) → 左手で右手首を掴み、強制的に指を引き剥がす(A)
- **技法**:
  - **The Heartbeat Rule**: このシーンで1回だけ、心情に近い言語化を使う。「——怖いのか、嬉しいのか、わからなかった。」のような一文。ただし「嬉しい」という語は直接使わず、身体感覚で示す
  - 手の震えの描写は「止まらない」のではなく「止まるまでの時間が延びている」——第1話の戦闘後の平静さとの対比で、侵食の進行を示す
  - 残心の構えの中で、月光に照らされた刀身が「美しい」と感じる瞬間——それが恐怖の核心。剣を美しいと感じてしまう自分
- **伏線の仕込み**:
  - 侵食第2段階の発現（手の震えの変質——恐怖の震えが高揚の震えと区別できなくなる）
  - 残心の構え（第9話「灰燼」で灰堂を斬った後、「残心をしなかった」ことで対比される予定）
  - 「美しい」の萌芽: 自分の剣を「美しい」と感じた最初の瞬間（F-001の発展）

### シーン4: 灰堂の影（噂）

- **場所**: 帰路の途中、長州藩の若い志士と合流する。河原か、路地裏の角
- **何が起きるか**: 同志の若い志士から、佐幕派の中に異質な存在がいるという噂を聞く。「仏門に入って還俗した剣客」「完璧で、何も残さない剣」「斬られた者は、斬られたことに気づかない」。名は灰堂。同志は「あの男は危険だ」と桂も言っていたと伝える。だが抜刀斎が反応するのは「完璧」や「危険」ではない——「何も残さない」という言葉。自分の手に残っている「この震え」が、灰堂にはないのだと。その意味を、まだ理解しない
- **視点キャラの内面**: 灰堂の噂は情報として処理する。だが「何も残さない剣」という言葉だけが、帰り道の闇の中で反芻される。自分の手にはまだ震えが残っている。震えが残っているということは——何かが残っているということだ。それが何であるかはわからないが
- **Scene & Sequel 骨格**: Scene（能動）——Goal: 帰路につく、日常に戻る / Conflict: 灰堂の噂が耳に入る——「何も残さない剣」の意味 / Disaster: 自分の手の震えと灰堂の不在が対比され、答えのない問いが残る
- **MRU ポイント**: 「何も残さない剣」という言葉(M) → 指先が冷える——先ほどまでの震えの熱が急に引く(F) → 右手を見る(R) → 拳を握り、懐に押し込む(A)
- **技法**:
  - 同志の語りは断片的に。灰堂を過剰に説明しない。「仏門に入って、出てきた」「何も感じない男らしい」程度
  - 灰堂の噂を聞いた後、最後に抜刀斎が一人で歩く帰路の描写。手の震えは止まっている——だが「止まったこと」が、灰堂の話を聞いた後だと不穏に響く
  - 章末は第1話の「四日後に、次の名前が来る」のような、次話への引きを仕込む。ただし第3話は巴視点なので、第2話の末尾で巴の存在を微かに予感させる——抜刀斎の帰路に、白梅の匂いが一瞬だけ漂う。あるいは、路地の向こうに女の影が一瞬見える
- **伏線の仕込み**:
  - 灰堂の暗示（F-004: 噂としての導入。「佐幕側にいた」「仏門」「還俗」の3語）
  - 「何も残さない剣」vs「手に残る震え」の対比（F-007の発展）
  - 第3話（巴視点）への橋渡し: 巴の存在の微かな暗示
  - 「美しい剣」の問いの残響: 今夜の自分の剣は「美しかった」のか

## 第1話からの引き継ぎ確認

- **嗅覚の侵食（第1段階）**: 4日経って薄れているが消えていない。戦闘で再び濃くなる
- **桂の大義**: 「新時代のため」に加えて「お前でなければ」が追加。依存構造の深化
- **「見事だった」の評価**: 第1話で桂が言った「見事だったそうだな」が、第2話では抜刀斎自身が自覚する段階に
- **刀を拭う動作**: 第2話でも戦闘後に行うが、焦点は「拭う」ではなく「手が離れない」（残心のモチーフへ移行）
