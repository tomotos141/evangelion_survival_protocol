# 第4話: 同居 (Cohabitation)

## 位置づけ
- **第二幕「沈黙」** の開幕。戦闘から日常へ、舞台と文法が変わる転換点
- **交互視点の初回**。抜刀斎と巴が同じ空間を、異なる感覚で語る
- 偽装夫婦としての共同生活の始まり。「剣の外にあるもの」の最初の提示
- 抜刀斎の不器用さ——箸の持ち方、飯の炊き方——が、巴の復讐を揺るがす種子を蒔く
- 食卓の沈黙：第10話「夕凪」の食卓との円環要素（同じ構図、異なる意味）
- 戦闘なし。全4シーン、日常のみ

## テーマ
「一人の沈黙と、二人の沈黙は、同じものではない」

---

## 前話からの引き継ぎ

- 巴は路地裏で「赤い髪の男」が刀を拭う手を震わせるのを目撃した（第3話シーン3）
- 「怪物は手を震わせない」——巴の中で「仇＝怪物」の図式に罅が入った
- 白梅の香りと血の匂いの対比が確立されている
- 抜刀斎の侵食：第1段階（嗅覚）＋第2段階（運動感覚）が継続中
- 巴はまだ「緋村抜刀斎」という名を知らない、あるいは名と顔が一致していない

## 時間経過
- 第3話から **数日〜1週間程度** が経過
- この間に：巴が長州派と接触する経緯があった（本文では詳述せず示唆にとどめる）
- 桂が「人斬りの隠れ蓑」として巴を抜刀斎の傍に配置する判断を下した

## シーン構成

### シーン1: 隠れ蓑（抜刀斎視点）

- **場所**: 長州藩の寄宿先。桂が訪ねてくる。昼
- **何が起きるか**: 桂が抜刀斎に、一人の女性と偽装夫婦として暮らすよう告げる。「お前が家庭を持つのは良い隠れ蓑だ」。抜刀斎にとって「家庭」という言葉は、口の中で転がしても意味が結ばない。従うことに疑問はない——桂の指示は常に大義に基づいている。だが初めて、任務ではないものを命じられた違和感がある
- **視点キャラの内面**: 「隠れ蓑」という言葉の冷たさに気づかない。日常が「道具」として位置づけられる構造を、まだ当然のものとして受け入れている。それ自体が侵食の症状——「日常」の価値を量る感覚が、もう鈍っている
- **Scene & Sequel 骨格**: Sequel——Reaction: 桂の言葉を受け止める。異論はない / Dilemma: 「家庭」が何を意味するのかわからない / Decision: 従う（いつもそうしてきた）
- **MRU ポイント**: 桂の「家庭を持つのは良い隠れ蓑だ」(M) → 胸の内側で何かが引っかかる——が、それに名前がつかない(F) → 「……わかった」と答える(R) → 部屋を見回す。一人分の布団、一人分の湯呑み。もう一人分がここに加わることを想像しようとして、できない(A)
- **技法**:
  - **Non-Visual First**: 冒頭は嗅覚。昨夜の任務の残り香が畳に染みついている。桂が来る前に手を洗った——だが指の間に鉄錆が残っている気がして、もう一度洗った
  - 桂の「君」呼びと、任務を伝える時のわずかな「間」を描く。ためらいがある——だが、ためらいの後に必ず命じる
  - 抜刀斎にとっての「日常」がいかに空虚か——一人分の生活の描写（湯呑み一つ、布団一組、何もない部屋）で示す
- **伏線の仕込み**:
  - F-002（大義の空洞化）: 桂の言葉は前と同じトーンだが、「家庭」を「隠れ蓑」として消費する構造が明示される
  - 「一人分の部屋」の描写——第10話で同じ部屋が「二人分」に変わっていることとの対比
  - 桂が巴について「身元は確かだ」と言う。何がどう確かなのかは語らない

### シーン2: 最初の朝（巴視点）

- **場所**: 抜刀斎が暮らす家。朝。巴が初めてこの家に入る
- **何が起きるか**: 巴が家に来る最初の朝。戸を開けると、中に男がいる——昼の光の中で見る「赤い髪の男」。路地裏で見た血に濡れた姿とは違う。着物は清潔で、血はない。だが若い。巴が予想していたよりも、ずっと若い。少年と言ってもいい年齢。仇はこんな顔をしているのか。巴はその驚きを顔に出さない
- **視点キャラの内面**: 路地裏では月光とシルエットだった男が、朝の光の中で人間の輪郭を持つ。赤い髪、痩せた肩、刀を帯びた腰——だが手は普通の手に見える。あの夜、震えていた手。復讐者として彼を観察する。だが「観察」の中に、すでに第3話で入った罅が広がっている
- **Scene & Sequel 骨格**: Scene——Goal: 仇の男の傍に身を置く（復讐のため）/ Conflict: 男が「怪物」に見えない。若すぎる。人間の顔をしている / Disaster: 男と目が合う。一瞬の沈黙。巴は「よろしくお願いします」と言う。声が自分のものに聞こえない
- **MRU ポイント**: 戸を開けた先に赤い髪が見える(M) → 息を飲む——路地裏の記憶が刺す(F) → 足が一瞬止まる(R) → 表情を殺して敷居を跨ぐ(A)
- **技法**:
  - **Non-Visual First**: 冒頭は触覚。敷居の木が足裏に触れる感触。他人の家に踏み込む感触
  - 巴の五感は「生活者の五感」——部屋の広さ、日当たり、土間の状態、水瓶の位置を無意識に読む
  - 抜刀斎の「若さ」を強調。巴は18歳。抜刀斎は15〜16歳。年上の女性が年下の少年を見ている構図
  - 二人の最初の会話は最小限。「……よろしく」「……ああ」。この二言の間にある沈黙の厚みを描く
- **伏線の仕込み**:
  - F-005（巴の復讐）: 仇の傍に身を置くことに成功。だが「仇の顔」が予想と違う
  - F-006（沈黙の変容）: 最初の沈黙は「探るような沈黙」——互いを測りかねている
  - 「赤い髪」の認識：路地裏の記憶と目の前の男が同一人物であることを巴が確認する瞬間

### シーン3: 不器用な手（抜刀斎視点）

- **場所**: 家の土間と裏庭。午後
- **何が起きるか**: 日常の仕事をする抜刀斎。薪を割る、竈に火をつける、米を研ぐ、飯を炊く。剣を持つ時は完璧に動く手が、斧の柄で滑り、火打ち石で指を打ち、米を水と一緒にこぼす。飯は焦げる。抜刀斎は焦げた飯の匂いを嗅いで——一瞬、別の匂い（焼けた肉、夜の路地）が重なる。その重なりを振り払う
- **視点キャラの内面**: 恥ずかしいとも、情けないとも思わない。ただ「できない」という事実がある。剣を握った時の手と、薪割りの斧を握った時の手が、同じ手とは思えない。日常の道具を持つと、手が途端に不確かになる。それが何を意味するのか——「剣以外のことがわからなくなっている」という事実を、抜刀斎はまだ言語化できない
- **Scene & Sequel 骨格**: Scene——Goal: 日常の仕事をこなす / Conflict: 身体が日常に適応できない。剣のための身体が、生活を拒んでいる / Disaster: 飯を焦がす。焦げた匂いの中に、別の記憶が一瞬重なる
- **MRU ポイント**: 焦げた飯の匂いが鼻を突く(M) → 胃の底が冷たくなる——なぜだかわからない(F) → 手が止まる(R) → 鍋底を見つめる。黒く焦げた米が、何か別のものに見える——目を逸らす(A)
- **技法**:
  - 「手」の描写に集中する。刀の柄を握る時の指の配置と、斧の柄を握る時の指の配置の違い。前者は完璧、後者はぎこちない。同じ手であることの異様さ
  - 焦げた飯の匂い→戦場の記憶の連鎖は、侵食の予兆（第3段階への布石）として機能する。だがこの時点ではまだ一瞬で消える
  - 巴がどこかから見ている気配を、抜刀斎は感じている。だが振り向かない。見られていることへの居心地の悪さ——それが「一人でいた時にはなかった感覚」の最初の芽
  - 「……すまない」と焦げた飯について巴に言う一言が、任務以外で発した最初のまともな言葉
- **伏線の仕込み**:
  - F-007（冴えと恐怖）: 剣の手と日常の手の断絶——「剣以外のことがわからなくなっている」の身体的証拠
  - 箸の持ち方、薪割りの手つき——第6話で巴の揺らぎの起点になる不器用さの初出
  - 焦げた匂いと戦場の記憶の重なり——第7話の触覚の侵食（第3段階）への予兆

### シーン4: 沈黙の食卓（巴視点）

- **場所**: 家の中。夕方〜夜。囲炉裏か卓袱台
- **何が起きるか**: 巴が米を炊き直し、簡素な食事を整える。二人で食卓を囲む。会話はほとんどない。抜刀斎は箸を握る力加減がおかしい——強すぎる。刀を握る力で箸を持っている。巴はそれを見ている。音は箸が器に当たる音と、虫の声だけ。だがその沈黙は、巴が一人で宿にいた時の沈黙とは違う。厚みがある。温度がある。何が違うのかを、巴はまだ言葉にできない
- **視点キャラの内面**: 復讐者としてここにいる。仇の傍で、仇が飯を食う姿を見ている。だが「仇が飯を食う」ということ自体が——人を斬った手で箸を持ち、米を口に運ぶということ自体が、怪物の行為には見えない。怪物は飯を焦がさない。怪物は箸を強く握りすぎたりしない。あの路地裏で震えていた手が、今、箸を不器用に使っている。巴はそれを見ていることが、観察なのか、何か別のものなのか、わからなくなり始めている
- **Scene & Sequel 骨格**: Sequel——Reaction: 食卓の沈黙が、一人の沈黙と違うことに気づく / Dilemma: この男は仇だ。仇の傍で飯を食っている。だが仇の飯の食い方は——人間の食い方だ / Decision: まだ何も決めない。ただここにいる。もう少しだけ、見ている
- **MRU ポイント**: 抜刀斎の箸が器に当たる音(M) → 清里の食べ方が一瞬よぎる——清里は箸の持ち方が綺麗だった(F) → 自分の箸が止まる(R) → 目を伏せて、再び米を口に運ぶ(A)
- **技法**:
  - **音の設計**: このシーンは音で構成する。箸と器の音、咀嚼音、虫の声、炭がはぜる音。会話がないことで、これらの小さな音が異常に大きく響く
  - 白梅の香り：巴の着物から漂う白梅の微かな香り。食卓の上で、味噌汁の湯気と白梅が混じる。抜刀斎がそれに気づくかどうか——気づいたとしても何も言わない
  - 箸の握り方の描写で、抜刀斎の「剣以外のことが下手」を巴の目から描く。清里の箸使いとの対比は一瞬だけ——MRUの中で処理し、長く引っ張らない
  - **The Heartbeat Rule**: このシーンで1回だけ直接的な感覚。「——二人分の沈黙は、重い」のような一文
  - 最後の一行に円環の種を蒔く。食卓を片付ける時の所作、あるいは巴が布巾で器を拭う手——第10話の同じ動作との対比
