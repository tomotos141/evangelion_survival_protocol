# 第3話: 白梅 (White Plum)

## 位置づけ
- **第一幕「血鉄」** の最終話。戦闘中心の世界に、日常と復讐者の視点が差し込まれる
- **巴視点の初登場**。1〜2話の抜刀斎視点から一転、彼を「外から見る」
- 巴の復讐動機（清里明良の仇）の確立
- 抜刀斎の侵食（第1〜2段階）を外部視点で描写——本人が気づいていない変化を読者に示す
- 白梅の香りの導入：血の匂いとの対比、第10話への円環要素
- 第2話末尾の「白梅の残り香」「衣擦れにも似た気配」を受ける

## テーマ
「仇の男は、血に濡れた手を震わせていた——その震えが、復讐者の足を止めた」

## シーン構成

### シーン1: 血の都（巴の京都）

- **場所**: 京都の市中。三条あたりの通り。昼〜夕方
- **時間**: 第2話の翌日か翌々日。巴が京都に来て数日が経っている
- **何が起きるか**: 巴の目を通した幕末の京都を描く。武家の娘が一人で歩く都市。刀を帯びた男たちが角を曲がるたびに目に入る。通りの辻には張り紙があり、どこかで誰かが斬られた話が聞こえてくる。巴にとって京都は「血と政治の都市」であり、生活者としてそこに身を置いている自分自身の異質さを感じている
- **視点キャラの内面**: 巴は目的を持ってここにいる。清里を斬った男を探している。だがこの都市では、人を斬った男の名は星の数ほどあり、「緋村抜刀斎」という名はまだ巴の耳に届いていない——あるいは届いても、どの噂が仇の男なのか判別がつかない。焦りはない。沈黙の奥に目的を沈め、日々を過ごしている
- **Scene & Sequel 骨格**: Scene（能動）——Goal: 仇の手がかりを探す（日常の延長として）/ Conflict: 京都に溢れる暴力の噂の中で、一人の男を特定できない / Disaster: 手がかりのないまま日が暮れる
- **MRU ポイント**: 辻で「人斬り」の噂話が聞こえる(M) → 指先が冷える(F) → 足が止まる(R) → 聞こえないふりをして歩き続ける(A)
- **技法**:
  - **Non-Visual First**: 冒頭は嗅覚から。「血の匂いがした——と思ったが、魚屋の前だった」のような誤認から入る。京都の「血の匂い」は巴の内面が投影したもの
  - 巴の五感は抜刀斎と質が違う。抜刀斎は戦闘者の五感（脅威を感知する精密機械）。巴は生活者の五感（人の声、食べ物の匂い、布の手触り）。同じ京都を全く異なる感覚で描く
  - この時点の巴の沈黙は「感情を隠すための沈黙」——周囲に対して壁を張っている
- **伏線の仕込み**:
  - 巴が京都の「血の匂い」を嗅ぎ取る感覚——後の抜刀斎の侵食描写（鼻腔の奥の鉄錆）との対比
  - 白梅の香り：巴が懐に入れている文（清里からの最後の手紙）を包んでいた白梅の花びら。その香りが巴自身に染みついている——巴が「白梅の女」であることの最初の提示
  - 「人斬り」の噂の中に「飛天」「影」等の断片。まだ繋がらない

### シーン2: 清里の面影

- **場所**: 巴が身を寄せている宿（下宿のような場所）。夜。行灯の光
- **何が起きるか**: 一人になった巴が、清里を思い出す。短い回想——清里がどんな人間だったかを、物ではなく行為の記憶で描く。清里の手が温かかったこと。笑い方が少しぎこちなかったこと。巴に白梅の枝を折ってきてくれたこと。清里は剣士だったが、強くはなかった。だがその不器用な強さの中に、巴は「日常」を見ていた
- **視点キャラの内面**: 清里の記憶は復讐の燃料だ。だが巴はその記憶を「燃やす」のではなく「抱えている」。まだ温かい。まだ痛い。この痛みを手放すことは、清里を二度殺すことだと思っている。だから手放さない。痛みごと抱えて、仇の男を探している
- **Scene & Sequel 骨格**: Sequel（受動）——Reaction: 清里の記憶が鮮明に蘇る / Dilemma: 記憶を抱えている限り復讐は正当だが、記憶は時間とともに薄れる。薄れることへの恐怖 / Decision: 明日も探す。見つけるまで、この痛みを手放さない
- **MRU ポイント**: 懐から取り出した文に残る白梅の香り(M) → 胸の奥が軋む(F) → 文を両手で包むように持つ(R) → 目を閉じて、清里の顔を思い描く(A)
- **技法**:
  - 回想は長く取らない。具体的な行為の記憶を2〜3個だけ。「清里は〜な人だった」の説明ではなく、「清里の手が白梅の枝を折る時の、指の力加減」のような身体的な記憶
  - 巴の感情は直接書かない。文を持つ手の力、呼吸の深さ、視線の落ちる場所で描く
  - **The Heartbeat Rule**: このシーンで1回、直接的な感情表現を使う。「——まだ、温かい」のような一文。清里の記憶が生きていることへの実感
- **伏線の仕込み**:
  - 清里の「不器用な優しさ」——後に抜刀斎の「不器用さ」（箸を落とす、飯を焦がす）との無意識な重なりが、巴の復讐を揺るがす原点になる
  - 白梅の枝を折ってきてくれた記憶——白梅の香りが「清里との記憶」に結びついていることの確立
  - 清里は強い剣士ではなかった——だからこそ、飛天御剣流の圧倒的な速度で斬られた。強さの非対称が復讐の痛みを深める

### シーン3: 目撃（血に濡れた男）

- **場所**: 夜の京都。路地裏の交差点。巴は偶然その場に居合わせる
- **時間**: 深夜。月が出ている（第2話の戦闘と同夜、あるいは別の任務の夜）
- **何が起きるか**: 巴が夜道を歩いている時、路地裏から男が現れる。着物に血が線を引いている。腰に刀。返り血に濡れた姿が月光に浮かぶ。巴は恐怖で足が止まる——だが男は巴に気づかない。男は路地の壁に背を預け、刀を鞘から抜き、布で拭い始める。その動作は丁寧で、手馴れていて——だが手が、震えていた
- **視点キャラの内面**: 恐怖。純粋な、生物としての恐怖。この男は今、誰かを斬ってきた。血の匂いが風に乗って届く。だが巴の目は恐怖の中で、手の震えに釘付けになる。人を斬った男が、刀を拭う手を震わせている。なぜ震えているのか。殺した男の重みか。恐怖か。——それとも。巴にはわからない。だがその震えが、「人殺しの化け物」ではなく「何かを抱えた人間」に見えた瞬間、復讐者としての視線に罅が入る
- **Scene & Sequel 骨格**: Scene（能動）——Goal: 帰路を急ぐ（宿へ戻る）/ Conflict: 血に濡れた男が路地裏にいる / Disaster: 男の手の震えを見てしまう——「人斬り」を「人間」として見てしまった
- **MRU ポイント**: 路地の闇から血の匂いが流れてくる(M) → 胃の底が冷たくなる(F) → 足が石畳に縫い止められたように動かない(R) → 壁の影に身を寄せて息を殺す(A)
- **技法**:
  - 抜刀斎の顔は見せない。月光の逆光で顔は闇に沈み、見えるのはシルエットと手元だけ。「赤い髪」だけが見える——だがこの時点で巴は「抜刀斎」という名を知らない
  - 手の震えの描写を丁寧に。第2話のシーン3で抜刀斎自身が感じた震えを、今度は外部視点で描く。内側から描いた震えと、外から見た震えの質感の差
  - 巴がこの男を「仇かもしれない」とまだ特定していないことが重要。人を斬る男を見た。手が震えていた。それだけ。だがこの「引っかかり」が全ての始まり
  - 声は聞かない。名前も知らない。ただ、血に濡れた男の手の震えだけが、記憶に残る
- **伏線の仕込み**:
  - 「赤い髪の男」——巴がまだ名前を知らない抜刀斎の最初の視覚的記憶
  - 手の震えの外部観測——F-010（侵食第2段階）の外部確認。読者は第2話で震えの正体（恐怖と歓喜の混合）を知っているが、巴にとっては「何かを抱えている」証拠
  - 「人殺しの手が震えている」——巴の復讐心に最初の罅を入れる場面（F-005の最初の兆候）
  - 巴がこの場面で逃げずに見続けた——復讐者としての冷静さか、それとも別の何かか

### シーン4: 白梅（香りの残響）

- **場所**: 巴の宿。深夜
- **何が起きるか**: 宿に戻った巴は、着物に染みついた血の匂いに気づく。自分は何もしていないのに、あの路地の空気が着物に移っていた。水で手を洗い、顔を拭く。懐から文を取り出す。白梅の香りが、血の匂いの下から浮かんでくる。清里の——いや、自分自身の匂い。白梅は巴の匂いだ。京都に来てから、血と煙と政治の匂いに埋もれていたが、まだ消えていなかった
- **視点キャラの内面**: あの男の手が震えていた。清里を斬ったのは、あの男だろうか。わからない。京都には人を斬る男が何人もいる。だがもしあの男が仇だとしたら——手の震えは何なのだ。復讐者が仇に求めるのは、怪物であることだ。怪物であれば斬れる。だが怪物の手は、震えない。巴はその矛盾を言葉にしない。ただ白梅の香りを吸い込み、文を懐に戻す
- **Scene & Sequel 骨格**: Sequel（受動）——Reaction: 血の匂いが着物に染みている。恐怖の余韻 / Dilemma: あの男は仇なのか。仇だとして、手の震えは何を意味するのか / Decision: 答えは出さない。ただ白梅の文を懐に戻し、目を閉じる——探し続ける。だが「何を」探しているのか、問いの形が少しだけ変わっている
- **MRU ポイント**: 着物の袖から血の匂いがする(M) → 喉の奥が詰まる(F) → 袖を鼻に寄せて確かめてしまう(R) → 水を汲んで手と顔を洗う(A)
- **技法**:
  - 白梅の香りと血の匂いの対比が、物理的に巴の嗅覚の中で起きる。血の匂い → 白梅の香り → 血の匂いが再び。嗅覚の中で二つが交互に現れるが、最終的に白梅が残る——巴がまだ「剣の外」にいることの証拠
  - 章末は巴の沈黙で閉じる。言葉にしない。ただ、文を握る手の力加減が、シーン2とは微妙に違う——シーン2では「清里の記憶にしがみつく」力だったが、ここでは「何かを確認する」力に変わっている
  - 次話（第4話「同居」）への橋渡し: 巴が「赤い髪の男」をもう一度見ることになる、という予感を残す。ただし直接的な予告はしない
- **伏線の仕込み**:
  - 白梅の香り vs 血の匂い——F-003（濁りの受容）の巴側の起点。二つの匂いが巴の中で共存し始める
  - 文を握る手の力の変化——F-006（沈黙の変容）の最初の兆候。まだ「感情を隠す沈黙」の段階だが、問いの形が変わっている
  - 「怪物であれば斬れる。だが怪物の手は、震えない」——復讐の構造に入った最初の亀裂（F-005）

## 第2話からの引き継ぎ確認

- **抜刀斎の身体状態**: 侵食第1段階（嗅覚）継続 + 第2段階（手の震え）発現済み。巴が目撃するのは第2段階の震え
- **第2話の末尾**: 白梅の残り香、路地の奥の気配——巴がそこにいた可能性を示唆。第3話でこれが巴の視点から裏打ちされる
- **時系列**: 第2話の戦闘と同夜（シーン3で目撃）、あるいは近い別の夜。いずれにせよ第2話の直後の時間帯
- **灰堂の噂**: 第3話では灰堂には触れない（巴の世界にまだ灰堂は存在しない）
