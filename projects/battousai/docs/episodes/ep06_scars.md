# 第6話: 傷痕 (Scars)

## 位置づけ
- **第二幕「沈黙」** の日常回（戦闘1/日常3の「日常」）
- **巴単独視点**。第3話「白梅」以来の巴視点回
- 復讐の動機の揺らぎ——「仇の男が人殺し以外の顔を見せる」ことで復讐の純度が濁り始める
- 清里の記憶が「鮮明でなくなっていく」ことへの恐怖と罪悪感
- 沈黙の変容: 「感情を隠す沈黙」→「言葉にできない共感の沈黙」への移行が起きる
- **巴の内面を直接語らない**（Story Profile §6 準拠）。行動・知覚・沈黙の質で描く

## テーマ
「傷痕が薄れていくことは、傷を忘れることなのか——それとも、傷の上に別の何かが重なっていくことなのか」

---

## 前話からの引き継ぎ

- 第5話で灰堂と遭遇した抜刀斎が、普段と違う様子で帰ってきた。箸を握りすぎる手で冷めた飯を食べ、刀の手入れをしなかった（いつもの手順から逸脱）
- 巴は奥の部屋から、帰還の足音を聞いている。起きていたのか寝ていたのかは不明のまま（5話末尾）
- 共同生活にリズムが生まれている: 巴が飯を炊き、抜刀斎が薪を割る。それぞれの手順
- 巴は仇の顔を朝の光で見ている（第4話）。若い。少年と言っていい年齢
- 侵食: 第1段階（嗅覚）＋第2段階（運動感覚）が継続。巴の目には「表情の硬化、反応の遅れ」として映る
- 抜刀斎の着物に白梅の残り香が移り始めている（第5話シーン1で匂いとして検知）

## 時間経過
- 第5話から **数日〜1週間**
- この間に: 抜刀斎は暗殺任務に出ていない（灰堂との邂逅の後遺が残っている、あるいは桂からの次の指令待ち）
- 二人の共同生活に「日常」が堆積し始めている

## シーン構成

### シーン1: 清里の傷痕（巴視点）

- **場所**: 家の中。早朝。巴が一人で起きている
- **何が起きるか**: 巴が懐の文（清里からの手紙、あるいは清里の遺品）に触れる。清里を思い出そうとする。竹刀を握る手、汗ばんだ掌、枝を折る癖——第3話で描いた記憶の断片を再び辿る。だが、記憶の輪郭が以前ほど鮮明ではない。清里の顔を思い浮かべようとして、別の顔——赤い髪の男の、箸を握りすぎて白くなった指——が割り込んでくる
- **視点キャラの内面（行動と知覚で描く）**: 文を懐に戻す手が、前より早い。以前は文を出して長く触れていた。今は触れて、すぐに戻す。その差異を巴は意識しない——だが読者には見える
- **Scene & Sequel 骨格**: Sequel——Reaction: 清里の記憶を確認する朝の習慣。文に触れる / Dilemma: 記憶の輪郭が薄れている。それは裏切りなのか / Decision: 文を懐に戻す。飯を炊く準備に立つ
- **MRU ポイント**:
  - 文の紙の質感が指に触れる。以前より紙が柔らかくなっている——何度も触れたから(M) → 指が止まる。清里の手を思い出そうとする(F) → 指を離す。文を懐に戻す(R) → 竈に向かう。火を起こす(A)
- **技法**:
  - **Non-Visual First**: 触覚から始める。文の紙の質感。手触りが変わってきたこと
  - 清里の記憶は「鮮明さの欠落」で描く。具体的なディテール（手の温度、声の高さ）が一つずつ「思い出せない」ことで、記憶の薄れを表現
  - 割り込む別の記憶（抜刀斎の手）は、巴の意識として描かない。単に「指が白くなるほど箸を握る男の手」が浮かぶ——誰の手とは書かない
  - 文を戻す動作の「速さ」の変化で、巴の内面の変化を間接的に見せる
- **伏線の仕込み**:
  - F-005（巴の復讐）: 清里の記憶の薄れ＝復讐の純度の低下
  - 文に触れる習慣——反復動作の第2回目。第3話では長く触れた。今回は短い

### シーン2: 不器用さ（巴視点）

- **場所**: 家の中と家の周囲。日中
- **何が起きるか**: 抜刀斎の日常の不器用さを、巴が間近で見る。薪割りで斧が滑る。魚を焼くのに手間取る。あるいは、箸を落とす。人を斬ることには天才的な男が、生活の動作の全てで不器用。だがその不器用さの中に、第5話にはなかった何かがある——灰堂と出会った後の抜刀斎は、普段より長く手を見つめる。箸を落とした後、すぐに拾わない。自分の手を見ている。何を考えているのかはわからないが、「人殺し」の顔とは違う表情がそこにある
- **視点キャラの内面（行動と知覚で描く）**: 巴は抜刀斎が箸を落とした時、黙って予備の箸を差し出す。そのとき、指先が触れるか触れないかの距離。巴の手が引っ込む速度が、以前より遅い
- **Scene & Sequel 骨格**: Scene——Goal: 仇の男を観察する（復讐者の目的） / Conflict: 観察するほど「人殺し以外の顔」が見えてしまう / Disaster（小）: 箸を渡す時の手の距離に、自分の動揺が出ている
- **MRU ポイント**:
  - 斧が丸太の節に弾かれて、抜刀斎の手から滑る。乾いた音(M) → 巴の視線が男の手に止まる。あの手は人を——いや。ここでは薪を割れない手だ(F) → 視線を外す。竈に向き直る(R) → 火吹き竹で炭を吹く。頬に熱が当たる(A)
- **技法**:
  - 「仇」として見る目と、「同居人」として見る目の混在を、行動の食い違いで描く
  - 抜刀斎の手の描写を反復するが、第4話（箸を握りすぎる）、第5話（灰堂の前で震えが止まる）との差異を出す——ここでは「手を見つめている」「箸を落とした後、すぐに拾わない」という新しい行動
  - 灰堂のことは巴の視点から直接描かない（巴は灰堂を知らない）。ただ「あの夜から、この男は何かが違う」という変化を知覚として描く
  - 巴の手が引く速度の「遅さ」で揺らぎを表現。直接言語化しない
- **伏線の仕込み**:
  - F-005（復讐の揺らぎ）: 仇の男の不器用さに動揺する
  - F-010（運動感覚の乱れ）: 巴の目を通した外部視点の侵食描写。抜刀斎が手を長く見つめることを捉える
  - 「箸を渡す」動作——第7話で交差する二人の濁りの布石

### シーン3: 復讐と日常の境界（巴視点）

- **場所**: 家の中。台所。午後
- **何が起きるか**: 巴が飯の支度をしている。いつから二人分の飯を当たり前に炊くようになったのか。復讐者として仇の傍にいるはずなのに、大根を剥き、味噌を溶いている。その手順は、清里との暮らしで覚えたもの——清里の母に教わった味噌汁の塩加減。仇の男に、清里の記憶で作った飯を出している。その矛盾に気づく瞬間。だが気づいても手は止まらない。飯を炊く手が止められない。偽装なのか本心なのか、自分でもわからなくなっている
- **視点キャラの内面（行動と知覚で描く）**: 味噌汁の味見をした時、手が止まる。長い停止。それから再び椀に味噌を足す。何を考えたのかは書かない。ただ、味噌を足す量が前より多い——「あの男」の好みに寄せている？　いや、塩が足りなかっただけかもしれない
- **Scene & Sequel 骨格**: Sequel——Reaction: 飯を炊いている。仇の男の分を / Dilemma: この手順は清里の母に教わったもの。仇に出す飯に、清里の記憶が使われている / Decision: 味噌を足す。手は止まらない
- **MRU ポイント**:
  - 味噌汁の湯気が顔に触れる。この匂いを知っている——清里の家の台所(M) → 手が止まる。杓子を持ったまま動かない(F) → 目を閉じる。開ける(R) → 味噌を足す。椀を膳に置く。二つ(A)
- **技法**:
  - **嗅覚軸**: 味噌汁の匂い＝清里の家の記憶。仇の男に出す飯が、清里の記憶で作られているという矛盾を、匂いの重なりで描く
  - 「二つ」の膳を並べる動作で、「二人分の暮らし」が復讐の外に出ていることを暗示
  - 清里の母に教わった味噌汁——具体的なディテール（大根の厚さ、味噌の量）で生活の記憶を立ち上げる
  - 巴の手が「止まらない」ことで、復讐と日常の境界が溶けていることを行動で見せる
  - 味噌を「足す」動作は、巴が抜刀斎の好みを無意識に学んでいることの暗示——だが「塩が足りなかっただけかもしれない」と曖昧にする
- **伏線の仕込み**:
  - F-005（復讐の揺らぎ）: 復讐者の手が、仇の飯を作っている矛盾
  - F-006（沈黙の変容）: 日常の所作が「偽装」から「習慣」へ移行し始めている
  - 味噌汁——円環要素。最終話の食卓との対比の布石

### シーン4: 沈黙の質の変化（巴視点）

- **場所**: 家の中。夜。抜刀斎が任務から帰ってくる
- **何が起きるか**: 抜刀斎が任務から帰る。血の匂いがする。巴は手拭いを差し出す。言葉はない。だがこの沈黙は、第4話の「探るような沈黙」とは質が違う。巴は「仇が帰ってきた」と思っているのか、「あの男が帰ってきた」と思っているのか。手拭いを差し出す動作に、復讐者の冷たさがあるのか、それとも——。抜刀斎は手拭いを受け取る。血の匂いが手拭いに移る。巴はその手拭いを後で洗うだろう。仇の血を洗う。清里の仇の血を
- **視点キャラの内面（行動と知覚で描く）**: 手拭いを差し出す巴の手。差し出す前に、一瞬だけ手拭いを自分の胸に押し当てている——白梅の香りを移すように。意識的な動作なのか無意識なのかは書かない。抜刀斎がそれを受け取った後、巴は膳を出す。いつもの手順。だが今夜は、膳を出した後に巴がその場に座る。いつもは奥の部屋に戻る。今夜は——座ったまま、何もしない
- **Scene & Sequel 骨格**: Scene——Goal: 帰還した男に手拭いを渡す。日常の手順 / Conflict: 手拭いに白梅の香りを移す動作。それは「復讐者」の行為ではない / Disaster（微小）: 膳を出した後、奥に戻らない自分。座ったまま、この男と同じ部屋にいる
- **MRU ポイント**:
  - 戸が引かれる音。足音が土間に落ちる。重い。疲れている(M) → 巴の手が手拭いを取る。差し出す前に、一瞬胸に押し当てる(F/R) → 立ち上がり、土間の男の方へ歩く(A)
  - 抜刀斎が手拭いで手を拭った後の、布に染みた鉄の匂い(M) → 巴の指先が、返された手拭いを受け取る時に硬くなる(F) → 手拭いを畳む。きちんと。角を合わせて(R) → 膳を出す。いつもの手順。だが今夜は座る(A)
- **技法**:
  - **嗅覚の二重構造**: 白梅の香り（巴の手拭い）と血の匂い（抜刀斎の手）の交差。手拭いに両方の匂いが重なる
  - 巴が「座る」ことの異常さ。これまでの手順からの逸脱。なぜ座ったのかは書かない。ただ座っている
  - 抜刀斎の反応も最小限: 巴が座っていることに気づく。だが何も言わない。飯を食い始める
  - **沈黙の質の描写**: 第4話S4の「二人分の沈黙」との差異。第4話は「箸と器の音に満ちた沈黙」だった。今回は——巴が何も食べていない。ただ座っている。飯を食う音だけがする。その不均衡な沈黙が、「感情を隠す沈黙」でも「探る沈黙」でもない新しい質を持つ
  - 最終行: 抜刀斎が食い終わる。箸を置く。二人の間に、何も起きない。何も起きないことが、この夜の全てだった
- **伏線の仕込み**:
  - F-006（沈黙の変容）: 「言葉にできない共感の沈黙」への転換点
  - F-008（円環: 刀を拭う）: 抜刀斎は飯の後に刀を拭うか？ 第5話では拭わなかった。今夜は？——巴がいる前で刀を拭う。巴がそれを見ている。仇の刀を見る目に、恐怖でも憎悪でもない何かが混じり始めている
  - F-009（嗅覚）: 白梅と血の匂いの交差——手拭いの上で二つの匂いが混ざる

## 比喩設計（metaphor_craft 準拠）

### 第3層（構造比喩）
- **記憶の質感**: 文の紙の柔らかさ＝記憶が手に馴染む＝輪郭が丸くなる。「鮮明さの減衰」を物理的な質感で表現
- **二つの膳**: 一つの膳（復讐者の孤独）→二つの膳（日常の共犯）。膳の数が関係性のバロメーター

### 第2層（鏡像比喩）
- **清里の手 vs 抜刀斎の手**: 竹刀を握る穏やかな手/箸を握りすぎる荒い手。同じ「男の手」だが質が正反対。巴の視界に、二つの手が重なったり離れたりする
- **味噌汁の味**: 清里の母に教わった味＝清里の記憶を仇に出す矛盾。匂いと味が記憶と現在をつなぐ

### 第1層（表面比喩）
- シーン1: 触覚（文の紙の質感、指先の感覚）
- シーン2: 視覚×触覚（斧が滑る音、箸を渡す距離）
- シーン3: 嗅覚（味噌汁の湯気、清里の台所の記憶）
- シーン4: 嗅覚の交差（白梅×鉄錆が手拭いの上で出会う）

### スケール反復の進行
| 比喩素材 | 前話まで | 本話 |
|---|---|---|
| 白梅の香り | 巴の記憶の核/着物への残り香 | 手拭いに意図的（？）に移す——白梅が能動的に鉄錆に向かう |
| 手の震え/握りすぎ | 灰堂の前で止まる→帰宅後に再発 | 巴の外部視点: 箸を落とす→手を見つめる（灰堂後の新行動） |
| 鉄の匂い | 場所ごとの層（血→水→線香→飯） | 手拭いの上で白梅と混ざる（両方の匂いが同じ布にある） |
| 文（清里の遺品） | 第3話で初登場。長く触れた | 触れる時間が短くなっている |
| 味噌汁 | 第4話で焦がした飯/第5話で冷めた飯 | 清里の母の味。仇に出す飯が清里の記憶で作られている |
