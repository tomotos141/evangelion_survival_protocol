# 飛天御剣流・剣術設定

> 速度は「見えない」で描く。読者に技の全容を見せない。
> 音、空気の切れ目、結果で速度を表現する。

---

## 1. 飛天御剣流の描写原則

### 速度の表現
- 技の軌道そのものを描写しない。「見えなかった」が最高の速度表現
- 振りかぶる動作を描いた次の文で、もう相手が倒れている
- 間を飛ばす。読者の認知にも「見えない」を体験させる
- 空気が裂ける音、衝撃波で揺れる炎、血飛沫が壁に届く——結果だけが速度を証言する

### 音の設計
- **抜刀**: 鍔鳴り → 鯉口を切る金属音 → 空気を裂く鋭い音。この三段階が0.5秒以内に起こる
- **斬撃**: 刃が空を切る風切り音。肉を断つ湿った音は書かない——速すぎて音が遅れてくる
- **納刀**: 鍔が鞘口に収まる「かちり」。この音が戦闘終了の句読点
- **着地**: 草鞋が地面を踏む音。飛天御剣流は跳躍を多用するため、着地音が戦闘のリズムを刻む

### 結果の描写
- 斬られた側は、斬られたことに気づかない。一拍遅れて膝が折れ、血が溢れる
- 返り血は抜刀斎の着物に線を引く。その線の角度で、どういう軌道だったかを読者が逆算する
- 周囲の反応で速度を測る。篝火の炎が一瞬遅れて揺れる。水溜まりに波紋が広がる

## 2. 本作で使用する技

### 龍翔閃（りゅうしょうせん）

下方から上方への斬り上げ。身体ごと跳躍する対空技。

- **身体描写**: 膝を深く沈めた瞬間、地面を蹴る脚の筋肉が悲鳴を上げる。身体が弾丸のように浮き上がる。刀は下から上へ——地面から天を裂くように走る
- **何が見えるか**: 相手の視界では、抜刀斎が沈んだ次の瞬間にはもう頭上にいる。視野の外から刃が来る
- **何が聞こえるか**: 地面を蹴る衝撃音。風を切る音が下から上に駆け上がる。そして着地の重い音
- **使用場面**: 第1話の暗殺シーン（開幕の戦闘で飛天御剣流の圧倒的な身体能力を見せる）

### 双龍閃（そうりゅうせん）

抜刀術の二段構え。最初の抜刀を囮にし、鞘での打撃を挟み、真の斬撃を叩き込む。

- **身体描写**: 右手が柄を握り、鯉口を切る。抜刀——だがこれは囮。左手に持った鞘が相手の腕を打つ。体勢が崩れた瞬間に、真の一太刀
- **何が見えるか**: 最初の抜刀に意識を取られた瞬間、視界の端から鞘が飛んでくる。そこで意識が途切れる。気づいた時には斬られている
- **何が聞こえるか**: 二つの音が重なる。鞘が骨を打つ鈍い音と、刃が肉を断つ音。二つの衝撃が一瞬のうちに
- **使用場面**: 第2話の戦闘（技の巧みさ=「冴え」を示す場面。抜刀斎が自分の技の上達に恐怖を覚える契機）

### 龍巻閃（りゅうかんせん）

回転を伴う横薙ぎの斬撃。全身の遠心力を刀に乗せる。

- **身体描写**: 踏み込んだ足を軸に身体が回転する。遠心力が腕に伝わり、刀の軌道が加速する。回転の最中は視界が流れる——だが抜刀斎の目だけは標的を捉え続ける
- **何が見えるか**: 回転する影。着物の裾が円を描く。その円の中に刃がある。見えた時にはもう遅い
- **何が聞こえるか**: 風を巻き込む低い唸り。着物が空気を叩く音。刃が通過した後の、空気が戻ってくる音
- **使用場面**: 第8話の乱戦（複数の敵を薙ぎ払う場面。「最も美しい剣」の一部として）

### 天翔龍閃（あまかけるりゅうのひらめき）

飛天御剣流の奥義。抜刀術の極致。超神速の踏み込みから放たれる、人間の知覚を超えた一撃。

- **身体描写**: 居合の構え。右足を前に。全身の筋肉が一瞬だけ緊張し——次の瞬間、弛緩と共に爆発する。踏み込みの衝撃で足元の地面が砕ける。刀が鞘を走る音すら、斬撃の後に届く
- **何が見えるか**: 何も見えない。構えた次の瞬間に、もう終わっている。傍観者には抜刀斎が「消えた」ようにしか見えない。刀が鞘に戻る音で、何かが起こったことを知る
- **何が聞こえるか**: 沈黙。次に、遅れてくる衝撃波。空気が割れる音。地面を砕く音。すべてが事後に届く
- **代償**: この一撃は身体を破壊する。踏み込んだ脚の筋肉が裂け、握った手の骨に罅が入る。奥義を放つたびに身体の寿命が削れる
- **使用場面**: 第9話の灰堂戦のみ。物語中一度きり。だがこの一撃は「美しくない」——初めて、技の完成度ではなく意志で振るう剣

### 九頭龍閃（くずりゅうせん）

九つの斬撃を同時に放つ、飛天御剣流の連撃奥義。

- **身体描写**: 刀が消える。九つの軌道が同時に走る——上段、中段、下段、左右、斜め。人間の腕は一本しかないのに、九つの斬撃が「同時に」存在する。その矛盾を超神速が成立させる
- **何が見えるか**: 刃の残像が九本の線になって空間を埋める。逃げ場がない。どこに避けても斬撃がある
- **何が聞こえるか**: 九つの風切り音が一つに重なり、轟音になる。個別の音は聞き分けられない
- **使用場面**: 第8話の乱戦のクライマックス（「最も美しい剣」の頂点。だが同時に「最も人間から遠い瞬間」）

## 3. 流派の身体性

### 「身体を壊す剣術」

飛天御剣流は人間の身体の限界を超えることで成立する流派。

- **超神速の代償**: 常人を超えた速度で動くたびに、筋繊維が切れ、関節に負荷がかかる。若さが補っているが、蓄積は確実に進む
- **技の後の描写**: 大技を放った後、抜刀斎の手が震える。膝が一瞬笑う。だがすぐに立て直す——まだ若いから。この「まだ」が不穏な伏線
- **日常への浸透**: 剣の後遺症が日常動作に表れる。箸を持つ手が強張る。首が回りにくい。寝返りを打つと肩が軋む
- **侵食との連動**: 身体の代償（§4の侵食システム）と飛天御剣流の物理的負荷が重なる。「斬れば斬るほど巧くなり、巧くなるほど身体が壊れ、身体が壊れるほど人間が消える」

### 抜刀斎の身体の変化（話数ごと）

| 時期 | 身体の状態 |
|---|---|
| 第1-2話 | 技の後に微かな震え。すぐ収まる。本人は気にしていない |
| 第3-5話 | 震えが収まるまでの時間が延びる。箸を落とす |
| 第6-7話 | 斬った感触が日常動作に重なる。筋肉の痛みが抜けない朝がある |
| 第8話 | 最高の剣を振るった後、立っているのがやっと。だが本人は気づかない——意識が混濁しているから |
| 第9話 | 天翔龍閃の代償。右腕が上がらなくなる。だがこの痛みは「人間の痛み」として肯定的に描く |

## 4. 灰堂の流派: 寂滅一刀流（じゃくめついっとうりゅう）

### 流派の概要
- 灰堂が仏門で悟り損ねた「空」を、剣で体現しようとした結果、自ら編み出した流派
- 正式な系譜はない。灰堂個人の身体と思想から生まれた一代限りの剣
- 名前の由来: 煩悩の寂滅——あらゆる感情を殺した先にある、完璧な一刀

### 特徴: 無駄のない直線の剣
- **軌道**: すべての斬撃が最短距離を走る。曲線がない。回転がない。直線だけ
- **速度**: 飛天御剣流ほど速くはない。だが予備動作が完全にゼロ。「来る」と感じた時には、もう刃が到達している
- **音**: 飛天御剣流が「空気を裂く」のに対し、寂滅一刀流は「音がしない」。空気を乱さないほど無駄がない
- **立ち姿**: 自然体。構えているように見えない。だが全身がどの瞬間からでも刀を振れる状態にある
- **表情**: 斬る時も、斬られる時も、表情が変わらない。そこに「人間」がいない

### 抜刀斎の飛天御剣流との対比

| | 飛天御剣流（抜刀斎） | 寂滅一刀流（灰堂） |
|---|---|---|
| **質感** | 熱い。荒々しい。生命力の爆発 | 冷たい。静か。生命力の不在 |
| **軌道** | 弧を描く。跳躍する。空間を使う | 直線。最短距離。空間を無視する |
| **音** | 風切り音、衝撃波、着地音。音に満ちている | 無音。空気を乱さない |
| **速度の質** | 爆発的。瞬間的な加速。身体を壊しながら出す速度 | 恒常的。常に同じ速度。身体を壊さない——壊すべき「中身」がないから |
| **代償** | 筋肉が裂け、関節が軋む。痛みがある | 何もない。痛みすら感じない |
| **剣に宿るもの** | 濁り——怒り、恐怖、罪悪感、そして微かな喜び | 空虚。何も宿らない |
| **美しさの質** | 荒削りで不完全。だからこそ人間の剣 | 完璧で冷たい。だからこそ人間の剣ではない |

### 灰堂の戦闘描写の指針
- 飛天御剣流の描写が「音と衝撃」なら、寂滅一刀流の描写は「沈黙と結果」
- 灰堂が剣を振った描写を入れない。構えている→次の文で相手が倒れている。抜刀斎の速度が「見えない」なら、灰堂の剣は「存在しなかった」ように描く
- 灰堂と対峙する時、抜刀斎は初めて「空虚の恐怖」を感じる。技で劣るのではない。「何も感じていない」ことが怖い

## 5. 技名の使用ルール

### 基本原則
- 通常の戦闘では技名を出さない。速度・音・結果で描写する
- 技名は記号ではなく、身体の動きの延長線上に置く

### 技名を出す場面（要所のみ）

| 話 | 場面 | 技 | 演出意図 |
|---|---|---|---|
| 第1話 | 開幕の暗殺 | 龍翔閃 | 飛天御剣流の圧倒的な身体能力を読者に叩きつける |
| 第2話 | 戦闘の終盤 | 双龍閃 | 技の巧みさ＝「冴え」を示す。恐怖の萌芽 |
| 第8話 | 乱戦のクライマックス | 龍巻閃→九頭龍閃 | 最も美しい剣。最も人間から遠い瞬間 |
| 第9話 | 灰堂との決着 | 天翔龍閃 | 奥義。だが「美しくない」。意志で振るう剣 |

### 技名を出さない場面
- 雑魚との戦闘。速度と結果だけで処理する
- 第5話の灰堂との初戦。ここでは技名を出さず、純粋に「身体と身体の衝突」として描く
- 第7話の戦闘。侵食が進行中であり、技名を出す余裕が抜刀斎の意識にない

### 技名の演出方法

技名は身体の動きの後に置く。先に技名を出してから描写するのではなく、描写の結実として技名が来る。

**良い例**:
> 膝を沈め、地を蹴った。身体が弾かれたように浮き上がる。刀は下から——地面を裂くように天へ駆け上がる。
> 龍翔閃。
> 男の体が宙に舞った時にはもう、抜刀斎は着地していた。

**悪い例**:
> 龍翔閃を放った。下方から斬り上げる一撃が敵を捉えた。

技名は「結果の名前」であって「宣言」ではない。身体が動き、刃が走り、結果が出た後に、それが何であったかを読者が知る——その順序を守る。
