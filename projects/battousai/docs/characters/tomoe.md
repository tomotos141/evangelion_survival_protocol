# キャラクター設定: 雪代巴 (The Silent Witness)

## 1. Basic Info (基本情報)
- **名前**: 雪代巴（ゆきしろ ともえ）
- **年齢**: 18歳
- **所属**: なし（元は武家の娘。許嫁・清里明良を抜刀斎に殺された復讐者として京都にいる）
- **Role (役割)**: もう一人の主人公、沈黙の共犯者、「剣の外にあるもの」の体現

## 2. Core Concept (核心)
> **「復讐のために近づいた男の隣で、復讐以外のものを見つけてしまった女」**
> 彼女の武器は刃ではなく沈黙。その沈黙の質が変わっていくことが、この物語のもう一つの軸になる。

## 3. Personality & Voice (性格・口調)
- **性格**:
    - 静かで控えめ。感情を表に出さないが、それは冷たさではなく、感情の器が深すぎて表面に浮かんでこないから。
    - 芯は強い。復讐を胸に京都まで来た女性であり、覚悟がある。だがその覚悟が揺らぐことに、自分自身が最も戸惑っている。
    - 生活の所作が美しい。飯を炊く、洗濯をする、花を活ける——「剣の外にあるもの」を無自覚に体現している。
- **口調サンプル**:
    - 日常: 「……お茶、淹れましたけど」
    - 動揺を隠して: 「……別に。そう見えただけです」
    - 復讐心が揺らぐ瞬間: 「あなたは——……いえ、何でもありません」
- **【重要】Behavioral Rules (行動指針)**:
    - **DO (やるべきこと)**: 沈黙と行動で内面を描く。言葉にしないことで、かえって感情の深さを伝える。視線、手の動き、呼吸の変化で心の揺れを表現する。白梅の香りを巴の存在の象徴として繰り返し使う。
    - **DON'T (やってはいけないこと)**: 感情を直接語る台詞（「私はあなたを憎んでいます」「私はあなたを——」等）。饒舌になる。泣きながら告白する。復讐の動機を自ら説明する。感情の変化を一気に描く（段階的な沈黙の変容で描くこと）。

## 4. Theme Answer (テーマへの回答)
> **「剣の外にあるもの」そのもの——不器用な日常、沈黙、白梅の香り。**
> 巴は抜刀斎に「剣の外の世界」を見せる存在だが、それは意図したものではない。復讐者として近づいたはずが、日常の中で自然と「剣以外のこと」を共有してしまう。飯を炊き、洗濯をし、沈黙を分かち合ううちに、巴自身の復讐もまた「濁って」いく。最終的に巴が選ぶのは、復讐を手放すことではなく、復讐と共存を抱えたまま隣にいること——抜刀斎の「濁りの受容」と鏡写しの着地。

## 5. Arc (変化の軌跡)

### 沈黙の変容マップ

| 段階 | 話数 | 沈黙の質 | 内面の状態 |
|------|------|----------|-----------|
| 復讐者 | 3話「白梅」 | 感情を隠すための沈黙 | 仇の男を見定めている。血に濡れた姿に憎悪を確認するはずが、刀を拭う手の震えに目が止まる。この「引っかかり」が全ての始まり |
| 動揺 | 4話「同居」 | 探るような沈黙 | 抜刀斎の傍にいるようになる。飯を焦がす、箸の持ち方が乱暴——「人殺し」以外の顔が見えてしまう |
| 動揺（深化） | 5話「灰刃」 | — | 抜刀斎が灰堂と出会い、恐怖を持ち帰る。その恐怖に気づいてしまう自分がいる |
| 動揺（転換点） | 6話「傷痕」 | 言葉にできない共感の沈黙 | 清里への想いと、それが「濁り始めている」ことへの自覚。抜刀斎が箸を落とす場面を見て、何かが決定的に揺らぐ |
| 共犯 | 7話「交錯」 | 共有する沈黙 | 二人の濁りが初めて交差する。巴の秘密（復讐者であること）が揺れる。言葉にしないまま、隣にいることを選び始めている |
| 共犯（深化） | 8話「頂」 | 見守る沈黙 | 抜刀斎が最も人間から遠ざかる瞬間を、巴だけが見ている。止められない。だが離れない |
| 選択 | 9-10話「灰燼」「夕凪」 | 言葉がなくても通じる沈黙 | 復讐を手放すのではなく、抱えたまま隣にいることを選ぶ。清里の死を忘れない。だがそれだけが自分の全てではなくなった |

### Starting State
許嫁の仇を討つために京都に来た復讐者。感情を沈黙の奥に沈め、冷静に相手を見定めようとしている。

### Pressure Point
抜刀斎の「人殺し以外の顔」——飯を焦がす、箸を落とす、刀を拭う手が震える——を日常の中で見てしまうこと（4-6話）。復讐の純度が「濁る」ことへの恐怖と戸惑い。

### Ending State
復讐を手放さない。清里の死を忘れない。だが、復讐と共存を抱えたまま、濁った男の隣にいることを選ぶ。巴もまた「濁りの受容」に至る。

## 6. Relationships (人間関係)
- **緋村抜刀斎**: 許嫁の仇。殺すべき男。だがその男の中に「剣以外の何か」——不器用さ、飯を焦がす手つき、刀を拭う手の震え——を見つけてしまう。それを認めれば清里の死が意味を失う。認めなければ自分の目が嘘をつくことになる。最終的に、どちらも手放さないことを選ぶ。
- **清里明良（故人）**: 許嫁。穏やかで優しい人だった。巴にとっての「剣の外にあるもの」の原型。だが清里の記憶が「復讐の燃料」として固定されていることに、巴自身が気づき始める。清里が望んだのは復讐ではなく、巴の幸福だったのではないか——その問いが、物語を通じて静かに巴を蝕む。
- **灰堂**: 直接的な関わりは薄い。だが灰堂の存在が抜刀斎を怯えさせることを通じて、間接的に巴の動揺を深める。「あの男がああなるかもしれない」という恐怖。
- **桂小五郎**: 抜刀斎を「道具」として使い続ける男。巴から見れば、抜刀斎を剣の世界に縛りつけている元凶。だが桂に直接抗うことはない——沈黙のまま、日常の中で別の引力を作る。
