# キャラクター設定: 桂小五郎 (The Righteous Enabler)

## 1. Basic Info (基本情報)
- **名前**: 桂小五郎（かつら こごろう）
- **年齢**: 20代後半〜30代前半（史実では1833年生まれ。物語時点で30歳前後）
- **所属**: 長州藩・維新志士の指導者
- **Role (役割)**: 構造的加害者、「斬る理由」の供給者、善意の政治家

### 歴史考証メモ
- 後の木戸孝允。維新の三傑の一人。長州藩の政治的中枢を担い、武力蜂起より政略を重視した人物
- 剣の腕も立つ（練兵館塾頭）が、本作では政治家としての顔を前面に出す
- 「逃げの小五郎」の異名は、危機回避能力の高さの裏返し。本作では「自分は斬らず、他者に斬らせる」構造の象徴として機能させる
- 史実の細部には縛られない（Design §9: 雰囲気優先）。ただし人物像の骨格——理想主義的な政治家、合理的判断者——は維持する

## 2. Core Concept (核心)
> **「新時代という大義で才能を正当化し、善意で人を沈める——自分の手は血に染まらない加害者」**
> 悪人ではない。新時代への理想は本物。だがその理想が、一人の少年を「人斬り」として消費し続けている構造に、気づいていないか——気づいていても止められない。

## 3. Personality & Voice (性格・口調)
- **性格**:
    - 理性的で冷静。長期的な政治戦略を描ける知性を持つ。
    - 理想主義者だが、理想のために手段を選ばない覚悟がある。その覚悟の中に抜刀斎の暗殺任務が含まれている。
    - 抜刀斎に対しては、指揮官としての距離感と、個人的な情の間で揺れている。だが最終的には常に「大義」が勝つ。
    - 自分が「斬らせる側」であることの罪悪感を、大義の正しさで塗り潰している。
- **口調サンプル**:
    - 政治家として: 「この国を変えるには、まだ血が足りぬ。——だが、その血の先に必ず夜明けがある」
    - 任務を伝える時: 「緋村。明後日の夜、祇園の裏手に佐幕派の密偵がいる。……頼めるか」
    - 抜刀斎への個人的な声かけ: 「……飯は食っているか。——いや、すまない。余計なことを言った」
    - 大義と個人の間で: 「君の剣がなければ、この国は変わらない。……だからこそ、君には——」（言葉が途切れる。「申し訳ない」が続くのか「頑張ってくれ」が続くのか、本人にもわからない）
- **【重要】Behavioral Rules (行動指針)**:
    - **DO (やるべきこと)**: 政治家としての理性的な言葉遣いと、抜刀斎への個人的な声かけの温度差を明確に描き分ける。「善意の加害者」としての構造を、桂自身が気づかない形で表現する。任務を伝える時の微かな間（ためらい）を描く——だがためらった後、必ず任務を伝える。
    - **DON'T (やってはいけないこと)**: 単純な悪役・冷血な政治家として描く。抜刀斎を道具として使っている自覚を明確に持たせる（自覚がないからこそ加害が深い）。反省や贖罪の台詞を言わせる。桂の視点から「善意の加害」の構造を説明する（読者が構造に気づけばいい）。

## 4. Theme Answer (テーマへの回答)
> **「剣の冴えは新時代への道具だ」——才能を大義に従属させることで正当化する。**
> 桂にとって抜刀斎の剣の才能は「新時代を切り拓くための手段」であり、その才能が少年の人間性を蝕んでいるという事実は、大義の重さの前で小さく見える。桂は悪人ではない——だからこそ残酷。「国のため」という言葉は嘘ではないが、その言葉が一人の人間を「人斬り」に固定し続けている。桂のテーマ回答は、抜刀斎のそれと表裏一体：抜刀斎が「剣の外にあるもの」を見つけるとき、桂の「大義」の空洞が浮かび上がる。

## 5. Arc (変化の軌跡)

| 話数 | 段階 | 桂の機能 |
|------|------|----------|
| 1話「夜雨」 | 大義の供給 | 暗殺任務後の抜刀斎に「新時代のため」と告げる。この言葉がまだ抜刀斎に届いている |
| 4話「同居」 | 反復 | 新たな任務の指示。桂の言葉は前と同じだが、抜刀斎の受け取り方が変わり始めている |
| 7話「交錯」 | 空洞化の兆し | 政治的危機に際して抜刀斎に任務を命じる。桂の言葉に対する抜刀斎の反応が鈍くなっている——だが桂はそれに気づかない |
| 8話「頂」 | 大義の空洞化 | 抜刀斎が大義の言葉に反応しなくなる。桂の「新時代」は正しい。だがその言葉はもう抜刀斎には届かない。善意の加害の構造が最も明確になる瞬間 |
| 10話「夕凪」 | 余韻 | 物語の決着後、桂は変わらず「新時代」を語り続ける。抜刀斎が剣の外を見つけたことに、桂は気づかないかもしれない——あるいは気づいても、言葉にしない |

### Starting State
新時代の理想に燃える政治家。抜刀斎の才能を正しく評価し、正しく活用している——と本人は信じている。

### Pressure Point
桂自身には明確な圧力点がない。それが構造的加害者たる所以。変化するのは桂ではなく、桂の言葉を受け取る抜刀斎の側。

### Ending State
変わらない。新時代を信じ、大義を語り続ける。桂の不変性が、抜刀斎の変化を逆照射する。

## 6. Relationships (人間関係)
- **緋村抜刀斎**: 最も有能な剣士であり、最も消耗させている人間。指揮官としての信頼、政治家としての利用、そして個人的な情——この三つが混在し、桂自身も整理できていない。任務を伝えるたびに微かなためらいがあるが、そのためらいは常に大義に飲み込まれる。善意の加害者。
- **灰堂**: 佐幕派時代の灰堂の存在は情報として知っている。「あの男は危険だ」と抜刀斎に警告する役割。だが灰堂の空虚が何を意味するか——抜刀斎の「未来」であることには気づかない。
- **雪代巴**: 抜刀斎の傍にいる女性の存在を把握しているが、深く関与しない。政治家として「弱点になりうる」と判断するか、「人間に戻る契機」と見るか——その判断の仕方自体が、桂の限界を示す。
