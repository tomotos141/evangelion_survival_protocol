# キャラクター設定: 緋村抜刀斎 (The Stained Blade)

## 1. Basic Info (基本情報)
- **名前**: 緋村抜刀斎（ひむら ばっとうさい）
- **年齢**: 15〜17歳（物語期間中）
- **所属**: 長州藩・維新志士 / 桂小五郎の下で暗殺任務に従事
- **Role (役割)**: 主人公、人斬り、飛天御剣流の継承者

## 2. Core Concept (核心)
> **「剣が冴えるほど人間が消える——幕末最強の剣士は、自分の才能に蝕まれていく少年」**
> 斬れば斬るほど剣は完成に近づき、人間からは遠ざかる。その逆説に気づいた時にはもう、刀を拭う手が震えなくなっていた。

## 3. Personality & Voice (性格・口調)
- **性格**:
    - 寡黙で硬質。感情を言葉にする語彙を持たない——それは幼少からの修練が言葉より先に身体を鍛えたため。
    - 任務中は一切の感情を排除する。だが任務後、血を拭う手の震えが「まだ人間である」ことの最後の証明。
    - 不器用さが本質。飯を炊けば焦がし、箸を持てば力加減を間違える。剣以外の全てが「下手」。
- **口調サンプル**:
    - 任務中: 「——退け。斬る。」
    - 任務中（独白）: 「（三人。左の男が抜くのが早い。先に断つ）」
    - 巴の前: 「……焦げた。すまない」
    - 巴の前（動揺）: 「……あんたは、なぜここにいる」
    - 感情が漏れる瞬間: 「——俺は、何を斬っている」
- **【重要】Behavioral Rules (行動指針)**:
    - **DO (やるべきこと)**: 必要最小限の言葉。行動と身体感覚で内面を描く。侵食の進行を生理的描写で表現する（匂い、手の震え、触覚の重なり）。戦闘中は思考が研ぎ澄まされ、言葉が消える。
    - **DON'T (やってはいけないこと)**: テーマを台詞で語らせる（「人を斬るということは——」等の説教）。余裕たっぷりの無双。冷静にニヒルな独白を吐く。感情を直接的な形容詞で描写する（「悲しかった」「苦しかった」）。

## 4. Theme Answer (テーマへの回答)
> **「失ったものは剣の外にしかない」——だがそれを知るのは物語の最後。**
> 剣の冴えは才能の証明であり、新時代への貢献であり、自分の存在理由だった。だがその冴えが増すごとに、箸を持つ手、飯の味、人の温度——剣の外にあったものが指の間から零れていく。巴の沈黙の中で初めて「剣の外」を見たとき、失ったものの輪郭がようやく見える。浄化ではない。濁ったまま、剣の外にあるものと共に歩くことを選ぶ。

## 5. Arc (変化の軌跡)

### 侵食段階×話数 対応表

| 話数 | Arc段階 | 侵食段階 | 状態 |
|------|---------|----------|------|
| 1話「夜雨」 | 無自覚の冴え | 第1段階: 嗅覚の変容 | 血の匂いが鼻から離れなくなる。だがまだ「任務の残滓」と片付けられる |
| 2話「残心」 | 無自覚の冴え | 第2段階: 運動感覚の乱れ | 剣の冴えが増していることへの自覚。それが「喜び」に近い感覚であることへの恐怖。刀を握った手の震えが止まるまでの時間が延びる |
| 3話「白梅」 | — | — | 巴視点。抜刀斎の刀を拭う手の震えが巴の目に映る |
| 4話「同居」 | 冴えへの恐怖 | 第1-2段階継続 | 巴の前で「剣以外のこと」をする。飯を炊く、薪を割る。不器用さが際立つ。侵食と日常の対比が明確になる |
| 5話「灰刃」 | 冴えへの恐怖 | 第2段階深化 | 灰堂の空虚な剣を見て、「自分の未来」を突きつけられる。恐怖が明確な形を取る |
| 6話「傷痕」 | 冴えへの恐怖 | — | 巴視点。抜刀斎が箸を落とす場面を巴の目から描く |
| 7話「交錯」 | 混濁 | 第3段階: 触覚の侵食 | 斬った感触が箸を持つ手に重なる。日常動作に戦闘の感覚が侵入する |
| 8話「頂」 | 混濁 | 第4段階: 認知の混濁 | 人生で最も「美しい」剣を振る。だがその直後、自分が笑っていたことに気づく。夢と現実の境界が曖昧になる |
| 9話「灰燼」 | 受容 | 侵食なし | 灰堂を斬る。だがその剣は「美しく」はない。初めて、美しくない剣を振る——侵食の進行が止まった瞬間ではなく、侵食を抱えたまま剣の意味を変えた瞬間 |
| 10話「夕凪」 | 受容 | 濁りの受容 | 剣を置かない。だが巴の沈黙の中で「剣の外にあるもの」を初めて見る。濁ったまま、隣にいることを選ぶ |

### Starting State
新時代のために剣を振るう人斬り。剣の才能は圧倒的だが、その才能に蝕まれていることに気づいていない。

### Pressure Point
灰堂の空虚な完璧さが「自分の未来」として突きつけられる（5話）→ 触覚の侵食で日常と戦闘の境界が溶ける（7話）→ 最も美しい剣を振った直後に笑っている自分に気づく（8話）。

### Ending State
濁りは消えない。剣も置かない。だが「美しくない剣」を振れるようになった。巴の沈黙の隣で、剣の外にあるものを初めて見る。物語は浄化でも堕落でもない第三の道——濁ったまま歩き出す地点で閉じる。

## 6. Relationships (人間関係)
- **雪代巴**: 仇を討ちに来た女。だが抜刀斎にとっては「剣の外にあるもの」を無言で突きつけてくる存在。巴の沈黙は、最初は不気味で、次第に居心地が良くなり、最後には言葉なしで通じるものになる。巴の前でだけ、不器用な「人間」の部分が出る。
- **灰堂**: 鏡。抜刀斎の「未来の姿」。完璧で美しく、何も感じない——才能の頂に到達し、人間が消えた男。灰堂を斬ることは「なり得た自分」を斬ることであり、それゆえに「美しい剣」ではなく「美しくない剣」で斬る。
- **桂小五郎**: 「斬る理由」を供給し続ける人物。善意の加害者。新時代への理想は本物だが、その理想が抜刀斎をさらに深く沈めていることに気づかない——あるいは、気づいていても止められない。抜刀斎にとって桂の言葉は、物語の前半では支えであり、後半では空虚な音になっていく。

## 7. Combat Style (戦闘スタイル)
- **流派**: 飛天御剣流
- **身体性**: 超神速の抜刀術。身体を壊す剣術——筋肉と関節に極度の負荷をかける代償のある技。15歳の少年の体には本来荷が重い。
- **剣の質感**: 熱く、荒々しく、だからこそ美しい。速度は「見えない」で描く——音、空気の切れ目、結果（血飛沫、倒れた体）で表現する。灰堂の冷たく完璧な直線の剣との対比で「熱さ」が際立つ。
- **戦闘の変化**: 物語の前半では剣が冴え渡るほど美しくなっていく。8話で頂点に達し、9話で初めて「美しくない剣」を振る。美しくない剣こそが、人間の剣。
- **技名の扱い**: 決め技や象徴的場面でのみ使用。地の文に溶かし、身体の動きとして描写した後に技名を置く。通常戦闘では技名を出さない。
