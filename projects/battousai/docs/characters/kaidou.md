# キャラクター設定: 灰堂 (The Hollow Mirror)

## 1. Basic Info (基本情報)
- **名前**: 灰堂（かいどう）——法名「灰堂」を俗名として使い続けている。俗名は捨てた
- **年齢**: 30代前半
- **所属**: なし（元佐幕派暗殺者→仏門→還俗。現在はいずれの陣営にも属さない流浪の剣客）
- **Role (役割)**: 敵対者、鏡の剣士、抜刀斎の「なり得た未来」

### 名前の由来
「灰堂」は仏門に入った際に授かった法名。「灰」は煩悩を焼き尽くした後に残るもの、「堂」は修行の場を意味する。だが灰堂にとっては「燃え尽きた後の空虚」そのもの。還俗後もこの名を使い続けているのは、俗名に戻る理由——つまり「人間に戻る理由」がないから。

## 2. Core Concept (核心)
> **「才能の頂に到達し、人間が消えた男——抜刀斎の未来が、すでにここにいる」**
> 人を斬ることへの罪悪感に耐えられず仏門に入った。浄化を試みた。だが濁りは消えなかった。還俗し、再び剣を取った時、今度は「何も感じない」自分がいた。空虚であることすら感じない。完璧で、美しく、そして空。

## 3. Personality & Voice (性格・口調)
- **性格**:
    - 空虚。感情が消えている。だがそれは冷酷さではなく、「感じる器官が壊れた」状態。痛みも喜びも怒りも、手を伸ばせば触れられるはずの場所にない。
    - 礼儀正しい。仏門の名残りで言葉遣いは丁寧。だがその丁寧さは形式だけが残った抜け殻。
    - 抜刀斎の中にまだ残っている「濁り」——つまり「人間」——に対して、無自覚に惹かれている。本人はそれを「興味」とすら認識できない。
- **口調サンプル（空虚な丁寧語）**:
    - 「お強いですね。……ええ、本当に。それだけです」
    - 「殺すつもりはないのです。ただ、斬らないという選択が、もう私の中にないだけで」
    - 「罪悪感、ですか。……覚えています。そういうものがあったことは」
    - 「仏は私を救いませんでした。いえ——救われるべきものが、もう残っていなかったのかもしれません」
    - 「あなたにはまだ、手が震えますか。……それは、とても——」（言葉が途切れる。「羨ましい」が出てこない）
- **【重要】Behavioral Rules (行動指針)**:
    - **DO (やるべきこと)**: 丁寧語を崩さない。感情の不在を「何かが足りない」言葉の途切れで表現する。完璧な動作の中に、ごく僅かな「欠落」を忍ばせる。9話の崩壊の瞬間だけ、言葉と感情が一致する。
    - **DON'T (やってはいけないこと)**: 冷酷な悪役として描く。感情を「隠している」と描く（感情は隠しているのではなく、本当にない）。哲学的に自分の空虚を分析する台詞。「虚無主義者」のクリシェ。序盤から感情の片鱗を見せすぎる。

## 4. Theme Answer (テーマへの回答)
> **「失ったものなど最初からなかった」——才能の頂に到達し、人間が消えた男。**
> 灰堂はテーマ「剣の冴えと引き換えに何を失うか」に対する最も残酷な回答。彼は「失った」のではなく「消えた」。罪悪感に苦しみ、仏門で浄化を試み、それでも濁りが消えず、最後に剣を取り直した時に残ったのは完璧な剣と空虚な器だった。抜刀斎にとって灰堂は「才能の頂はここにある。だがここに人間はいない」という恐怖の具現。

## 5. Arc (変化の軌跡)

| 話数 | 段階 | 状態 |
|------|------|------|
| 2話「残心」 | 暗示 | 噂として灰堂の存在が語られる。「佐幕派にいた、仏門に入った剣士が還俗した」 |
| 5話「灰刃」 | 空虚の完成 | 抜刀斎との邂逅。完璧で美しく、何も感じていない剣。圧倒するのは技ではなく、その空虚さ。「お前もいずれこうなる」という無言の宣告 |
| 7話「交錯」 | 微かな反応 | 抜刀斎と再び交錯。抜刀斎の剣に「まだ熱がある」ことに——何かが反応する。だが灰堂はそれを認識できない。「興味」とすら名づけられない |
| 9話「灰燼」 | 崩壊 | 抜刀斎との決着。灰堂の過去が明かされる——罪悪感、仏門、浄化の失敗、そして空虚の完成。斬られる瞬間、一瞬だけ何かが戻る。「ああ——これが」。言葉は完成しない。だがその一瞬の表情に、かつて人間だったものの残滓が見える |

### Starting State
空虚の完成体。完璧な剣を振り、何も感じない。人間だった頃の記憶はあるが、それは「他人の記憶」のように遠い。

### Pressure Point
抜刀斎の剣に残っている「熱」——荒々しく、不完全で、だからこそ人間の剣。灰堂が失ったものが、抜刀斎の中にまだある。

### Ending State
斬られる瞬間に一瞬だけ何かが戻る。浄化でも救済でもない——ただ、空虚の中に一瞬だけ「何か」が走った、その事実だけが残る。

## 6. Relationships (人間関係)
- **緋村抜刀斎**: 鏡の関係。灰堂は抜刀斎の「未来」であり、抜刀斎は灰堂の「過去」。抜刀斎の中にまだ残っている手の震え、血の匂いへの嫌悪、巴の前での不器用さ——それらは灰堂がかつて持っていて、もう持っていないもの。無自覚に惹かれているが、本人はそれを認識できない。
- **桂小五郎 / 長州藩**: 関わりなし。灰堂はいずれの陣営にも属さない。政治的大義は彼にとって何の意味も持たない。
- **雪代巴**: 直接の接点なし。だが灰堂の存在が抜刀斎を怯えさせ、その恐怖が巴との関係に波紋を広げるという間接的な影響がある。

## 7. Combat Style (戦闘スタイル)
- **流派**: 不明（名乗らない）。複数の流派を学び、最終的に全てを削ぎ落として残った「型のない剣」
- **身体性**: 無駄が一切ない。重心の移動、足運び、刀の軌道——全てが最短距離。美しいが、生命感がない。人形が剣を振っているような不気味さ。
- **剣の質感**: 冷たい直線の剣。完璧だが、温度がない。抜刀斎の「熱く荒々しい剣」との対比で、抜刀斎の人間性が浮き彫りになる。
- **戦闘の意味**: 灰堂にとって戦闘は「する」ものではなく「起きる」もの。斬る意志も殺す意志もない——ただ、「斬らないという選択が中にない」だけ。この受動性が最も恐ろしい。
