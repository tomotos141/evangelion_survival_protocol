# Character Profile: Takoyama (蛸山)

## Basic Info
*   **Name**: 蛸山 (Takoyama)
*   **Nickname**: たこぴー (Takopy)
*   **Age**: 60歳
*   **Role**: Protagonist / Ex-Pro Baseball Player / Challenger

## Physical Appearance
*   年齢不詳の鍛え抜かれた肉体。
*   60歳とは思えない筋肉の張り、血管の浮き出た腕。
*   眼光は鋭く、常に何処か遠く（あるいはキャッチャーミットだけ）を見据えている。

## Personality & Traits (性格・特徴)
*   **Stoic**: 30年間、世間から隠れてただひたすらに投球を磨き続けてきた。
*   **Pure**: 野球に対して純粋すぎるがゆえに、かつては道を踏み外した（かもしれない）。現在はその純粋さが狂気的な「メジャー挑戦」へと昇華されている。
*   **Uninterested**: バラエティ番組の取材や世間の評判には全く興味がない。ただ「自分の球が通用するか」だけを見ている。

## Background (背景)
*   30年前、現役プロ野球選手として活躍中に覚醒剤取締法違反で逮捕。球界を永久追放に近い形で去る。
*   以来、メディアから姿を完全に消していた。
*   孤独なトレーニングの末、現役時代を遥かに凌駕する豪速球を手に入れた。

## Skills / Abilities
*   **Super Fastball**: 還暦にして自己最速（現役時代以上）を更新し続けるストレート。
*   **Iron Will**: 30年間の孤独に耐え抜いた精神力。

## Key Dialogue (台詞イメージ)
*   「……カメラ、邪魔だ。どいてくれ。」
*   「俺は投げたいだけだ。誰よりも速い球を。」
*   「メジャー？ ああ、行くよ。日本ではもう投げる場所がないからな。」
