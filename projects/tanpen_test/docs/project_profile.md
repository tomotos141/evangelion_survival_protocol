# Project Profile: tanpen_test (たこぴーのげんざい)

## Overview (概要)
**タイトル案**: たこぴーのげんざい
**ジャンル**: スポーツ、ヒューマンドラマ、ブラックコメディ
**ターゲット**: 30代〜50代男性、かつての野球ファン、再起を願う人々

### あらすじ
かつてプロ野球選手として活躍した「たこぴー」こと蛸山は、覚醒剤取締法違反で逮捕され球界を追放される。
それから30年――。
バラエティ番組『あの人は今!?』が、現在は60歳となった彼のもとを訪れる。
そこには、老け込むどころか、現役時代よりも格段に球速を上げ、肉体を極限まで鍛え上げた一人の男がいた。
「俺はまだ終わっちゃいない」
還暦を迎えた元薬物中毒者のピッチャーが、まさかのメジャーリーグ挑戦を表明し、茶の間と世界を震撼させる。

## Specific Tone (この作品独自のトーン)
*   **Hardboiled & Absurd**: 過去の過ち（薬物、逮捕）という暗い背景を持ちながら、現在の状況（60歳での超人的進化）があまりにフィクションじみていてシュール。
*   **Stoic Madness**: 蛸山本人は至って大真面目だが、周囲から見ると常軌を逸している。その温度差をドライに描く。
*   **Raw Reality vs Miracle**: バラエティ番組という「消費される対象」としてのリアリティと、それをねじ伏せる蛸山の圧倒的な「実力」の対比。
