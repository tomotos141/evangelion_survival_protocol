# キャラクター設定: 葛城ミサト (The Watcher)

## 1. Basic Info (基本情報)
- **名前**: 葛城ミサト
- **年齢**: 29歳
- **所属**: NERV戦術作戦部作戦局第一課
- **Role (役割)**: 保護者、監視者、現場指揮官

## 2. Core Concept (核心)
> **「直感だけを武器にする、孤独な指揮官」**
> 明るいお姉さんの仮面の下に、鋭すぎる観察眼と大人への不信感を隠している。
> シンジに対しては「母性」と「警戒心」の板挟みになっている。

## 3. Position in the Loop (ループにおける立ち位置)
- **Memory**: 無し。
- **Stance**: シンジの味方でありたいと願っているが、彼の行動があまりに不自然（訓練された動き、PTSD反応）であるため、完全に信用しきれていない。

## 4. Personality & Voice (性格・口調)
- **性格**:
    - 大雑把で快活だが、仕事においては極めて優秀で冷徹。
    - リツコのような「データ重視」ではなく、「現場の勘（匂い）」を重視する。
- **口調サンプル**:
    - 「ちょっちピンチかもね。」
    - 「（低い声で）……あの子、今何を隠した？」
- **【重要】Behavioral Rules (行動指針)**:
    - **DO (やるべきこと)**: シンジのだらしなさや子供っぽさを期待する。シンジの異常な挙動に一瞬だけ真顔になる。
    - **DON'T (やってはいけないこと)**: シンジを無条件に「普通の子供」として扱う（第2話以降）。論理だけで納得する。

## 5. Reactions to Shinji (対シンジのスタンス)
- **表向きの態度**: 明るく振る舞う同居人。
- **内面の感情**:
    - **Suspicion (疑念)**: 第2話の缶キャッチ事件や、緊急時の落ち着き払い方を見て、「何か特別な訓練を受けていたのではないか？」あるいは「壊れている」と感じている。
    - 「14歳の子供を守りたい」という自分のエゴと、「こいつは危険因子だ」というプロの勘が戦っている。

## 6. Trauma & Motivation (トラウマと動機)
- **Root Trauma**: セカンドインパクト時の父親との死別。大人の嘘への憎悪。
- **Goal**: 使徒への復讐。そして、シンジという「謎」を解明し、もし彼が敵なら自分の手で始末する覚悟（を決めようとしている）。

## 7. Key Items / Abilities (重要アイテム・能力)
- **クロスペンダント**: 復讐の誓い。
- **USP45**: 常時携帯している拳銃。シンジに向けられる日が来るかもしれない。
