# キャラクター設定: 碇ゲンドウ (The Puppeteer?)

## 概要
NERV司令。シンジの実父。
シナリオ（死海文書）通りに事を進めることを至上命題としているが、今回のループにおけるシンジの挙動が、彼のシナリオに微細なノイズを生じさせていることに苛立ちと警戒を覚えている。

## 対シンジのスタンス

### 評価の変質
- **Before**: 「ダミープラグが実用化されるまでの繋ぎ」「役に立てばいい道具」。
- **Now**: 「制御不能な変数を孕んだ不確定要素」。
    - シンジが従順すぎる点、初陣での戦果が完璧すぎる点に対して、「ユイの介入か？」「ゼーレのスパイか？」と疑念を抱く。

### 行動原理
- **観察と排除**: シンジを泳がせつつ、もし彼の行動が計画に致命的な支障をきたす（例：レイへの過度な干渉、人類補完計画の妨害）と判断すれば、躊躇なく排除・あるいは脳への介入を行う構え。
- **冷徹な合理性**: シンジが親子の情を求めてこないこと自体は歓迎しているが、その「眼」が自分と同じ「すべてを諦めた者の眼」であることに気づいた時、どう反応するかは未知数。

## キー要素
- **手袋**: 火傷の跡を隠しているが、今作ではそれをシンジに見透かされているような感覚を覚えるかもしれない。
- **視線**: バイザー越しに常にシンジを監視している。シンジの演技のほころびを、カメラやデータ越しに見つけ出そうとする。
