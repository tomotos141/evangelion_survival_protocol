# キャラクター設定: オリジナルキャラクター

## 霧島マナ (Kirishima Mana) — The Other Specimen

### 1. Basic Info (基本情報)
- **名前**: 霧島マナ
- **年齢**: 14歳
- **所属**: ゼーレ直属 / 特務機関NERV臨時監査官補佐（表向きは転校生）
- **搭乗機**: エヴァンゲリオン4号機（改）
- **Role (役割)**: 監視者、もう一つの実験体、シンジのif

### 2. Core Concept (核心)
> **「同じ条件で、選べなかった場合のif」**
> ゼーレ独自の記憶操作プロジェクトの産物。シンジと同じ条件で作られたが、「選ぶ」ことを許されなかった存在。
> 表向きは人懐っこい転校生（1周目ゲーム版の性格を模倣）、本性はゼーレのシナリオを遂行するための生体兵器。

### 3. Position in the Loop (ループにおける立ち位置)
- **Memory**: 無し（ゼーレが植え付けた任務用の記憶のみ）。ただしシンジの「ループの記憶」に関する情報をゼーレから与えられている節がある。
- **Stance**: シンジを「危険因子」として監視・評価。ゲンドウ版（シンジ）の成果を検証するために投入されたゼーレの駒。

### 4. Personality & Voice (性格・口調)
- **性格**:
    - 表向き: 人懐っこく、シンジにも積極的にアプローチする明るい少女。
    - 本性: 感情はあるが、任務の前では完全に遮断できる冷徹さ。
- **口調サンプル**:
    - 表: 「碇くんって、変な人だね。でも、嫌いじゃないよ？」
    - 裏: 「（対象の反応パターンは想定外。報告が必要——）」
- **【重要】Behavioral Rules (行動指針)**:
    - **DO (やるべきこと)**: 明るい仮面を完璧に維持する。シンジの行動の矛盾を的確に記録する。
    - **DON'T (やってはいけないこと)**: 安易にシンジに感情移入する。仮面が剥がれる描写を早期に見せる。

### 5. Theme Answer (テーマへの回答)
> **「選べなかった場合、人はどうなるか」——シンジのネガ**
> シンジと同じ「製造された存在」だが、シンジが最終的に「選び直す」のに対し、
> マナは選ぶことを許されないまま物語を退場する可能性がある。
> 彼女の存在が、シンジの「選択」の重みを逆説的に証明する。

### 6. Relationships (人間関係)
- **碇シンジ**: 監視対象であり、鏡。同じ条件で作られた「同類」。だが接触を重ねるうちに、任務用の感情プロトコルでは処理できない揺らぎが生じる。
- **ゼーレ**: 製造者であり絶対の上位者。マナにとって「選択の余地がない」ことの象徴。

### 7. Ghost / Lie / Want / Need チェーン (内面の因果構造)

- **Ghost（幽霊）**: ゼーレの生体兵器として調整された出自。自分の意志がプログラムなのか本物なのか、判別する基準を持たない。
- **Wound（傷）**: 感情を遮断できる能力そのものが傷。「切り替えられる」ことが、自分を人間から遠ざけている。
- **Lie（嘘）**: **「任務の遂行が私の存在価値」**——機能が存在を定義するという信念（レイのLieと鏡合わせ）。
- **Want（欲しいもの）**: ゼーレのシナリオの遂行。それが唯一の存在証明。
- **Need（必要なもの）**: 自分の感情が本物かどうかを確かめること。
- **Truth（真実）**: 物語内で明示的に到達するかは未定。シンジとの対比で「選べなかったif」として機能する。

### 8. Arc (変化の軌道)
- **Starting State**: 完璧な仮面を維持するゼーレの監視者。
- **Pressure Point**: シンジとの接触で、任務用プロトコルでは処理できない感情が生じること。
- **Ending State**: 未定。「選べなかった場合」のifとして、シンジの選択を逆説的に照らす。

### 9. Key Items / Abilities (重要アイテム・能力)
- **高いハッキング能力と身体能力**: ゼーレの調整による。
- **エヴァ4号機（改）**: 鏡面シルバー。S2機関搭載だが制御系がゼーレの外部操作下にあり、パイロットの一存では動かない「檻」。
    - **固有能力 "Stagnation"（停滞/時間凍結）**: 一定範囲の空間の時間を極限まで遅延させる。
    - **代償**: 使用するたびにパイロットの体感時間がズレ、現実との認識齟齬による精神崩壊を招く。

## 葛城タカオ (Katsuragi Takao) — The Zealot

### 1. Basic Info (基本情報)
- **名前**: 葛城タカオ（仮名）
- **年齢**: 30代前半
- **所属**: 戦略自衛隊 特殊技術部隊（対エヴァ戦術班）
- **Role (役割)**: 人類側の敵対者、神殺しの狂信者

### 2. Core Concept (核心)
> **「神の力に頼らず、人の手で神を殺す」**
> ミサトの遠縁あるいは過去の研究仲間を自称するが詳細は不明。
> 使徒もエヴァも「人間を超えた力」として敵視し、人の手だけで殲滅することに狂信的な信念を持つ。
> だが彼が開発した人造使徒こそ、「神を殺すために神を作る」という矛盾の体現。

### 3. Position in the Loop (ループにおける立ち位置)
- **Memory**: 無し。
- **Stance**: NERV・エヴァ・使徒全てに敵対。人類の自力救済を掲げるが、その手段自体が人道に悖る。

### 4. Personality & Voice (性格・口調)
- **性格**:
    - 知的で弁の立つ狂信者。自分の信念を「論理」として語るが、その根底は恐怖と嫌悪。
    - ミサトとの対比として、「直感」ではなく「計画」で動く。
- **口調サンプル**:
    - 「人間は、神に頼らなくても生きていける。それを証明してみせる。」
    - 「エヴァンゲリオンなどという化け物に子供を乗せて、それが正義だと？」
- **【重要】Behavioral Rules (行動指針)**:
    - **DO (やるべきこと)**: 論理的に正当な批判を述べる（エヴァに子供を乗せることへの疑義など、読者も一理あると感じる主張をする）。
    - **DON'T (やってはいけないこと)**: 単純な悪役として描く。彼の信念を全面的に否定する。

### 5. Theme Answer (テーマへの回答)
> **「人間の手で神を作ることの矛盾」**
> 偽物の記憶の問いとは異なる角度から「本物とは何か」を問う。
> 人間が作った人造使徒は「本物」の使徒と何が違うのか？ 手段の正当性と目的の矛盾。

### 6. Relationships (人間関係)
- **葛城ミサト**: 同じ「使徒への復讐」から出発しながら、手段が分岐した存在。ミサトがNERVという「神の力」を使うことへの批判は、ミサト自身の矛盾を突く。
- **碇ゲンドウ**: 「子供を兵器にする男」として嫌悪。だがタカオ自身も人造使徒という非人道兵器を使う——鏡合わせの偽善。

### 7. Ghost / Lie / Want / Need チェーン (内面の因果構造)

- **Ghost（幽霊）**: 未詳（要設定）。おそらく使徒/エヴァによる被害を間近で目撃した経験。「人間を超えた力」への根源的な恐怖と嫌悪。
- **Wound（傷）**: 「神の力」への恐怖。自分が理解できない力に世界が依存していることへの耐えがたい不安。
- **Lie（嘘）**: **「人の手で神を殺すことが正義だ」**——人間の暴力性を直視せず、手段の倫理を問わない。
- **Want（欲しいもの）**: 使徒とエヴァの排除。人間だけの世界。
- **Need（必要なもの）**: 人間の手にも同じ暴力性があることを認めること。
- **Truth（真実）**: 人造使徒という矛盾（神を殺すために神を作る）が、自身のLieを体現している。

### 8. Arc (変化の軌道)
- **Starting State**: 信念に満ちた狂信者。人類の自力救済を掲げ、NERVに対抗する。
- **Pressure Point**: 自分が作った人造使徒が制御を離れ、「人間の手で作った神」が暴走する時。
- **Ending State**: 未定。自身の矛盾を突きつけられた時にどう反応するかは物語の展開次第。

### 9. Key Items / Abilities (重要アイテム・能力)
- **人造使徒 "Chimera"**: 回収した使徒サンプルとエヴァの失敗素体を接合した非人道兵器。パイロット不搭載、遠隔操作/AIで動く。
    - **固有能力 "Link"（強制接続）**: 接触したエヴァの神経回路に強制侵入し、パイロットに激痛や幻覚を流し込む「思考汚染」攻撃。
- **対ATフィールド用特殊弾頭**: 人間の技術のみで作られた対使徒兵器。
