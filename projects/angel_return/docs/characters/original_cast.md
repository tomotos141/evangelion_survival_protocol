# 機体設定: 追加機体

## エヴァンゲリオン4号機（改） (Unit-04 Custom)
*   **カラーリング**: 鏡面シルバー
*   **特徴**: S2機関搭載実験機だが、制御系が完全にゼーレの外部操作下にあり、パイロット（マナ）の一存では動かない「檻」。
*   **固有能力**: **"Stagnation" (停滞/時間凍結)**
    *   一定範囲の空間の時間を極限まで遅延させる。
    *   防御に使えば「絶対防御」、攻撃に使えば相手を回避不能な状態で固定する。
    *   **代償**: 使用するたびにパイロットの体感時間がズレていき、現実世界との認識齟齬（タイムラグ）による精神崩壊を招く。

## 人造使徒 (Mock Angel) - "Chimera"
*   **概要**: 戦略自衛隊が極秘に回収した使徒のサンプルと、エヴァの素体（失敗作）を無理やり接合した非人道兵器。
*   **制御**: パイロットは搭乗せず、遠隔操作またはAI（ダミープラグの劣化版）で動く。
*   **能力**: **"Link" (強制接続)**
    *   接触したエヴァの神経回路に強制侵入し、パイロットに激痛や幻覚（ノイズ）を流し込んで無力化する。
    *   「思考汚染」攻撃特化型。
