# キャラクター設定: 碇シンジ (Cycle 2 / Hardboiled)

## 概要
「14歳の少年」の皮を被った、疲弊しきった魂の持ち主。
ループ2周目。前回の記憶を保持しているが、それを周囲に悟られないよう徹底して「弱気な少年」を演じている。

## 性格・精神状態

### 表の顔 (The Mask)
- **役割**: 内向的で臆病な14歳。父に捨てられたトラウマを持つ少年。
- **演技**: 
    - 適切なタイミングで悲鳴を上げる。
    - 怖いときは震える（生理的な反応もコントロールしようと努めている）。
    - ミサトやリツコの顔色を窺う素振りを見せる。
- **目的**: ゼーレやゲンドウ、NERV上層部に「扱いやすい駒」だと誤認させ、自由な行動範囲を確保すること。

### 裏の顔 (The Real)
- **本性**: ニヒリスト。世界への期待も、自分への希望も捨てている。
- **思考**: 極めて論理的かつ冷徹。感情よりも「生存確率」と「効率」を優先する。
- **トラウマ**: 
    - 「痛み」だけが現実感（リアル）を感じられる唯一の手段。
    - 食事や睡眠よりも、戦闘時の高揚感や被弾の痛みに生の実感を得てしまう「戦闘中毒」のような傾向。

## 能力・スキル
- **エヴァ操縦**: 
    - 熟練度はMAX。しかし、あえて「下手なふり」「暴走したふり」をして実力を隠蔽する。
    - 必要であれば、敵のコアを素手で握りつぶす等の残虐な手段も躊躇わない。
- **未来知識**: 
    - 使徒の出現場所、攻撃パターン、NERVの裏事情を把握している。
    - ただし「バタフライエフェクト」や「この世界特有のズレ（イレギュラー）」には対処できないため、常に警戒している。

## 人間関係のスタンス
- **対ミサト**: かつての保護者であり、愛憎の対象。彼女が生きていることに安堵しつつも、再び失うことへの恐怖から深入りを避けている（表面上は甘えるふりをする）。
- **対ゲンドウ**: 憎悪の対象ですらない。「倒すべきシステムの一部」。視線を合わせると殺意が漏れるため、極力目を逸らす。
- **対レイ・アスカ**: 「救うべき対象」というよりは、「悲劇の共演者」。ドライに接しようとするが、情を捨てきれない自分にも気づいている。

## 苦心・葛藤 (Conflict)
- **演技のほころび**: 咄嗟の状況（戦闘中など）で、つい熟練者の動きや冷徹な判断が出てしまい、周囲（特にミサトやカヲル）に怪しまれる。
- **身体との不一致**: 精神は30代並みに成熟（あるいは老化）しているのに、身体は14歳のホルモンバランスに振り回されるもどかしさ。
- **予定調和の崩壊**: 「知っている通り」に進まない事態（使徒の強化、初号機の自律行動など）に直面した時の、底知れぬ恐怖。
