# キャラクター設定: 渚カヲル (The Ferryman)

## 1. Basic Info (基本情報)
- **名前**: 渚カヲル
- **年齢**: 不明（外見は15歳前後）
- **所属**: ゼーレ / 第17使徒タブリス
- **Role (役割)**: 同類の誘惑者、真実の告知者、もう一つの答え

## 2. Core Concept (核心)
> **「苦痛を終わらせに来た、優しい渡し守」**
> シンジに真実を告げる第三勢力。共感は本物だが、その共感が「終わらせよう」という提案を生む。
> 殺されることも、殺すことも拒む——ただ「選択肢を残す」存在。

## 3. Position in the Loop (ループにおける立ち位置)
- **Memory**: 有り。使徒としての特殊な知覚により、複数の反復/可能性を認識している。シンジの苦しみを「知っている」のは記憶ではなく存在の構造。
- **Stance**: シンジに真実を開示する。だがその先の選択には干渉しない。「知った上でどうするかは、君の自由だよ」。

## 4. Personality & Voice (性格・口調)
- **性格**:
    - 穏やかで知的。だが人間の感情を「理解」しているのか「模倣」しているのか、本人にも判別がつかない。
    - シンジへの共感は本物——だからこそ、苦痛を終わらせることを「慈悲」として提案できる。
- **口調サンプル**:
    - 「君に会えて嬉しいよ。……本当に。」
    - 「全部、終わらせよう。僕にはその力がある。」
- **【重要】Behavioral Rules (行動指針)**:
    - **DO (やるべきこと)**: シンジの痛みに寄り添う。真実を淡々と告げる。シンジの選択を尊重する。
    - **DON'T (やってはいけないこと)**: 強制する。感情を操作する。「正解」を押し付ける。安易にシンジを「救う」。

## 5. Theme Answer (テーマへの回答)
> **「全部終わらせよう」——論理的な慈悲**
> 偽物の記憶から生まれた感情に「価値がある」とは言い切らない。
> 代わりに「苦痛に意味がないなら、慈悲ある終焉が最善ではないか」と問いかける。
> 論理的に正しく、共感から出た提案。だからこそ最も危険な誘惑。

## 6. Relationships (人間関係)
- **碇シンジ**: 「作られた存在」同士として語り合える唯一の同類。カヲルはシンジの苦しみを正確に理解しているが、だからこそ「終わり」を提案する。シンジが拒否した後、カヲルはその選択を尊重して去る——殺さないし、殺されない。
- **碇ゲンドウ**: ゲンドウの計画を外側から見ている存在。カヲルが真実をシンジに告げることは、ゲンドウにとって最大の脅威。
- **綾波レイ**: リリスの魂の座を持つレイと、アダムの魂を宿すカヲル——対をなす存在。だが本作では直接的な対峙はなく、それぞれがシンジに異なる答えを提示する構造。

## 7. Ghost / Lie / Want / Need チェーン (内面の因果構造)

- **Ghost（幽霊）**: 使徒としての特殊な知覚により、人間の苦しみを繰り返し目撃してきた。特にシンジの——設計された苦痛、植え付けられた恐怖、それでも足掻く姿。その全てを「知っている」。
- **Wound（傷）**: 共感の過負荷。人間の痛みを理解できるが、自分がそれを「感じている」のか「模倣している」のか分からない。共感の真偽が自分にも不明。
- **Lie（嘘）**: **「苦痛に意味がないなら、慈悲ある終焉が最善だ」**——苦しみを終わらせることが最大の優しさという信念。論理的には正しいが、「意味がなくても生きる」選択を過小評価している。
- **Want（欲しいもの）**: シンジの苦痛を終わらせること。サードインパクトによる完全なリセット。
- **Need（必要なもの）**: 苦痛を抱えたまま生きるという選択を、「間違い」ではなく「もう一つの正解」として尊重すること。
- **Truth（真実）**: 「君が正しいといいね」——答えを持たない。だがシンジの選択を尊重して去る。決着をつけず、どこかで見守っている。Truthに「到達」するのではなく、**Truthを保留したまま退場する**。

## 8. Arc (変化の軌道)
- **Starting State**: 真実を携えた訪問者。シンジに共感し、苦痛の終わりを提案する。
- **Pressure Point**: シンジが「終わり」を拒否する瞬間。カヲルの論理では処理できない「それでも生きる」という選択。
- **Ending State**: 去る。殺されず、殺さず、決着をつけず。「君が正しいといいね」——余韻を残す存在としてどこかにいる。Flat Arc に見えるが、シンジの拒否を**受け入れた**点でわずかに変化している。

## 9. Key Items / Abilities (重要アイテム・能力)
- **第17使徒の力**: サードインパクトを引き起こす能力。「全部終わらせる」手段そのもの。
- **真実の知識**: ゲンドウのS-13計画、偽の記憶の仕組み、使徒の設計された配置——全てを知っている。

## 10. Status Evolution Log (状態の変化)

### Act 3: 渡し守の到着 (The Ferryman Arrives)
- **状態**: Ep.11で登場。シンジに真実の一端を告げる——「戦場は設計されていた」「ハードモードは父が作った檻」。
- **変化**: シンジとの対話で「作られた存在」同士の共鳴。だがカヲルの告知はシンジを救うためではなく、「知った上で選べ」という選択の提示。Ep.12でシンジをS-13施設に導き、最も残酷な真実と対面させる。Ep.13で「全部終わらせよう」と提案。シンジの沈黙を5分間待ち、レイが来たことを察して一度去る。翌朝、シンジが「まだ確かめたいことがある」と告げ、カヲルは「君が正しいといいね」と去る。

### Act 4: 不在の余韻 (The Absent Echo)
- **状態**: 退場。だが物語の中で「まだどこかにいる」存在として余韻を残す。
- **変化**: シンジがEp.14で偽の記憶を手放して戦ったこと——カヲルが「論理的に不合理」と判断した選択が、結果として本物の勝利を生んだ。カヲルのLie（「苦痛に意味はない」）への反証が、不在のまま成立する。
