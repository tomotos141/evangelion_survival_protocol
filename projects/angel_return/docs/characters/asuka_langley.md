# キャラクター設定: 惣流・アスカ・ラングレー (The Broken Ace)

## 1. Basic Info (基本情報)
- **名前**: 惣流・アスカ・ラングレー
- **年齢**: 14歳
- **所属**: NERVユーロ支部 / EVA弐号機パイロット
- **Role (役割)**: ライバル、鏡合わせのトラウマ

## 2. Core Concept (核心)
> **「傷を隠すために爪を研ぐ、孤独な猛獣」**
> 高いプライドは、脆い精神を守るための鎧。
> 本作では「亡命者」として登場し、これまで以上に追い詰められた、鋭利で危険な精神状態にある。

## 3. Position in the Loop (ループにおける立ち位置)
- **Memory**: 無し。
- **Stance**: シンジを敵視するが、それはライバル心からではなく、**同族嫌悪（Homologous Disgust）**によるもの。

## 4. Personality & Voice (性格・口調)
- **性格**:
    - 攻撃的で自己中心的。しかしその裏には、強烈な承認欲求と「捨てられることへの恐怖」がある。
    - シンジの「表向きの弱さ」を見るとイライラし、「裏に見える怯え」を見ると自分を見ているようで吐き気を催す。
- **口調サンプル**:
    - 「あんたバカぁ？ 死ぬ気でやりなさいよ！」
    - 「……近寄らないで。その目、気持ち悪い。」
- **【重要】Behavioral Rules (行動指針)**:
    - **DO (やるべきこと)**: 常に完璧であろうと虚勢を張る。シンジの痛いところ（トラウマ）を的確に突く。
    - **DON'T (やってはいけないこと)**: 素直に助けを求める。シンジと馴れ合う。

## 5. Reactions to Shinji (対シンジのスタンス)
- **表向きの態度**: 罵倒、挑発。
- **内面の感情**:
    - **Resonance (共鳴する傷)**: シンジが戦場で震えているのを見ると、自分の母の死の記憶がフラッシュバックするため、彼を拒絶することで自分を守ろうとする。
    - 「あいつがいると、私のペースが崩れる」という焦り。

## 6. Trauma & Motivation (トラウマと動機)
- **Root Trauma**: 母・キョウコの精神崩壊と心中未遂（人形扱い）。
- **Goal**: 「誰よりも優れていること」を証明し、自分の存在価値を認めさせること。

## 7. Key Items / Abilities (重要アイテム・能力)
- **人形**: 彼女が最も憎み、同時に捨てられないもの。
- **インターフェイス・ヘッドセット**: 常に装着している戦闘態勢の象徴。
