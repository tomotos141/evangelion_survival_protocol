# キャラクター設定: 惣流・アスカ・ラングレー (ループにおける立ち位置)

## シンジとの関係性 (Circle Cycle: 共鳴する傷)

- **シンジの態度**:
  - アスカに対して「腫れ物に触る」ような態度をとる。
  - 彼女の罵倒や暴力に対して、反論する気力すらなく、ただ**「これ以上傷つけないでくれ（僕も君も）」という懇願の目**を向ける。
  - 戦闘においては、彼女が被弾しそうになると、自分の身を呈して過剰に庇う（自己犠牲精神というより、目の前で誰かが傷つくことへのパニック反応）。

- **アスカの反応**:
  - **同族嫌悪 (Homologous Disgust)**: 
      - 当初は「暗いガキ」として見下すが、シンジのふとした瞬間の「怯え」や「過呼吸」を見るたびに、自分が必死に隠しているトラウマ（母親のこと、孤独）を突きつけられるような不快感を覚える。
      - 「あんた、何に怯えてるのよ！？」と詰め寄るが、それは図星を突かれたくないが故の防衛攻撃。
  - **不気味さ**:
      - 自分の罵倒に対して、シンジが怒るのではなく「ひどく悲しそうな顔」で黙り込むことに、言いようのない居心地の悪さを感じる。
      - 従来のような「喧嘩友達」にはなれない。もっとヒリヒリした、傷を舐め合うような関係性。
