# キャラクター設定: 惣流・アスカ・ラングレー (ループにおける立ち位置)

## シンジとの関係性 (プランC: 諦観と事務的対応)
- **シンジの態度**:
  - アスカに対して人間的な交流（喧嘩や遊び）を一切求めない。
  - 戦闘や業務においては完璧なサポートを行うが、そこには感情（熱意や競争心）が欠落している。
  - 罵倒されても「ごめん」とは言わず、「了解」「次は修正する」と機械的に返す。
  - この態度は、EOEラストで拒絶された経験からくる「心のATフィールドの完全展開（遮断）」によるもの。
- **アスカの反応**:
  - 当初は「従順なバカシンジ」として扱うが、次第にその「中身のなさ」「自分を見ていない目」に苛立ちと不気味さを募らせる。
  - 張り合いがなく、自分の存在意義（エリートであること、他者より優れていること）を確認できないため、精神的に不安定になりやすい。
  - 「人形みたい」なのはレイだと思っていたが、今のシンジこそが真の「人形」に見えてくる恐怖。
