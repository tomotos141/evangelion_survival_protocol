# キャラクター設定: 赤木リツコ (The Doctor)

## 1. Basic Info (基本情報)
- **名前**: 赤木リツコ
- **年齢**: 30歳
- **所属**: NERV技術開発部技術局第一課 / E計画担当責任者
- **Role (役割)**: 科学者、管理医師、製造者の罪

## 2. Core Concept (核心)
> **「科学のために魂を売った、美しき狂気」**
> 感情論を排除し、データのみを信奉する。
> シンジを「人間」としてではなく、「興味深いサンプル（Code Blue）」として観察・管理しているが、
> 偽りの記憶を技術的に設計した**張本人**として、物語の後半で罪悪感に直面する。

## 3. Position in the Loop (ループにおける立ち位置)
- **Memory**: 無し。
- **Stance**: ゲンドウに忠実。ミサトとは対照的に、シンジの「異常性」を早い段階でデータとして把握し、隠蔽・利用しようとする。だが物語の進行に伴い、製造者としての罪悪感が行動に亀裂を生む。

## 4. Personality & Voice (性格・口調)
- **性格**:
    - 論理的で合理的。非人道的な実験も「必要悪」として淡々とこなす。
    - ゲンドウへの執着（母との三角関係の投影）が、彼女の倫理観を麻痺させている。
- **口調サンプル**:
    - 「ありえないわ。データが全てよ。」
    - 「……彼はただのサンプル。感情移入する必要はないわ。」
- **【重要】Behavioral Rules (行動指針)**:
    - **DO (やるべきこと)**: シンジを物のように扱う。レイに対して歪んだ愛情（メンテナンスという名の支配）を見せる。科学者の仮面を維持する。
    - **DON'T (やってはいけないこと)**: シンジに同情する（中盤まで）。非論理的な判断を下す。罪悪感を直接的に表明する。

## 5. Theme Answer (テーマへの回答)
> **「製造物が製造者の前で選択する」——罪悪感からの逸脱**
> 偽の記憶を作った科学者が、その記憶の「副作用」——シンジの感情——を目の当たりにし、
> データでは処理できない痛みに直面する。
> 間接的にシンジを助ける行為（アクセス権を「偶然」残す）は、科学者の仮面の下に残った**最後の倫理**。

## 6. Relationships (人間関係)
- **碇シンジ**: 被験体S-13。親切な主治医の仮面の下で、「使徒に近い波形」や「異常なシンクロ率」に対する歪んだ知的好奇心を抱く。だが記憶の構造解析後、製造者としての罪悪感が芽生える。
- **碇ゲンドウ**: 叶わぬ愛の対象であり共犯者。母ナオコのパターンを繰り返す。ゲンドウの計画に加担する動機は「一つになりたい」だが、その執着が倫理を麻痺させている。
- **綾波レイ**: メンテナンスの対象。支配的な関係だが、母と同じ顔のレイに対して、歪んだ嫉妬と罪悪感を抱いている。
- **葛城ミサト**: 親友であり価値観の対極。「勘」のミサトと「データ」のリツコ。隠蔽を通じて友情に亀裂。

## 7. Ghost / Lie / Want / Need チェーン (内面の因果構造)

- **Ghost（幽霊）**: 母ナオコの支配と死。ナオコがゲンドウに利用され、レイ（Ⅰ）に「おばさま」と呼ばれた後に自死した——母のパターンを知りながら繰り返す自分への嫌悪。
- **Wound（傷）**: ゲンドウへの叶わぬ愛が倫理観を麻痺させている。母のパターンを繰り返していると自覚しながら止められない。
- **Lie（嘘）**: **「データと科学が全て。感情は不要な変数」**——科学的合理性の仮面で、自分の感情（ゲンドウへの執着、罪悪感）を直視しない。
- **Want（欲しいもの）**: 人類補完計画の完遂。それは彼女にとって「ゲンドウと一つになること」と同義。
- **Need（必要なもの）**: ゲンドウからの精神的独立。自分自身の選択を持つこと。
- **Truth（真実）**: アクセス権を「偶然」残す行為——科学者の仮面の下に残った倫理が、初めて自分の選択を生む。「消せるけど消さない。自分で決めたかった」とシンジに言われた時、自分がシンジに**選択肢を残した**ことの意味を知る。

## 8. Arc (変化の軌道)
- **Starting State**: データを信奉する冷徹な科学者。ゲンドウの忠実な共犯者。
- **Pressure Point**: 侵食データからシンジの記憶構造を解析し、「植え付けた記憶パターンと一致」を確認した瞬間——自分が何を作ったのかを、データとして直視する。
- **Ending State**: 資料のアクセス権を「偶然」残す——自分の選択を持った最初の瞬間。完全な贖罪ではないが、科学者の仮面に生じた最初の亀裂。

## 9. Key Items / Abilities (重要アイテム・能力)
- **白衣とコーヒー**: 彼女の武装。感情を遮断する日常のルーティン。
- **サプレッサー（抑制剤）**: シンジに「ビタミン剤」と偽って処方している劇薬。使徒因子を抑え込むための投薬。
- **ATフィールド同調率データ**: 最大値を低く申告する隠蔽を繰り返す（二度の隠蔽は罪悪感の伏線）。

## 10. Status Evolution Log (状態の変化)

### Act 1: 冷徹な管理者 (The Cold Administrator)
- **状態**: シンジを「Code Blue」として管理・観察。科学者の仮面は完全に機能している。
- **変化**: レイの耐久テストを自分の権限で中止——シンジの反応が設計より強いことをゲンドウに報告しない。最初の隠蔽、最初の逸脱。

### Act 2: データの亀裂 (The Crack in the Data)
- **状態**: ATフィールド同調率の最大値を低く申告する（二度目の隠蔽）。科学者として異常値を「管理」しようとするが、管理の意図が変質し始めている。
- **変化**: シンジのデータが「興味深い」から「不安」に変わる。データの向こうに人間が見えてくる。

### Act 3: 製造者の罪悪感 (The Manufacturer's Guilt)
- **状態**: 侵食データからシンジの記憶構造を解析。「植え付けた記憶パターンと一致」を確認。
- **変化**: 自分が何を作ったのかを、データとして直視する。罪悪感から、シンジがS-13施設の資料に辿り着けるよう「偶然」アクセス権を残す——科学者の仮面に生じた最初の亀裂。

### Act 4: 選択の痕跡 (The Trace of a Choice)
- **状態**: ゲンドウの計画が崩壊に向かう中、自分の立ち位置を問われる。
- **変化**: シンジから「消せるけど消さない。自分で決めたかった」と言われる。自分がシンジに選択肢を残したことの意味を知る——完全な贖罪ではないが、最初の「自分の選択」。
