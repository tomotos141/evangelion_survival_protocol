# Ep.10: 侵食 (The Erosion)

## 位置づけ
- **Act 3: 包囲** の第2話。【使徒戦④：寄生型】
- Ep.9の「檻」から解放されたシンジの精神が脆くなったところに、寄生型使徒が襲来
- シンジの記憶がフラッシュバックで漏れ出す——偽の記憶の「構造」がリツコの手に渡る
- アスカの残響が最も強く疼く回。無防備なシンジの傍で涙を流す
- レイのATフィールドが悪夢を止める——静かな奇跡

## テーマ
「夢と記憶の境界が溶ける時、漏れ出したものは——嘘だった」

## 使徒設計：寄生型（第7使徒）

### 外見
- 初期形態：黒い粒子状の生物群。蟲の群れのように見える
- エヴァの装甲に取り付くと、表面を覆う黒い苔のように広がる
- 完全寄生状態では装甲と融合し、エヴァの輪郭が歪む——腕が伸び、背中に突起が生える。エヴァが「別の生き物」に変わっていく

### 能力：精神寄生
- エヴァの神経接続を通じてパイロットの精神に侵入する
- パイロットの精神を「養分」として消費し、自らの成長に転換する
- 侵食が進むにつれ、パイロットの意識が薄れ、**夢と現実の境界が消失**する
- 記憶が「漏出」する——うわごと、体の動き、モニターに映る脳波パターンとして外部に流出
- コアは存在しない。**パイロットの意識そのものが使徒のコア**。パイロットを覚醒させる以外に倒す方法がない

### 裏設計
- ゲンドウが「浸食テスト」として配置した使徒
- 目的：シンジの記憶構造を外部から読み取ること。侵食中の脳波パターンから「植え付けた記憶」のアーキテクチャが解析可能
- リツコがデータを取得する口実を作るための使徒

## シーン構成

### シーン1：黒い粒子

- 作戦会議。ジオフロント外縁で未知の汚染パターン検出
- 映像：EVAケージの外壁に、黒い粒子が付着している。苔のように、ゆっくりと広がる
- リツコ：「パターン青。……だが、実体がほとんどない。ATフィールドも検出されていない」
- ミサト：「攻撃してこないの？」
- リツコ：「今のところは。だが……増殖している」
- 出撃命令。シンジが初号機に乗る
- コクピットに座った瞬間、頭の奥で何かが蠢く感覚。ノイズのような、微かな耳鳴り
- シンジ独白：（……檻から出たばかりで、また戦場か。体が重い）
- Ep.9の「保護措置」で精神が削られている。そこに寄生型の使徒

### シーン2：装甲が食われる

- 初号機が出撃。黒い粒子群に接近する
- ATフィールドを展開——粒子はATフィールドをすり抜ける。物理的な存在ではなく、**精神的な存在**
- 黒い粒子が初号機の装甲に取り付き始める。足元から、腰へ、胸部装甲へ
- リツコ：「まずい。神経接続を通じてパイロットに——」
- ミサト：「強制排出！ エントリープラグを——」
- 間に合わない。黒い苔が神経接続端子を覆った瞬間、シンジの意識が**揺れる**
- 視界がぶれる。コクピットの計器盤が滲む。自分がどこにいるか分からなくなる
- 初号機が膝をつく。制御不能

### シーン3：夢が浸水する

- シンジの意識の内部。夢と現実の境界が溶けている
- コクピットにいるはずなのに、見えるのは——ミサトのキッチン。レイの白い部屋。アスカの背中。学校の廊下
- 偽の記憶がフラッシュバックとして噴出する。制御できない
- 「1周目」の記憶が——映像として、音声として、体の感覚として漏れ出す
- シンジの口が勝手に動いている。うわごと。発令所のスピーカーから声が漏れる
- 「……綾波……逃げて……使徒が……」
- 「……ミサトさん……ミサトさんが……死んだ……」
- 「……アスカ……アスカ……ごめん……」
- 発令所が凍りつく。シンジの口から出ているのは、経験していないはずの出来事の断片
- ミサトの顔が青ざめる。「ミサトさんが死んだ」——あの夜、シンジが泣きながら言った言葉の、具体的な映像が漏れている
- オペレーター：「脳波パターン異常！ 記憶領域の活性度が通常の400%を超えています！」
- リツコの指が震えている。モニターに映る脳波パターン——それは、**リツコが設計した記憶インプラントのアーキテクチャと一致している**

### シーン4：アスカの名

- 弐号機のケージ。アスカが出撃準備をしている
- 発令所のスピーカーからシンジのうわごとが聞こえる
- 「……アスカ……ごめん……アスカ……」
- アスカの手が止まる
- 自分の名前。あの少年の口から、苦しそうに、何度も
- 残響が——**爆発する**。胸の奥で何かが割れる音がする
- この声を知っている。聞いたことがある。**前に**。いつ。どこで
- 記憶にはない。でも体が覚えている。この声で名前を呼ばれた時の、胸が軋む感覚
- アスカ：「……っ」——ヘルメットを外す。出撃しない。走る。ケージから、医療棟へ
- ミサト：「アスカ！ どこへ——」
- アスカは止まらない

### シーン5：医務室

- 初号機は強制的にケージへ回収。寄生体はエヴァと分離不能の状態
- シンジはエントリープラグから引きずり出され、医務室に搬送される
- 意識不明。だが体が痙攣し、うわごとが止まらない。夢の中で使徒と戦っている——正確には、使徒がシンジの記憶を食い続けている
- モニターの脳波が不規則に跳ねるたびに、シンジの唇が動く。聞き取れない言葉。時折、名前
- 医療スタッフが退室した後——アスカが来る
- ドアの前で立ち止まる。数秒。そして入る
- シンジの顔を見る。汗まみれで、苦しそうで、子供のように小さい
- ベッドの傍に座る。椅子の背もたれに手を置くが——手が震えている
- アスカ：「……なんで。なんであたしの名前呼ぶのよ。あんたに、あたしの何が分かるの」
- 返事はない。シンジは眠り続けている
- 時間が流れる。アスカは動かない。見張りのように、あるいは祈りのように
- シンジの顔が歪む。悪夢がひどくなっている。手が無意識にベッドのシーツを握りしめる
- アスカが——自分でも理由が分からないまま、その手に触れる
- 冷たい。だが触れた瞬間、残響が最も強く、最も静かに疼く
- 涙が出る。泣くつもりなどなかった。泣く理由もない。初対面のはずの少年の手に触れただけで
- でも涙が止まらない。体が泣いている。魂が覚えているものが、目から溢れている
- アスカ：「……バカ。あんたなんか、知らないのに」

### シーン6：レイの来訪

- 深夜。医務室の照明が落とされている
- アスカは椅子に座ったまま眠ってしまっている。シンジの手にはまだ触れたまま
- ドアが音もなく開く。レイが入ってくる
- レイはアスカを見る。アスカの頬に涙の跡がある。そしてシンジの手を握っている
- レイは何も言わない。アスカを起こさない
- ベッドの反対側に回る。シンジの額に手を置く
- そして——ATフィールドを展開する。ごく微小な、医療機器にも反応しないほど小さなフィールド
- シンジの額から、レイの手を通じて、静かなフィールドが広がる
- シンジの脳波が変わる。不規則な跳ねが収まっていく。悪夢の嵐の中に、凪が生まれる
- レイのATフィールドが使徒の精神侵食を押し返しているのではない。ただ、**シンジの精神に安全な場所を作っている**
- シンジの表情が緩む。苦痛が薄れる。手の力が抜ける
- レイ：「……碇くん。ここにいるわ」
- アスカがそれを聞いたかどうかは分からない。でもアスカの眠りも少しだけ深くなる

### シーン7：リツコの分析——真夜中の罪

- リツコの研究室。深夜。モニターに囲まれている
- 侵食中のシンジの脳波データ。通常では見ることのできない、記憶領域の深層パターン
- リツコの指がキーボードの上で止まる
- パターン照合の結果が出ている。シンジの漏出した記憶の構造——それは、**リツコ自身が設計した記憶インプラントのアーキテクチャと完全に一致している**
- 植え付けた記憶が、使徒の侵食で表層に押し出され、そのまま漏れている
- リツコ：「……やっぱり。やっぱり、そうだったのね」
- 知っていた。設計したのは自分だから。でも確証を目の前にすると——手が震える
- あの少年の中にある「前の世界の記憶」は、リツコが技術的に書き込んだ偽物
- ゲンドウの命令で。ユイを取り戻すという妄執のために。あの14歳の少年を素材にして
- リツコはデータを保存する。ゲンドウへの報告書を書き始める——だが
- 途中で手が止まる
- レイの声が頭に蘇る。「碇くんは、壊れていますか」「約束する」とリツコは言った
- リツコがやったこと：報告書のデータから、最も重要な部分——**記憶インプラントとの照合結果**——を削除する
- ゲンドウには「使徒の侵食パターンの解析データ」だけを渡す。シンジの記憶が偽物だという確証は、報告しない
- そして——シンジが将来この資料に辿り着けるよう、ゼーレの実験施設のアクセス権を「偶然」残す。データベースの削除漏れを装って
- リツコ：「……これで、あの子が自分で辿り着けるかもしれない」
- 三度目の隠蔽。だが今回は、ゲンドウから隠すだけでなく——**シンジに鍵を渡す**行為
- Ep.12でシンジがゼーレの施設にたどり着く、その「偶然」の正体

### シーン8：目覚め

- 翌朝。シンジが目を開ける
- 最初に見えるのは白い天井。医務室。既視感——Ep.9の白い部屋
- だが今回は違う。横を見ると——アスカが椅子で眠っている。猫背で、不自然な姿勢で
- そしてベッドの反対側、壁に寄りかかるようにして——レイが目を閉じている
- シンジは動けない。全身が泥のように重い。使徒に食われた精神の残滓
- でも——二人がいる。この部屋に
- アスカが目を覚ます。シンジと目が合う
- 一瞬の沈黙。アスカが自分の手を見る——シンジのシーツの上に置かれたままだった手。慌てて引っ込める
- アスカ：「っ……。起きたの。……別に、あたしはただ、当直の代わりに」
- シンジ：「……ありがとう」
- アスカ：「お礼なんかいらない。勘違いしないで」
- 三度目の「勘違いしないで」。でも今回は——声が震えている
- レイも目を開ける。シンジを見る。微かに、本当に微かに——口角が動く
- レイ：「……おはよう、碇くん」
- シンジの目に涙が滲む。泣きたいわけではない。ただ——生きて戻ってきた
- エヴァの外壁に寄生していた使徒は、レイのATフィールドがシンジの精神を安定させたことで養分供給が断たれ、衰弱して消滅した。物理的な勝利ではなく——精神の回復による勝利
- ミサト：（扉の外に立っている。入れない。入る資格がないと思っている）

## タイトル「侵食」の多義性
1. **使徒の精神侵食**——寄生型使徒がシンジの精神を食い荒らす
2. **記憶の侵食**——偽の記憶が表層に漏れ出し、シンジの「現在」を侵食する
3. **残響の侵食**——アスカの中で残響がさらに深く根を下ろす。涙が出るほどに
4. **罪の侵食**——リツコの良心が、ゲンドウへの忠誠を侵食し始める
5. **信頼の侵食**——ミサトとシンジの間の信頼に、Ep.8-9の亀裂が広がっている

## 構造的な仕掛け

| 要素 | 設計意図 |
|------|---------|
| 寄生型使徒 | 物理攻撃で倒せない。パイロットの精神回復だけが勝利条件。「戦わない使徒戦」 |
| 記憶の漏出 | 偽の記憶がうわごとで漏れる→リツコが記憶構造を確認。技術的な証拠がここで確定する |
| 「アスカ」の名 | シンジが苦しみの中でアスカの名を呼ぶ。残響がアスカの中で最大振幅に達するトリガー |
| アスカの涙 | 理由なき涙。魂が覚えているものが溢れる。Ep.13でレイが「惣流さんの涙は誰にもプログラムできない」と言える根拠 |
| レイのATフィールド | ごく微小な展開で精神を安定させる。Ep.6の坑道での共鳴の発展形。静かな奇跡 |
| リツコの鍵 | アクセス権の「偶然」の削除漏れ。三度目の隠蔽だが、今回はシンジに鍵を渡す積極的行為 |
| ミサトの扉の外 | 医務室に入れないミサト。善意の裏切りの代償が、物理的な距離として表現される |
| 二人の目覚めの立ち会い | アスカ＝手に触れている（感情の証明）。レイ＝ATフィールドで守った（存在の肯定）。二つの愛の形が一つの部屋に |

## Ep.9からの接続
- Ep.9で精神が削られたシンジ→使徒の侵入が容易になる
- ゲンドウの「浸食テスト」宣言が実行される
- アスカの「不在の痛み」(Ep.9) → シンジの名前に反応して走り出す（Ep.10）
- レイのリツコへの「約束」(Ep.9) → リツコの良心が動く伏線の回収

## Ep.11への接続
- リツコが残した「鍵」→ Ep.12でシンジが施設に辿り着く
- シンジの記憶漏出のデータ → ゲンドウが「次のフェーズ」を判断する材料
- 目覚めの朝、シンジの中に芽生えた「生きて戻ってきた」感覚が、Ep.11でカヲルの「全部終わらせよう」に対する抵抗力になる
- アスカの涙 → 理由が分からない感情が、Ep.12で施設に「導かれる」原動力に
