# Ep.11: 渡し守 (The Ferryman)

## 位置づけ
- **Act 3: 包囲** の第3話。使徒戦なし——真実が語られる回
- **転換④発火**：「学習する世界」の正体はゲンドウとゼーレが設計した檻だった
- カヲル登場回。第5のパイロット候補としてNERVに公式配属される
- カヲルとシンジ、「作られた存在」同士として語り合う——物語で最も静かで、最も残酷な対話

## テーマ
「真実は、渡し賃を要求する。知ったら、もう戻れない」

---

## カヲルの設定

### 正体
- ゼーレが送り込んだ「観察者」。使徒の因子を持つ存在
- ゼーレのシナリオを知っているが、ゼーレに完全に忠実ではない。自分の意志で動く余地がある
- シンジと「同じ側」——作られた存在、使い捨てのコマ。その共感は本物
- ゼーレは「シンジの精神を最終的に壊す」ためにカヲルを投入した。だがカヲルは「壊す」のではなく「知らせる」ことを選ぶ

### NERVでの立場
- 第5のパイロット候補として公式配属。書類上はユーロ支部残存プロジェクトからの転籍
- ゲンドウはカヲルの正体を知っているが、ゼーレとの政治的バランスのため受け入れる
- 他のパイロットからは「新しいパイロット候補」として認識される

## シーン構成

### シーン1：第5の子供

- NERV発令所。全パイロットへの通達
- 「第5のパイロット候補として、渚カヲルが着任する」
- ミサト：「ユーロ支部の残存プログラムから……？ 今のタイミングで？」
- リツコ：「上からの人事よ。——ゼーレの推薦」
- ミサトの目が鋭くなる。ゼーレの名前が出た瞬間、空気が変わる
- 着任式。制服を着た銀髪の少年が、穏やかな微笑みで立っている
- カヲル：「はじめまして。渚カヲルです。——よろしくお願いします」
- 第一印象：完璧に礼儀正しい。完璧に穏やか。完璧に——**不自然**
- シンジの偽の記憶が反応する。カヲルの名前を知っている。だが——記憶の中のカヲルと、目の前のカヲルの「温度」が違う
- レイがカヲルを見ている。表情はない。だがATフィールドが微かに揺れている。何かを感じ取っている
- アスカ：「ふぅん。また一人増えるの。——足手まといにならないでよね」
- カヲルがアスカに微笑む。アスカは目を逸らす。あの笑顔の裏に何があるか分からないから

### シーン2：同調テスト

- カヲルの同調テスト。エヴァ（仮設弐号機のスペアパーツ機体）に乗る
- 結果：異常なシンクロ率。初回で62%
- リツコ：「……ありえない。通常、初回は20%前後よ。パイロット経験がなければ」
- ミサト：「経験があるの？」
- リツコ：「書類上はない。……だからこそ不自然なの」
- ゲンドウはモニターを見ているが、何も言わない。知っている
- テスト後、シンジがカヲルに話しかけられる
- カヲル：「碇シンジくん、だよね。……少し、話せるかな」
- シンジ：「……僕に何か？」
- カヲル：「初めての場所は不安だから。先輩に聞きたいことがあるんだ」——自然な口実
- シンジは断る理由がない。二人で歩き始める

### シーン3：最初の対話——屋上

- NERV施設の屋上。人工的な星空の下
- カヲルが柵に寄りかかる。風が銀色の髪を揺らす
- 最初は普通の会話。NERVの施設のこと、パイロットのこと、食堂の味のこと
- だがカヲルの質問には——常に裏がある
- カヲル：「碇くんは、エヴァに乗ることをどう思ってる？」
- シンジ：「……怖いよ。でも、乗らなきゃいけないから」
- カヲル：「誰のために？」
- シンジ：「……みんなのために。綾波とか、アスカとか、ミサトさんとか」
- カヲルが微笑む。その笑顔が——少しだけ、寂しそうに歪む
- カヲル：「……君は、優しいんだね。でも——その"みんな"を守りたい気持ちは、いつから？」
- シンジ：「え？」
- カヲル：「最初から？ それとも——**誰かにそう思うように作られた**？」
- シンジの心臓が跳ねる。カヲルの言葉が、檻の中でゲンドウが投げた問いと重なる
- シンジ：「……何を言ってるの」
- カヲル：「ごめん。変なことを聞いた。——忘れて」
- でもシンジは忘れられない。「作られた」という言葉が、棘のように刺さったまま

### シーン4：アスカとカヲル

- 訓練後の更衣室付近。アスカがカヲルとすれ違う
- カヲル：「惣流さん」
- アスカ：「……何」
- カヲル：「君の弐号機、美しいね。ユーロ支部の子が——よく一人で守ったものだ」
- アスカの目が鋭くなる。ユーロ支部のことを知っている。データを見たのか、それとも——
- アスカ：「……あんたには関係ない」
- カヲル：「そうだね。——でも、一人で背負わなくてもいいんだよ」
- アスカ：「はぁ？ 何様のつもり。あたしに説教？」
- カヲルは笑って去る。アスカが睨む。でも——言葉が刺さっている
- 「一人で背負わなくてもいい」。その言葉を、残響が受け取っている。前にも、誰かが同じことを言った気がする

### シーン5：レイの直感

- レイが端末でカヲルのデータを見ている
- 公式の経歴。ユーロ支部、パイロット候補育成プログラム、身元保証人——ゼーレ
- レイ：（……この人は、違う）
- ATフィールドの残響。着任式でカヲルの近くにいた時、レイのフィールドが反応した
- 使徒の因子。レイ自身が持っているものと——**同じ波長**
- レイはシンジに言うべきか迷う。でも確信がない。そして——カヲルがシンジを「壊そうとしている」のか「助けようとしている」のかが分からない
- レイ：「……見ている、しかできない」
- 静かな見守り。Ep.5から変わらないレイの在り方

### シーン6：二度目の対話——真実の入口

- 数日後。カヲルがシンジを呼び出す。今度はジオフロントの人工湖
- 水面に映る二人の影。カヲルが石を投げる。波紋が広がる
- カヲル：「碇くん。一つ聞いてもいい？」
- シンジ：「……うん」
- カヲル：「君の"記憶"——使徒との戦い方を知っていたこと。ヤシマ作戦のこと。……それが、**どこから来たか**、考えたことはある？」
- シンジの呼吸が止まる。カヲルが——知っている
- シンジ：「……なんで、それを」
- カヲル：「僕も、"作られた"側だから」
- 沈黙。水面の波紋が消えるまでの長い時間
- カヲル：「僕はゼーレに作られた。君は——碇ゲンドウに」
- シンジ：「何を——」
- カヲル：「まだ全部は言えない。でも一つだけ。——君が戦ってきた使徒は、偶然君の前に現れたわけじゃない」
- シンジの世界が軋む
- カヲル：「サキエル。ラミエル。鏡の使徒。寄生体。——全て、**君の行動データを使って、戦場が設計されていた**」
- **転換④**。ハードモードは天災ではなく——**父が設計した檻**
- シンジ：「……嘘だ」
- カヲル：「嘘だったらいいのにね。僕もそう思うよ」——その声が、本当に悲しそうで
- シンジの膝が折れる。湖畔の砂利に膝をつく
- 全ての戦闘が。レイと這った坑道も。アスカと割った鏡も。全てが——**ゲンドウに見られて、設計されて、テストされていた**
- シンジ：「……なんで。なんで教えてくれるの」
- カヲル：「君は知るべきだと思ったんだ。……知った上でどうするかは、君の自由だよ」
- カヲルの手がシンジの肩に触れる。その手は——温かい。使徒の因子を持つはずの存在の手が

### シーン7：世界の底で

- 夜。シンジがNERVの廊下を歩いている。どこへ向かうでもなく
- カヲルの言葉が頭の中で反響している
- 「戦場が設計されていた」——あのラミエルの光が初号機を撃ったのは、ゲンドウが仕組んだから？
- あの坑道でレイと手を繋いだのは、ゲンドウが見ていたから？
- あの鏡の空間でアスカと連携したのは、ゲンドウのテストだったから？
- 全てが——全部が、台本の上
- （いや。台本じゃない。設計だ。僕は設計図の上で踊っていただけだ）
- 足が止まる。壁に手をつく
- 吐き気。でも胃は空っぽで何も出ない。乾いた嗚咽だけが廊下に響く
- ミサトに話したこと。あの夜の涙。「みんなが死ぬのを見た」——あの「記憶」すら、誰かが植え付けたものだとしたら
- （僕の涙は、本物だったのか）
- 答えが出ない。答えが出ないまま、シンジは歩き続ける

### シーン8：アスカの扉

- シンジが辿り着いたのは——アスカの部屋の前
- なぜここに来たか分からない。足が勝手に来た
- ドアの前で立ち止まる。ノックしようとして——手が止まる
- （アスカの名前を呼んだ記憶も。あの戦闘で体が連携した感覚も。全部、設計通りなら）
- （僕が彼女を「知っている」気持ちも、作り物だったら）
- ドアをノックしない。立ち去る
- 部屋の中で、アスカが起きている。足音を聞いていた。誰かがドアの前に来て、そして去ったことを
- アスカ：「……」
- ドアを開けない。開ける理由がないから。でも——心臓が速く打っている
- 二人の間にドアがある。それだけの距離なのに、今は宇宙よりも遠い

### シーン9：カヲルの独白

- NERVの一室。カヲルが窓辺に立っている
- 月が見える。人工のジオフロントの天蓋に映る偽の月
- カヲルの独白。読者だけが聞く
- （碇くん。君に全部を話すことはまだできない。「記憶が偽物だ」という最後の真実は、君自身が辿り着かなければ意味がない）
- （僕ができるのは道を示すことだけ。渡し守として——川の向こう側があることを教えるだけ）
- （でも。もし君が壊れてしまったら——僕には「終わらせる」方法がある）
- カヲルの手が自分の胸に触れる。使徒のコアが鼓動している
- （サードインパクト。全てを白紙にすれば、誰も苦しまなくなる。それは——慈悲かもしれない）
- （でも、まだだ。まだ、碇くんが選ぶ前に終わらせるわけにはいかない）
- カヲルの目が閉じる。偽の月に照らされた銀色の髪
- Ep.13でカヲルが「全部終わらせよう」と提案する——その伏線。善意からの提案だが、最終手段でもある

### シーン10：設計者の報告

- ゲンドウの執務室。リツコが報告に来ている
- リツコ：「浸食テストの解析結果です。使徒の侵食パターンと、パイロットの精神構造の相関データ」
- ——記憶インプラントとの照合結果は含まれていない。リツコが削除した
- ゲンドウ：「渚カヲルの接触は」
- リツコ：「予定通り。シンジ君に情報の断片を渡した模様です」
- ゲンドウ：「問題ない。真実を小出しにすることで精神を段階的に追い詰める。一度に全てを知らせるよりも——効率的だ」
- ゲンドウにとって、カヲルの「真実の開示」すらシナリオの一部。だが——
- ゲンドウ：「記憶構造の完全解析は」
- リツコ：「……データ量が膨大で、完了には時間がかかります」
- 嘘。データは既に確認した。だがゲンドウには渡していない
- ゲンドウ：「急げ」
- リツコ：「はい」
- 退室するリツコ。廊下で——自分の胸を押さえる
- （嘘をついた。碇司令に。……もう、戻れない）
- レイの「約束」、シンジの涙、アスカの名を呼ぶうわごと——全てが、リツコの中の何かを変えた
- 科学者が「倫理」を選び始めた瞬間。だがその選択が正しかったのかは、まだ分からない

## タイトル「渡し守」の多義性
1. **カヲル＝渡し守**——三途の川の渡し守。真実という「対岸」へシンジを渡す役割
2. **渡し賃**——真実を知ることの代償。知ったら元の世界には戻れない
3. **渡す者と渡される者**——カヲルは真実を渡すが、自分は対岸に行けない。作られた存在の悲しみ
4. **リツコの渡し**——鍵を渡す。ゲンドウ側から、シンジ側へ。リツコ自身も川を渡り始めている
5. **ドアの前の渡し**——シンジがアスカの部屋の前まで来て、渡らずに去る。まだ渡れない川

## 構造的な仕掛け

| 要素 | 設計意図 |
|------|---------|
| NERV内部からの登場 | カヲルを公式の立場に置くことで、自然にシンジに接近できる。怪しさと公的な信頼が共存 |
| 異常なシンクロ率 | 使徒因子を持つ存在の証拠。リツコの疑念、ゲンドウの承知が描かれる |
| 段階的な真実開示 | 最初の対話で種を撒き、二度目で核心を告げる。一気に崩さず追い詰める構成 |
| 「作られた側」の共感 | カヲルとシンジの共通点。だが対処法が違う——カヲルは「終わらせる」、シンジはまだ選んでいない |
| アスカの扉 | 物理的に近いのに精神的に最も遠い。ドアをノックしない選択が、Ep.12での「近づかないで」の伏線 |
| リツコの嘘 | データを隠す＝ゲンドウへの反逆の始まり。Ep.12で「偶然のアクセス権」として実を結ぶ |
| 偽の月 | ジオフロントの天蓋に映る偽の月をカヲルが見る。偽物の中にいる「作られた存在」の象徴 |
| ゲンドウの「効率的」 | カヲルの真実開示すら利用する冷徹さ。だがリツコのデータ隠蔽は計算外 |

## Ep.10からの接続
- Ep.10で精神が消耗したシンジ → カヲルの真実を受け止める余力が少ない
- リツコの記憶構造確認(Ep.10) → 報告書の改竄(Ep.11)
- アスカの涙(Ep.10) → カヲルの「一人で背負わなくてもいい」が刺さる
- レイの直感 → カヲルの使徒因子に反応するATフィールド

## Ep.12への接続
- カヲルの真実（「戦場が設計されていた」）→ Ep.12で「記憶が偽物」という最終真実へ
- リツコの鍵（アクセス権の削除漏れ）→ シンジがゼーレの施設を発見する
- アスカの扉 → Ep.12「近づかないで。僕の中の君は、作り物だ」の伏線
- カヲルの「終わらせる方法」→ Ep.13でカヲルが正式に提案する
- シンジの「僕の涙は本物か」→ Ep.12で培養槽の映像を見た時に最も残酷に反復される
