# Ep.9: 檻 (The Cage)

## 位置づけ
- **Act 3: 包囲** の第1話。使徒戦なし——人間が敵になる回
- Ep.8 の転換③（ミサトの善意の裏切り）が直接のトリガー。ゲンドウが「保護」の名目でシンジを隔離する
- **感情定着の剥離テスト**：レイやアスカの映像を見せてシンジの反応を観察。シンジが「実験動物」だと気づく瞬間
- ミサトの後悔、アスカの不在の痛み——シンジ不在の間に、周囲のキャラクターも変化する

## テーマ
「守るつもりだった手が、檻の鍵を回していた」

---

## シーン構成

### シーン1：「保護」の通達

- 朝。シンジがNERVに呼び出される
- ミサトに連れられて歩く。ミサトの表情が固い。何かを隠している
- 「精神状態の診断と安定化のための一時的な保護措置」——ミサトの口から出るのは官僚的な説明
- シンジ：「……保護？」
- ミサトは目を合わせない。シンジを医療棟の奥、見慣れない区画へ案内する
- 白い部屋。ベッドと机と監視カメラ。窓はない
- シンジの記憶が反応する——レイの「調整室」と同じ匂い。消毒液と、人工的な清潔さ
- ミサト：「すぐに終わるから。……ごめんね」
- ドアが閉まる。ロックの電子音。シンジは一人になる
- （シンジはまだ気づいていない。ミサトが泣きそうな顔をしていたこと）

### シーン2：最初のテスト——「質問」

- 時間の感覚が曖昧な部屋。何時間経ったか分からない
- ドアが開く。入ってくるのは——リツコ
- リツコの表情は事務的。だが手元のタブレットを握る力が微かに強い
- 「いくつか確認をさせて。これは通常のメンタルスクリーニングよ」
- 質問が始まる。最初は普通——好きな食べ物、最近の睡眠時間、ストレスの自覚
- だが徐々にベクトルが変わる
- 「碇くん。……綾波レイについて、どう思う？」
- シンジが戸惑う。「どう思う」とは？
- 「惣流さんについては？」
- 「葛城三佐は？」
- 人物名が出るたびに、シンジの瞳孔径、心拍数、皮膚電位がリアルタイムでモニタされている
- シンジはそれに気づいていない。リツコの背後のモニターに、自分の生体データが波形になって流れている

### シーン3：映像

- 二度目のセッション。今度はリツコではなく、モニターだけが起動する
- 映像が映る
- 最初はレイの「調整」の記録映像。あの白い部屋で、ベルトに固定され、声を上げないレイ
- シンジの拳が握られる。あの夜の記憶が蘇る。嘔吐したくなる衝動を抑える
- 次に——ユーロ支部の壊滅映像。アスカの弐号機が一機で使徒と戦っている。一人で、ボロボロになりながら
- シンジの呼吸が浅くなる。知っている。記憶の中のアスカも、いつもこうだった。一人で戦って、一人で壊れていった
- だがこの映像は偽の記憶の中のものではない。**今の、この世界の**アスカの戦い
- 最後の映像——シンジ自身。監視カメラからの映像。レイの前で泣いているシンジ。アスカと連携訓練をしているシンジ。ミサトのキッチンで涙を流しているシンジ
- 自分を外側から見る異様さ。あの夜の涙も、あの戦闘の恐怖も、全てカメラに記録されていた
- シンジの中で、何かが切り替わる
- 「……これは、テストですか」
- 返答はない。モニターが消える。白い部屋に戻る
- シンジは自分の手を見る。震えている。感情のせいではない——**自分が観察されていると気づいた**震え
- （実験動物が、自分が実験動物だと気づいた瞬間）

### シーン4：ゲンドウの登場

- 三度目のドアが開く。今度は——ゲンドウ
- 手を組んだ姿勢。サングラスの奥の目は見えない
- 長い沈黙。ゲンドウがシンジを見ている。シンジがゲンドウを見上げている
- ゲンドウ：「お前の"記憶"は、どこまで正確だ？」
- シンジの心臓が止まる
- 「記憶」という言葉。ゲンドウは知っている。シンジが「前の世界」のことを知っていると、最初から
- シンジ：「……何を、言って」
- ゲンドウ：「とぼけるな。お前はヤシマ作戦を知っていた。地中侵攻では冷静すぎた。惣流を初対面で知人のように見た」
- 全て見られていた。全て記録されていた。Act 1から、一度も
- ゲンドウ：「もう一度聞く。お前の記憶は、どこまで正確だ」
- シンジは答えられない。「正確だ」と言えば利用される。「知らない」と言えば嘘がバレる
- 沈黙が檻になる。ゲンドウは急がない。この沈黙こそが「剥離テスト」の本体だから
- ゲンドウが立ち去る。何も言わずに。ドアが閉まる
- シンジは膝を抱えて座り込む。歯が鳴っている

### シーン5：ミサトの後悔

- ミサトの執務室。デスクに座ったまま動けない
- シンジの「保護措置」の書類が目の前にある。自分がサインした書類
- 「保護」のはずだった。この子を守るためだった
- だがシンジが隔離されてから36時間、ミサトにはシンジとの面会が許可されていない
- ミサト：（……あたしが、あの子を売ったの？）
- 廊下でリツコとすれ違う。リツコの表情が疲弊している。何かを抱えている顔
- ミサト：「リツコ。シンジ君は——」
- リツコ：「予定通り進行中よ」——素通りする
- 「予定通り」。保護ではない。**予定**
- ミサトがゲンドウの執務室へ向かう。拳を握りしめて
- 「司令。シンジ君の保護措置について、経過報告を——」
- ゲンドウ：「必要ない」
- ミサト：「……なぜ面会が許可されないんですか。あの子は——」
- ゲンドウ：「葛城三佐。君は報告を上げた。それは正しい判断だった。あとは我々が対応する」
- 「我々が対応する」。その一言に、ミサトの善意が粉砕される
- ミサト：「……シンジ君は、被験者ですか」
- ゲンドウ：沈黙。サングラスの奥から、感情のない目がミサトを見る
- ミサト：「答えてください、司令！」
- ゲンドウ：「下がれ」
- ミサトが退室する。廊下で壁に手をつく。膝が震えている
- （あたしが……あたしのせいだ。あの子を信じて受け止めたつもりで、あの子を檻に閉じ込めた）

### シーン6：アスカの苛立ち

- NERVの訓練施設。アスカが一人でシミュレーターに入っている
- スコアは出ている。だが苛立っている。何かが足りない
- 鏡の使徒との戦闘以来——一人で戦うと、体の動きに違和感がある。**隣にいるはずの何かが、いない**
- アスカ：「……っ、何よこれ。集中できない」
- 足が勝手に半歩引く。弐号機の左側を空けるような動き。誰かのための空間
- アスカはそれに気づいて、操縦桿を殴る
- 「あいつ、何日休んでるのよ。サボり？ 根性なし」
- レイが訓練室の入口に立っている。無言で
- アスカ：「何。用がないなら消えて」
- レイ：「碇くんは、今……」
- アスカ：「知らない。興味ない。あいつが何してようと、あたしには関係ない」
- レイが何か言いかけて、やめる。静かに去る
- アスカが一人残される。シミュレーターの中で、自分が空けた「隣のスペース」を見つめている
- 内心：（なんであたしは、あいつがいないだけで、こんなに調子が狂うの）
- 残響が疼く。「不在」の痛み。記憶にはないのに、この空白を知っている

### シーン6.5：アスカの突撃——Lieへの挑戦

- **アスカがシンジの居場所を知った後の行動**
- レイとの会話から、シンジが「保護」ではなく**閉じ込められている**と察する
- アスカは直接行動に出る。医療棟深層区画のセキュリティゲートへ
- 「弐号機パイロット、惣流・アスカ・ラングレー。碇シンジの面会を要求する」
- 守衛：「面会不可です。司令の——」
- アスカ：「あたしはNERVの正規パイロットよ。連携相手の状態確認は作戦上の義務。——**あたしの戦績を見てからものを言いなさい**」
- ここでアスカのLie（「誰よりも優れていれば、捨てられない」）が**実力を盾にした要求**として発露する
- 守衛は動揺するが、電話一本でゲンドウの回答が来る：「却下」
- アスカ：「っ……冗談じゃない！」——ゲートに体当たりする。肩で、拳で。金属が鳴るだけ
- 保安部員が駆けつける。アスカが取り押さえられる
- アスカ：「離しなさいよ！ あたしが最高のパイロットだって分かってるでしょ！ あたしが必要なら、あいつだって——」
- 言葉が途中で止まる。自分が何を言おうとしたか、分かってしまった
- **「あいつだって必要」**。それは戦力としてか？ それとも——
- 保安部員に引き離される。廊下に一人。肩が赤くなっている
- **結果：完全な失敗**。実力も肩書きも、ここでは何の意味もなかった
- アスカの矜持が砕ける音。「最強であること」で状況を動かせなかった
- でもアスカは泣かない。代わりに壁を殴る。拳から血が滲む

> アスカ：「……力じゃ、開かないの」

- この一言がLieへの最初の亀裂。Ep.14で**力ではなく言葉で**壁を壊す反転への布石
- （Ep.14の「だったら何よ」は、拳ではなく感情をぶつける行為——Ep.9で拳が届かなかった経験が、アスカの武器を変える）

### シーン7：レイの静かな行動

- レイが端末を操作している。シンジの所在を調べている
- 医療棟の深層区画。面会不可。権限レベル不足
- レイの指が止まる。「面会不可」の文字を見つめている
- あの坑道で手を握った人が、今は白い壁の向こうにいる
- レイはゲンドウの執務室には行かない。直接対峙する方法を知らないから
- 代わりに——リツコの研究室へ向かう
- レイ：「赤木博士。碇くんは、いつ戻りますか」
- リツコ：「……まだ、分からないわ」
- レイ：「碇くんは、壊れていますか」
- リツコの手が止まる。レイの目を見る。あのクローンの目が——初めて、**問い詰めている**
- リツコ：「……壊すつもりはない。約束する」
- 約束。リツコ自身が守れるか分からない約束。だがレイはそれを受け取って、頷いて、去る
- リツコが一人残される。自分の手を見る
- （約束した。……守れるの、あたしに）
- Ep.10でリツコが「偶然」アクセス権を残す行動への、最初の種

### シーン8：解放——何も変わらない笑顔

- シンジが医療棟から出てくる。「診断完了。異常なし」の紙一枚を渡されて
- 何日ぶりかの外の空気。NERVの人工照明ではない、本物の太陽
- ミサトが出迎える。笑顔を作っている。だがその笑顔の裏を、シンジは今は見える
- シンジ：「ミサトさん。……心配かけて、ごめんなさい」
- いつものシンジの台詞。だが声のトーンが違う。感情が一枚、薄い膜の向こう側に行ってしまった
- ミサト：「ううん。もう大丈夫だから。……帰ろ」
- 二人で歩く。シンジはミサトの横顔を見ない
- 信頼は死んではいない。だが——**傷がついた**。あの部屋に閉じ込められたのは、ミサトの報告が引き金だったと、シンジはまだ知らない。でも何かが変わったことだけは分かっている
- 廊下でアスカとすれ違う
- アスカが立ち止まる。シンジを見る。何か言いたそうな顔
- シンジ：「……ただいま」
- アスカ：「……っ。別に。待ってなんかないし」——早足で去る
- でもすれ違う瞬間、シンジは見た。アスカの目が赤かったことを。泣いていたのか、眠れなかったのか
- シンジは追いかけない。追いかける余力が、今はない

### シーン9：監視者の所見

- ゲンドウの執務室。冬月が横に立っている
- モニターには「保護措置」中のシンジのデータ。感情反応の波形、瞳孔径の変化、心拍の推移
- ゲンドウ：「感情定着は想定以上だ。レイへの反応——保護欲。惣流への反応——罪悪感と未知の共鳴。葛城への反応——依存」
- 冬月：「……碇。あの少年はただの素材ではなくなっているぞ」
- ゲンドウ：「素材だからこそ、感情が深い。偽の記憶に定着した感情は、本物と区別がつかないほどに成長している」
- 冬月：「それでも続けるのか」
- ゲンドウ：「……ユイを取り戻すために必要だ」
- 冬月が黙る。ゲンドウの動機は「愛」であり、それが全てを歪めている
- ゲンドウ：「次の段階へ移行する。——浸食テストだ」
- Ep.10 への直接的な布石。使徒の投入は「偶然」ではない

## タイトル「檻」の多義性
1. **物理的な檻**——白い部屋。シンジが閉じ込められる保護室
2. **善意の檻**——ミサトの善意がシンジを閉じ込めた。守るつもりが牢獄になる
3. **記憶の檻**——偽の記憶に閉じ込められたシンジの存在そのもの
4. **ゲンドウの檻**——ユイへの愛に閉じ込められた男。息子を道具にすることでしか動けない
5. **アスカの檻**——一人で戦うことしか知らない少女が、「隣の不在」に閉じ込められる

## 構造的な仕掛け

| 要素 | 設計意図 |
|------|---------|
| 映像による揺さぶり | ゲンドウが「感情の剥離テスト」を行う。レイ・アスカ・シンジ自身の映像で反応を測定。シンジが「実験動物」だと気づく転換点 |
| ミサトの後悔 | 善意が裏切りになった瞬間を体感させる。ゲンドウの「下がれ」でミサトの無力さが確定 |
| アスカの「隣のスペース」 | 戦闘中に残響で連携した体が、日常でも「隣にいるはずの存在」を求めている。不在の痛み |
| アスカの突撃と失敗 | Lie（「最強であれば」）を武器にした行動が権力の壁に跳ね返される。**力では開かない**という体験がEp.14で武器を「拳→言葉」に変える転換点 |
| レイの「約束」 | リツコに「壊すつもりはない」と約束させる。Ep.10でリツコが良心に従う伏線 |
| ゲンドウの「質問」 | 記憶を持っていることを知っている上での問い。答えられないことが最大のテスト |
| 解放後のシンジの変化 | 声に感情の膜がかかる。信頼が「傷ついた」状態。完全な断絶ではなく、ヒビ |
| 冬月の良心 | 「あの少年はただの素材ではなくなっている」——ゲンドウ体制内部の亀裂 |

## Ep.8からの接続
- Ep.8シーン9-10（善意の裏切り→「保護措置」）の直接の帰結
- ミサトの報告内容（「みんなが死ぬのを見た」）がゲンドウに渡り、「記憶の精度テスト」のトリガーに
- Ep.8でアスカが察した「シンジの変化」が、Ep.9ではシンジの「不在」として体感に変わる

## Ep.10への接続
- ゲンドウの「浸食テスト」宣言が使徒戦④のトリガー
- リツコのレイへの「約束」が、Ep.10でリツコが記憶構造データを確認した後の行動を決める
- シンジの感情の膜——保護室での経験で精神が脆くなっており、浸食型使徒の侵入が容易になる
- アスカの「不在の痛み」が、Ep.10で医務室に駆けつける動機に繋がる
