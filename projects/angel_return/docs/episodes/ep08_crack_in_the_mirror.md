# Ep.8: 鏡の裂け目 (The Crack in the Mirror)

## 位置づけ
- **Act 2: 乖離** の最終話。【使徒戦③：空間歪曲型】
- アスカとシンジの**初共闘**。言葉より先に体が連携する——残響が戦場で初めて動く
- **転換③発火**：シンジがミサトに感情的な吐露→ミサトが善意でゲンドウに報告。安全圏の崩壊
- アスカの温度推移：激昂(Ep.7) → **困惑(Ep.8)**。残響への戸惑いと、シンジがミサトを選んだことへの名前のない悔しさ

## テーマ
「鏡が割れた時、中から出てきたのは——知らないはずの自分だった」

## 使徒設計：空間歪曲型（第6使徒）

### 外見
- 第3新東京市上空に出現する「鏡面」。実体のない使徒
- 巨大な円形の歪みが空に浮かぶ。周囲の景色が鏡のように反射・屈折している
- 美しい。虹色の干渉縞が走る。だがその美しさの下には空間そのものを折り畳む暴力がある

### 能力：空間折畳
- 一定範囲の空間を歪曲し、「箱庭」を形成する。閉じ込められた対象は外界から完全に切り離される
- 箱庭内部では重力方向が不安定に変動し、上下左右の概念が信用できなくなる
- 使徒の本体像が鏡面反射で複数に見える。どれが本物か識別不能
- 物理攻撃は空間の折り目に沿って逸れる。当たらない
- **弱点**：一機のATフィールドでは歪曲を押し返せないが、二機が異なる方向から同時にATフィールドを展開すると空間の折り目が「裂ける」。裂け目からコアが露出する

### 裏設計
- ゲンドウが配置した使徒。アスカの残響がシンジとの共闘で発現するかをテストする目的
- 「一人では倒せない」設計は意図的。連携を強制し、感情反応データを取る
- 使徒戦表の③：表＝アスカとの初共闘、裏＝アスカをぶつける実験

## シーン構成

### シーン1：連携訓練——噛み合わない歯車

- 連携訓練がシミュレーターで行われている。ミサトの指示でシンジとアスカの二機共闘パターン
- アスカは一人で仕留めようとする。シンジのフォローを「邪魔」と感じている
- シンジの偽の記憶が「アスカとの連携パターン」を知っている。だが実際のアスカの動きは記憶と**微妙にズレる**
- ズレの正体：偽の記憶に入っている「1周目のアスカ」と、目の前の「残響を持つアスカ」は同じ人間のはずなのに動きの癖が違う
- シンジはまだ「世界が学習したから変わった」と合理化している
- リツコがデータを見ている。二機のシンクロパターンに不規則な共振が混じっている——まだ微弱だが、何かが反応しかけている
- 訓練終了。アスカ：「あんたの動き、読めない。次はもっと分かりやすく動きなさいよ」——実は自分の体が勝手に反応しかけていることへの苛立ち

### シーン2：鏡面の出現

- 第3新東京市の昼下がり。空に異常が発生
- 最初は虹のような光学現象。やがて空の一角が**鏡**になる——地上の景色が反転して映っている
- 美しい。見上げる市民もいる。だがその鏡面が拡大し始めた瞬間、空間そのものが軋む
- 使徒警報。パターン青
- ミサト：「出撃。二機同時。——シンジ君、アスカ、初めての実戦連携よ」
- アスカ：「一人で十分」 ミサト：「命令よ」
- 射出。二機が地上に立った瞬間——鏡面が落ちてくる。空間が折り畳まれ、二機を包み込む
- 外界との通信が途絶。発令所では計器が全てノイズに埋もれる
- ミサト：「シンジ君！ アスカ！ ……応答して！」——返事はない

### シーン3：箱庭

- 閉鎖空間の内部。シンジとアスカだけの世界
- 重力が狂っている。足元が「下」である保証がない。壁面に第3新東京市の景色が歪んで映っている
- 使徒の像が複数見える。鏡面の反射で、同じ姿が七つ、八つ。どれが本体か分からない
- アスカが即座にATフィールドを展開し、空間を押し返そうとする→**跳ね返される**。弐号機が壁面に叩きつけられる
- アスカ：「っ……なによ、これ！ ATフィールドが効かない！？」
- シンジの偽の記憶を検索する。この使徒のデータはない。「正解」がない
- シンジ独白：（知らない。この敵を、僕は知らない。……1周目にはいなかった使徒？ それとも——また、記憶と違う？）
- ラミエル戦に続く三度目の「記憶との齟齬」。だが今は考えている余裕がない

### シーン4：一人では壊せない鏡

- アスカが何度も突撃する。鏡面の像を片っ端から殴る→すべて虚像。拳が空を切る
- 弐号機の損傷が蓄積する。アスカの焦りが声に出る
- 「動きなさいよ！ なんで当たんないのよ！ こんな——こんなので、あたしが！」
- シンジが冷静に分析しようとする：「アスカ、待って。使徒の鏡面は空間の折り目だ。一方向からの力じゃ突破できない」
- アスカ：「じゃあどうしろっていうのよ！」
- シンジ：「二人で——別方向から同時にATフィールドを展開する。折り目を挟み込んで、裂く」
- アスカ：「あんたと息を合わせろっていうの？ 訓練でもまともに連携できなかったのに？」
- シンジ：「……それでも、やるしかない」
- 沈黙。アスカが歯を食いしばる。一人で戦うことしか知らない少女が、初めて「頼る」を選ぶ瞬間
- だがその選択は、理性からではない

### シーン5：残響が動く

- 二機が陣形を取る。シンジが右、アスカが左。鏡面の使徒を挟む配置
- 「行くわよ。カウント、あんたに合わせる」——アスカが言う。初めて相手に合わせると宣言した
- シンジがカウントを取る。三、二、一——
- ATフィールド同時展開。空間が軋む。折り目が揺れる——だが、裂けない。**タイミングが微妙にズレている**
- 使徒が反撃。歪曲した空間の圧力が二機を押し潰しにかかる
- 弐号機の装甲が軋む。初号機の左腕が空間の折り目に巻き込まれて歪む
- アスカ：「くっ……もう一回！」
- 二度目の試行。またズレる。理性で合わせようとしている限り、身体のリズムが同期しない
- 三度目——追い詰められた瞬間。アスカの頭の中が真っ白になる
- **その時、体が勝手に動く**
- 訓練でもシミュレーターでも出なかったパターン。アスカの弐号機が初号機の死角に滑り込み、シンジの呼吸に合わせるように——いや、**呼吸を知っているかのように**ATフィールドを重ねる
- 空間が裂ける。鏡面にひび割れが走る。虹色の光が砕け散る
- 裂け目の奥に——使徒のコア。脈打つ赤い球体
- 二機の拳が同時にコアを貫く。打ち合わせなしの完全同期
- 粉砕。使徒消滅。折り畳まれていた空間が元に戻り、第3新東京市の青空が広がる

### シーン6：「勘違いしないで」

- 戦闘後。ケージ
- アスカがプラグスーツのまま壁に寄りかかっている。黙っている
- シンジが声をかけようとする。「アスカ、さっきの——」
- 「勘違いしないで」——遮る。でも声に力がない
- 「たまたまよ。偶然タイミングが合っただけ。次はない」
- シンジ：「……うん」
- アスカが去る。背中を見せたまま
- 内心：（なんで。なんであたしの体は、あいつの動きを**知っていた**の。訓練で一度も合わなかったのに。あの瞬間だけ——頭が空っぽになった瞬間だけ、体が勝手に……）
- 残響が疼く。戦闘中の一体感の残像。温かくて、怖い
- Ep.7の「いつもそう」に続く二度目の残響の発露。今回は言葉ではなく**身体**が反応した
- （裏：ゲンドウの実験としては「成功」。残響が戦闘で発現した＝ゼーレの想定を超える反応強度。だがこのデータはゲンドウにとっても計算外の大きさ）

### シーン7：ミサトへの吐露

- 夜。ミサトのマンション。キッチン
- シンジがテーブルに座っている。戦闘の高揚が引いた後の、空洞のような疲労
- ミサトがビールを開けずにコーヒーを入れている。シンジの様子がおかしいことに気づいている
- 長い沈黙の後——シンジが口を開く
- 「ミサトさん」
- 「……うん」
- 「僕は……みんなが死ぬのを、見たことがある」
- ミサトの手が止まる
- 「ミサトさんも。綾波も。アスカも。……みんな、死んだ」
- メカニズムは語らない。語れない。ただ涙が落ちる。テーブルの木目に小さな染みが広がる
- ミサト：「……いつ」
- シンジ：「……前に。ずっと前に」
- ミサトはそれ以上問い詰めない。テーブルを回り込んで、シンジの頭を抱きしめる
- 「……よく、頑張ったわね。一人で、ずっと」
- シンジが声を殺して泣く。Ep.5でレイの前で泣いた時とは違う。**保護者に甘えている**涙
- ミサトの顎がシンジの頭の上にある。その目は——優しいまま、**決意に変わっている**
- ミサトの内心：（この子は壊れかけている。14歳の子供が、こんな重荷を一人で抱えていた。……守らなきゃ。あたしが守る。そのためには——）
- 善意。純粋な善意。だがそれが最悪の選択を生む

### シーン8：シンジの安堵、アスカの疼き

- 翌日。NERV内
- シンジの空気が微妙に変わっている。肩の力が僅かに抜けている。誰かに話した後の、重荷を分けた安堵
- アスカがそれに気づく。廊下ですれ違った瞬間
- アスカ：「……あんた、なんか変わった？」
- シンジ：「え？ ……そうかな」
- アスカはシンジの目を見る。昨日までの追い詰められた翳りが、ほんの少しだけ薄れている
- アスカ：「……誰かに、何か話した？」
- シンジが一瞬、目を逸らす。アスカはそれを見逃さない
- アスカ：「……別に。気のせいよ」——背を向ける。足早に去る
- 内心：（あたしじゃない。あたしじゃない誰かに、あいつは……）
- 残響が疼く。この痛みに名前はない。だが体が覚えている——**「また置いていかれた」**という感覚
- なぜ「また」なのか分からない。初めてのはずなのに。でも胸の奥が、焦げるように熱い
- 理由の分からない悔しさ。シンジが選んだのは自分じゃなかったという事実だけが、残響の炎を燃やす
- アスカは自分の部屋に入り、ドアに背中を預けて座り込む。膝を抱える
- ——泣かない。泣かないと決めている。Ep.7と同じ。でも今回は、唇を噛む力が少しだけ強い

### シーン9：善意の裏切り

- ゲンドウの執務室
- ミサトが入室する。背筋は伸びているが、手が微かに震えている
- 「碇司令。……シンジ君のことで、報告があります」
- ゲンドウ：サングラスの奥の目は見えない。「続けろ」
- ミサトが話す。シンジの言葉を——感情的な吐露の内容を、軍人としての報告に翻訳して
- 「パイロットが未経験のはずの出来事について、経験者のような反応を示しています。精神的負荷が限界に近い状態です。保護措置を——」
- ゲンドウ：「……了解した。適切な対応を取る」
- その声に、ミサトが期待した「保護」の温度はない。事務的な処理の響き
- ミサトの背筋に冷たいものが走る。だが——「上に報告した」という事実が、彼女の良心を一時的に安心させる
- 退室するミサト。ドアが閉まった後のゲンドウ
- サングラスを外す。その目は——**満足している**
- 「フェーズ3。感情定着の深化を確認。……次は、剥離テストだ」
- Ep.9「檻」への直接的な布石。「保護」の名の下に行われるのは、シンジの隔離と尋問

### シーン10：鏡の裂け目の先に

- 短い場面。レイの自室
- レイが端末でATフィールドの戦闘記録を閲覧している
- 二機のATフィールドが同期した瞬間のデータ。位相が重なっている
- レイはEp.6での自分とシンジの同調を思い出す。あの坑道で感じた温かさ
- だが今回のデータは——種類が違う。レイとの同調は「静かな共鳴」だった。アスカとの同調は「衝突の中の爆発的な一致」
- レイ：「……違う、もの」
- 嫉妬ではない。レイにはまだその語彙がない
- ただ、何かが変わり始めていることへの認識。碇くんの周りで、鏡が一枚、割れた
- そしてその裂け目の向こうに見えるものが何なのか——レイにはまだ分からない
- 最後の一行。レイが端末を閉じ、窓の外を見る。月が出ている
- 「……碇くん。あなたは、大丈夫？」
- 誰にも聞こえない問いかけ。Ep.5で始まった変化が、少しずつ言葉を持ち始めている

## タイトル「鏡の裂け目」の多義性
1. **使徒の鏡面**——空間歪曲が作り出した鏡の箱庭。二機のATフィールドで裂いて勝利する
2. **シンジとアスカの鏡像関係**——偽の記憶を持つ少年と、本物の残響を持つ少女。互いの「鏡」が戦闘で初めて重なる
3. **信頼の鏡にヒビ**——ミサトという「安全な大人」の鏡に裂け目が入る。善意が裏切りに変わる瞬間
4. **アスカの自己認識の裂け目**——「知らないはずの自分」が体の中から現れた恐怖。鏡を見たら知らない顔が映っていた

## 構造的な仕掛け

| 要素 | 設計意図 |
|------|---------|
| 空間歪曲で閉じ込める | 「一人では出られない」=連携を物理的に強制。アスカの「一人で十分」が通用しない状況を作る |
| 偽の記憶にない使徒 | ラミエル戦（記憶の正解が通じない）に続き、記憶の信頼性をさらに揺るがす |
| 三度の試行 | 理性→理性→**無意識**。頭で合わせようとしている間は成功しない。残響が動くのは理性が消えた瞬間 |
| 「勘違いしないで」 | アスカの防御台詞。Ep.7の「客じゃないわ、戦力よ」と同構造——強がりで本音を隠す |
| 感情的な吐露の選択 | メカニズムではなく感情を話すことで、ミサトの「母性」を刺激する。善意の裏切りの動機を自然にする |
| アスカの「また」 | Ep.7の「いつもそう」に続く残響の発露。今回は言葉ではなく**内心の感覚**として。前周の記憶に由来する置き去りの痛み |
| ミサトの報告の「翻訳」 | 感情の吐露を軍事報告に変換する過程で、シンジの真意が削ぎ落とされる。善意が情報を歪める |
| ゲンドウの「剥離テスト」 | 感情定着を確認した後は、剥がした時の反応を見る段階。Ep.9の隔離に直結 |
| レイの「違う、もの」 | シンジ-レイの同調とシンジ-アスカの同調の質的差異をレイ自身が認識。恋愛設計の布石——二つの愛の形の分岐点 |
| 監視カメラのモチーフ | Ep.5、Ep.6に続く反復。シンジが安堵して眠る部屋の天井に赤いランプ。安全の幻想 |

## Ep.7からの接続
- 連携訓練の摩擦 ← Ep.7「必要ない。あたし一人で十分」の延長
- アスカの残響：「いつもそう」(Ep.7・言葉) → **体が勝手に動く**(Ep.8・身体) → 段階的に発露が強まっている
- ミサトの疑念：Ep.7でシンジがアスカを「知っている顔」をしたことが、Ep.8で吐露を受け止める素地になっている
- リツコの観察：Ep.6で同調率を低く申告した女が、Ep.8でも二機の共振データを見ている。三度目の隠蔽が近づいている

## Ep.9への接続
- ゲンドウの「保護措置」＝隔離。Ep.9「檻」の直接的なトリガー
- ミサトが自分の報告が引き金だったと知り、激しく後悔する
- アスカの「また置いていかれた」感覚が、Ep.9でシンジ不在時の苛立ちに変わる
- レイの静かな懸念が、Ep.9でシンジの異変に最初に気づく布石になる
