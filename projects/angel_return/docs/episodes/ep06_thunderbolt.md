# Ep.6: 雷撃の神殿 (Thunderbolt)

## 位置づけ
- **Act 2: 乖離** の第2話。【使徒戦②：ラミエル改】
- Ep.5で「泣いた少年」とレイが、初めて戦場で共闘する
- **転換①発火**：シンジの「前知識」がゲンドウの仕掛けたテストだったことが裏で確定する回
- ATフィールド同調——偽の記憶に基づく深い感情定着が、戦闘能力として発現する
- レイが「また」を口にする——初めて自分から未来を望む

## テーマ
「正解を知っていた。だからこそ、墜ちた」

---

## シーン構成

### シーン1：幾何学の死神

- 第5使徒ラミエル降臨。青い正八面体、空中に静止する完璧な殺意
- シンジの偽の記憶が即座に反応——「ヤシマ作戦」。1周目では陽電子砲の長距離狙撃で仕留めた
- シンジは「知っている自信」で作戦会議に口を出す。「遠距離狙撃なら勝てます」
- ミサトが驚く。だが理に適っている。採用される
- **ここが罠**。シンジは気づいていないが、ヤシマ作戦の情報はゲンドウがわざとシンジの偽の記憶に仕込んだ「最適解」。シンジがこれを提案すれば＝記憶が機能している証拠
- （裏レイヤー：ゲンドウは最初から地中侵攻プランを並行で準備している。ヤシマは「テスト用の餌」）

### シーン2：反射する閃光

- 陽電子砲発射。世界を白く塗りつぶす閃光
- ビームはラミエルの多重次元屈折に弾かれ、自軍に跳ね返る
- 初号機の右肩装甲が蒸発。シンジが意識を失いかける
- 「1周目」の正解が、今度は自分を殺しに来た
- シンジの中の合理化：「世界が学習した。使徒も進化した。だから正解が変わった」
- まだ「記憶が偽物」とは思わない。でもEp.5の「1周目にはなかった」に続く、二度目の亀裂
- 発令所で——ゲンドウの顔が映る。**驚いていない**。最初から分かっていた顔

### シーン3：奈落への転換

- 医務室で目を覚ますシンジ。全身が痛む
- ミサトが地中侵攻作戦を提示。地図から消された廃棄坑道を通り、ドリルの真下＝最も脆弱な零距離へ潜行する
- シンジ独白：（僕の「正解」は通じなかった。でも——まだ戦える。今度は記憶の「答え合わせ」じゃなく、目の前の敵と向き合う）
- ミサトが二機体制を告げる。零号機が随伴
- シンジの胸が痛む——Ep.5の白い部屋。あの「調整」を受けた直後のレイを、また戦場に引きずり出す
- でもレイは既にケージにいる。志願した、とミサトが言う

### シーン4：暗闇の胎内

- 地下坑道への降下。初号機と零号機、四つん這いで這い進む
- 暗い。狭い。泥とヘドロ。Ep.4の廃棄区画の記憶が蘇る——あの甘ったるい腐敗臭
- 頭上からドリルの重低音。岩盤が軋む。時間がない
- シンジは恐怖で震えている。偽の記憶の「自信」が剥がれた後に残るのは、ただの14歳の恐怖
- 通信越しのレイの声。「……碇くん、聞こえる？」
- Ep.5とは違う。あの白い部屋で「いつものこと」と言った少女が、今は自分の意志でここにいる
- シンジ：「怖いよ、綾波」——素直に言えるようになっている。Ep.5の夜を越えたから
- レイ：「……私も。でも、あなたがいるから」——レイの初めての「怖い」。Ep.5で「この人は違う」と思った相手だから言える

### シーン5：ATフィールド同調

- 坑道がさらに狭まる。零号機のATフィールドが前方のシンジの背中を温めている
- その時、異変。二機のATフィールドが**干渉し始める**
- シンジの感覚：レイの存在が「見える」。通信なしで、彼女がどこにいるか、何を感じているか分かる
- 位相が揃っている。二つの心臓が同じリズムで脈打つような感覚
- 発令所でオペレーターが動揺する。「ATフィールド同調率……異常値です！ 二機の位相がほぼ完全に重なっています！」
- リツコの目が見開かれる。これはシンクロ率ではなく、二つの魂の共鳴。設計パラメータを超えている
- リツコは数値を記録するが——**ゲンドウへの報告で、同調率の最大値を低く申告する**（Ep.5に続く二度目の隠蔽）
- シンジにはリツコの隠蔽は見えない。ただ、レイとの不思議な一体感だけがある
- （裏レイヤー：高い同調率の原因は、偽の記憶に定着した「レイへの感情」の深さ。ゲンドウの設計が意図以上に機能している。だがリツコは「それだけじゃない」と直感している——Ep.5でシンジが流した涙が、パラメータ外の何かを生んだのでは）

### シーン6：零距離決戦

- ジオフロント天頂直下。ドリルの先端が目の前
- シンジがATフィールドでラミエルの防壁を抉り開ける——その瞬間、ドリルの内部から零距離砲撃
- レイがESVシールドで割り込む。超高温のエネルギーを受け止める
- 盾が溶ける。零号機の右腕が焼ける。**レイは声を上げない**
- Ep.5の反復——耐久テストと同じ。痛みに声を上げないレイ。でも今回は「いつものこと」じゃない。**自分で選んでここにいる**
- シンジの中で何かが弾ける。恐怖が怒りに変わるのではなく——「もう見せたくない」（Ep.5の夜の感情）が、体を動かす
- 初号機がレイの横をすり抜け、灼熱のコアを素手で掴む
- 両手が焼ける。神経接続の向こう、シンジ自身の皮膚も爛れる
- 咆哮——言葉にならない。ただ、この痛みを二度と彼女にさせないという、名前のない力
- コア粉砕。ラミエル消滅

### シーン7：瓦礫の底で

- 戦闘後。瓦礫の中、二機が倒れている
- シンジが零号機のハッチを強制解放。レイを引きずり出す
- レイの右半身が焼けている。プラグスーツが肌に張り付いている
- 「綾波……っ！」——叫ぶ。揺さぶる
- レイの目が開く。焦点が合うまでの長い数秒
- 「……碇くん」
- シンジが泣いている。また泣いている。Ep.5と同じ——でも今回は理由が分かる
- レイ：「……なぜ泣くの」
- Ep.5の「なぜ泣いているの」の反復。でも声のトーンが違う。前は不思議だった。今は——**確認している**。あの時と同じ人間が、同じように泣いてくれているか
- シンジ：「……怖かったんだよ。君が、死んじゃいそうで」
- レイの左手が伸びる。シンジの頬に触れる。涙に触れる
- 「……熱い。あなたの温度」
- Ep.5の白い部屋では、レイはシンジから目を逸らさなくなった「だけ」だった。今は——触れている。接触が始まった

### シーン8：「また、一緒に乗れる？」

- 救助を待つ暗闇の中。二人だけ
- シンジがレイの冷えた手を握っている。自分の焼けた掌で
- 長い沈黙。ドリル音はもうない。ただの静寂
- レイがぽつりと言う：

> 「……また、一緒に乗れる？」

- シンジが驚く。レイが何かを「望んだ」のは、この言葉が初めてだから
- Ep.5のレイは「いつものこと」と苦痛を受け入れていた。自分から何かを求めることがなかった
- 「また」——未来の時制。レイの中に「次」が生まれている
- シンジ：「……うん。何度でも」
- 簡素な答え。でもレイの目が——Ep.5で一瞬だけ見開かれたのと同じように、微かに揺れる
- 救助隊のライトが闇を裂くまで、二人は手を離さない
- （Ep.12で「6番目のシンジ」が同じように泣き、同じように手を握る映像を見せられた時——この夜の全てが崩壊する）

### シーン9：監視カメラの赤い光

- 短いカット。シンジの視点
- 医務室に搬送される途中、天井の監視カメラの赤いランプが目に入る
- ゲンドウが見ている。いつも見ている
- シンジ独白：（……あの人は、何を確認しているんだろう）
- 「確認」という言葉が浮かんだことに、自分で違和感を覚える。「観察」ではなく「確認」
- でもすぐに意識が薄れる。深く考える余裕がない
- （裏レイヤー：ゲンドウにとってこの戦闘の意味——①ヤシマ作戦を提案した＝偽の記憶が機能している、②ATフィールド同調が高い＝レイへの感情定着は成功、③地中侵攻は最初から準備していた＝ヤシマの成否は問題ではなかった。全てはテスト）
- ゲンドウのシナリオ上、Ep.6は「成功」。でもリツコが隠した同調率の異常は、シナリオの外にある

## タイトル「雷撃の神殿」の多義性
1. ラミエル＝「神の雷」。正八面体の「神殿」のような美しさと、雷のような破壊力
2. 地下坑道＝「神殿の地下」。聖域の下に隠された汚穢の通路
3. 「雷撃」＝シンジの「正解」が自分に跳ね返る衝撃。自らの知識に撃たれる
4. ラミエル戦の場が「神殿」なら、シンジとレイが交わした言葉は「祈り」に近い
