# Ep.5: 人形の夢 (Ghost in the Shell)

## 位置づけ
- **Act 2: 乖離** の幕開け
- レイとの本格的な出会い。「君が泣かないから、代わりに」の起点
- 偽の記憶と現実の最初の明確なズレ——記憶の信頼性に最初の亀裂
- リツコの罪悪感の種が蒔かれる回

## テーマ
「人形は泣かない。でも泣いてほしい人がいる」

---

## シーン構成

### シーン1：命令

- シンジがリツコから呼び出される
- 「零号機パイロットの調整に立ち会いなさい。司令の命令よ」
- シンジの偽の記憶が反応する——「1周目」のレイの記憶。穏やかで無表情な少女
- でもシンジは不安を感じる。「調整」という言葉の響きに、記憶にない違和感がある
- （裏レイヤー：ゲンドウがシンジをレイの「調整」に同行させるのは、S-13の感情反応データを取るため）

### シーン2：最深部へ

- NERV最深部への降下。リツコと二人きりのエレベーター
- 階層が下がるごとに空気が変わる。無機質に、冷たくなる
- リツコの表情が硬い。普段の科学者然とした冷静さの下に、何かがある
- シンジ：「赤木博士……『調整』って、何をするんですか」
- リツコ：「……見れば分かるわ」
- 目を合わせない。ここにリツコの罪悪感の最初の種がある
- （Ep.10でリツコが「偶然」アクセス権を残す動機は、この場面でシンジを見た時に始まる）

### シーン3：耐久テスト

- 最深部の白い部屋。ガラス越しに見えるのは——
- レイが拘束具に固定されている。周囲にモニターとケーブル
- 「調整」の実態は**生体部品としての耐久テスト**
- ATフィールドの限界値を測定するために、わざと閾値を超える負荷をかけている
- レイの体が軋む。唇が白い。でも**声を上げない**
- オペレーターが淡々と数値を読み上げる。「負荷率78%……82%……」
- リツコが作業を指示する。手は震えていないが、声が微かに低い
- シンジは偽の記憶を探る——「1周目」にこんな場面はなかった。レイの調整はもっと穏やかなものだったはず
- **記憶と現実の最初の明確なズレ**
- でも今のシンジはまだ「世界が学習して条件が変わったから」と合理化できる

### シーン4：嘔吐

- 負荷率が90%を超える。レイの体が痙攣する。それでも声を上げない
- シンジの視界が歪む。胃がせり上がる
- 膝をついて**嘔吐する**。白い床に、酸っぱい匂い
- リツコが振り返る。オペレーターの手が止まる
- シンジ：「やめ……やめてください。もう——」
- リツコ：「碇くん、これは必要な——」
- シンジ：「**必要なわけない！**」
- 声が裏返る。怒りなのか恐怖なのか、自分でも分からない
- リツコの目が揺れる。一瞬だけ。でもすぐに目を逸らす
- テストが中止される。ゲンドウの判断ではなく、リツコが**自分の権限で**止めた
- （これがリツコの中に小さな亀裂を生む。Ep.10の「偶然」への道筋）

### シーン5：空白の廊下

- テスト後。シンジが最深部の廊下を一人で歩いている
- 口の中にまだ酸っぱい味が残っている
- 偽の記憶と現実のズレが頭を回る
- （1周目のレイは……あんな目に遭っていたのか？ いや、記憶にはない。世界が変わったから？ それとも——）
- 「それとも」の先は考えない。まだ考えたくない
- あの白い部屋で声を上げなかったレイの顔が、目の裏に焼き付いている

### シーン6：レイの部屋

- レイの個室。最深部に近い、殺風景な部屋。ベッドと机だけ
- テスト後のレイが横になっている。目は開いている。天井を見ている
- シンジがドアの前に立っている。ノックする手が震える
- 入る。レイが視線だけでシンジを見る

> レイ：「……何の用」
> シンジ：「その……大丈夫ですか」
> レイ：「大丈夫。いつものこと」

- 「いつものこと」——その一言がシンジの胸を抉る
- あの苦痛が「いつものこと」である世界。それを受け入れている少女
- シンジはレイの傍の床に座る。何を言えばいいか分からない

### シーン7：「君が泣かないから」

- 沈黙。長い沈黙
- レイが天井を見たまま、ぽつりと言う

> 「なぜ泣いているの」

- シンジが自分の頬に触れる。——濡れている。泣いていると気づかなかった
- シンジが泣いている理由を自分でも説明できない。偽の記憶のプログラム？ それとも——
- でも今はそんなことを考えない。ただ、正直に：

> 「……君が泣かないから、代わりに」

- レイの目が——ほんの一瞬だけ、見開かれる
- 無表情の下で、何かが動いた。名前のない何か
- 調整に立ち会う人間は何人もいた。リツコも、オペレーターも、ゲンドウも
- 泣いた人間は**一人もいなかった**。シンジが最初
- レイ独白：（……この人は、違う）
- それ以上は何も言わない。でもレイがシンジから目を逸らさなくなった。それだけで十分

### シーン8：ゲンドウの確認

- 短いカット。ゲンドウがモニターでシンジとレイの接触を見ている
- シンジの感情反応データ。嘔吐、涙、怒り——全てが記録されている
- **巻き戻し**：テスト中のシンジの叫びの瞬間。「**必要なわけない！**」——あの声が録音されている
- ゲンドウの手が組まれている。いつもの姿勢。いつもの仮面
- だがシンジの叫びがスピーカーから流れた瞬間——**0.5秒、手の指が緩む**
- ゲンドウ自身が気づいていない微かな反応。あるいは気づいていて、即座に組み直した
- （その声が——ユイの声に似ている。不当な扱いに対して怒りを向ける声の質が。だがこの連想をゲンドウは意識しない。**Ep.15で手が崩れる瞬間の、最初の種**）
- ゲンドウ：「……感情定着は想定通りか」
- リツコ：「パターン通りです。ただ——」
- 言いかけて止まる。「ただ」の先——シンジの反応が「設計されたパターン」より**強かった**こと
- リツコはそれを報告しない。**最初の隠蔽。最初の逸脱**
- （裏レイヤー：ゲンドウにとってシンジの涙はデータ。だがリツコはシンジの涙を見て、自分が何をしているか初めて直視した）
- （裏レイヤー②：ゲンドウの手の0.5秒の緩み——冬月はモニター室の隅からこの瞬間を見ている。何も言わない。だが覚えている。Ep.9の「あの少年はただの素材ではなくなっている」という発言の根拠の一つ）

### シーン9：夜——人形の夢

- 夜。シンジの部屋。眠れない
- レイの顔が頭から離れない。痛みに耐える顔ではなく——最後に自分を見た、あの目
- 偽の記憶の中の「レイ」は、もっと遠い存在だった。触れられない人形
- でも今日見たレイは——人形じゃなかった。**人形にされている人間**だった
- シンジの中に生まれた感情：「もう見たくない」。でもそれは「目を逸らしたい」ではなく——
- 「もう**見せたくない**」。あんな姿を、あの子に
- これは偽の記憶が設計した「守りたい」か？ それとも本物か？
- 今のシンジには区別がつかない。でも胸の痛みは今、ここにある
- （Ep.12で「6番目のシンジ」が同じ台詞を言った時、この夜の感情が全て崩壊する。自分だけの涙だと思っていたものが、量産された反応だったと知る地獄）

## タイトル「人形の夢」の多義性
1. レイが「人形」として扱われている——生体部品としての耐久テスト
2. 人形であるレイが「夢」を見始める——シンジとの出会いで何かが動く
3. シンジ自身も「人形」だった（後に判明）——S-13という製造物。この回の涙すらプログラムかもしれない
4. 「人形の夢」＝人形が人間になりたいと願う物語。レイもシンジも、その夢の途中にいる

## 構造的な仕掛け

| 要素 | 設計意図 |
|------|---------|
| 「調整」の実態 | 原作より過酷に。「生体部品の耐久テスト」という表現が、後にシンジ自身にも跳ね返る（S-13も「テスト」の産物） |
| シンジの嘔吐 | Ep.12で自分がテスト対象だったと知って嘔吐する反復の原点。他者の痛み→自分の真実 |
| 「1周目にはなかった」 | 記憶への最初の亀裂。まだ「世界が変わったから」と合理化できるが、種は蒔かれた |
| 「君が泣かないから、代わりに」 | 物語で最も残酷な反復の起点。Ep.12で別のシンジが同じ台詞を言う。自分だけの言葉→量産された出力 |
| リツコがテストを自分の権限で止める | ゲンドウの命令ではなく自分の判断。小さな逸脱がEp.10の「偶然」に繋がる |
| リツコの「ただ——」の隠蔽 | シンジの反応が設計より強かったことを報告しない。リツコの中の亀裂の始まり |
| レイ「いつものこと」 | 苦痛の日常化。これが「普通」であるという絶望を一言で伝える |
| レイがシンジから目を逸らさなくなる | 言葉ではなく視線の変化。レイの変化は常に静かで微かだが確実 |
| 「見たくない」→「見せたくない」 | シンジの動機が自己防衛から利他に変わる瞬間。Ep.14で「誰かを守る時に体が動く」の原型 |
| ゲンドウにとって涙はデータ | シンジの最も人間的な反応が、設計者にはデータポイントに過ぎない。冷酷さの具体化 |
| ゲンドウの手の0.5秒 | シンジの叫びがユイを想起させる微かな亀裂。Ep.15で手が崩れる瞬間の最初の種。冬月だけが目撃し、Ep.9の発言の根拠に |
