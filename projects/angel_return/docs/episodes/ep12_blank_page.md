# Ep.12: 白紙 (Blank Page)

## 位置づけ
- **Act 3: 包囲** の最終話
- **転換⑤**：物語最大のどんでん返し——シンジの「1周目の記憶」は偽物だった
- 前話（Ep.11）でカヲルから「ゲンドウが戦場を設計していた」と知らされた直後

## テーマ
「自分だけの言葉だと信じていたものが、プログラムの出力だった」

---

## シーン構成

### シーン1：沈黙の朝

- Ep.11でカヲルから転換④を聞かされた翌朝
- シンジは自室で天井を見ている。**父が自分を追い詰めていた**——その衝撃がまだ消化できていない
- だが「自分の記憶」はまだ信じている。ここがシンジにとって最後の安全地帯
- 読者もまだ「シンジは2周目のベテラン」だと信じている

### シーン2：リツコの「偶然」

- シンジがNERV内を歩いていると、端末に**ログインしたままのアクセス権**が残っている
- リツコが「偶然」残したもの（Ep.10で罪悪感から仕込んだ伏線の回収）
- シンジが見つけるのは**施設の座標**と、暗号化されたプロジェクト名だけ
- 全容は分からない。でも「自分に関係がある」と直感する

### シーン3：カヲルとの道行き

- 未明。NERVの監視が手薄になる時間帯
- カヲルが監視カメラの死角ルートを知っている——ゼーレの情報が彼の中にある
- シンジがカヲルに座標を見せる。カヲルは知っている顔をする
- カヲル：「……行くのかい。知らなければ、まだ戻れるよ」
- シンジ：「僕はもう、知らないふりができない」
- 二人でゼーレの施設へ向かう。道中の静かな会話

> カヲル：「怖くないのかい」
> シンジ：「怖いよ。でも……怖いって感覚だけは、嘘じゃない気がするから」

- この台詞が後から効いてくる——「感覚は嘘じゃない」は、偽りの記憶と本物の感情というテーゼの前振り

### シーン4：施設——最初の違和感

- ゼーレの地下施設。無機質な白い廊下
- 最初に見つけるのは**データログ**。「被験体」の記録
- 被験体番号、投与日時、記憶パターンのバージョン……
- シンジはまだ理解していない。「これは何の実験だ……？」
- カヲルは黙っている。**知っていたが、自分からは言わない**。シンジ自身が辿り着くのを待つ

### シーン5：ガラスの向こう

- 奥の部屋。ガラス越しに見えるのは**培養槽の列**
- 中身はもう空。だが残留物がある——**人の形の痕跡**
- 壁のモニターに残る被験体の記録映像。再生する
- 映像の中の少年が**シンジと同じ顔**をしている

**最初の映像**：
- 「6番目のシンジ」が、白い部屋で誰かに語りかけている
- 「——君が泣かないから、代わりに」
- **シンジの血が凍る**。それはEp.5でレイに言った、自分だけの言葉だったはず
- でも「6番」が、同じ状況で、同じ感情で、同じ言葉を発している

**二番目の映像**：
- 別の番号のシンジ。目が虚ろで、壁に頭を打ちつけている
- 記録の注釈：「記憶定着率47%、廃棄」

**三番目の映像**：
- また別のシンジ。笑っている。だが次の瞬間、けいれんを起こして崩れ落ちる
- 注釈：「パターンG-7、過負荷により破損」

### シーン6：最初の解釈——「クローン」

- シンジの手が震え始める
- だがまだ致命傷ではない。シンジは**自分を守るための解釈**に辿り着く

> 「……僕の、クローンを作ろうとしていた？」
> 「僕のコピーを量産して……兵器に？」

- これでも十分にショッキングだ。読者もこの解釈で一旦納得する
- 自分のコピーが作られ、壊され、捨てられていた。怒りと嫌悪が込み上げる
- 「父さんは……ここまで……」

### シーン7：「逆だよ」

- カヲルが静かに口を開く

> 「……逆だよ」

- シンジが振り返る

> カヲル：「彼らがコピーなんじゃない。君が——最後に成功した、コピーの方なんだ」

- 沈黙
- シンジの目が見開かれる
- 最後のファイルを開く。**自分の被験体番号**が記載されている
- 「被験体S-13。記憶パターン：Final Version。投与内容：第壱〜拾捌使徒戦の疑似体験記憶、人類補完計画関連情報、対人関係記憶（感情定着用）。定着率：98.7%。備考：**実戦投入可**」

> シンジ：「……S-13……13番目……」
>
> 「1周目なんて、なかったのか」
>
> 「僕は2周目の"僕"じゃなくて……」
>
> 「最初から、これが……1回目？」

- 膝が折れる。嘔吐する
- （Ep.5でレイの耐久テストを見て嘔吐した反復——**今度は自分が実験体だったと知って**）

### シーン8：カヲルの沈黙

- カヲルがシンジの傍に屈む
- シンジ：「……知ってたのか」
- カヲル：「確信はなかった。でも……君が"作られた側"だという可能性は、感じていた。僕自身がそうだから」
- カヲルの共感は本物。でも**事前に言わなかった**という事実が、小さな亀裂を残す
- カヲルは優しく手を差し伸べる。でもシンジはその手を取れない

### シーン9：不在——レイとミサト

- 場面転換。NERV側。朝
- ミサトがシンジの部屋を訪ねる。空。ベッドは使われた形跡がない
- ミサト：「シンジ君……？」——嫌な予感。Ep.9の「檻」を自分が招いた記憶が蘇る。今度は逆に、自分から逃げたのか
- 保安課に連絡。カヲルも不在と判明。ミサトの顔が険しくなる
- 同じ頃——レイが目を閉じている。ATフィールドが微かに揺れている
- レイ：「……碇くんが、遠い」
- ATフィールドの感応——坑道の共鳴以来、レイはシンジの存在をぼんやりと感じ取れる。その感覚が今、距離を示している
- レイはミサトに報告しない。ただ——待つ。待つことしかできないことを、知っている
- レイ：「……戻ってきて」。Ep.10の医務室と同じ言葉。だが今回は、自分が傍にいてやれない場所にシンジがいる

### シーン10：アスカの到着——残響に導かれて

- NERV側。午後
- アスカは自室にいる。シンジの不在に苛立っている——と思いたい
- だが突然、**残響が激しく疼き始める**。頭痛。吐き気。視界の端にちらつく見知らぬ白い廊下
- 自分でも理由が分からないまま、体が動いている。気づいたら第三新東京市の外へ
- アスカ：「……何よ、これ。なんであたし、こんなところに……」
- 残響がこの施設を「知っている」。アスカの魂が、この場所に反応している
- （**なぜ彼女の残響がこの施設に反応するのか**——次の謎として残る。ゼーレの実験とアスカの残響の関係は後のエピソードで掘り下げる余地）

- 施設に入ったアスカが見るのは、**床に座り込んだシンジと、壁一面の「碇シンジ」の記録**
- 残響が最も強く疼く——**この光景を、魂のどこかが「知っている」**
- アスカ：「……何よ、これ」

### シーン11：拒絶

- アスカがシンジを立たせようとする
- 「立ちなさいよ。こんなところにいたら——」
- シンジがアスカの手を振り払う

> 「近づかないで。僕の中の君は、作り物だ」
>
> 「僕が君を見て感じたこと……全部、誰かがプログラムした感情だったんだ」
>
> 「だから……僕の気持ちを信じないでくれ」

- アスカの顔が歪む。怒りか悲しみか、自分でも分からない

> 「……っ、勝手にしなさいよ！」

- 走り去る。でも涙を見せなかったのは、**アスカの最後の矜持**

### シーン12：白紙

- 施設に残されたシンジとカヲル
- シンジが呟く

> 「僕は……何だったんだろう」
>
> 「14年分の記憶。泣いたことも、怒ったことも、誰かを好きになったことも」
>
> 「全部、データ？」

- カヲルが静かに言う
> 「……それでも、君は泣いている。今、この瞬間」

- でもその言葉はシンジに届かない。まだ届くには早すぎる
- エピソード終了

---

## タイトル「白紙」の多義性
1. シンジの過去が**白紙に戻った**（記憶が全て嘘だった）
2. 施設の**白い壁と白い廊下**（無機質な製造現場）
3. シンジの未来が**白紙になった**（2周目の知識という武器を失った）
4. これから何を書くかは**シンジ次第**（Act 4への希望の種）

## 構造的な仕掛け

| 要素 | 設計意図 |
|------|---------|
| リツコの「偶然」 | Ep.10の伏線回収。加害者が間接的に真実への道を開く |
| 「君が泣かないから、代わりに」の反復 | 自分だけの言葉が**量産された言葉**だったと知る恐怖。原作ネタではなく作中の台詞だから、読者にも直接刺さる |
| 「クローン」→「逆だよ」の二段構え | どんでん返しの中にもう一段のどんでん返し。読者が一度安心した足場をもう一回崩す |
| 被験体S-13 | 13番目の成功例。シンジの特別さは「たまたま壊れなかった」だけ |
| 嘔吐の反復 | Ep.5（他者の痛み）とEp.12（自分の真実）の対称構造 |
| 未明の脱出 | カヲルがゼーレの情報で監視の死角を知っている。NERVからの脱出自体がカヲルの立ち位置を示す |
| レイの「遠い」 | ATフィールド感応でシンジの距離を感じ取る。Ep.6坑道の共鳴の延長。Ep.13で「ノックなし」で来る動機の前振り |
| ミサトの不在発覚 | Ep.9で檻に閉じ込めた女が、今度はシンジの脱出に気づく。加害者が「見失う」逆転構造 |
| アスカの残響による到着 | 「なぜ残響がこの施設に反応するのか」が次の謎となり、物語の推進力を維持 |
| カヲルの「今、君は泣いている」 | Ep.13でレイが言う「あの日私を見て泣いたのは嘘じゃない」の前振り。同じ方向の言葉だが、カヲルの言葉はまだ届かない→レイの言葉で初めて届く、という段差を作る |
| アスカへのシンジ側からの拒絶 | Ep.14でアスカ側から壁を壊す反転の準備。拒絶した側が拒絶される苦しみを知り、されど側が壁を壊す勇気を持つ |
