# Ep.7: 深紅の亡命者 (Crimson Storm)

## 位置づけ
- **Act 2: 乖離** の中盤
- アスカ登場回。原作の「華やかな登場」の反転——全てを失った亡命者として現れる
- **転換②**：アスカには前周の「残響」がある。記憶ではなく魂が覚えている感情の欠片
- シンジの偽の記憶 vs アスカの本物の残響——物語のテーゼが始動する回

## テーマ
「知らない記憶が、魂を焦がす」

---

## シーン構成

### シーン1：壊滅の報

- NERV発令所に緊急通信。**ユーロ支部（第2支部）壊滅**
- ミサト：「生存者は？」
- オペレーター：「弐号機パイロット1名。弐号機と共に護送中」
- ミサト：「……たった一人？」
- 別のオペレーターが補足する：「JSSDF極東方面の通信が活発化しています。ユーロ支部の残存資材の回収を巡って……**陸自の特殊研究班——"高雄"の名前が出ています**」
- ミサト：「高雄？ ……聞いたことないわね。——今はいい、弐号機パイロットの受け入れが先よ」
- （**痕跡①**：高雄ムサシ率いるJSSDFの特殊部隊「キメラ」。ユーロ支部壊滅に乗じて独自の回収作戦を展開している。この名前は後に再登場する余地を残す）
- ゲンドウが画面を見ている——**驚いていない**。知っていた顔
- 冬月だけがそれに気づく。だが何も言わない
- （裏レイヤー：ユーロ支部壊滅のタイミング自体がゼーレの計画。シンジに「残響」を持つ被験体をぶつける実験の始まり）

### シーン1.5：嵐の前の朝——日常の聖性

- 壊滅の報が届く直前の朝。NERVの食堂
- シンジとレイが向かい合って朝食を取っている。味噌汁の湯気。レイはパンの耳を残す
- シンジ：「……綾波、耳は食べないの？」
- レイ：「硬い」
- シンジが自分の皿にレイのパン耳を引き取る。無言のやりとり。Ep.5以来の静かな信頼の積み重ね
- ミサトが缶コーヒーを片手に隣のテーブルに座る。昨夜の書類作業で目の下にクマがある。でも笑っている
- ミサト：「二人とも、学校は？」
- シンジ：「今日は午後からです」
- ミサト：「そう。……じゃあ午前中は少し自由ね」
- 食堂の窓から差し込む朝の光。この何気ない朝食の風景が——Ep.8でシンジが「みんなが死ぬのを見た」と打ち明けた時の、**ミサトが守りたかったもの**の具体像
- **この日常はもう戻らない**。アスカの到着が全てを加速させる。だからこそ、ここで描く意味がある
- （構造的意図：嵐の前の静けさ。読者に「壊される前のもの」を見せることで、壊れた後の喪失感が増す）

### シーン2：深紅の到着

- 輸送機が着陸する。弐号機の巨体がケージに運び込まれる
- タラップから降りてくるのは——赤い髪の少女。14歳
- だが「華やかな登場」ではない。服は汚れ、目の下にクマがある。ユーロ支部から逃げ延びて何日も経っている
- それでも背筋は伸びている。**折れることを拒否している体**
- 出迎えのミサトに対して、最初の一言：

> 「惣流・アスカ・ラングレー。弐号機パイロット。——**客じゃないわ。戦力よ**」

- 同情されることを全力で拒絶している。亡命者ではなく戦力として扱えという宣言
- ミサトはその強がりの下にある傷を見抜くが、今は踏み込まない

### シーン3：初接触——シンジの顔

- シンジがケージでアスカを見る
- その瞬間、**偽の記憶が反応する**。懐かしさ。罪悪感。胸の奥が痛む
- 「1周目のアスカ」の記憶——一緒に戦った記憶、すれ違った記憶、最後まで救えなかった記憶（全て偽物だが、シンジはまだ信じている）
- シンジの顔に、自分でも制御できない感情が浮かぶ。**懐かしさと、痛みと、「ごめん」が混ざった目**
- アスカがそれを見る

### シーン4：激昂

- アスカの目が見開かれる。次の瞬間——

> 「なんなのあんた、その目……**気持ち悪い**」

- シンジが固まる
- アスカの怒りは二重構造：
  - **表層**：シンジの目に「怯え」を見た。自分のトラウマ（母親の死、ユーロ支部の壊滅、一人で生き延びた恐怖）と同じものを映す鏡。同族嫌悪
  - **深層**：説明できない激情。初対面のはずなのに、**知っている**。この目を、この顔を、どこかで見た。その「どこか」が思い出せない。思い出せないことが腹立たしい

> 「初対面で何その顔。あたしのこと知ってるみたいな面してんじゃないわよ」

- シンジ：「……ごめん」
- アスカ：「謝んな！ ますます気持ち悪い！」
- 走り去る。シンジが一人残される
- シンジの偽の記憶が囁く——「前もこうだった」。でも今回の激しさは、記憶のどのパターンとも違う

### シーン5：ミサトの観察

- ミサトがシンジとアスカのやり取りを見ていた
- Ep.2以来、シンジの「異常性」に気づいているミサト
- シンジがアスカを見た時の顔——初対面にしては**情報量が多すぎる**
- ミサト独白：（……あの子、アスカのこと知ってる。会ったことないはずなのに）
- まだ確信ではない。だが疑念が一つ増える
- （これがEp.8でシンジが打ち明ける→ミサトが報告する流れの伏線）

### シーン6：弐号機起動テスト

- アスカの実力を確認するための起動テスト
- 弐号機が動く。その動きは——**美しい**
- シンジやレイとは質が違う。天性のセンスと、鬼のような訓練量が共存している
- シンクロ率も高い。リツコ：「……優秀ね。データ通り」
- テスト中、アスカは誰も見ていない瞬間だけ、**目を閉じている**。弐号機の中にいる時だけ、強がりを降ろせる
- テスト後、発令所で：
- ミサト：「明日からシンジくんとの連携訓練を——」
- アスカ：「必要ない。あたし一人で十分」
- レイが遠くからアスカを見ている。無表情。だが——何かを感じている

### シーン7：残響の片鱗

- 夕方。NERV内の廊下で、シンジとアスカが再び遭遇する
- アスカはまだ怒っている。でも逃げない。**向き合う**
- 口論になる。アスカがシンジの「怯え」を攻撃する

> 「あんたみたいなのがエヴァに乗ってるの？ 怯えた目で、震えた手で？」
>
> 「そんなんで誰を守れるの」

- シンジが言い返せない。図星だから
- そしてアスカが、不意に——**言うはずのないことを言う**

> 「……あんたはいつもそう。肝心な時に、逃げ——」

- **途中で止まる**。自分が何を言いかけたか分からない
- 「いつもそう」——初対面なのに。「いつも」がどこから来たのか、アスカ自身に分からない
- シンジが凍りつく。今の言葉、偽の記憶のどこにもない。**1周目のシンジに向けられたはずの言葉の断片**
- シンジ：「……今、何て……」
- アスカ：「は？ 何が。——別に何も言ってない」
- ごまかす。でも自分の心臓が速く打っているのが分かる
- 二人とも、今起きたことの意味が分からない。でも空気が変わった

### シーン8：夜——魂の疼き

- 夜。アスカに割り当てられた部屋
- 眠れない。ユーロ支部の壊滅ではなく——**シンジの顔**が頭から離れない
- 残響が疼く。映像ではなく**感覚**
  - 誰かの背中の温度。隣にいた時の距離感。一緒に走った時の息遣い
  - 全て「知らない記憶」。でも体が覚えている
- アスカ：「……なんなの、これ」
- 胸に手を当てる。心臓が痛い。怒りじゃない。もっと古い、もっと深い何か
- 名前をつけられない感情。でも一つだけ確かなこと——**あの少年に関係している**
- アスカは枕に顔を埋める。泣かない。泣かないと決めている
- でも残響は止まらない

### シーン9：レイの直感

- 短い場面。レイが自室の窓辺に立っている
- アスカの起動テストを見た時、レイは何かを感じた
- レイ独白：（……あの人は、碇くんを知っている。碇くんの知らない碇くんを）
- レイの直感。クローンとして「自分」の境界が曖昧だからこそ、他者の魂の欠片に敏感
- 何も言わない。何もしない。でも——見ている
- （Ep.13で「惣流さんの涙は、誰にも作れないものだったわ」と言えるのは、この時からアスカを見続けていたから）

### シーン10：設計者の視点

- 短いカット。ゲンドウの執務室
- モニターにはシンジとアスカの接触データ
- ゲンドウ：「……反応したか」
- ゼーレとの通信記録が画面に映る。「第2支部処理完了」「被験体の接触実験、承認」
- ユーロ支部壊滅は使徒による偶然ではない。**ゼーレが計画的に潰した**
- アスカをシンジにぶつけることで、S-13の感情定着パターンが「残響」持ちの存在にどう反応するかを観察している
- ゲンドウにとってアスカは「変数」であり「試薬」
- だがゲンドウが読み違えていること——アスカの残響は**制御できない**。ゼーレの想定を超えている
- （この「読み違え」がAct 3以降で効いてくる。アスカの残響こそがゲンドウのシナリオを崩す最大の変数になる）

## タイトル「深紅の亡命者」の多義性
1. アスカの赤い髪——深紅の少女が亡命してきた
2. 「亡命」＝故郷を失った者。ユーロ支部だけでなく、「前の世界」からの亡命者でもある
3. 「深紅」＝怒りと情熱の色。でも血の色でもある——傷ついている
4. 亡命は「逃げる」ではなく「生き延びる」。アスカの本質

## 構造的な仕掛け

| 要素 | 設計意図 |
|------|---------|
| 嵐の前の朝食 | 壊される前の日常の具体像。ミサトが「守りたかったもの」を可視化し、喪失の予感を強化。読者の感情的投資を回収するための仕込み |
| 亡命者としての到着 | 原作の華やかな登場の反転。全てを失った状態で現れるから、強がりが防御であることが際立つ |
| 「客じゃないわ、戦力よ」 | 同情を拒否する一言。アスカの矜持と傷の両方が凝縮 |
| シンジの「情報量が多すぎる顔」 | 偽の記憶がアスカを「知っている」から。ミサトの疑念を深め、Ep.8の転換③に繋がる |
| 「いつもそう」の漏出 | 残響の最初の発露。初対面なのに「いつも」が出る不自然さ。シンジの偽の記憶にはないフレーズ |
| 二重の怒り | 表層＝同族嫌悪（怯えの鏡）、深層＝残響による説明不能な激情。層が分かれていることで読み返し時に発見がある |
| 弐号機の中でだけ目を閉じる | 唯一の安全地帯。強がりを降ろせる場所。Ep.14で「乗って戦いに行く」動機の種 |
| レイの直感 | 「碇くんの知らない碇くんを知っている」。レイだけが気づく。Ep.13への長い伏線 |
| ゼーレの計画 | ユーロ支部壊滅が人災。転換④で判明した時、この回の全てが違う意味を持つ |
| アスカの残響＝感覚だけ | 映像や記憶ではなく「体温」「距離感」「息遣い」。記憶より深い層に刻まれているから消せない |
| シンジの偽記憶との齟齬 | 「前もこうだった」のに激しさが違う。偽の記憶のパターンと実際のアスカのズレが、記憶の偽物性を予告 |
| Ep.8との接続 | アスカの「残響」とシンジの「偽の記憶」が初共闘で噛み合う不思議さ→二人とも驚く |
