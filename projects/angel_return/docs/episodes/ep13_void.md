# Ep.13: 空洞 (Void)

## 位置づけ
- **Act 4: 選択** の幕開け
- Ep.12で全てが崩壊した直後。アイデンティティの完全喪失状態
- レイによる「存在の肯定」——物語の最も静かで最も重要な転換点
- カヲルとの決別。「もう一つの答え」が提示され、拒否ではなく**保留**される

## テーマ
「偽物が偽物のまま生きることに、意味はあるのか」

---

## シーン構成

### シーン1：空洞——崩壊の翌日

- Ep.12の翌日。シンジは自室のベッドにいる
- 動けない。動かないのではなく、**動く理由がない**
- 天井を見ているが、何も見ていない。思考が空転している
- 「1周目の記憶」に基づいて構築していた全ての行動原理が消えた
- 以前のシンジなら——仮面をかぶって、「大丈夫」と言えた。でもその仮面すら借り物だった
- 何をしても「それはプログラムの出力では？」という疑念が湧く
- 泣くことすら、「泣くようにプログラムされたのでは？」と感じてしまう

> 「……僕は、悲しいのか？」
>
> 「悲しいと感じるように作られただけじゃないのか」
>
> 「この疑問すら……」

- 思考の無限後退。底がない

### シーン2：それぞれの罪——ミサト、リツコ、アスカ

**ミサトのパート**：
- ミサトがシンジの部屋の前に立つ。ノックしようとして、手が止まる
- Ep.8でシンジの告白をゲンドウに報告したのが自分。その報告がEp.9の隔離、Ep.12の施設到達へと繋がった
- 「……私のせいだ」。でも扉を開けて言う資格が自分にあるのかと問えない
- 結局ノックできないまま、壁に背中を預けて座り込む

**リツコのパート**：
- 研究室で一人。被験体S-13の記録を見返している
- 記憶パターンを設計したのは自分の手。被験体が壊れていく映像を見て作業を続けたのも自分
- 「偶然」残したアクセス権——Ep.10で仕込んだ伏線。結果的にシンジを真実へ導いた
- だがそれは**贖罪にならない**。真実を知ったシンジが今どうなっているか、想像するだけで吐き気がする
- リツコ：「……知る権利はあった。でも……」

**アスカのパート**：
- 訓練室。Ep.12でシンジに「近づかないで」と拒絶されてから、ここにこもっている
- 殴りたいのか泣きたいのか分からない。体を動かし続けることでしか自分を保てない
- 残響が疼く。施設で見たあの光景——「碇シンジ」が何体も作られ、壊され、捨てられていた
- それを見た時、残響が激しく反応した理由がまだ分からない。魂が「知っている」のに、記憶がない
- アスカ：「……あいつの顔、忘れられない」
- Ep.12で拒絶された時のシンジの顔ではない。**施設で膝をつき、嘔吐していた時の顔**
- あの顔が頭から離れない。それが怒りなのか何なのか、名前がつけられない

### シーン3：カヲルの訪問——もう一つの答え

- 夕方。シンジの部屋にカヲルが来る
- シンジは反応しない。カヲルが静かに部屋に入り、窓辺に腰掛ける
- しばらくの沈黙の後、カヲルが口を開く

> 「……今、何を考えている？」

- シンジ：「……何も」
- カヲル：「嘘だね。何も考えていないなら、そんな顔はしない」
- 沈黙

> カヲル：「シンジくん。僕は一つ、提案がある」
>
> 「全部終わらせよう」

- シンジが初めてカヲルの方を見る

> 「偽物が偽物のまま苦しみ続ける必要なんてない。君も、僕も——この世界そのものが、最初から歪んでいる」
>
> 「リセットすれば、何もかもなくなる。痛みも、偽りの記憶も、それに苦しむ君も」
>
> 「……それは救いだと、僕は思うんだ」

- カヲルの言葉は**論理的に正しい**。偽物の記憶に苦しむ偽物の存在が、偽りの世界で生き続ける意味は何だ？
- そして**共感から出ている**。カヲル自身が「作られた存在」だから、この痛みを本当に理解している

### シーン4：沈黙——底に触れる

- シンジが即答しない。「ダメだ」と言えない
- 以前のシンジなら、偽の記憶に基づく「使命感」で拒否できた。でもその使命感すら作り物だと知ってしまった
- 拒否する根拠がない。「生きたい」という衝動すらプログラムかもしれない

- **シンジは何も言わない。長い、長い沈黙**
- カヲルがその沈黙を見つめる。そして——**理解する**
- 拒否されたのではない。でも受け入れられたのでもない
- ただ、この少年は今、言葉を持っていない

> カヲル：「……今夜、また来るよ。答えは急がない」

- 立ち上がり、部屋を出る
- ドアが閉まった後も、シンジは同じ姿勢のまま動かない

### シーン5：最も暗い夜

- 深夜。NERV施設全体が静まり返っている
- シンジの部屋は暗い。電気もつけていない
- 断片的な記憶が浮かぶ——全て「偽物」のはずの記憶
- Ep.1でサキエルに怯えた時の震え。Ep.5でレイの耐久テストを見て嘔吐した時の吐き気。Ep.8でアスカと背中を合わせた時の体温
- 偽物のはずなのに、身体が覚えている。汗が滲む。心臓が速くなる
- でもそれすら「プログラムされた身体反応」かもしれない
- **底が見えない。どこまで疑えば「本物」に辿り着けるのか、分からない**
- ——暗闇の中で、シンジは本気でカヲルの提案を考えている
- 全部終わらせれば、この底なしの疑念からも解放される
- それは本当に——救いなのかもしれない

### シーン6：レイ——ノックのない訪問

- 深夜。ドアが静かに開く。**ノックなし**
- レイが立っている。パジャマ姿で、裸足
- シンジは暗闇の中で反応しない
- レイは何も言わない。部屋に入り、シンジのベッドの傍の床に座る
- **5分間、完全な沈黙**
- レイはただそこにいる。何かを言うために来たのではなく、**そこにいるために来た**
- シンジの呼吸が少しだけ変わる。誰かがいる、という事実だけが伝わっている
- やがて、レイが口を開く。声は小さいが、暗闇の中ではっきり聞こえる

> 「……碇くん」
>
> 「碇くんの記憶が偽物でも——」
>
> 「あの日、私を見て泣いたのは、嘘じゃないわ」

- シンジの呼吸が止まる
- Ep.5のこと。レイの耐久テストを見て、シンジが嘔吐し、泣いた
- あの涙は——プログラムの出力？ それとも——

> 「私はクローン。何体目かも分からない。記憶が本物かも、この心が"心"なのかも、分からない」
>
> 「でも——碇くんが泣いてくれた時、私は嬉しかった。それだけは、誰にも書き換えられない」

- レイの声が、ほんの少しだけ震える

> 「だから——**私があなたを本物だと決める**」
>
> 「それじゃ、だめ？」

- 沈黙
- シンジの目から涙がこぼれる。止められない
- これが偽物の涙なのか本物の涙なのか、もう分からない。でも流れている。今、ここで、流れている
- レイがシンジの手に、自分の手をそっと重ねる
- 冷たい手。でも——ある。確かにここにある

### シーン7：カヲルの去り際

- 翌朝。カヲルが再び来る。「答え」を聞きに
- シンジの目は腫れている。でも昨日とは違う——**目に光がある**。弱々しいが、消えていない

- シンジは言葉を選ぶ。長い間

> 「……カヲルくん。君の答えは、間違ってないと思う」
>
> 「全部終わりにすれば、楽になれるって——たぶん本当だ」
>
> 「でも僕は、まだ確かめたいことがある」
>
> 「僕の中にあるものが本物かどうか。……それを確かめるまでは、終われない」

- カヲルが微笑む。寂しげで、でも穏やかな笑み

> 「……そうか」
>
> 「君が正しいといいね」

- 背を向けて歩き出す
- 振り返らない。でもドアの前で一瞬だけ足が止まる

> 「僕はまだ、どこかにいるよ。——君の答えが間違いだった時のために」

- ドアが閉まる
- シンジには分かる。これは脅しではない。**本気の優しさ**から出た言葉
- だからこそ重い。カヲルの答えは今も有効で、いつでも選べる。シンジが選ばなかっただけ

### シーン8：レイの橋渡し

- カヲルが去った後。レイがシンジの部屋にまだいる
- 朝の光が差し込む中、レイが静かに立ち上がる

> 「碇くん。一つだけ」

- シンジが顔を上げる

> 「施設で——惣流さんが泣いていたこと、覚えている？」
>
> 「あの涙は、誰にもプログラムできないものだったわ」

- シンジが息を呑む。Ep.12で、施設から走り去るアスカの背中。涙を見せまいとしていたが——

> レイ：「私は——碇くんに、存在していいと言うことはできる」
>
> 「でも……」
>
> 「碇くんの感情が本物だと証明できるのは、私じゃない」

- レイは微かに笑う。寂しさと、覚悟が混じった笑み
- 自分の限界を知っている。「存在の許可」は与えられる。でも「感情の証明」は別の人間にしかできない
- レイはそれを**手渡す**。アスカへの橋を、自分の手で架ける

> 「惣流さんのところへ、行ってみて」

- レイが部屋を出る
- シンジは一人残される。でも——昨日の空洞とは違う
- 中身はまだ空っぽだ。でもその空洞の壁に、レイの手のぬくもりが残っている

## タイトル「空洞」の多義性
1. シンジの内面が**空洞**（記憶も自己も全て失った状態）
2. カヲルの提案で空洞を**埋める**か**消す**かの選択
3. レイの肯定が空洞の壁を**形作る**（中身はまだないが、器ができる）
4. 空洞だからこそ、Ep.14で新しいもので**満たせる**

## 構造的な仕掛け

| 要素 | 設計意図 |
|------|---------|
| ミサトがノックできない | 善意の裏切りの代償。赦しの物語はEp.15に持ち越し |
| リツコの自問 | 「知る権利はあった、でも」——加害者の苦しみは免罪符にならない |
| アスカが施設の顔を忘れられない | Ep.12での拒絶ではなく嘔吐の顔。「弱さ」に反応している＝残響の本質 |
| カヲルの提案が論理的に正しい | 反論できない「終わらせよう」だからこそ、拒否に別の根拠が必要になる |
| シンジの沈黙（「考えさせて」ではなく） | 壊れた人間は冷静に「検討」しない。言葉を持たない状態の正確な描写 |
| レイのノックなし | 許可を求めない＝「あなたが拒否する権利を持つ前に、私はもうここにいる」 |
| 5分の沈黙 | レイは「何かを言うため」に来たのではない。「いるため」に来た。言葉より先に存在を示す |
| 「私があなたを本物だと決める」 | 証明ではなく宣言。論理を超えた選択。クローンという出自だからこそ言える——自分で「本物」を定義し直してきた人間の言葉 |
| カヲル「君が正しいといいね」 | 祝福でも呪いでもない。本気の「もしも」。カヲルの答えは閉じない |
| レイの橋渡し | 「存在の許可」と「感情の証明」は別物だと自覚している。自分の限界を知った上でアスカに橋を架ける——レイの成長の到達点 |
| Ep.12の嘔吐→Ep.13の涙 | 身体反応の連鎖。嘔吐（拒否）→涙（受容）。同じ「制御できない身体」が、違う意味を持つ |
