## Notes
- アスカの残響の「理由」は意図的に解明しない。記憶ではなく魂の領域として、説明を超えたものとして残す。
- カヲルとの決着はつけない。「君が正しいといいね」と去り、余韻で閉じる。
- Ep.14のシンクロ率急上昇は「既存パターンに一致しない」ことが重要——新しいシンジの誕生の証。
