# 世界観設定: 敵対勢力と脅威 (Twisted Hard Mode)

## 1. 変異使徒 (Fusion Angels)
ループの歪みにより、使徒の特性が混在・強化されている。「知識」が逆に「罠」となる。

- **第3使徒 (変異体)**:
  - **ベース**: サキエル
  - **追加特性**: ラミエルの「加粒子砲」の予兆（高エネルギー反応）あるいは、ガギエルのような水生特化の高速移動能力を陸上で発揮するなど、物理法則を無視した挙動。
  - **学習能力**: シンジの予測を上回る速度でATフィールドの中和・侵食を行う。

## 2. 人類側の敵意 (Betrayal of Humanity)
ゼーレ、およびそれに従う戦略自衛隊の行動指針が、1周目とは異なっている。

- **対エヴァ・ドクトリン**:
  - 表向きは「対使徒」だが、裏の優先順位は「使徒殲滅 ≧ 初号機の無力化/破壊」。
  - 初号機が制御不能（暴走や覚醒の兆候）を示した瞬間、即座にN2兵器などの最大火力で**パイロットごと**排除する命令が出ている可能性がある。
  - ネルフ本部への誤射を装った攻撃や、支援砲撃の遅延・拒否などが頻発する。

## 3. シンジの立ち位置
- **四面楚歌**: 目の前の使徒（未知の強敵）と、背後の人類（味方のはずが殺しに来る）の挟み撃ち。
- **孤立**: この状況をミサトすら知らない可能性がある（彼女は現場指揮官として板挟みになる）。
