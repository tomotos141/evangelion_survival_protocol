# 新規脅威設定：無人追撃機「レイヴン」 (Autonomous Tracker: RAVEN)

> **「逃れられぬ視線、静かなる摩耗」**

## 1. Basic Data (基本データ)
- **名称**: 無人追撃機「レイヴン」(RAVEN / 鴉)
- **分類**: 自律型観測・妨害ドローン
- **外見**: 翼幅5メートルほどの無機質な黒い全翼機。表面には光学迷彩が施されており、飛行音も極限まで抑えられている。
- **出現場所**: シンジたちの脱走ルート上空。高度3,000メートル付近を旋回。

## 2. Abilities & Nature (能力・特性)
### Core Ability (固有能力)
- **Quantum Spectral Tracking (量子分光追跡)**:
    - 結晶装甲が放つ特有の「因果の歪み（パターン青の残響）」を量子レベルで追跡する。
    - 物理的な隠蔽が通用せず、シンジたちが移動を続ける限り、その座標をネルフに送信し続ける。
- **Psychological Harassment (心理妨害)**:
    - 攻撃ではなく、不定期な超指向性超音波や、睡眠を妨害する特定の周波数の電磁波を放つ。

### Hard Mode Element (ハードモード要素)
- **Anti-Ability Strategy**:
    - シンジの『Causality Anchor』やレイの『Absolute Void』の使用を検知すると、即座に散開し、能力の「効果範囲外」から広域爆撃（煙幕・攪乱弾）を行う。
    - パイロットが能力を使うほど、その位置がより鮮明に特定される「観測の罠」として機能する。

## 3. Threat to Characters (キャラクターへの脅威)
### Psychological Impact (精神的影響)
- **"Watching Eyes" (監視の圧迫)**:
    - 24時間365日、どこまでもついてくる無数の「目」に対するノイローゼ。
    - 安らぎという概念そのものを奪われ、精神的な自壊を待たれる感覚。
- **Rei's Degradation**: 常に『Absolute Void』を展開して身を隠さなければならないため、レイの身体の結晶化が加速する。

## 4. Strategy & Defeat (攻略と撃破)
### Expected Failure (想定される失敗)
- 数機を撃墜しても、すぐに後続が補充されるため、力による解決が無意味化している。

### The Cost of Victory (勝利の代償)
- 追跡を撒くためには、自らの「気配」を完全に消す＝人間としてのバイタルを停止させる一歩手前まで追い込む、死の静寂が必要となる。
