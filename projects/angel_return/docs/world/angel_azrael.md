# 新規使徒設定：第8使徒 アズラエル (Azrael)

> **「沈黙の叫び、死を告げる声」**

## 1. Basic Data (基本データ)
- **名称**: 第8使徒 アズラエル (Azrael / 死を告げる天使)
- **ベース**: 完全新規 (Original)
- **外見**: 巨大な鐘、あるいはパイプオルガンのような無機質な集合体。空中に浮遊し、周囲に音波による歪み（波紋）を発生させている。
- **出現場所**: 第3新東京市上空 2,000メートル付近に静止。

## 2. Abilities & Nature (能力・特性)
### Core Ability (固有能力)
- **Resonance Feedback (共鳴フィードバック)**:
    - 周囲の「音」や「思考波（脳波）」を収集し、特定の周波数で増幅して送り返す。
    - 物理的な衝撃波としてビルを粉砕することも、精密な精神干渉波としてパイロットを狂わせることも可能。
    - **沈黙の領域**: 使徒の周囲半径数キロは、通常の音が伝播しない（音波がすべて使徒に吸収されるため）。

### Hard Mode Element (ハードモード要素)
- **Cognitive Hazard (認識災害)**:
    - パイロットが抱く「殺意」や「敵意」を敏感に感知し、それを増幅させて**「目の前の動くもの（＝味方機）」**へと向けさせる。
    - つまり、戦意が高まれば高まるほど、同士討ちのリスクが増大する。

## 3. Threat to Characters (キャラクターへの脅威)
### Psychological Impact (精神的影響)
- **対 アスカ**:
    - 第8話での出来事により、シンジに対して潜在的な「殺意」を抱いている。アズラエルはその殺意を強制的に引き出し、増幅させる。
    - 「あいつさえいなければ」「あいつが私を殺そうとした」という被害妄想が肥大化し、使徒ではなく初号機を攻撃したくなる衝動に駆られる。
- **対 シンジ**:
    - アスカからの殺意を直接ぶつけられることになる。
    - 彼は「敵を倒す」ことよりも、「暴走する味方（アスカ）から身を守る」ことにリソースを割かねばならなくなる。

## 4. Strategy & Defeat (攻略と撃破)
### Analytical Failure (分析・予測の失敗)
- 当初は「音波攻撃を行う使徒」と分析されるが、真の脅威が「敵意の暴走」であることに気づくのが遅れる。
- 弐号機が出撃するが、即座に錯乱状態に陥り、初号機にライフルの銃口を向ける。

### The Cost of Victory (勝利の代償)
- **The Silence Strategy (思考停止作戦)**:
    - 殺意を感知させないためには、「何も考えない」か「心を殺す」しかない。
    - シンジは自身の感情を極限まで遮断し（あるいはダミープラグに近い精神状態を自己誘導し）、機械的に使徒へ接近する。
    - 一方、アスカは最後まで殺意を制御できず、シンジに取り押さえられたまま（機能停止させられたまま）、目の前でシンジが単独で敵を殲滅する様を見せつけられる。
    - 結果として、「シンジには勝てない」「精神力で負けた」という敗北感が深く刻まれる。
