# 現状整理：Act 2 終盤における世界情勢と「詰み」の予感

物語が第11話（Act 3への転換点）を迎えるにあたり、作中世界における各勢力・キャラクターの状況を整理する。

## 1. NERV：戦略的機能不全
かつては「事象の予測（MAGI）」と「エヴァによる迎撃」で成り立っていたNERVのドクトリンが、完全に崩壊している。

- **MAGIの限界**: 使徒が「学習」し、物理法則を上書き（因果改変）するレベルに達したことで、MAGIの算出する生存確率は常に0%を示し続けている。ミサトの「奇策」も、使徒側がその裏をかくようになり、人命と機体の消耗だけが加速している。
- **リソースの枯渇**: ジオフロントのインフラが使徒の攻撃（第10話の凍結など）で深刻なダメージを受け、修復が追いついていない。ネルフ内部では「勝つため」ではなく「今日生き残るため」の非人道的な措置（電力の強制徴用、バイオパーツの過負荷）が常態化している。

## 2. SEELE：死海文書の不一致
ゼーレが信奉する「死海文書の外典」のシナリオから、事態が致命的に逸脱し始めている。

- **シナリオの喪失**: 予定されていた使徒が現れず、前回のループの攻略法を逆用する「変異体」ばかりが出現することに対し、ゼーレは「何者か（観測者）が因果を歪めている」と判断。
- **強硬策への転換**: シナリオ通りの「補完」が不可能と判断した場合、ゼーレは世界を強制的に無に還す「サードインパクトの早期発動」へ傾斜しつつある。

## 3. キャラクターの状態
### 碇シンジ（感情の摩耗と解離）
- 「生かすこと」には成功しているが、「救うこと」にはことごとく失敗している。
- アスカの拒絶と第9話以降の度重なる精神負荷により、感情をオフにする**「解離性防衛」**が常態化。もはや人間らしい共感よりも、機械的な「処理」を優先するようになっており、そのギャップが周囲に不気味さを与えている。

### 惣流・アスカ・ラングレー（アイデンティティの崩壊）
- 命を救われるたびに、自尊心が削り取られている。
- 特に第10話での「シンジに特攻され、自分は逃がされる」という屈辱は致命傷となった。
- 「使徒の恐怖」よりも「シンジへの憎悪と依存」の板挟みになっており、パイロットとしてのシンクロ率が極端に不安定化。もはや戦力としては「壊れている」状態。

### 綾波レイ（システムの部品への退化）
- 都市防衛システムの一部として酷使され、肉体と魂の境界が曖昧になっている。
- 彼女にのみ「シンジのループ」の微かな残響が届いており、今のシンジが「正気と狂気の境界」にいることを、誰よりも深く、無言で理解している。

## 4. 第10使徒ハドニエル（因果の檻）
この使徒は単なる敵ではなく、世界がシンジの「ループというチート」を認識し、それを**「バグとして排斥」**するために生み出した免疫反応である。
- 「戦って勝つ」ことが、使徒による「巻き戻し」のトリガーになる。
- 勝利を目指すほど状況が悪化するというメタ的な矛盾が、シンジに**「戦うことそのものを止める（凍結）」**という発想を抱かせる最大の要因となる。

---

## 結論：Act 3「凍結」への必然性
現在の世界は、以下の理由により「物理的な解決」が不可能となっている。
1. 使徒（世界）が攻略を学習しきっており、既存兵器では太刀打ちできない。
2. アスカ（第2の心）が完全に折れており、連携が不可能。
3. ネルフ（組織）が自壊寸前。

この「詰み（チェックメイト）」の状態から、シンジが**「盤面そのものを結晶化させ、一時停止ボタンを押す」**のが、第11話以降の展開となる。
