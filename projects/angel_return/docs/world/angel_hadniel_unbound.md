# 新規使徒設定：第10使徒 ハドニエル（解放態） (Hadniel - Unbound)

> **「蓄積された死の奔流、因果の慣性」**

## 1. Basic Data (基本データ)
- **名称**: 第10使徒 ハドニエル（解放態） (Hadniel - Unbound)
- **ベース**: 第10使徒 ハドニエル
- **外見**: 凍結されていた銀の砂時計が内部から粉砕され、中から「不透明な灰色の影」がジオフロント全域に霧散した状態。特定の中心を持たず、空間そのものが「震えている」ように見える。
- **出現場所**: ジオフロント全域（因果の決壊地点）。

## 2. Abilities & Nature (能力・特性)
### Core Ability (固有能力)
- **Inertial Retribution (慣性の報復)**:
    - 凍結（静止）していた期間中に蓄積されていたはずの「物理現象の慣性」を一気に解放する。
    - 止まっていた風は衝撃波となり、抑え込まれていた熱はプラズマ化し、蓄積されていた音はあらゆる物質を粉砕する共振となる。
- **Ephemeral Mimicry (刹那の擬態)**:
    - 解放された時間の残像の中で、1周目の悲劇や、このループで起きた「回避されたはずの死」を物理的な質量（影）として具現化し、無差別に周囲を蹂躙する。

### Hard Mode Element (ハードモード要素)
- **Causality Backlash (因果の跳ね返り)**:
    - 凍結という「無理な現状維持」を選択したシンジとレイに対し、その止めていた時間の重みがそのまま物理的な「重圧」として襲いかかる。
    - シンジが「救おうとしたもの」への執着が、そのままハドニエルの攻撃強度に変換される。

## 3. Threat to Characters (キャラクターへの脅威)
### Psychological Impact (精神的影響)
- **The Guilt of Savior (救済者の罪悪感)**:
    - 自分が守るために止めた時間が、結果としてネルフを破壊し、仲間を傷つける「凶器」となった事実。
    - 「善意による最悪の結果」という、シンジの最も深いトラウマを刺激する。
- **Identity Collapse (アイデンティティの崩壊)**:
    - 目覚めた直後のミサトやアスカにとって、平和だったはずの世界を壊した犯人が「シンジ」に見えるという、絶対的な孤独。

## 4. Strategy & Defeat (攻略と撃破)
### Analytical Failure (分析・予測の失敗)
- 凍結が解けた瞬間、MAGIの全メモリが「過去ログ」に埋め尽くされ、現状維持さえ不可能となる。

### The Cost of Victory (勝利の代償)
- **The Paradox of Choice (選択の逆説)**:
    - この使徒を倒す手段は「存在しない」。なぜなら、ハドニエル自体が「時間の歪み」そのものだから。
    - 唯一の解決策は、ハドニエル（時間の濁流）に呑み込まれる前に、ネルフという「因果の震源地」から離脱し、世界の一部を切り捨てること。
    - **Eternal Exile**: 勝利ではなく、世界からの「逃亡」と「結晶化したレイ」という、取り返しのつかない傷跡のみが残る。
