# 世界観設定: エヴァンゲリオン固有能力 (Redefined Origin Skills)

> **「それは兵器としての機能ではない。世界に対する、魂の拒絶の形である」**

この世界線（2周目）において、エヴァ各機体はパイロットの精神的深淵に呼応した、物理法則を再定義する固有能力を持つ。これらはネルフの想定を超えた「バグ」であり、シンクロ率の上昇とともに機体の形状をも変貌させていく。

## 1. 初号機 (Unit-01) / 碇シンジ
- **能力名**: **"Causality Anchor" (因果の錨)**
- **核心**: 1周目の結末を知るシンジの「結末への執着」が具現化した能力。
- **効果**: 
  - 接触した事象を、シンジの観測する「あるべき状態」へと強制的に固定・固定。
  - 敵のA.T.フィールドや攻撃を物理的な質感に変え、それを「捕食（Devour）」することで自身のエネルギーや装甲へと変換する。
  - **視覚効果**: 初号機の手に触れた空間がガラスのようにひび割れ、赤い結晶が侵食するように広がっていく。
- **リスク**: 因果の重みがシンジの肉体に直接フィードバックされ、彼の心臓や肺が結晶化し始める。

## 2. 零号機 (Unit-00) / 綾波レイ
- **能力名**: **"Absolute Void" (絶対的な虚無)**
- **核心**: 「私はなにものでもない」というレイの根源的な空虚が、周囲を無に還す力。
- **効果**: 
  - 零号機の周囲一定範囲における、すべての「動力（ベクトル）」を停止、あるいは霧散させる。
  - 熱、衝撃、精神汚染、さらには時間さえも、彼女の領域内では「定義」を失い、静止する。
  - **視覚効果**: 零号機を中心に、音のない「白銀の霧」が立ち上り、色彩と熱を奪い去る。
- **リスク**: レイ自身の「存在（魂）」が薄れ、肉体が透明な結晶へと透けていく。

## 3. 弐号機 (Unit-02) / 惣流・アスカ・ラングレー
- **能力名**: **"Rule Breaker" (法を拒絶する者)**
- **核心**: 「私は私だ」という強烈な自己主張が、世界が定めたルール（物理法則や使徒の障壁）を無視し、破壊する。
- **効果**: 
  - 対象が持つ「特性」や「無敵性」の定義を力づくで剥ぎ取る。どれほど強固な盾であっても、アスカが「存在してはならない」と断じた瞬間、それはただの脆弱な肉塊へと成り下がる。
  - **視覚効果**: 弐号機が咆哮するたびに、空間に赤い「クラック（亀裂）」が奔り、使徒の装甲が剥がれ落ちる。
- **リスク**: 世界からの反発を一身に受けるため、機体が受けたダメージが直接パイロットの神経へと焼き付く。

## 変異段階 (Evolutionary Stages)

### 段階 1: 結晶装甲 (Crystallized Armor)
- **状態**: 第14話以降。固有能力が制御を超えて物理的に定着した姿。
- **初号機**: 左腕から胸部が赤い結晶に覆われ、「因果を喰らう」ことで欠損を自己修復し続ける異形へと変貌。
- **零号機**: 全身が半透明の白銀の結晶となり、もはや食事や呼吸を必要としない「事象の偶像」へと変容。
