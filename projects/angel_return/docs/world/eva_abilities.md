# 世界観設定: エヴァンゲリオン固有能力 (Unique Abilities)

この世界線（ループ）では、各エヴァ・パイロットの魂の特性に関連した「固有能力（Origin Skill）」が発現する。これらはATフィールドの応用技術だが、他者には模倣できない。

## 零号機 (Unit-00) / 綾波レイ
- **能力名**: **"Reflect" (鏡面反射)**
- **効果**: 
  - 受けたエネルギー攻撃や精神汚染を、ATフィールドの極性を反転させることでそのまま相手に送り返す。
  - 「私はなにものでもない」というレイの虚無性が、あらゆる攻撃を透過・反射させる鏡となる。
- **リスク**: パイロットの自我希薄化が進む。

## 初号機 (Unit-01) / 碇シンジ
- **能力名**: **"Devour" (捕食)**
- **効果**:
  - ATフィールドを接触させた相手から、文字通りエネルギーや物質を「奪い取る」。
  - 敵のATフィールドを中和するだけでなく、食い破って自分のエネルギーに変換する（S2機関の擬似的な再現）。
  - シンジの「強い渇望」と「欠落」が具現化した能力。
- **リスク**: 使徒の汚染を取り込みやすく、ヒトならざるものへの変異が加速する。

## 弐号機 (Unit-02) / 惣流・アスカ・ラングレー
- **能力名**: **"Pierce" (貫通)**
- **効果**: 
  - あらゆる防御（どれほど分厚いATフィールドや装甲でも）を一点突破で貫く。
  - 物理的な槍やナイフだけでなく、認識阻害などの抽象的な壁さえもこじ開ける「絶対的な拒絶の否定」。
  - 「私を見て！」という強烈な自己顕示欲が、対象に強制的に己を認識させる攻撃となる。
- **リスク**: 防御を捨てた特攻になりがちで、自身へのダメージフィードバックも大きい。

## 仮設５号機・６号機以降 (未定)
