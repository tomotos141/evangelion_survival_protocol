# 世界設定：事象の腐食 (Causality Decay)

> **「観測の途切れた場所から、世界は砂へと還る」**

## 1. Overview (概要)
- **名称**: 事象の腐食 (Causality Decay)
- **分類**: 世界の免疫システム / エントロピー増大現象
- **発生条件**: 第11話における「凍結儀式（Freeze Protocol）」により、時間の流れが強制的・物理的に停止された領域の末端から発生する。

## 2. Nature (特性)
### Core Mechanism (核となる性質)
- **Observation Dependency (観測依存)**:
    - 凍結された世界を維持しているのは、シンジとレイの強力なA.T.フィールドと、彼らの「意識（観測）」である。
    - 二人の注意が及ばない、あるいは「ここにあるはずだ」という認識が薄れた場所から、物質の定義が曖昧になり、色彩を失った「灰」となって崩壊していく。
- **Entropy Accumulation (エントロピーの蓄積)**:
    - 止まった時間の中でも、本来進むべきはずだった因果の「圧力」は蓄積されている。
    - 腐食はその圧力が漏れ出した綻びであり、一度始まると連鎖的に周囲を飲み込んでいく。

### Hard Mode Element (ハードモード要素)
- **Resource Depletion (精神的リソースの枯渇)**:
    - 世界を維持するためには、シンジかレイのどちらかが常に「世界がここにある」という強い意志を注ぎ込み続けなければならない。
    - 休息（睡眠）や精神的な動揺は、そのまま世界の崩壊（腐食）の加速に直結する。
    - **No Safe Haven**: 凍結された世界に安全な場所はなく、二人は「崩壊していく檻」の中で寄り添い続けることを強いられる。

## 3. Threat to Characters (キャラクターへの脅威)
### Psychological Impact (精神的影響)
- **Eternal Vigilance (永遠の警戒)**:
    - 「自分が目をそらせば、世界が消える」という極限の強迫観念。
    - シンジにとっては、守るために止めた世界が、自分のせいで消えていくという皮肉な呪縛となる。
- **The Mirror of Void (虚無の鏡)**:
    - 腐食によって消えた場所には、何も残らない。そこから這い出してくるのは、過去の自分たちの「失敗した影」や、ありえたかもしれない「残酷なif」の声である。

## 4. Countermeasures (対抗策)
### The Fragile Balance (脆い均衡)
- 二人が物理的に接触し、互いの存在を確認し合うことで、観測強度を高め、腐食を一時的に押し留めることが可能。
- だがそれは、二人の自我の境界を曖昧にし、肉体的な「同化」を招く危険な賭けでもある。
