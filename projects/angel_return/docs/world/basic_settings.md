# 世界観設定 (Base Canon)

## ベースライン
**新世紀エヴァンゲリオン (TVアニメ版) / The End of Evangelion (旧劇場版)**

このプロジェクトは上記をベースとした二次創作です。新劇場版の設定（使徒の番号、エヴァの機体番号、用語の違いなど）とは混同しないように注意します。

## 主な特徴
- **使徒**: 第3使徒サキエル ～ 第17使徒タブリス、第18使徒リリン。
    - アダムとリリスは別個の存在として扱われる。
- **エヴァ**: 零号機、初号機、弐号機（参号機、四号機、量産機）。
- **組織**: ネルフ、ゼーレ、戦略自衛隊。
- **地理**: 第3新東京市（箱根）、ジオフロント。
- **人類補完計画**: ゼーレのシナリオ（全人類の単一生命体への還元）とゲンドウのシナリオ（ユイとの再会）の対立。
