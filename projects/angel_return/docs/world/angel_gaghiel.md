# 新規使徒設定：第9使徒 ガグエル (Gaghiel)

> **「熱を喰らうもの、絶対零度の顎」**

## 1. Basic Data (基本データ)
- **名称**: 第9使徒 ガグエル (Gaghiel / 咆哮する魚)
- **ベース**: 原作では水中の使徒だが、本作では「熱エネルギーを捕食する」特性を持つ変異体として再定義。
- **外見**: 巨大な深海魚のような骨格を持つが、肉体は半透明の氷のような結晶で構成されている。
- **出現場所**: ジオフロント最深部の「中央排熱処理施設」。ここで地熱とエヴァの廃熱を喰らい尽くし、エリア全体を凍結させて巣食っている。

## 2. Abilities & Nature (能力・特性)
### Core Ability (固有能力)
- **Heat Predation (吸熱能力)**:
    - 周囲の熱エネルギーを急速に吸収し、自身の質量へと変換する。
    - 触れた物体は瞬時に絶対零度近くまで冷却され、分子結合が崩壊して粉々に砕け散る。
    - **Entropy Field**: 使徒の周囲は熱力学的な法則が歪み、あらゆる動力が急速に減衰・停止する。

### Hard Mode Element (ハードモード要素)
- **Environment Hazard**:
    - 戦場はマイナス200度の極寒地獄。エヴァですら活動限界時間は数分（バッテリー効率が極端に落ちるため）。
    - 外部電源ケーブルは凍結して破損するため、内蔵電源のみでの戦闘を強いられる。

## 3. Threat to Characters (キャラクターへの脅威)
### Physiological Impact (生命の危機)
- シンジとアスカは、この極寒の閉鎖空間に閉じ込められる。
- エヴァが機能停止（ダウン）すれば、エントリープラグ内の生命維持装置も止まり、緩やかな凍死が待っている。
- 互いに憎み合っていようとも、生き延びるためには**互いの体温**を分け合う（ＬＣＬを通じて熱交換する、あるいは無線で声をかけ続けて意識を保つ）しかない。

## 4. Strategy & Defeat (攻略と撃破)
### Analytical Failure (分析・予測の失敗)
- 当初は「排熱異常」として調査に向かうが、予想外の吸熱速度により退路を断たれる。
- 救援部隊もエリア凍結により接近不可能。

### The Cost of Victory (勝利の代償)
- **A.T. Field Phase Reversal & Compression (位相反転・過剰圧縮)**:
    - 外部からのエネルギー供給が絶たれた状態で使徒を倒す唯一の方法。
    - それは、A.T.フィールドを自身の内側へ向けて畳み込み、空間の摩擦と干渉によって極大の「圧縮熱」を発生させること。
    - エヴァ自体を数万度の発熱体に変え、吸熱限界を超えさせて使徒を内側から爆散させる。
    - シンジはこの精神汚染と肉体崩壊のリスクを伴う役割を、アスカではなく自分（初号機）で引き受ける。
    - 「僕が焼ける前に、君だけでも逃げろ」
    - アスカはその献身を見て、憎悪と複雑な感情の間で激しく揺れ動くことになる。
