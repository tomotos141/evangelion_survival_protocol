# Hard Mode Guidelines: Adversarial Evolution Rules

## 概要
本作の世界（2周目）は、単に敵が強いだけでなく、**「前回の敗北データを学習し、メタ的な対策を講じてくる」**という対抗進化（Adversarial Evolution）の性質を持つ。
ここでは、各使徒や環境がどのように「ハードモード化」しているかの指針を定める。

## 基本ルール (The Meta-Rules)
1.  **既知の攻略法の無効化**:
    - 「前回と同じ手」は通用しない。むしろ、その攻略法を罠として利用してくる。
    - 例：プログレッシブナイフの有効範囲に入ると自爆する、など。
2.  **精神攻撃の早期化**:
    - アラエル等の後半の使徒だけでなく、初期の使徒からパイロットへの精神干渉（汚染）を行ってくる。
3.  **都市機能との癒着**:
    - 使徒は単独で攻めてくるだけでなく、第3新東京市のインフラ（電力、地下水路、コンピュータシステム）をハッキング、あるいは物理的に侵食して攻撃してくる。

## 使徒別進化案 (Draft)

### 第3使徒 サキエル (Done)
- **進化:** 初撃から自爆特攻に近い高出力レイザーを使用。
- **結果:** 初号機の捕食によって殲滅されたが、シンジに「味（人肉食の感覚）」というトラウマを植え付けた。

### 第4使徒 シャムシエル (Next)
- **Original:** 光の鞭を持つイカのような使徒。
- **Evolution:** **「光学迷彩と触手の複合」**
    - 姿を透明化し、センサー類を欺瞞する。
    - プログナイフでの接近戦を誘い、見えない鞭で四肢を切断しにかかる。
- **Counter:** ミサトの勘ではなく、シンジの「殺気感知（PTSD由来の過敏さ）」で位置を特定する泥臭い戦いになる。

### 第5使徒 ラミエル
- **Original:** 正八面体の要塞。強力な加粒子砲。
- **Evolution:** **「全方位反射装甲と地中侵攻」**
    - ヤシマ作戦（陽電子砲）を予測し、一点集中のエネルギー攻撃に対して「鏡のように反射」する対策済み装甲を持つ。
    - 地上からの攻撃を完全に無効化しつつ、ドリルに変化してNERV本部へ直下型侵攻を行う。
- **Story:** このため「ヤシマ作戦」は失敗。シンジたちは自らも地下へ潜り、敵の懐へ特攻する「窒息寸前の近接戦闘」を強いられる。

### 第6使徒 ガギエル
- **Original:** 水中型。戦艦２隻で口をこじ開けて撃破。
- **Evolution:** **「液状化と寄生」**
    - 巨大な魚の姿ではなく、無数の小型群体が集まった「生きた黒い水」として登場。
    - 艦船に取り付き、乗員を溶かして取り込みながら、ゾンビシップ化した艦隊でアスカを襲う。
    - エヴァ弐号機の装甲隙間から侵入しようとする生理的嫌悪感を煽る敵。

### 第7使徒 イスラフェル
- **Original:** 分裂する使徒。ユニゾンアタックで撃破。
- **Evolution:** **「非対称分裂とタイムラグ攻撃」**
    - 左右対称ではなく、囮（デコイ）と本体に分かれる。
    - しかも再生のタイミングを意図的にズラしてくるため、同時攻撃（ユニゾン）が無意味化する。
    - 攻略には「息を合わせる」ことではなく、アスカとシンジが互いを囮にして潰し合うような、壮絶な連携（という名の共食い）が必要になる。

## 環境の変化 (Environmental Hazards)
- **赤い海:** 最初から海は赤く、腐敗臭がする。海洋生物は全滅している。
- **気候異常:** 「常夏」ではなく、湿度異常に高い「亜熱帯の腐海」のような気候。カビや錆の進行が早い。
- **人間発電所:** 第4話で判明。都市のエネルギー効率が異常に良いのは、クローン人間の生体エネルギーを転用しているため。
