# キャラクター設定: キーパーソン (カヲル & マリ)

## 渚カヲル (Kaworu Nagisa) - "The Antagonist Savior"
*   **役割**: 最大の障壁にして、歪んだ救済者。
*   **設定**:
    *   全てのループの記憶を保持している。
    *   過去のループで何度もシンジを救おうとし、失敗（シンジの精神崩壊や拒絶）を見てきた。
    *   **結論**: 「シンジ君が苦しまない唯一の方法は、彼を個として存在させない（＝人類補完計画による融合）ことだ」と断定。
*   **行動**:
    *   シンジの敵として立ちはだかる。使徒を指揮し、あるいは自らがMark.06（またはそれに相当する機体）に乗り、シンジを精神的に追い詰めて「補完」を受け入れさせようとする。
    *   その態度は慈愛に満ちているが、やることは冷酷無比。

## 真希波・マリ・イラストリアス (Mari Makinami Illustrious) - "The Trickster"
*   **役割**: 所属不明のイレギュラー。
*   **設定**:
    *   NERVともゼーレとも異なる第3の機関（IPEA、またはヴィレの前身組織）のエージェント。
    *   目的は「ループの観測」と「S2機関（神の力）の解析」。
*   **シンジへの態度**:
    *   シンジの「捕食」能力に強いフェチズムと興味を抱く。「君、イイ匂いがするねぇ。獣の匂いだ」と接触してくる。
    *   味方ではないが、シンジがカヲルやゲンドウに出し抜かれそうになると、面白半分で助言や助太刀をする。
*   **搭乗機**: 仮設5号機、または強奪した8号機。

# 世界観設定: ループの真相 (The Loop Origin)

## 原因: 初号機 (神) の願望機化
*   **仕組み**: EOEのラストで「生命の樹」と同化した初号機が、シンジの深層心理にある「やり直したい」「まだ終わりたくない」という未練をトリガーに、時間遡行（量子的な再構成）を行っている。
*   **皮肉**: シンシが絶望して「もういい」と諦めない限りループは終わらないが、シンジが希望を持って「生きたい」と願えば願うほど、「満足する結末」に至るまでループが続いてしまうジレンマ。
*   **解除条件**: シンジが「痛み」や「他者との不和」を受け入れ、その上で「それでも世界は美しい」と心から肯定すること（EOEの結論を、ポジティブな形で再定義すること）。
