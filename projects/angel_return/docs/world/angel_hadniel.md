# 新規使徒設定：第10使徒 ハドニエル (Hadniel)

> **「因果の檻、不変なる徒労」**

## 1. Basic Data (基本データ)
- **名称**: 第10使徒 ハドニエル (Hadniel / 因果の観測者)
- **ベース**: 完全新規 (Original)
- **外見**: 巨大な銀の砂時計を内包した、透明な多面体。中心部の「砂」が逆流するたびに、周囲の空間にノイズが走る。
- **出現場所**: ジオフロント上空。垂直に降下しながら、接触した範囲の「時間軸」を歪ませる。

## 2. Abilities & Nature (能力・特性)
### Core Ability (固有能力)
- **Causality Rewind (因果の巻き戻し)**:
    - 自身、および影響圏内で起きた事象を秒単位、あるいは分単位で「発生前」の状態に強制的に書き換える。
    - 攻撃が命中したという「事実」そのものが消失し、世界は数分前の平穏な状態へと回帰する。
    - **Mental Residue (精神の残滓)**: 物理的な巻き戻しが行われても、干渉を受けたパイロットの「記憶」や「蓄積された恐怖」だけは巻き戻されず、同じ恐怖を何度も体験させられる。

### Hard Mode Element (ハードモード要素)
- **Observer Loop (観測者ループ)**:
    - シンジが持つ「未来の知識」というアドバンテージを完全に無効化する。
    - シンジが「正解の行動」を取った瞬間に、使徒はその結果を観測し、即座に因果を巻き戻すことで対策を行う。

## 3. Threat to Characters (キャラクターへの脅威)
### Psychological Impact (精神的影響)
- **対 シンジ**:
    - 「何度やり直しても無駄だ」という、自分のループという存在そのものを嘲笑されているような感覚。
    - レイを救おうと足掻くほど、その救済すらも巻き戻されるという絶望。
- **対 アスカ**:
    - 「自分の存在意義（戦果）」がそもそも発生しなかったことにされる虚脱感。
    - 自身が命を救われた事実さえも巻き戻されることへの不気味さと、シンジへの不信。

## 4. Strategy & Defeat (攻略と撃破)
### Analytical Failure (分析・予測の失敗)
- MAGIは当初「空間干渉」と分析するが、徐々に「計算結果が過去のものと重複し、未来の計算が停止する」という異常事態に陥る。

### The Cost of Victory (勝利の代償)
- **The Decisive Choice (決定的選択)**:
    - この使徒を「倒す」ことは不可能。倒した瞬間に「倒したという因果」が巻き戻されるから。
    - 攻略ではなく、世界そのものを因果の連鎖から切り離し、静止させる「凍結」という結論を出すためのトリガーとなる。
