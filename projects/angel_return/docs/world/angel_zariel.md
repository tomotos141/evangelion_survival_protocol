# 新規使徒設定：第7使徒 ザリエル (Zariel)

> **「形なき恐怖、侵犯する霧」**

## 1. Basic Data (基本データ)
- **名称**: 第7使徒 ザリエル (Zariel / 監視の天使)
- **ベース**: 完全新規 (Original)
- **外見**: 特定の形状を持たない、銀色の霧状・ガス状の集合体。微小なナノマシンのような粒子の集まりにも見える。
- **出現場所**: 第3新東京市全域を覆う「異常気象」として出現。

## 2. Abilities & Nature (能力・特性)
### Core Ability (固有能力)
- **Amorphous & Intangible (不定形・物理無効)**:
    - 打撃、斬撃、実弾攻撃はすべて効果がない（すり抜ける）。
    - 爆風で一時的に散らすことは可能だが、即座に再集合する。
- **Invasion & Contamination (侵食と汚染)**:
    - エヴァの装甲の継ぎ目、通気口、あるいはATフィールドの微細なほころびから機体内部へ侵入する。
    - 侵入した粒子は回路をショートさせ、生体部品（筋肉繊維など）に直接癒着・壊死を引き起こす。

### Hard Mode Element (ハードモード要素)
- **Anti-EVA Strategy**:
    - 物理攻撃しか持たないエヴァ（特に弐号機）に対し、接触することなく内部から無力化する戦術を取る。
    - パイロットが吸い込む、あるいはプラグ内に侵入されると、直接神経系に干渉し、「生理的な不快感」や「幻覚」を引き起こす精神汚染を行う。

## 3. Threat to Characters (キャラクターへの脅威)
### Psychological Impact (精神的影響)
- **対 アスカ**:
    - 「自分のテリトリー（エヴァ、プライド）」を土足で踏み荒らされることへの極度の嫌悪感。
    - 物理的な攻撃手段を持たないため、自身の強みである「格闘戦」や「射撃戦」が封じられ、パニックに陥りやすい。
    - 霧による視界不良と閉塞感が、彼女の孤独感を刺激する。
- **対 シンジ**:
    - 「見えない敵」への恐怖。
    - しかし、彼は「敵は学習する」という前提で動いているため、比較的冷静に「自分ごと攻撃させる」などの捨て身の戦術を発想できる。

## 4. Strategy & Defeat (攻略と撃破)
### Analytical Failure (分析・予測の失敗)
- **初期対応の遅れ**:
    - レーダーに捕捉されず、単なる気象異常として処理されるため、初動での迎撃が不可能。
    - エヴァが出撃しても、敵の所在がつかめず、ザリエルによる一方的な侵食を許してしまう。

### The Cost of Victory (勝利の代償)
- **Friendly Fire Strategy (同士討ち作戦)**:
    - 侵食された弐号機を囮・檻として利用する。
    - シンジ（初号機）が冷却剤タンクを破壊し、**アスカごと**使徒を凍結させる（あるいは熱光線で消毒する）。
    - アスカは凍傷と精神的ショックで重傷を負い、プライドを粉々にされる。シンジに対しては「助けられた」感謝よりも、「殺されかけた」という恐怖と憎悪が残る。
