# 世界観設定: ループの代償と制約 (ハードモード)

## ループの仕様: "煉獄"
- **不可避の収束**: 誰かを救おうとすると、別の誰かが犠牲になる、あるいは対象がより悲惨な目に遭うという「運命の揺り戻し」が強烈に働く。
- **精神の摩耗**: ループは「リセット」ではなく「積み重ね」。疲れも絶望も癒えないまま、ただ時だけが戻る。

## 周囲の違和感
- **NERV / ゲンドウ**:
    - シンジの異常な様子（老成した絶望、手慣れすぎた操縦）を即座に見抜き、警戒レベルを引き上げる。
    - 「シナリオと違う」存在として、シンジが監視・拘束の対象になったり、より非人道的な実験台にされる可能性がある（ダミープラグの早期投入など）。
- **使徒の変化**:
    - シンジの強さに呼応するように、使徒の学習・進化も加速する。パターン青の反応が最初から異なるなど、攻略法が通用しないケースが出てくる。

## 物語のトーン
- 閉塞感、焦燥感、無力感。
- 「勝った」としても、失うものが大きすぎるピュロスの勝利。
