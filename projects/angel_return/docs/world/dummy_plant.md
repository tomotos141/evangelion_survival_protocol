# Location: ダミープラグ・プラント (The Factory)

## 概要
NERV本部最深部、セントラルドグマに隣接する特別立入禁止区画。
表向きは「ダミーシステムおよびEVAシミュレーションデータの保管庫」とされているが、実態は綾波レイの複製（スペア）を製造・保管、および調整する工場である。

## 雰囲気 (Atmosphere)
- **Visual**:
    - 全体が無機質な金属と強化ガラスで構成されている。リツコの研究室とは異なり、ここは「工場」的な冷たさがある。
    - 巨大な円筒形の水槽（LCLタンク）内には、無数の「綾波レイ」の素体が漂っている。彼女たちは胎児のように丸まっているか、あるいは無表情に外を見つめている。
    - 照明は薄暗く、水槽の放つ青白い光だけが光源となっている。
- **Auditory**:
    - 常に低い駆動音（ポンプの循環音）が響いている。
    - 時折、気泡が弾ける音や、調整中のレイが発する微かな呻き声（あるいは生体パーツが切断される不快な音）が聞こえる。
- **Olfactory (嗅覚)**:
    - リツコの研究室と同じく、消毒液の匂いがするが、ここにはそれに混じって**「鉄錆（血）」と「羊水（LCL）の甘い腐敗臭」**が漂っている。第4話の地下廃棄区画と同じ系統の臭いだが、こちらはより人工的で濃密。

## ギミック / 設備
- **調整槽 (Calibration Tank)**:
    - 中央にある、稼働中のレイが入るための小型水槽。
    - ここでは脳への直接データ転送や、肉体の再生治療が行われる。
    - 調整の過程で、激痛を伴う神経接続テストが行われることがあり、その様子は「拷問」と区別がつかない。
- **廃棄シュート**:
    - 「エラー」を起こした個体や、古くなった素体を廃棄するためのハッチ。ここから第86廃棄区画（第4話の舞台）へ直結している。

## 2周目特有の要素
- **生産ラインの加速**:
    - 敵対勢力（使徒）の進化に対抗するため、以前よりも使い捨て前提の運用がなされており、水槽内のスペアの数が明らかに多い。
    - 未完成の個体（欠損や奇形）もそのままサンプルとして残されている場合がある。
