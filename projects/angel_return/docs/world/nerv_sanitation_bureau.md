# NERV衛生局 (NERV Sanitation Bureau)

## 概要
NERV直轄の精神衛生管理機関。「精神汚染スクリーニング」を名目に、第3新東京市の住民——特に児童・生徒の精神状態を強制的にスキャンし、管理下に置く。表向きは公衆衛生機関だが、実質的にはNERVの情報統制・人材管理の末端装置。

## 組織原理
- **悪意ではなく無関心による加害**。構成員は個人的な嗜虐心で動いているのではなく、数値とプロトコルに従って「業務」を遂行しているだけ。人間を見ているのではなく、データを処理している。
- この事務的な冷淡さが、意図的な悪意よりもはるかに深く対象者を傷つける。子供の傷口を業務報告と同じ温度で読み上げる——その無関心こそが本質的な暴力。
- **描写方針**: 挑発的な悪役として描かない。台詞は平坦・事務的に。感情の不在そのものが恐怖となるように。

## 権限と手順
- 学校・公共施設への予告なし立入検査権を保有
- 対象者を「被検体No.XXX」として管理（非人格化）
- スクリーニングの流れ: サイレン → 出席番号順整列 → ハンディスキャナーによる個別検査 → 異常値検出時は要観察/連行
- 家族歴・血縁間の「汚染相関」も調査対象
- 抵抗者には「再教育施設」への送致を示唆

## 装備
- 白い不透明な防護服、フェイスシールド（表情を隠す）
- ハンディタイプの高精度精神汚染スキャナー（銃口に似た外観）
- タブレット端末（被検体データベース接続）
- メインユニット + ネットワーク接続（校舎単位で一時展開）

## 碇司令との権力関係
- 衛生局は碇ゲンドウの直接管轄下にはないが、NERV本局の指揮系統に属する
- 碇司令の息子（サードチルドレン）に関するインシデントは報告書の提出が必要
- 報告書がゲンドウの目に触れた場合の報復を恐れており、現場レベルでは「碇」の姓が事実上の抑止力として機能する
- この力学がEp.03でシンジの「碇ゲンドウの息子」という立場を盾にした撤退を可能にした

## 登場箇所
- Ep.03「硝子のプリズム」: 学校での定期スクリーニング。トウジの精神汚染係数がイエローレベルを示し、サクラとの遺伝的不適合因子を事務的に読み上げる。シンジの機材破壊により撤収。
