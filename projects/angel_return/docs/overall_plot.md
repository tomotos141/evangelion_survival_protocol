# Overall Plot: Angel Return (Title TBD)

## Core Concept
**「強くてニューゲーム」の皮を被った、実存的不安の物語。**
主人公・碇シンジは2周目の知識と技術を持つが、世界そのものが微妙に変質しており（ハードモード）、かつ自身の精神も摩耗している。
彼は「14歳の少年」を演じながら、破滅的な未来を回避、あるいは「正しく終わらせる」ために暗躍する。

## Themes
- **The Mask**: 社会的役割（演技）と本質（エゴ）の乖離。
- **Uncanny Valley**: 知っているはずの親しい人々が、微妙に違う反応を示す不気味さ。
- **Fatalism**: 運命を変えようとする行為そのものが、新たな悲劇の引き金になる皮肉。

## Story Arc (構成案)

### Act 1: 潜伏 (The Impostor) - 第1話〜第4話
**目的**: シンジがNERV内部での安全を確保しつつ、ミサトやリツコの監視の目を欺く。
- **Episode 1: 使徒、再来 (Done)**
    - サキエル殲滅。シンジは恐怖を演じるが、初号機の暴食というイレギュラー発生。
- **Episode 2: 同居人、観察者**
    - ミサトとの生活開始。彼女の杜撰な生活に対し、つい「慣れた手つき」で世話をしてしまい怪しまれる。
    - 「あなたは誰？」という無言の問いとの戦い。
- **Episode 3: 硝子のプリズム**
    - 学校生活。トウジ・ケンスケとの接触。
    - 殴られイベントを「わざと殴らせて同情を買う」計算高いムーブで処理しようとするが、トウジの妹の容態が前回より悪いことを知り動揺する。
- **Episode 4: 雨の逃避行（フェイク）**
    - 家出イベント。本来なら精神的に追い詰められての家出だが、今回は「ミサトを油断させるための演出」として家出を決行。
    - しかし、街で出会うケンスケとの会話で、予期せぬ「この世界の歪み」に触れる。

### Act 2: 乖離 (The Divergence) - 第5話〜第10話
**目的**: 原作シナリオからの逸脱（イレギュラー）への対処。アスカ、レイとの関係性の変化。
- **Episode 5: 笑わない少女**
    - レイとの接触。彼女に対して「救済」ではなく「共犯」を求める誘惑に駆られる。
    - ヤシマ作戦（ラミエル戦）。敵のＡＴフィールドが強化されており、従来の出力では抜けない。シンジは「暴走」を装って出力を強引に引き上げるか、隠し持っていた戦術を使うか迫られる。
- **Episode 6: 赤い来訪者**
    - アスカ来日。彼女はシンジを見て即座に「同類」の匂い（傷ついた獣の匂い）を嗅ぎつける。
    - 仲良く喧嘩するのではなく、互いに腹を探り合う張り詰めた「ユニゾン」。
- **Episode 7～: 使徒の進化**
    - 出現する使徒の順番や能力が変わり始める。
    - シンジの「予知」が外れ、即興での対応を強いられる場面が増加。
    - ミサトがシンジの過去（空白の14年間？）について独自調査を開始。

### Act 3: 崩壊 (The Collapse) - 第11話〜
**目的**: ループの真相解明と、ゲンドウ・ゼーレとの直接対決。
- **The Trigger**: バルディエル（トウジ）戦。ここでの選択が分岐点。
    - 前回と同じ悲劇を繰り返すか、ダミープラグを破壊してでも止めるか。
    - シンジは「大人としての責任」と「子供の無力さ」の狭間で、決定的な選択を迫られる。
- **The Truth**: カヲルの登場。彼もまたループしているのか？
    - 「27曲目の不協和音」の正体が判明。世界が壊れている原因。
- **Climax**: サードインパクトの阻止、あるいは「世界のリセット」の拒絶。
    - シンジはエヴァを降りるためではなく、エヴァを葬るために最後の戦いに挑む。

## Key Mysteries (未解決の伏線)

2.  **初号機の自律行動**: ユイの意志なのか、それとも別の何かが混じっているのか？
3.  **ゲンドウの視線**: 彼は最初からシンジがループしていることに気づいている？（死海文書外典？）
