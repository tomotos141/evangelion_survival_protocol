# Overall Plot v2: Evangelion: Survival Protocol

## Core Concept
**「強くてニューゲーム」の皮を被った、アイデンティティの物語。**
主人公・碇シンジは2周目の知識と技術を持つ——と本人は信じている。
だがその「1周目の記憶」は、ゲンドウとゼーレが植え付けた**偽物**だった。

物語は、嘘の記憶で世界を欺いてきた少年が、その記憶すら嘘だったと知り、
それでも**「ここまで生きてきた自分は本物だ」**と選び直すまでの過程を描く。

## Adaptation Policy
**Anti-Retelling & Original Expansion**
原作アニメのエピソードをなぞることはせず、設定を活かした完全オリジナル展開を主軸とする。
既知の使徒やイベントが登場する場合でも、その攻略法や結末は劇的に変更し、
常に「未知の恐怖」と「ギリギリの綱渡り」を描く。

## Themes
- **The Mask**: 社会的役割（演技）と本質（エゴ）の乖離。さらにその「本質」すら作り物だったという二重の仮面。
- **Real / Fake**: 偽りの記憶から生まれた感情は本物か？ 存在の正当性は出自で決まるのか？
- **Adversarial Design**: 「学習する世界」の正体は、父親が設計した地獄だった。天災ではなく人災。
- **Three Answers**: 存在の問いに対する三者三様の答え——レイ（存在の許可）、カヲル（終わらせてもいい）、アスカ（本物かどうかなんて知るか）。

## 設計原則（Design Principles）

Author DNA（`.agent/author_profile.md`）を本作品に適用した3つの構造原則。

### 1. 身体的代償の設計（Erosion Tracking）

> **偽の記憶で高シンクロ率を叩き出すたびに、身体が少しずつ壊れる。**

偽の記憶は脳のキャパシティを超えて精神-身体接続を酷使する。結果として、戦闘のたびにシンジの身体に**不可逆な微小損傷**が蓄積する。心理的代償（アイデンティティの空洞化）が物語の主軸だが、身体的代償はその**物理的な証拠**として機能する。

| Ep | 戦闘 | 身体的代償 | 描写 |
|----|------|-----------|------|
| 1 | サキエル | 左手の指先の痺れ | 戦闘後、箸を落とす。「疲労だ」と合理化 |
| 6 | ラミエル改 | 味覚の鈍化 | レイとの食事で「味が薄い」。塩分濃度は正常 |
| 8 | 空間歪曲型 | 右耳の高音域消失 | アスカの声が時々聞こえない。残響の声との対比 |
| 10 | 寄生型 | 左目の視野欠損（一時的→微小残存） | Ep.12で施設の文字が読みにくい伏線に |
| 14 | 最後の使徒 | **なし** | 偽の記憶を使わずに戦った→侵食が起きない |

**テーマ接続**: 偽の記憶が「偽物」でも、その記憶で戦った身体の損傷は「本物」。記憶を手放した後も指先の痺れは残る——**身体が戦ってきた証は消えない**。Ep.14で「僕の筋肉は本物だ」と言える根拠に、痺れや味覚の鈍化という不可逆な証拠が重なる。

**Ep.15での回収**: リツコに「消せますか？」と聞く場面。記憶は消せるかもしれない。でも指先の痺れは消えない。「消せるけど消さない」の重みが、身体的代償によって倍加する。

### 2. 日常の聖性と嵐の配分（Storm & Calm Rhythm）

> **暴力と喪失の間に「生きていること」の手触りを挟む。壊される前のものを見せなければ、壊れた後の喪失は伝わらない。**

| 配置 | 内容 | 構造的機能 |
|------|------|-----------|
| Act 1 (Ep.2-3) | ミサトとの同居。缶ビール、料理の失敗、布団の匂い | 「守りたかったもの」の原型。Ep.8の裏切りで破壊される |
| Act 2 Ep.7冒頭 | 朝食の風景。レイのパン耳、味噌汁の湯気 | 嵐の前の凪。アスカ到着後は二度と戻らない日常 |
| Act 3 | **意図的に不在** | 日常の聖性を奪うことで、Act 3の窒息感を増幅 |
| Act 4 Ep.15 | 夕暮れの帰り道。手は繋いでいないが距離が近い | 壊れた後の新しい日常の予感。「始まり」の手触り |

**ルール**: 各Actに最低1つの「凪」シーンを配置する。ただしAct 3は**意図的にゼロ**にすることで、Act 4の帰り道の風が際立つ。

### 3. 沈黙の設計（What Is NOT Written）

> **最も重要な瞬間は「書かないこと」で語る。**

| 場面 | 書かないもの | 効果 |
|------|-------------|------|
| ゲンドウの手が崩れる (Ep.15) | 内面描写 | 読者の解釈に委ねる |
| レイの5分間 (Ep.13) | 会話 | 「いるために来た」が言葉より重い |
| ミサトがノックできない (Ep.13) | ノック音 | できなかったことが最も雄弁 |
| アスカの残響の理由 | 説明 | 魂の領域は説明を超える |
| カヲルとの結末 | 決着 | 「君が正しいといいね」で去る |
| ゲンドウの手の0.5秒 (Ep.5) | ゲンドウの自覚 | 冬月だけが見ていた無意識の亀裂 |

## Story Arc（全15話・4幕構成）

### Act 1: 潜伏 (The Impostor) — Ep.1〜4 【現行維持】
**目的**: シンジがNERVおよび「世界」の監視の目を欺き、生存圏を確保する。

- **Ep.1: 使徒、再来**
    - サキエル殲滅。シンジは「PTSDサバイバー」として恐怖に耐えながら戦う。初号機の捕食行動というイレギュラー発生。
    - 【裏】ゲンドウの最初のテスト。「前知識がある人間」がどう動くか観察開始。
- **Ep.2: 同居人、観察者**
    - ミサトとの生活開始。過剰反応がミサトに「異常性」を疑わせる。
- **Ep.3: 硝子のプリズム**
    - 学校での精神汚染スクリーニング騒動。トウジを守って介入。CODE BLUEの伏線。
- **Ep.4: 地下の迷宮**
    - 地下廃棄区画で「人間を燃料とする都市の真実」を目撃。使徒的因子が恐怖に呼応。

**Act 1で植える追加伏線**:
- シンジの「記憶」と微妙に食い違う小さな違和感（本人は「世界が学習したから」と合理化）
- ゲンドウがシンジを見る目の異様な冷静さ（観察ではなく**確認**している目）

### Act 2: 乖離 (The Divergence) — Ep.5〜8
**目的**: 人間関係が深まると同時に、シンジの「記憶」への信頼が揺らぎ始める。

- **Ep.5: 人形の夢** ※詳細: [ep05_ghost_in_the_shell.md](./episodes/ep05_ghost_in_the_shell.md)
    - リツコに連れられNERV最深部へ。レイの「調整」の実態は生体部品としての耐久テスト。
    - シンジが嘔吐。「1周目にはこんなことなかった」——偽の記憶と現実の最初の明確なズレ。
    - レイの部屋で：「なぜ泣いているの」「君が泣かないから、代わりに」——Ep.12で最も残酷に反復される台詞の起点。
    - レイの目が変わる。泣いた人間はシンジが最初。「この人は違う」。
    - リツコがテストを自分の権限で中止。シンジの反応が設計より強いことをゲンドウに報告しない——最初の隠蔽、最初の逸脱。
    - 【裏】ゲンドウにとってシンジの涙は感情定着のデータポイント。だがシンジの叫びがユイの声に似た瞬間、**組んだ手の指が0.5秒緩む**——最終対峙での手の崩壊の最初の種。冬月だけが目撃。

- **Ep.6: 雷撃の神殿** ※詳細: [ep06_thunderbolt.md](./episodes/ep06_thunderbolt.md) 【使徒戦②：ラミエル改】
    - シンジが偽の記憶に基づき「ヤシマ作戦」を提案。自信を持って放った閃光がラミエルの多重次元屈折に弾かれ、自軍に跳ね返る。「正解」が自分を殺しに来た——Ep.5に続く二度目の亀裂。
    - 地中侵攻作戦に切り替え。レイと共に廃棄坑道を這い進む。暗闇の中でATフィールドが干渉し始め、同調率が異常値に——偽の記憶に定着した感情が戦闘能力として発現。
    - レイが初めて「怖い」を口にし、戦場で自らシンジを庇う。Ep.5の耐久テストとの反復だが、今回は自分の意志で。
    - 戦闘後、レイ：「……また、一緒に乗れる？」——初めて未来を望む言葉。「いつものこと」と苦痛を受容していた少女に「次」が生まれる。
    - リツコがATフィールド同調率の最大値を低く申告（Ep.5に続く二度目の隠蔽）。
    - 【裏】ヤシマ作戦の情報はゲンドウが偽の記憶に仕込んだ「餌」。シンジが提案した＝記憶が機能している証拠。地中侵攻は最初から並行準備されていた。
    - 【転換①発火】ゲンドウは最初からシンジをテストしていた。

- **Ep.7: 深紅の亡命者** ※詳細: [ep07_crimson_storm.md](./episodes/ep07_crimson_storm.md)
    - **嵐の前の朝食**: シンジとレイの朝食（パン耳、味噌汁の湯気）。ミサトのクマと笑顔。壊される前の日常の具体像——「日常の聖性」の設計配置。
    - ユーロ支部壊滅の報。ゲンドウだけが驚かない（裏：ゼーレの計画的処理）。通信にJSSDFの特殊研究班「**高雄**」の名前（痕跡①）。
    - アスカが亡命者として到着。「客じゃないわ、戦力よ」——全てを失った状態で、同情を拒否する矜持。
    - シンジの偽の記憶がアスカを「知っている」。懐かしさと罪悪感が顔に出る。アスカはそれを見て激昂——二重の怒り（同族嫌悪＋残響の激情）。
    - 【転換②】口論中にアスカが「あんたはいつもそう」と漏らす。初対面なのに「いつも」——残響の最初の発露。シンジの偽の記憶にはないフレーズ。
    - 夜、残響が疼く。映像ではなく感覚——体温、距離感、息遣い。名前のつかない感情がシンジに向いている。
    - レイの直感：「あの人は、碇くんの知らない碇くんを知っている」。
    - 【裏】アスカをシンジにぶつける接触実験。だがアスカの残響はゼーレの想定を超えている——Act 3以降でシナリオを崩す最大の変数に。

- **Ep.8: 鏡の裂け目** ※詳細: [ep08_crack_in_the_mirror.md](./episodes/ep08_crack_in_the_mirror.md) 【使徒戦③：空間歪曲型】
    - アスカとの初共闘。言葉より先に体が連携する。二人とも驚く。
    - 戦闘後、アスカの困惑：「勘違いしないで。次はない」
    - シンジがミサトに部分的な真実を打ち明ける。ミサトは受け止めたように見せて——
    - 【転換③】ゲンドウに報告する。善意の裏切り。安全圏の崩壊。
    - アスカはシンジがミサトを選んだことに、理由の分からない悔しさを覚える。

### Act 3: 包囲 (The Siege) — Ep.9〜12
**目的**: 人間こそが敵。全ての真実が暴かれ、シンジの世界が崩壊する。

- **Ep.9: 檻** ※詳細: [ep09_the_cage.md](./episodes/ep09_the_cage.md)
    - ゲンドウがシンジを「保護」の名目で隔離。テストと称した尋問。
    - ゲンドウ：「お前の"記憶"は、どこまで正確だ？」
    - ミサトが自分の報告が引き金だったと知り、激しく後悔。ゲンドウに詰め寄るが、返答に凍りつく。
    - アスカの中で「気になる」が育っている。シンジの不在が気になって苛立つ。
    - **アスカの突撃**: パイロットの肩書きを盾にシンジへの面会を要求、完全に失敗。「力じゃ、開かないの」——Lie（能力＝存在価値）への最初の亀裂。力ではなく言葉で壁を壊すEp.14への布石。

- **Ep.10: 侵食** ※詳細: [ep10_the_erosion.md](./episodes/ep10_the_erosion.md) 【使徒戦④：寄生型】
    - エヴァに精神侵食する使徒。シンジの「記憶」がフラッシュバックで漏れ出す。
    - うわごとで「アスカ」の名を呼ぶ。
    - アスカが医務室で付き添う。寝ているシンジの顔を見て残響が最も強く疼く。涙が出る。
    - 深夜、レイが静かに来て、ATフィールドを重ねる。シンジの悪夢が止まる。
    - 【裏】リツコが侵食データからシンジの記憶構造を解析。「植え付けた記憶パターンと一致」を確認。罪悪感から、後にシンジが資料に辿り着けるよう「偶然」アクセス権を残す。

- **Ep.11: 渡し守** ※詳細: [ep11_the_ferryman.md](./episodes/ep11_the_ferryman.md)
    - カヲル登場。シンジに真実の一端を告げる。
    - 「学習する世界」の正体——ゲンドウとゼーレが、シンジの行動データを使って戦場を設計していた。
    - 【転換④】ハードモードは父が設計した檻だった。
    - カヲルとシンジ、「作られた存在」同士として語り合う。
    - カヲルの人事資料に「適格者候補B-7：霧島マナ。現況：行方不明」の記載（痕跡②）。レイの視線が止まるが意味は追えない。
    - カヲル：「君は知るべきだと思ったんだ。……知った上でどうするかは、君の自由だよ」

- **Ep.12: 白紙** ※詳細: [ep12_blank_page.md](./episodes/ep12_blank_page.md)
    - リツコがEp.10で「偶然」残したアクセス権から、施設の座標を発見。カヲルと共にゼーレの施設へ。
    - 培養槽の映像で「別のシンジ」がEp.5でレイに言った台詞をそのまま発している——自分だけの言葉がプログラムの出力だった恐怖。
    - シンジは「自分のクローンが作られていた」と解釈するが、カヲル：「逆だよ」——**シンジ自身がコピー側**だった。
    - 【転換⑤】被験体S-13。13番目にして初めて壊れなかった成功例。1周目の記憶は全て植え付けられた偽物。
    - 施設のデータログに「並行プロジェクト：適格者候補B-7（霧島）。残響定着実験（対照群）」の記録（痕跡③）。アスカの残響の起源がゼーレの実験に繋がることを示唆。
    - アスカが残響に導かれて施設に到着。残響がこの場所を「知っている」——理由は不明（次の謎へ）。
    - シンジが自らアスカを遠ざける：「近づかないで。僕の中の君は、作り物だ」
    - アスカ：「……っ、勝手にしなさいよ！」

### Act 4: 選択 (The Choice) — Ep.13〜15
**目的**: 全てが崩壊した後で、それでも「自分」を選び直す。

- **Ep.13: 空洞** ※詳細: [ep13_void.md](./episodes/ep13_void.md)
    - アイデンティティの完全崩壊。記憶が偽物なら、自分は誰だ？
    - ミサト（ノックできない）、リツコ（自問）、アスカ（施設での顔が忘れられない）——それぞれの罪と痛み。
    - カヲルが「全部終わらせよう」と提案。論理的に正しく、共感から出た言葉。シンジは即答で拒否できない。
    - **シンジの沈黙**。言葉を持たない。カヲルはそれを理解し、一度去る。
    - 最も暗い夜。シンジは本気でカヲルの提案を考えている。
    - 深夜、レイがノックなしで訪れる。5分の完全な沈黙——「いるために来た」。
    - レイ：「私があなたを本物だと決める。それじゃ、だめ？」——存在の肯定。シンジが泣く。
    - 翌朝、カヲルとの決別。シンジ：「まだ確かめたいことがある」。カヲル：「君が正しいといいね」——去る。決着はつかない。
    - レイの橋渡し：「惣流さんの涙は、誰にもプログラムできないものだったわ」「私では足りない」——アスカへの橋を自分の手で架ける。

- **Ep.14: 残響と咆哮** 【使徒戦⑤：最後の使徒】 ※詳細: [ep14_echoes_and_roar.md](./episodes/ep14_echoes_and_roar.md)
    - ゲンドウの計画外の使徒が出現。物語で初めてゲンドウが動揺する。
    - アスカが残響に導かれてケージへ駆けつけ、動けないシンジに告白。「あたしに向かって言い直してみなさいよ。同じ言葉を」
    - シンジは偽の記憶の技術を意図的に手放してエヴァに乗る。シンクロ率32%まで急落。
    - アスカも弐号機で出撃するが押し返される。アスカが危ないと感じた瞬間、身体記憶が発動——Ep.1,6,8で実際に戦った経験だけが体を動かす。
    - 3度の突進。不格好で泥臭い、しかし**本物の勝利**。既存パターンに一致しない新しいシンクロ。
    - 発令所の片隅でレイが静かに頷く。Ep.13の言葉が届いたことの確認。
    - 戦闘後、アスカ：「さっきの叫び、あたしの知ってるどの"碇シンジ"とも違った。あんただけのものだった」

- **Ep.15: 巡礼の始点** ※詳細: [ep15_starting_point.md](./episodes/ep15_starting_point.md)
    - Ep.14の翌朝。シンジが**自ら**ゲンドウの元へ向かう（Ep.9の呼び出しとの対称）。
    - ゲンドウが語る動機——ユイを取り戻すための記憶植え付け。「お前は道具だ」。
    - シンジの反転：「あんたの感情は本物か？」——物語全体の問いが設計者に跳ね返る。ゲンドウが初めて言葉に詰まる。
    - 「母さんに会いたいなら、自分の足で行けよ」——赦しではなく超克。ゲンドウの手を組んだ姿勢が15話で初めて崩れる。
    - ミサトとの再出発。「方法が間違っていただけ」——赦しではなく「ここから」の合意。
    - リツコへ：「消せるけど消さない。自分で決めたかった」——製造物が製造者の前で選択する。
    - レイとの着地：「分からない。でも、それでいいと思えるようになったわ」——答えのない問いを共に抱える同志。
    - アスカとの帰り道。「昨日のは忘れなさいよ」「どの部分を？」「全部。……いや、最後だけ覚えてていい」
    - **残響の問い**: シンジが施設のログにあった「残響」の記述に触れる。アスカ：「これはあたしのもの」——起源が何であれ、感情の所有権を宣言する。答えは次の物語に属する。
    - 最終独白：「借り物の記憶で走った14話分は、もう終わった。これが、僕の——1話目だ」
    - **物語が終わるのではなく、本当の物語が始まる地点で閉じる**。

**方針**: 表は「キャラの関係を動かす舞台装置」、裏は「ゲンドウに操作されていた陰謀」。転換④で全てが繋がり、読者が過去の戦闘を読み返した時に鳥肌が立つ構造。

| # | Ep | 使徒 | 表の機能 | 裏の機能 | 身体的代償 |

| ③ | 8 | 空間歪曲型 | アスカとの初共闘 | アスカをぶつける実験（残響の戦闘発現テスト） | 右耳高音域消失（アスカの声が時々聞こえない） |
| ④ | 10 | 寄生型 | 記憶漏洩→偽物の確証 | リツコが記憶構造を解析 | 左目視野欠損（施設で文字が読みにくい伏線） |

- ④：戦闘後、リツコが不自然にシンジの脳波データを持ち出していた
- ⑤：ゲンドウの計画外。だからこそゲンドウだけが動揺している

## キャラクター役割

> 各キャラクターは中心テーマ（「偽物の記憶から生まれた感情は本物か？」）に対する**異なる回答**を体現する。
> Ghost → Lie → Truth のチェーンが、それぞれの物語行動を駆動する。

### 碇シンジ — 偽りの記憶を持つ少年

| | |
|--|--|
| **Ghost** | EOEの記憶——全員が死ぬ世界、アスカの首を絞めた掌の温度。偽物だが感覚だけは本物 |
| **Lie** | 「1周目の記憶さえ正しく使えば、今度は誰も死なない」——知識が救済を保証するという信念 |
| **Truth** | 「借り物の記憶で走った14話分は、もう終わった。これが、僕の——1話目だ」 |

- **Lieが駆動する行動**: 偽の記憶を根拠にした先読み・戦術（Act 1-2）→ 記憶の偽物判明で全てが瓦解（転換④）→ 記憶を手放し、32%の裸の自分で戦う（最終戦）
- **物語の問い**: 偽物の記憶から生まれた感情は本物か？
- **答え**: 記憶が偽物でも、ここまで戦ってきた自分は本物だ

### 綾波レイ — 「先輩」/ 存在の肯定

| | |
|--|--|
| **Ghost** | 「代わりがいる」存在として製造された出自。ダミープラントの同じ顔の群れ |
| **Lie** | 「私は命令を遂行し、還るべき場所（リリス）に還る部品に過ぎない」——機能が存在を定義する |
| **Truth** | 「分からない。でも、それでいいと思えるようになったわ」——他者の存在を肯定する行為が自分を肯定する |

- **Lieが駆動する行動**: 司令の命令に従順（Act 1）→ シンジとの関係で「私」という個体を選び始める → 「私があなたを本物だと決める」で許可を与える側に立つ
- **テーマへの回答**: 存在の許可。本物かどうかは、他者が「本物だ」と決めることで成立する
- シンジと同じ傷（出自の否定）を先に生きてきた同類。恋愛ではなく魂の共鳴

### 惣流・アスカ — 「鏡」/ 感情の証明

| | |
|--|--|
| **Ghost** | 母キョウコの精神崩壊と心中未遂。「ママ、こっちを見て」に応答がなかった瞬間 |
| **Lie** | 「誰よりも優れていれば、捨てられない」——能力が存在価値を保証する |
| **Truth** | 「あんただけのものだった」——他者の「本物」を認めることが、自分の感情の本物を受け入れる入口 |

- **Lieが駆動する行動**: パイロットとしての実力で存在証明（到着時）→ 拘留されたシンジに肩書きで面会を要求、失敗（Lieへの亀裂）→ 使徒に技術が通じずLie粉砕 → 力ではなく言葉で壁を壊す（反転）
- **テーマへの回答**: 「本物かどうかなんて知るか」——分析ではなく挑発で本質を突く。理由のない感情が最も強い
- **残響**: 前周の魂の欠片。記憶ではなく身体感覚（背中の温度、距離感、息遣い）。偽の記憶を持つシンジとの対比がテーゼを構成する
- 温度推移：激昂 → 困惑 → すれ違い → 無防備な接近 → 拒絶 → 不在の痛み → 告白 → 隣にいる

### 碇ゲンドウ — 「設計者」/ 真の黒幕

| | |
|--|--|
| **Ghost** | ユイの消失——初号機への吸収。目の前で妻が消え、自分には何もできなかった無力感 |
| **Lie** | 「ユイを取り戻すためなら、どんな犠牲も正当化される」——愛が全ての非道を免罪する |
| **Truth** | 物語内で到達しない。だがシンジの「あんたの感情は本物か？」に言葉が詰まり、組んだ手が初めて崩れる——その沈黙がTruthへの入口 |

- **Lieが駆動する行動**: 偽の記憶の設計・植え付け → 息子を「素材」として運用 → シンジが設計を超え始めると手が0.5秒緩む（最初の亀裂）→ 最終対峙で手が崩れる
- 動機が「愛（ユイへの）」であることが単純な憎悪を許さない。加害者と被害者が同じ問いの前に立つ構造
- **テーマへの回答**: 答えられない。その沈黙自体が回答

### 葛城ミサト — 「善意の共犯者」/ 贖罪

| | |
|--|--|
| **Ghost** | セカンドインパクト時の父の死。大人は嘘をつく——だから自分は「正しい大人」にならなければ |
| **Lie** | 「大人として正しいことをすれば、子供を守れる」——正しい手続き（報告・組織的対応）が保護になるという信念 |
| **Truth** | 方法が間違っていただけ。「正しい手続き」ではなく「この子の隣にいる」ことが保護だった |

- **Lieが駆動する行動**: シンジの異常に気づく → 「正しい大人」としてゲンドウに報告 → それが引き金になりシンジが拘束される → 善意が加害になったと知り、組織を裏切る側に回る
- ミサトのノックできなかった手——「書かないこと」で最も雄弁に語る沈黙の設計

### 渚カヲル — 「同類の誘惑者」/ もう一つの答え

| | |
|--|--|
| **Ghost** | 使徒としての特殊知覚で人間の苦しみを繰り返し目撃。特にシンジの設計された苦痛の全てを「知っている」 |
| **Lie** | 「苦痛に意味がないなら、慈悲ある終焉が最善だ」——苦しみを終わらせることが最大の優しさ |
| **Truth** | 到達しない。「君が正しいといいね」——答えを保留したまま退場する |

- **Lieが駆動する行動**: 真実を告げ、シンジに「全部終わらせよう」と提案 → シンジが拒否 → 殺さない、決着をつけない → 不在のまま、シンジの選択が自分のLieへの反証になるのを見守る
- **テーマへの回答**: 終わらせてもいい。だがシンジは終わらせない方を選んだ。その選択を尊重して去る

### 赤木リツコ — 「製造者の罪」

| | |
|--|--|
| **Ghost** | 母ナオコの支配と死。母のパターンを知りながら繰り返す自分への嫌悪 |
| **Lie** | 「データと科学が全て。感情は不要な変数」——科学的合理性でゲンドウへの執着と罪悪感を覆い隠す |
| **Truth** | アクセス権を「偶然」残す行為——科学者の仮面の下の倫理が、初めて自分の選択を生む |

- **Lieが駆動する行動**: 偽の記憶を技術的に設計（ゲンドウの共犯者）→ 罪悪感が仮面の隙間から漏れる → 資料のアクセス権を「事故」で残す → シンジに「消せるけど消さない」と言われ、自分の選択の意味を知る

### 霧島マナ — 痕跡のみの存在

> 本編には直接登場しない。ゼーレの並行プロジェクト「残響定着実験」の被験体として、データログや人事ファイルに名前が残るのみ。

- 人事記録：「適格者候補B-7。現況：行方不明」（カヲルの資料に記載）
- データログ：「並行プロジェクト：適格者候補B-7（霧島）。転送先：ユーロ支部。備考：残響定着実験（対照群）」
- JSSDF特殊研究班「高雄」の名前がユーロ支部壊滅時の通信に登場
- **機能**: アスカの残響の起源がゼーレの実験に繋がることを示唆する伏線。次の物語への扉

## Key Mysteries（伏線リスト）

### 主要伏線（全体構造に関わる）

1. **シンジの記憶の違和感** — Act 1から微細な食い違い。本人は「世界の学習」と合理化。身体的代償（指先の痺れ、味覚の鈍化）が物理的な証拠として蓄積
