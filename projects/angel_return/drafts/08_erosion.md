# Episode 8: 侵食する霧 (The Erosion)

## Scene 1: 不協和音、あるいはノイズ
**Loc**: ネルフ本部・訓練射撃場 / **Time**: 朝 / **Cast**: シンジ、アスカ、リツコ

「遅い！」

シミュレーターから出た瞬間、アスカの怒声が飛んできた。
彼女はタオルで汗を拭うこともせず、仁王立ちで僕を睨みつけている。

「反応速度が0.5秒遅れてるわよ。あんた、やる気あるの？」
「……ごめん」
「謝ればいいと思ってんの！？ 実戦ならあんたのせいで私も死ぬとこだったわよ！」

彼女の苛立ちはピークに達している。
昨日の戦闘で傷ついた弐号機はまだ修理中。彼女のプライドも同様だ。
自分の弱さを認められない彼女は、その焦燥をすべて僕という「格好のサンドバッグ」にぶつけている。

「アスカ、そこまでになさい」

ガラス越しに、リツコの声が響く。

「シンジ君のスコアは合格ラインよ。むしろ、あなたが突出して攻撃的すぎるだけ」
「はぁ！？ 私が悪いっていうの！？」

アスカはさらに激昂する。
僕はただ、俯いてその嵐が過ぎ去るのを待った。
……違うんだ、アスカ。僕は君の邪魔をしているんじゃない。
君が突出しすぎて「死ぬ」未来が見えるから、あえてバックアップに回っているだけなんだ。
でも、それを説明する言葉を僕は持たない。

## Scene 2: 形なき侵入者
**Loc**: 第3新東京市街地 / **Time**: 昼下がり / **Cast**: シンジ、ミサト

異常は、音もなく始まった。
警報はない。ただ、街を覆っていた薄い靄が、急激に質量を持ち始めた。

「……霧？」

ミサトのマンションのベランダから、僕はそれを見ていた。
白い霧ではない。銀色の、金属光沢を持つ微粒子のような霧。
それが、まるで生き物のようにビルの隙間を縫って、ジオフロントへの通気坑へと吸い込まれていく。

『総員、第一種戦闘配置！』

ミサトの携帯端末が鳴る。
僕は反射的に立ち上がった。
来た。
レーダーには映らない。でも、肌が粟立つこの感覚は間違いなく「敵」だ。

## Scene 3: 不在の戦場
**Loc**: ジオフロント内 / **Cast**: アスカ（弐号機）、シンジ（初号機）

「目標、映像確認できません！ レーダー反応なし！」
「そんなの、手当たり次第に撃てば当たるでしょ！」

アスカの弐号機がパレットライフルを乱射する。
だが、弾丸は銀色の霧を素通りし、虚しくビルの壁を砕くだけだ。

『やめなよアスカ。物理攻撃は効かない』
『うるさい！ 命令しないで！』

焦るアスカ。
その時、弐号機の警告灯が一斉に赤く染まった。

『警告、機体内部に異物侵入！ エントリープラグ内圧上昇！』
『な……何、これ……！？』

モニター越しのアスカの悲鳴。
彼女のプラグスーツの隙間から、銀色の粒子が這い回るように侵入し始めていた。

## Scene 4: 汚染
**Loc**: 弐号機エントリープラグ内 / **Cast**: アスカ

「いや……やだ、入ってくる……！」

気持ち悪い。
虫が這うような感触。いや、もっと冷たくて、無機質なものが、私の皮膚を、神経を直接撫でていく。

『ママ……助けて……』

意識が混濁する。
霧の向こうに、人形が見えた。首のもげた人形。
私を置いていったママ。
違う、私は人形じゃない。私は選ばれたパイロットエリートなのよ。

「どいてよぉぉぉッ！！」

アスカは操縦桿をめちゃくちゃに叩いた。
だが弐号機は動かない。
神経接続がジャックされている。私の体が、私の言うことを聞かない。

## Scene 5: 氷の棺桶
**Loc**: 初号機内 / **Cast**: シンジ

アスカの絶叫が通信回線を飽和させる。
精神汚染レベルが危険域に達している。

「……葛城さん、許可を」
『え？』
「冷却タンクを爆破します。弐号機ごと凍らせる」

ミサトが息を飲む気配がした。
それはアスカの命に関わる危険な賭けだ。
でも、いま彼女を救う（殺させない）方法はそれしかない。

「許可を！」
『……許可する！ やりなさい！』

僕はためらいなくトリガーを引いた。
地下都市の貯水槽に隣接する、大規模冷却システムのパイプライン。
それを、プログナイフで切断する。

ゴォォォォッ！！

超低温の冷却液が、弐号機に向けて噴出する。
銀色の霧が一瞬で凍りつき、動きを止めた。
同時に、弐号機の装甲も白く凍てついていく。

「……ごめん、アスカ」

僕は凍りついたアスカの機体を抱きしめるように固定し、動けなくなった使徒の「核（コア）」――実体化した一瞬の隙――を、ナイフで抉り出した。

## Scene 6: 殺意の証明
**Loc**: 病室 / **Time**: 数日後 / **Cast**: シンジ、アスカ

アスカは重度の凍傷で入院していた。
僕は見舞いのために、リンゴを一つ持って病室に入った。

彼女はベッドの上で、包帯だらけの姿で僕を見た。
その目に宿っていたのは、感謝ではない。
底知れぬ憎悪と、恐怖だった。

「……殺す気だったんでしょ」

掠れた声。

「あんた、私を囮にした。私ごとあいつを殺した」
「……そうしないと、君が侵食されて死んでた」
「嘘よッ！！」

アスカがサイドテーブルの花瓶を投げつける。
砕け散るガラス。水が床に広がる。

「あんたなんか……死ねばよかったのに」

僕は何も言わずに、割れた破片を拾い始めた。
わかっていたことだ。
僕たちは分かり合えない。
でも、君は生きている。それでいい。

病室を出ると、廊下の冷たい空気が肌に触れた。
僕の「孤独な戦争」は、まだ続いていく。
