# Episode 15: 巡礼の始点 (The First Footstep)

鋼鉄のゲートを、自らの内側から食い破るようにして、僕たちは、かつて自分たちが守ろうとしていた「城」の外に出た。

視界を埋め尽くしたのは、鼻腔の奥を容赦なく刺す鮮烈な鉄錆の匂い、そして、咽せ返るような死の色彩だった。

海はあまりにも赤かった。
1周目の記憶の底にある、淡い生命の欠如した朱色ではない。

それはさらに淀み、不気味な粘り気を持った、濃縮された噴出後の鮮血の如き深紅だった。
打ち寄せる波は重く、鉛のような質量を伴って、塩害で白骨のように朽ち果てた超高層ビル群の裾野を、執拗に打ち付けている。

空は、第10使徒ハドニエルの残滓が撒き散らした不透明な灰色の蓋に覆い尽くされていた。
太陽の光はその厚い鉛の層を透過し。
不気味な、熱も宿さない無機質な鈍色の円となって、ただ無関心にこの死にゆく世界を照らしていた。

ここでは風さえもが、僕たちの結晶化した装甲に触れると、事象の矛盾に耐えきれず石のように硬く砕け散っていく。

「はぁ、っ……はぁ……、……っ」

初号機という、もはや人としての輪郭を失いつつある結晶의 巨躯を一歩動かすだけで、肺の最も深い奥底が、白熱した鉄を呑み込んだかのように疼き、焼ける。

エントリープラグを無理やり満たし続けているLCLの液体は、既に生身の少年の生命を維持する機能を、とうの昔に失い始めていた。

機体の表面を寄生虫のように侵食した深紅の結晶。
それが、周囲の因果の連鎖を強引に逆流させ。
僕の呼吸という、最も原始的な生命維持活動そのものを「なかったこと」にしようと介入を繰り返している。

「……碇君。足を止めてはいけないわ」

隣で零号機（改）が音もなく静止した。
その機体の本来あるべきだった黄色の装甲。
そして、過去の戦いの傷を痛々しく隠していた幾重もの包帯は、もうどこにも存在しない。

全身を、月明かりを吸い込んだかのような半透明の白銀の結晶に包まれ。
色彩という名の俗世の未練をすべて捨て去った、凍りついた偶像のように、彼女はただ、赤い海のどこまでも続く水平線を見つめていた。

「大丈夫だよ、綾波。行こう。もう誰にも、僕たちを『便利な部品』として」
「書き換え可能な『予備』として扱わせない場所へ」

僕は初号機の、結晶化し鋭い爪へと変貌した指先で、彼女の細く。だが鋼鉄よりも硬い白銀の指を握った。

操縦桿という旧時代の産物はもはや必要ない。
僕たちの神経は、プラグ内にまで血管のように張り巡らされた結晶の不気味な脈動を通じて直接溶け合い。
互いの氷点下まで冷え切った体温を、そして魂が摩耗していく軋みを分かち合っていた。

夜が来る。
それは光が消えることではなく、灰色の空が、より一層の不可視の重圧を伴う闇へと沈殿していくことだった。

僕たちは崩れかけた沿岸の工業地帯に身を隠した。
潮風と共に運ばれてくる塩分が、剥き出しになった結晶装甲の隙間にこびりつき。
僕が動くたびに、まるで誰かが耳元で硝子を噛み砕いているような不快な共鳴音を立て続ける。

本来ならばエヴァンゲリオンという異形の巨体の重みに、コンクリートの基部は耐えきれず、流体のように崩落するはずの場所だ。だが、僕は初号機の左腕を、ビルの中心を貫く錆びついた鉄骨へと突き立てた。そして、「因果の錨」を闇に解き放った。

空間そのものが巨大な硝子を打ち砕いたかのような、凄惨な不協和音が、静寂の夜を暴力的に切り裂いた。

僕という怪物の絶対的な意志が、「崩落」という平凡な物理的未来を力づくで拒絶する。
ビルの鉄骨から深紅の結晶が生き物のような速度で芽吹き、僕たちを不変の台座へと作り変えた。

「……碇君。休んで、周辺の観測は、私が空白で隠すから」

レイの乗る零号機が僕の背後に寄り添うように跪く。
彼女の能力『Absolute Void（絶対的な虚無）』。

それが展開されると。僕たちの周囲数百メートルが、音も熱も。そして「存在の定義」さえも消失した、完全なる真空の檻となった。

ネルフ本局が放った高精度の赤外線センサーからも、地表を舐めるような音響探知機からも、僕たちの存在はこの観測可能な世界から、物理的に抹消される。

世界から切り取られた、僕たち二人だけの密室。

僕はプラグの中で、震える手でプラグスーツの胸元を引き剥がした。
やはりだ。

鎖骨の、本来なら柔らかい皮膚があったはずの場所に、深紅に透き通った小さな結晶の芽胞が、皮膚を内側から突き破り、僕の肉を糧にして芽吹いていた。

因果の書き換えという、神の領域への冒涜に対する。
この死にゆく世界からの、冷酷な領収書だ。

「……綺麗ね。……碇君。……とても。……暖かい」

レイの声は、直接脳髄を撫で上げるような思念となって届く。
彼女の眼球も、今は既に結晶化の最終段階にあり。
視覚さえも失っているはずだった。

それでも僕には、彼女が、この呪われた結晶の芽生えを、慈しみ微笑んでいるのが分かった。
僕たちはもう人間には戻れない。この地獄の果てを目指す、孤独な巡礼者なのだから、短い。石の中に閉じ込められたかのような眠りは、頭上から降り注ぐ、金属的な不協和音によって切り裂かれた。

黒い闇を嘲笑うかのように、高度3,000メートル付近で、僕たちの領域を執拗に探る無数の影が旋回し始めた。

無人追撃機「レイヴン」。
初期型のそれよりも遥かに洗練され、殺意を削ぎ落とした監視の化身。
彼らは爆弾を落とすわけでもない。

ただ規則的に放たれる指向性超音波が、結晶化した僕の意識の隙間を暴力でかき回し。
「お前は観測されている」という呪いを脳髄に打ち込もうとしてくる。

「っ、ふざけるな。いい加減に、放っておいてくれよっ！」

僕はもはや機能していない、ただの飾りのレバーを力の限り握り締めた。
自分の腕が装甲の結晶化と同期し。
もはや自分の意志だけでは持ち上げられないほどに重くなっている事実に、肺が圧迫される。

「因果の錨」を全開に解き放てば。空一面を因果の裂け目（クラック）で埋め尽くし。
あの金属の鴉どもを一羽残らず虚無へと叩き落としてやることができる。だが、それはできない。僕が大きな力を使えば。
僕たちの位置を本隊に教えてしまうことになる。そして、理性を消失させ僕を食らいたいがために彷徨い続ける「アスカ」を呼び寄せてしまう。

僕たちは、逃げることさえ。あるいは戦うことさえ。
潔くは許されていない。

ただこの灰色の荒野を一歩ずつ歩き続け。
肉体を、そして世界そのものを少しずつ削り落とされ。
全身が結晶となって風に消え去るその時まで、都合よく「消費」されるのを、待つしかないのだ。

「……碇君。行かないと。鴉が群れを呼んだわ」
「東の空、境界線の向こうから、大きな死の匂いが近づいている」

レイの声に弾かれるように、僕は初号機を立ち上がらせた。
事象を固定していた深紅の結晶が、不快な粉砕音を立てて砕け散る。

止まっていた時間の流れという「重力」が、報復のように、僕の肺を再び強く圧迫し始めた。

夜明けが来た。だが、その光は空を明るく染め上げることを拒んでいた。

ただ。死を連想させる灰色から、人としての未練をすべて削ぎ落とした、より薄く冷たい灰色へと、死人の肌のような生気のない色に移ろっただけに過ぎなかった。

「ねえ、レイ。僕はどこまで、いつまで行けるんだろうね」

ネルフのデータベースにも人理の記録にも存在しない、地図の完全なる空白地帯。
人為的な観測が途絶え、物理法則の定義そのものが剥がれ落ち。
世界が灰色の砂へと還り始めている「事象の腐食」領域。

そこまで辿り着けば。あるいは、ようやく。誰の目にも止まらない真実の意味のある「死」を、手に入れることができるのだろうか。

「あなたの行く場所が、私の還る場所。どこまでも一緒よ、シンジ君」

レイの零号機が、初号機の隣に寄り添うように並び立った。
二体の異形と化した、エヴァンゲリオン。

深紅の結晶装甲が、夜明けの僅かな死んだ光を乱反射し。
この色彩を、意味を、未来を失いゆく世界の中で、唯一、残酷な輝きを放っていた。

僕は一歩を踏み出した。
それは、弱かった僕の脚が、二度度戻れない日常を文字通り踏みにじり。
アスファルトと共に完膚なきまでに粉砕する音だった。

一歩、また一歩。
背後に残るのは不吉な重みで砕かれた文明の残骸と、剥がれ落ちた結晶の破片。

ネルフ本局からの緊急無線が絶え間なく空から降り注ぐ。
ミサトさんやアスカの、憎しみと焦燥の混ざり合ったその声は、今の僕には、もはや過去から届く意味を成さない雑音に過ぎなかった。

僕たちは、自分たちが一度は守り、そして自らの手で破壊した世界の荒野へと踏み出した。
誰にも祝福されず、誰にも愛されない。
僕たちだけの、果てしない巡礼が今始まったのだ。

たとえ、その先に救いなど何一つないとしても、僕たちが刻んだ足跡（フットステップ）だけは、消しようのない事実として、この滅びゆく世界に、確かに残されている。

僕たちは、歩き続ける。
