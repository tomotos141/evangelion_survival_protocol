# Episode 11: 静止する砂時計 (Stillborn Hourglass)

世界は、古い磁気テープのようにその輪郭から汚れ、ほつれ始めていた。

ネルフ本部、中央発令所のメインスクリーン。
そこに映し出された第3新東京市の光景は、もはや解像度の低い悪質な悪夢そのものだった。

そこにあるはずの超高層ビルが、一度激しく明滅したかと思うと、建設途中の剥き出しの鉄骨へと退行し、あるいは完全に消失して一面の更地へと書き換えられる。

第10使徒ハドニエル。
その多面体の影が幾何学的な不吉さを伴って空に現れてから、この街における「時間」という尺度は、狂った計器のように、その信頼性を完全に失っていた。

「また第十七管区が消えました……！ 修復中だった区画が、爆撃される前の無傷な状態に……いいえ、建設前の更地に戻っています！ 時間軸の整合性が取れません！」

「モニターに砂嵐発生！ 現在時刻が過去のログに吸い込まれています！ メインバンクのデータが、一分ごとに数時間分消失しています！」

伊吹マヤさんの悲鳴に近い叫びが、無数の電子警報音の渦に掻き消されていく。
それは物理的な破壊よりも、生存の根底を根こそぎ奪い去るような、根源的な「拒絶」だった。

ネルフが積み上げてきた歩みも、職員たちが昨日交わした言葉も、事象との連続性を失い、濁った泥水のように混ざり合っていく。

起きたはずの「昨日」が、起きていないはずの「過去」へと飲み込まれ。
今この瞬間という立脚点さえもが砂の城のように崩れ去っていく。

『……起きた昨日が、起きていない今日に書き換えられていく。世界そのものが、自らの記述を消しゴムで消しているのね』

赤木リツコ博士が、震える手でタバコの火を灰皿に押し潰した。
その指先さえもが、不透明な揺らぎの中で一瞬、子供のように小さく見えた。

因果の崩壊はもはや観測装置の不具合ではなく。
人間の肉体という現実さえも侵食し始めていた。

ジオフロントのパイロット待機室。
そこは外界の混乱から防護されているはずだが、不気味なほどの静寂が、かえって終末の気配を濃厚に漂わせていた。

「……あんた、何か言いなさいよ！ なんでそんな、落ち着いていられるわけ！？」

アスカの声が震えながら僕を撃ち抜く。
彼女は葛城ミサトさんの胸倉に縋りつくような、今にも泣き出しそうな表情でそこに立っていた。

かつての傲慢な黄金の輝きは失われ、ただ出口のない焦燥感と、自分の積み上げた戦果（アイデンティティ）がノイズと共に消し飛ばされていくことへの恐怖だけが、彼女を突き動かしていた。

「ダメよ、アスカ。今のあなたの精神波形（パルス）じゃ、この因果の揺らぎには耐えられない。プラグに入った瞬間に、あなたの意識は昨日と今日の狭間に吸い込まれて霧散してしまうわ」

「そんな……っ！ じゃあ、こいつはどうなのよ！？ なんで、シンジだけが普通でいられるのよ！？」

アスカの指先が、壁際に音もなく佇む僕を指差した。
僕は、ただそこにいた。

視線を向けても、僕の瞳は彼女の姿を適切な解像度で結ばない。
瞬きすら忘れ、呼吸の回数さえも最小限にまで間引かれ、表面温度の感じられない硝子の球体のような瞳。

一度きりと信じていたやり直し。
その期待が裏切られ、絶望さえも使い古した古いレコードのように繰り返される日々の中で、僕が手に入れたのは、命の温もりを代償に手に入れた、底知れない「効率」と「諦念」の凍土だった。

「……あんた、怖くないの？ 昨日さえも失っていく、自分という存在が薄皮を剥ぐように消されていく、この感じが」

僕は答えない。
剥落していく昨日を惜しむ、そんな当たり前の人間らしい感傷さえ。
僕は既に自分自身の「生存維持には不要なノイズ」として、遠い記憶の隔離病棟に閉じ込めていた。

怖がることが、どれほどのエネルギーを浪費するか。
悲しむことが、どれほど因果の固定を難しくするか。

僕は、僕という存在を、この2周目の地獄を終わらせるための「精密な部品」へと、自らの手で削り出していたのだ。

ネルフ深部、セントラルドグマに隣接するレイのメンテナンスルーム。
LCLを満たした水槽の底で、綾波レイが静かに僕を呼んだ。

彼女の肌は、背景を埋め尽くすドス黒い影に溶けそうなほどに白く。そしてどこか半透明な、実体感を欠いた揺らぎを帯びていた。

「零号機の神経パルスを、使徒への干渉を食い止めるための『重石』として使い続けているの。今のところ、この本部だけは『今』の座標を保てているわ。でも……」

「……そんなことをすれば、君という個人の定義が崩れる。君の魂が、情報の波に飲まれて消えてしまう」

僕は、水槽の冷たいガラスにそっと触れた。
レイという少女。

彼女は今、使徒ハドニエルによる事象の巻き戻しに対抗するための、巨大な楔……。
あるいは、ネルフというシステムによって浪費される使い捨ての防波堤として、そこに沈んでいた。

昨日を繋ぎ止めようとするたびに、彼女の記憶は混濁し、彼女という「個」は薄れ。
代替可能な「部品」としての純度だけが高まっていく。

「代わりは……既に、たくさん用意されているから、私が消えても、ネルフの機能は、維持されるわ」

「そんなものは、要らないんだ。代わりの君なんて、どこにもいない」

僕は、レイの瞳の底を覗き込んだ。
そこにあるのは、司令官からの命令でも、エヴァのパイロットとしての役割でもない。

ただ、消え入りそうな命の灯火が、「私をここに留めて」と、音のない悲鳴を上げている。
僕は知っている。彼女がこれから辿るはずの、あの残酷な対消滅を、だからこそ。これ以上の犠牲を、彼女をただの「システム維持のコスト」として摩耗させることだけは、自分の魂にかけても、この2周目の全存在を賭してでも許せなかった。

エヴァ初号機のパレットライフル。
そのトリガーにかけた人差し指の、微かな皮膚の感覚。
それが、不意に、何の説明もなく消失した。

正確には、指をかけたという「過去の事実」そのものが、空間の記述から暴力的に削り取られたのだ。

（……二十一回目だ）

僕は、構え直すことさえしなかった。
空中に浮かぶハドニエルの砂時計。

その巨大な、水晶のような多面体が、わずかに不協和音を立てて逆流する。
どれほど完璧な狙撃を試みようと、命中の一瞬手前で世界が先返りする。

弾丸を放ったという事実。
照準を合わせたという時間。
前進しようとする僕の意志、勝とうとする渇望。

そのすべてが、ハドニエルという怪物にとっては、時間を巻き戻すための芳醇な「動力源」として吸い取られていた。

僕に、1周目の知識があるからこそ。僕に、やり直したいという強い願いがあるからこそ。
あらゆる攻略法が、そのまま自分を縛る鉄格子の檻へと変わる。

僕自身の、「やり直したい」というループの呪縛そのものが、使徒という形を借りて僕の無力さを嘲笑っている。

「勝利を……結果（ゴール）を目指すから、巻き戻されるんだ。目的を、未来を捨てればいい」

僕は、エントリープラグ内のLCLに沈み、目を閉じた。

一度きりと信じた「やり直し（2周目）」。

だが、その世界さえも、かつてない静かな、そして徹底的な拒絶を伴って、幕を下ろそうとしていた。

僕が積み上げてきた、誰かを救うための足掻きのすべてが、この閉塞した円環の一部に過ぎなかったことを、僕は理解した。

カヲル君が囁いた「やり直し」も、ハドニエルが強いる「巻き戻し」も、結局は、誰かが、あるいは世界そのものが用意した袋小路で、僕という道化が躍らされているだけだ。

「勝利なんて、最初から存在しなかった。ただ、この袋小路の因果を、僕の腕で無理やりへし折る。それだけが、残された唯一の道だ」

僕は、初号機の掌を、隣で膝をつき、今にも消え入りそうな絶叫を上げている零号機へと差し出した。

「僕のA.T.フィールドと、君の魂を、完全に同期させる。この世界の『現在』を、結晶の檻に閉じ込めるんだ。因果の連鎖から、この世界そのものを物理的に切り離す」

（それは……誰も、もう動けなくなるということ？ ……時間が、永遠に停滞するの？）

「ああ。僕と、君以外はね。誰も、君を傷つけられない場所に、僕が連れて行く」

沈黙。
やがて、冷たい機械音や爆発の振動をかき消すように、レイの、小さく、硬く。そしてどこか安堵したような肯定の波紋が、僕の神経に届いた。

（……わかったわ。あなたが、私を……、私として止めてくれるなら）

「……何をしているの！ 二人とも、動力がオーバーロードしているわ！ 磁場が反転して、ジオフロントそのものが臨界点に達している！ 逃げなさい、シンジ君！！」

葛城さんの、最後になるかもしれない悲鳴を、僕は優しく。そして冷徹にシャットアウトした。

初号機と零号機。
本来なら反発し合い、決して触れ合うことのない二つの魂。二つのA.T.フィールド。

それが、ハドニエルの砂時計を、因果の特異点ごと包み込むように膨れ上がり、凝固していく。

「おやすみなさい、ミサトさん。さよなら、昨日」

眩い光。
それは破壊的な爆発ではなく、世界の「徹底的な拒絶」であり、物理的な「停止」だった。

初号機を中心点として広がる、深紅の波紋。
それに触れたものは、空気の一分子、光を運ぶ光子に至るまで、物理的な「静止」を強制され、琥珀のような紅い結晶体へと変わり果てていく。

落下していたコンクリートの破片も。吹き荒れていた爆風も、そして、勝ち誇るように事象の逆転を続けようとした第10使徒ハドニエルさえも、すべてが、深紅の檻の中に閉じ込められた。

静寂。
物語を無理やり終わらせるのではなく、ただ書きかけのページの途中で、乱暴に本を閉じたかのような美しい沈黙。

結晶化した世界の中で、僕はただ。
隣に並び、自分と同じように白銀の結晶へと変容し始めたレイの機体だけを見つめていた。

もう、誰も、彼らを都合よく駒として扱うことはできない。
もう、誰も、彼らに戦いと犠牲を強いることはできない。

ここは、因果の届かない、僕たちだけの永遠の午後の墓所だ。
静謐な、そして残酷な、僕たちの沈黙の聖域。
僕の罪と、彼女の痛みが、琥珀の中で永久に結晶化し続ける。
