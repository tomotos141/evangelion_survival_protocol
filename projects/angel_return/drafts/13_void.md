# 空洞

天井を見ていた。

あの施設から戻って、どれくらい経ったのか分からなかった。ベッドに横たわっている。目は開いている。天井がある。白い天井。あの施設の白とは違う。ここはNERVの居住区画で、天井には空調のダクトが走っていて、角に小さなひび割れがある。それだけの違い。

被験体S-13。記憶パターン：Final Version。定着率98.7%。

数字が頭の中を回っている。98.7%。ほぼ完璧。ほぼ本物と区別がつかない。あの白い部屋でレイに言った言葉。あの坑道の底で握った手。あの鏡の箱庭でアスカと連携した体の記憶。全てがデータだった。全てが設計図の中にあった。

以前の僕なら——仮面をかぶって、「大丈夫」と言えた。2周目のベテランとして、痛みを飲み込んで前に進む演技ができた。でもその仮面すら借り物だった。仮面の下にあるはずの素顔が、そもそも誰かに描かれたものだった。

何をしても、同じ疑念が湧く。

起き上がろうとする。起き上がろうとする意志は、プログラムの出力ではないのか。悲しいと感じる。悲しいと感じるように設計されただけではないのか。この疑念すら。この疑問を持つこと自体が、記憶パターンFinal Versionの仕様の範囲内ではないのか。

底がなかった。

どこまで掘っても、自分のものだと言える地盤に辿り着けない。泣くことすら疑わしかった。涙腺が反応する。胸が詰まる。でもそれは「泣くようにプログラムされた身体」の仕様通りの動作ではないのか。泣いている自分を眺めている自分がいて、その自分を眺めている自分もいて、どの層にも床がない。

贖罪にはならない。リツコさんはそれを分かっている人だ。製造者が製造物の前で膝をつくことの滑稽さを、あの人は誰よりも理解している。だからこそ、膝をつく代わりに端末のアクセス権を残した。直接的な救済ではなく、間接的な道標。科学者らしい贖罪の形だと思った。

「近づかないで。僕の中の君は、作り物だ」

拒絶された時の怒りではなく。壊れていく僕の顔が、アスカの中で疼いている。それが何という名前の感情なのか、アスカ自身にも分かっていないだろう。

分かっていないまま、体を動かし続けている。残響が疼くたびに、拳を叩きつけている。

一言。

「君が正しいといいね」

背を向けた。歩き出した。振り返らなかった。ドアの前で一瞬だけ足が止まった。

「僕はまだ、どこかにいるよ。——君の答えが間違いだった時のために」

ドアが閉まった。

カヲルの足音が廊下を遠ざかっていく。軽い足取り。来た時と変わらない。拒絶されても崩れない。それがカヲルの強さであり、痛みでもあった。

脅しではなかった。本気の優しさから出た言葉だった。だからこそ重い。カヲルの答えは今も有効で、いつでも選べる。僕が選ばなかっただけだ。

今日は、選ばなかった。明日もそうである保証は、どこにもない。

***

カヲルが去った後、綾波がまだ部屋にいた。

照明の光が、綾波の横顔を照らしていた。壁に寄りかかったまま、窓のない壁を見ている。

綾波がゆっくりと立ち上がった。

「碇くん。一つだけ」

顔を上げた。

「あの施設で——惣流さんが泣いていたこと、覚えている？」

息を呑んだ。あの施設で。走り去るアスカの後ろ姿。涙を見せまいとしていた。でも——

「あの涙は、誰にもプログラムできないものだったわ」

綾波の声は静かだった。確信がこもっていた。

「私は——碇くんに、存在していいと言うことはできる」

間があった。

「でも……碇くんの感情が本物だと証明できるのは、私じゃない」

綾波が微かに笑った。寂しさと、覚悟が混じっていた。自分の限界を知っている顔だった。ここまでは私の領分。ここから先は、私では届かない。その線引きを、綾波は静かに受け入れていた。存在の許可は与えられる。でも感情の証明は、別の人間にしかできない。

「惣流さんのところへ、行ってみて」

その言葉を最後に、綾波は部屋を出た。裸足のまま。足音がほとんど聞こえなかった。

一人になった。

部屋は昨日と同じだった。天井があって、壁があって、ベッドがあって、空調が回っている。何も変わっていない。

でも昨日の空洞とは違った。

中身はまだ空っぽだった。記憶が偽物であることは変わらない。S-13であることは変わらない。底なしの疑念はまだ消えていない。

ただ、空洞の壁に、冷たい手のぬくもりが残っていた。

あの暗闇の中で繋がれた手。証明ではなく宣言。論理ではなく選択。「私があなたを本物だと決める」。クローンが、被験体に向けて、その言葉を選んだ。

空洞の壁は、まだ薄い。中身はない。でも器ができた。

何をそこに入れるのかは、まだ分からない。

立ち上がった。足が床についた。冷たい。一歩目が重かった。二歩目も重かった。三歩目で、少しだけ体が前に進むことを思い出した。

ドアに手をかけた。

アスカのところへ行くには、まだ早いかもしれなかった。言葉がまだ見つからない。あの施設で振り払った手の痛みが、まだ指に残っている。でも綾波が架けた橋が、薄闇の向こうに見えていた。

今日は、終わらせなかった。

廊下に出た。空調の風が頬に触れた。冷たい。その冷たさが、あの暗闇で繋いだ手の冷たさとは違う種類のものだと、体が知っていた。

それだけが、今の僕に言えることだった。
