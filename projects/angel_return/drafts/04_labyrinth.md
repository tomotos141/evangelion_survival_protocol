# Episode 4: 地下の迷宮 (The Labyrinth)

深夜二時。NERV本部の居住ブロックは、死神の寝息のように静まり返っていた。空調の低い唸りだけが、コンクリートの壁を伝ってどこまでも続いている。僕は幾度目かの寝返りを打ち、天井の染みを数え尽くしたあと、もはや横たわっていることそのものが苦痛になり、ベッドから這い出した。

目を閉じると、すぐにそれが来る。ラミエルの核を——あるいは使徒そのものを——握り潰した瞬間の感覚が、指先に生々しい熱として蘇る。掌の奥で何かが弾け、骨の髄まで伝播した、あの快楽にも似た衝撃。「美味い」と、僕の心の奥底にいた何者かが歓んでいた。骨を噛み砕き、魂を啜る渇望に震えていた。あれは恐怖だったのか、歓喜だったのか、その境界がもう判然としない。温いミルクを飲んでも、皮膚が真っ赤になるまでシャワーを浴びても、幻覚は僕の肉体の内側に棲みついたまま離れなかった。

「……はぁ、はぁ……。……まだ、身体が焼けているみたいだ」

汗走る額を手の甲で拭い、僕は徘徊するように廊下へ出た。深夜のNERVは昼間とはまるで別の生き物だ。蛍光灯は三本に一本の割合で間引かれ、通路の奥は薄暗い灰青色の闇に沈んでいる。自分の足音が妙に大きく聞こえる。自販機コーナーの無機質な青い光を目指して歩いていたその時、視界の端で何かが動いた。

立ち入り禁止区域に指定された重厚な金属フェンスの向こう側。本来なら警備ロボットすら近寄らないはずの「深度廃棄区画」の闇の中で、懐中電灯の細い光が、怯えるようにちらついていた。

「……誰だ？」

警備員ではない。光の動きが、あまりにも不規則で、そして「欲」に満ちている。何者かがシステムを搔い潜って侵入したとしても、それは僕の預かり知ることではない。引き返すべきだ。だが、その光が向かっている先——錆びついた扉のプレートを見た瞬間、背筋に氷の指を這わされたような感覚が走った。

『第86廃棄区画 / DANGER: BIOHAZARD / DO NOT ENTER』

記憶が正しければ、そこには開発に失敗したエヴァの残骸と、ダミープラグの初期プロトタイプが投げ捨てられている。NERVの胃袋の底だ。記憶が正しければ——その確信が、以前ほど揺るぎないものではなくなっていた。いずれにせよ、生身の人間が無知のまま迷い込み、無傷で戻れるような清潔な場所ではない。

「……待ってよ！ そこは、入っちゃダメだ！」

僕は理性を置き去りにし、フェンスの尖った上部を乗り越えた。掌にフェンスの錆が食い込み、鉄の味が口の中に広がる。心臓が激しく脈打つ。見捨てられなかった。理由は分からない。ただ、足が動いた。

僕は液晶を見つめたまま、しばらく動けなかった。巻き戻した覚えも、再生した覚えもない。誰かが触ったのか。それとも——この「やり直し」の世界そのものが、僕の知らないところで、一歩だけ先に進んだのか。答えは出ない。ただ、25ではなく26という数字が、朝日の中で静かに光っていた。

僕は立ち上がり、朝日の中へ歩き出した。
