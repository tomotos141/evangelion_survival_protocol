# Episode 5: 人形の夢、機械の神 (Ghost in the Shell)

## 概要
*   **視点**: 碇シンジ
*   **目的**: 綾波レイの実態を確認するため、NERV最深部のダミープラントへ侵入する。
*   **手段**: 赤木リツコへの心理的ハッキング（ソーシャル・エンジニアリング）により、セキュリティを突破する。

## 詳細プロット

### Scene 1: 科学者の隙
*   **状況**:
    *   NERV本部、リツコの執務室（または休憩室）。
    *   シンジは「定期検査の結果を聞く」という名目で彼女を訪ねる。
*   **心理戦**:
    *   リツコは疲労している。シンジはコーヒーを差し出し、完璧な「気遣いのできる少年」を演じる。
    *   会話の中で、彼女のトラウマである「母親（赤木ナオコ）」や「ゲンドウへの複雑な感情」を刺激するキーワードを、無自覚を装って投げかける。
    *   リツコが動揺し、思考が一瞬空白になった隙に、彼女の白衣のポケットからIDカードを抜き取る（あるいはデータをスキミングする）。
*   **独白**:
    *   「……簡単すぎる。人間は機械よりもセキュリティホールが多い」

### Scene 2: 降下
*   **侵入**:
    *   盗んだIDでセントラルドグマへのエレベーターを作動させる。
    *   MAGIは「赤木リツコ博士」としてアクセスを承認する。
*   **環境**:
    *   深度が増すにつれ、空気は冷たくなり、そして鉄錆の臭いが濃くなる。
    *   第4話で見た「赤い廃液」の配管が、ここへ集約されている。

### Scene 3: 水槽の聖母
*   **到着**:
    *   ダミープラント。無数の綾波シリーズが浮かぶ水槽。
    *   だが、今回は「運用方法」が違う。
    *   水槽の水は濁り、ケーブルが極太になっている。彼女たちはただ眠っているのではなく、何かの計算処理に酷使されている。痙攣する素体たち。
*   **発見**:
    *   部屋の中央。ひときわ太いケーブルに繋がれた、オリジナルの綾波レイ。
    *   彼女は機械の一部のように磔にされ、モニターには膨大なエラーログと戦術データが流れている。
    *   彼女自身が、NERVの防衛システムを動かす生体CPUとして扱われている。

### Scene 4: 接触と殺意
*   **対話**:
    *   シンジがレイに触れる。その肌は高熱を発している。
    *   レイが薄目を開ける。「……碇、くん？ どうして……ここは、ダメ……」
    *   彼女は自分の痛みよりも、シンジが汚染されることを心配している。
*   **覚醒**:
    *   その献身が、シンジの何かを決定的に踏み越えさせる。
    *   恐怖でも同情でもない。純粋にして冷徹な「殺意」。
    *   このシステムを作った全ての大人たちへの、明確な宣戦布告。

### Scene 5: 決意の引き金
*   **撤収**:
    *   警報が鳴る前兆を感じ、シンジは退室する。今はまだ、彼女を助け出す力がない。
    *   帰り際、リツコの部屋に寄り、IDカードを何食わぬ顔で戻す（ついでに、アリバイ工作として「相談ありがとう」のメモを残す）。
*   **Ending**:
    *   シンジの独白。
    *   「もう『逃げない』なんて言わない。……これからは僕が、このクソったれな世界を追い詰める番だ」
    *   彼の瞳から、怯えた少年の色が完全に消え失せる。
    *   （ここで、次号エヴァ搭乗時のシンクロ率が異常値を示す予兆）
