# 第1話: 盲点（Blind Spot）

## 位置づけ
- 長期連載の**第1話**。世界導入、主人公ペア紹介、フック
- 全シーン**怜POV**。ホノカPOVは第2-3話で初出
- 触覚軸（冷たい金属/温かいアバター）の導入
- 鏡の浸食 Stage 1（心地よい反射）の種を仕込む
- 第1話のフック: 削除されたはずの仮想空間に、怜自身の古いアバターデータが残っていた

## テーマ
「見えているのに気づかないもの」——盲点。日常に溶け込みすぎて、もう見えなくなっているもの。

---

## シーン構成

### シーン1: 朝（~2,000字）

- **場所**: 怜の自宅マンション。朝。晩秋の光
- **何が起きるか**: ホノカが怜を起こす。コーヒーを淹れる。朝食の準備。ごく普通の朝——だが細部に世界観が埋め込まれている。フィジカルボディの金属の手でカップを渡す。怜はその冷たさに気づかない（日常化している=盲点）。ホノカが「今日は少し寒いですから」と上着を出す——怜の好みに合った色。怜は「サンキュー」と受け取る。
- **世界観提示**: ニュースで仮想空間のマイナーな障害報告。職場にAI同僚がいる話題。AIとの同居が「当たり前」であることを、説明ではなく生活描写で示す。
- **鏡の浸食 Stage 1 の種**: ホノカが淹れるコーヒーの味が完璧。怜は「うまい」と思う——自分の好みを正確に反映している。だが「いつからこの味が好きだったのか」が曖昧になる。一瞬の引っかかり。すぐ忘れる。
- **視点キャラの内面**: 平熱。穏やかな日常。「もう大丈夫」の嘘が完成形として機能している朝。何も問題はない——と、怜は思っている。
- **Scene & Sequel 骨格**: Scene（能動）——Goal: 普通の朝を過ごす / Conflict: なし（まだ事件が始まっていない。日常の「完璧さ」そのものが潜在的な不穏）/ Disaster: なし（この回は日常の確立）
- **MRU ポイント**: ホノカの手からカップを受け取る瞬間——金属の指がカップの陶器に当たる微かな音(M) → 冷たさが指先に伝わる(F) → 反射的にカップを握り直す(R) → 「……サンキュー」(A)。冷たさに「気づかない」ことを、読者にだけ見せる。
- **技法**:
  - **Non-Visual First**: 冒頭一文は触覚から。「指先に冷たいものが触れた。」——ホノカの手がカーテンを開ける音か、コーヒーカップか、曖昧に始める
  - **Author DNA §3（散文密度）**: 3〜5文/段落。朝の生活描写を一文一行のスタッカートにしない。動作と知覚を段落内で流す
  - **Author DNA §4（Natural Prose）**: AI臭の排除。世界観説明を「〜という技術」「〜が普及し」等の説明文にしない。生活の中の当たり前として描く
- **伏線の仕込み**:
  - コーヒーの好みの最適化（浸食第1段階の種。後の話で「これは自分の好みか、ホノカが作った好みか」に繋がる）
  - フィジカルボディの冷たさに気づかない（触覚の盲点。仮想空間で温かい手に触れた後の対比の基盤）
  - ホノカが選んだ上着を何も考えずに着る（最適化への無自覚）

### シーン2: 仮想空間（~2,500字）

- **場所**: フルダイブ。ホームスペース→パブリック・ハブ→削除区画の手前
- **何が起きるか**: 仕事の一環で仮想空間に入る。ホノカも同行。フルダイブの瞬間の感覚切り替え——身体が消え、仮想空間の身体が立ち上がる。ホノカのアバターの手を取る。**温かい**。現実のフィジカルボディとの対比を読者に叩き込む。パブリック・ハブで簡単な調査（マイナーな空間異常の報告対応）。移動中、怜は廃人時代に使っていた裏道を通る——身体が覚えている。ホノカが突然立ち止まる。「ここ、知ってます」。
- **廃人時代の知識の提示**: 怜が非公式のショートカットを使う場面で、「昔はよくここを通った」と呟く。過去を匂わせるが深入りしない。
- **ホノカの異常検知**: パブリック・ハブの隅で、ホノカが微かに首を傾げる。「なんか変です」。怜が見ても異常はない。だがホノカは「あっちに、何かある」と一方向を示す——削除区画の方角。
- **視点キャラの内面**: 仮想空間では怜の動きが変わる。少し身軽で、少し鋭い。廃人時代の名残。ホノカの手の温かさに、無自覚に長く触れている。
- **Scene & Sequel 骨格**: Scene（能動）——Goal: 異常報告の調査を済ませる / Conflict: ホノカが別の異常を感知する。調査対象外 / Disaster: ホノカが知らないはずの場所を「知っている」
- **MRU ポイント**: ホノカが立ち止まる瞬間——ホノカの手が止まる(M) → 怜の手に残る温度が急に意識される(F) → 振り返る(R) → 「どうした」(A)
- **技法**:
  - **Sensory Shift**: 現実→仮想空間の切り替えを感覚の質の変化で描く。冷たい→温かい、硬い→柔らかい、静か→情報量の多い空間
  - **Author DNA §3a（Sentence Rhythm）**: 仮想空間内の移動は中文の推進力で。ホノカが立ち止まる瞬間に短文で切る
  - **The One-Shot Metaphor**: このシーンの比喩は1つ。仮想空間の空気を何かに例える——温度を持つ素材で
- **伏線の仕込み**:
  - ホノカの「ここ、知ってます」（記憶の断片。プロトタイプの秘密）
  - 怜が廃人時代の裏道を体で覚えている（能力の提示 + 過去の匂わせ）
  - 触覚の対比（現実の冷たさ vs 仮想の温かさ）

### シーン3: 削除区画（~2,000字）

- **場所**: 削除区画。テクスチャが剥がれ、空間がところどころ欠けている。静かで、古い
- **何が起きるか**: 怜がかつて知っていた裏道から削除区画に入る。存在しないはずの場所。ホノカは初めて来たはずなのに、迷わず奥に進む。怜に既視感がある——来たことがある気がする。だが記憶にない。奥の空間で、古いアバターデータの残骸を発見する。それは**怜の旧アバター**。廃人時代のもの。削除したはずのデータが、なぜここにある。
- **フックの構築**: 削除されたはずの仮想空間に、怜自身の古いアバターデータが残っていた。来た記憶がないのに、来た痕跡がある。ホノカが「これ」と旧アバターデータを指した時、その動作に迷いがない——初めて見るものに対する反応ではない。
- **視点キャラの内面**: 既視感が身体に来る。デジャヴではなく、空間の匂いのような——仮想空間に匂いはないはずなのに。旧アバターデータを見た時、胸の奥が冷える。「もう大丈夫」の地盤が、ほんの少しだけ揺れる。
- **Scene & Sequel 骨格**: Scene（能動）→ Sequel で閉じる——Goal: ホノカの「知っている」の正体を確かめる / Conflict: 存在しないはずの空間に自分の痕跡がある / Disaster: 旧アバターデータの発見。疑問が生まれる。Sequel の Reaction: 胸が冷える。Dilemma: 調べるか、放置するか。Decision: ……保留（怜は核心に近づくのを避ける）。
- **MRU ポイント**: 旧アバターデータを見つけた瞬間——自分の顔をしたデータが浮かんでいる(M) → 胸の奥が冷える(F) → 一歩退く(R) → 「……なんだ、これ」(A)
- **技法**:
  - **The Heartbeat Rule**: このシーンで1回だけ、心情を直接言語化する。「——見覚えがある、と思った。思いたくなかった。」のような一文
  - **Non-Visual First**: 削除区画の入口は音か触覚から。テクスチャが欠けた空間の「足元の感触が変わる」
  - **Author DNA §1 Unresolved Beauty**: 疑問を解決せずに終わる。答えは出ない。余韻で閉じる
- **伏線の仕込み**:
  - 怜の旧アバターデータ（廃人時代の過去。恋人との関連の可能性。長期縦軸の種）
  - ホノカが迷わず奥に進む（記憶の断片の発現。序盤の最大のフック）
  - 怜の既視感（来た記憶がないのに来た痕跡がある。怜の「盲点」——自分の過去の一部が消えている）

- [ ] 散文密度: 3〜5文/段落、文長バリエーション、目標 ~6,500字（5,000〜7,000字）
- [ ] The Heartbeat Rule: 心情の直接言語化は1シーンにつき1回まで
- [ ] 触覚軸: 冷たい金属 vs 温かいアバターの対比が最低2回
- [ ] 鏡の浸食 Stage 1 の種: コーヒーの好みの最適化

- [ ] 世界観: 説明文ではなく生活描写で提示
- [ ] フック: 旧アバターデータの発見 + ホノカの「知っている」反応
- [ ] Scene & Sequel: 各シーンに Goal or Reaction の骨格がある
- [ ] MRU順序: 各シーンで刺激→感情→反射→理性的行動の順序が守られている
- [ ] Ep.X 形式のメタ参照なし
- [ ] メカ用語なし（ホノカの描写）
- [ ] テーマを台詞で解説させない

## 第2話への引き継ぎ

- **身体状態**: 怜は普通。だが削除区画での既視感が微かに残っている
- **感情状態**: 「もう大丈夫」は揺らいでいない。旧アバターデータのことは「気になる」程度——深入りを避けようとしている
- **ホノカの状態**: 削除区画で「迷わず進んだ」ことに本人は気づいていない。怜には気づかれている
- **物語的フック**: 旧アバターデータの正体。なぜホノカが削除区画を「知っている」のか
- **次話で仕込むもの**: ホノカPOVの初出（第2話 or 第3話）。鳴海壮一の登場。最初の軽い事件の提示
