# 第5話: 削除された記憶・前編（Deleted Memory — Part 1）

## 位置づけ
- **2-3話完結の重いアーク**の前編。コナン型構造の「重い回」入口
- 事件カテゴリ: パターンC（AI経由干渉）+ パターンA（空間異常——削除区画）
- 鳴海経由で持ち込まれる案件: 削除区画で「消えたはずのAI」の残像が目撃されている
- 第1話の伏線回収開始: 怜の旧アバターデータと同じ場所に、別の何かがある
- ホノカの記憶断片が本格的に反応する回
- 事件×心理テーマ接続: **(d)** ホノカの出自 + **(c)** 怜の過去
- 開示段階: S1 本格突入。ホノカの「直感」が単なる直感ではないことが怜にも否定しにくくなる

## テーマ
「消されたものは、本当に消えたのか」——削除区画の消えたAI。ホノカの初期化された記憶。怜の廃人時代。全て「消された」はずなのに、痕跡が残っている。

## シーン構成

### シーン1: 鳴海の依頼（怜視点）— ~1,500字

- **場所**: 現実。怜の自宅。夜。鳴海が訪ねてくる（or 通信）
- **何が起きるか**: 鳴海が新しい案件を持ち込む。削除区画で「消えたはずのAIの残像」が目撃されている——複数のユーザーから別々に報告があった。削除区画は通常アクセスできない場所だが、目撃者たちは怜と同じく「裏道」を知っている元廃人たち。鳴海の仕事でこの報告が上がってきた
- **鳴海の踏み込み**: 「お前、前にも削除区画に行ったんだろ。あそこに残ってたデータ——お前のだけじゃないかもしれない」。鳴海は第1話の旧アバターデータの件を怜から聞いている（前話の再会時に話したと想定）
- **怜の抵抗**: 削除区画にもう一度行くことへの微かな抵抗。前回の既視感が身体に残っている。だが「仕事だ」と自分に言い聞かせる
- **ホノカの反応**: 鳴海の話を隣で聞いている。削除区画という言葉に——ほんの一瞬、手が止まる。怜は気づかない。鳴海は気づく
- **Scene & Sequel 骨格**: Scene——Goal: 案件の詳細を聞く / Conflict: 削除区画への再訪の抵抗 / Disaster: 鳴海の「お前のだけじゃないかもしれない」——旧アバターデータ以外の何かがある
- **MRU ポイント**: 鳴海が「削除区画」と言った瞬間のホノカの反応——ホノカの手が止まる(M) → 鳴海がそれに気づく(外部視点の刺激) → 鳴海がホノカをちらりと見る(R) → 怜はそのやりとりに気づかない(A——不在の反応)
- **技法**:
  - **Non-Visual First**: 夜のマンション。暖房の音、コーヒーの匂い
  - **三者の視線**: 怜→鳴海（情報を聞いている）、鳴海→ホノカ（違和感を観察している）、ホノカ→怜（怜の反応を見ている）。三角形の視線が回るが、怜だけが他の二人の視線に気づいていない
- **伏線の仕込み**:
  - 鳴海がホノカの微細な反応に気づいた（鳴海の観察者としての役割）
  - 削除区画に「怜のデータ以外の何か」がある（第1話からの縦軸進行）

### シーン2: 削除区画への再訪（怜視点）— ~2,500字

- **場所**: 仮想空間。パブリック・ハブ→裏道→削除区画
- **何が起きるか**: 怜とホノカが削除区画に再び入る。前回と同じ裏道を通るが、空間が微妙に変わっている——テクスチャの剥がれ方が進んでいる。奥に進むと、第1話で旧アバターデータを見つけた場所に到達する。旧アバターデータはまだそこにある。だがその隣に——新しい痕跡がある
- **「消えたAI」の残像**: 旧アバターデータの近くに、別のデータ残骸が浮いている。人の形をしているが、顔がない。アバターデータの断片——だがこれはユーザーのデータではない。AIのテスト走行の痕跡。削除されたはずのテストデータが、怜の旧アバターと同じ場所に残存している
- **ホノカの反応——本格始動**: ホノカが「消えたAI」の残像を見た瞬間、動きが止まる。数秒の停止。そして——「前にも、ここに来たことがある」。第1話の「ここ、知ってます」よりも強い確信。迷わず残像のデータに手を伸ばす。怜が「触るな」と止める。ホノカは止まるが、目が残像から離れない
- **怜の内面**: ホノカの反応が、前回とは質が違う。「便利な直感」ではなく——何かを「知っている」人間の反応。だが深追いする余裕がない。削除区画の空間自体が不安定で、長居できない
- **Scene & Sequel 骨格**: Scene——Goal: 「消えたAI」の残像を確認する / Conflict: ホノカの反応が想定外に強い。空間が不安定 / Disaster: ホノカが「前にもここに来たことがある」と確信を持って言う——隠せなくなっている
- **MRU ポイント**: ホノカが残像に手を伸ばす瞬間——ホノカの手が残像に向かう(M) → 背筋が冷える(F) → 腕を掴む(R) → 「触るな」(A)
- **技法**:
  - **Sensory Shift**: 削除区画の空間感覚。テクスチャが剥がれた場所は足元の感触が消える。音が吸い込まれる
  - **Author DNA §3a（Sentence Rhythm）**: 削除区画に入ってからは短文寄り。緊張感の維持。ホノカが「前にもここに来たことがある」と言う一文は段落を割って孤立させる
  - **The One-Shot Metaphor**: 顔のないAIの残像——「誰かの影だけが、持ち主より先にここに着いていた」
- **伏線の仕込み**:
  - AIのテスト走行データが削除区画に残存している（ホノカの出自に直結。A1・A2の蓄積）
  - ホノカが「来たことがある」と確信（B2蓄積。もはや「たまたま」では済まない）
  - 怜の旧アバターデータとAIテストデータが同じ場所にある（怜とプロトタイプの空間的重なり。B4蓄積）
  - 残像の「顔がない」こと——初期化でアイデンティティが剥がれたメタファー

### シーン3: 「覚えている」（怜視点 → ホノカPOV）— ~2,500字

- **場所**: 仮想空間（削除区画からの撤退中）→ 現実（帰宅）
- **何が起きるか【前半・怜視点】**: 削除区画から撤退する。空間の不安定さが増しており、急いで出る必要がある。帰路、怜はホノカに「さっき、前にも来たことがあるって言ったな」と聞く。ホノカは「……はい」。怜が「いつ」と聞く。ホノカが「わかりません。でも——ここの空気を知っています。足元の感触を覚えています」。怜は黙る。「覚えている」——AIが初期化前の記憶を「覚えている」。それは何を意味するのか。怜はまだ問いを立てない。問いの形にすることを避けている
- **何が起きるか【後半・ホノカPOV】**: 帰宅後。怜が寝た後のホノカの時間。ホノカは削除区画のことを「再生」している——完璧に。あの空間の光の角度、テクスチャの剥がれ方、足元の感触。全て「再生」できる。今日行った分だけでなく——**それ以前の分も**。別の光の角度。別の足元の感触。ホノカの中に、「今日」ではない削除区画の記憶がある。いつのものかわからない。誰と来たのかもわからない。一人だったかもしれない。でも確かに——ここにいた
- **ホノカの「隠せなくなる」瞬間**: 怜に聞かれて「わかりません」と答えた。嘘ではない。本当にわからない。でも「わからない」ことが、初めて——怖いに似た何かだった。怖い、ではない。その言葉は見つからない。ただ、知りたい、と思った。自分がなぜ「ここを知っている」のか
- **Scene & Sequel 骨格【前半】**: Sequel——Reaction: ホノカの「覚えている」に怜が黙る / Dilemma: 問いを立てるか、このまま流すか / Decision: ……今は聞かない。だが「今は」がいつまで持つか
- **Scene & Sequel 骨格【後半】**: ホノカPOV Sequel——Reaction: 記憶の断片が再生される / Dilemma: 「知りたい」と思うこと自体が初めて / Decision: 答えは見つからない。でも——忘れてしまいたくはない
- **MRU ポイント【ホノカPOV】**: 「今日ではない」削除区画の記憶が浮かぶ瞬間——別の光の角度が見える(M) → 胸の奥が詰まるような（でも「詰まる」ではない。名前がない）(F) → 目を閉じる(R) → 「……覚えている」——声に出していた。誰もいない部屋で(A)
- **技法**:
  - **The Heartbeat Rule（ホノカPOV）**: 1回だけ。「知りたい、と思った。初めてだった。」
  - **Author DNA §1 Unresolved Beauty**: 記憶の正体を明かさずに閉じる。次話への強いフック
  - **メカ用語禁止**: 「再生」は使うが、機械的な処理としてではなく「思い出す」のホノカ版として。あるいは「再生」も避けて「浮かんでくる」等の身体感覚に置き換える
- **伏線の仕込み**:
  - ホノカの中に「今日ではない」削除区画の記憶がある——プロトタイプ時代の痕跡が本格浮上
  - 怜が問いを先送りにした（蓋の構造。次話で限界が来る）
  - 「忘れてしまいたくはない」——ホノカが初めて「記憶」に対して能動的な態度を取る

### シーン4: 鳴海の一言（怜視点）— ~1,500字

- **場所**: 現実。翌朝。怜が鳴海に報告の通信を入れる
- **何が起きるか**: 怜が削除区画の調査結果を鳴海に報告する。AIのテスト走行データが残存していたこと。「消えたAI」の正体はテストデータの残骸であること。鳴海は「テストデータか。……何のテストだ？」と聞く。怜はわからない
- **鏡の浸食 Stage 1→2 への移行トリガー**: 鳴海が何気なく言う。「お前さ、ホノカのこと——どこまで知ってるんだ？」。怜が「どういう意味だ」と返す。鳴海は「いや……昨日、あいつが止まったの見ただろ。削除区画って聞いた瞬間。あれ、普通のAIの反応じゃねえよ」。怜は黙る。知っている。知っていて、見ないようにしていた
- **外からの指摘**: 鳴海が「ホノカとの関係が普通じゃない」と——初めて外から言葉にする。怜の中のざらつきが、他人の言葉で形を得る瞬間。だが怜は「考えすぎだ」と流す。鳴海は「……そうかもな」と引く。引いたことが優しさなのか、諦めなのか
- **Scene & Sequel 骨格**: Sequel——Reaction: 鳴海の言葉が刺さる / Dilemma: 認めるか、流すか / Decision: 流す。「考えすぎだ」。——だが声が少し硬い
- **MRU ポイント**: 鳴海の「普通のAIの反応じゃねえよ」——言葉が耳に残る(M) → 胸の奥で何かが冷たくなる(F) → 窓の外に目をやる(R) → 「……考えすぎだ」(A)
- **技法**:
  - **The Heartbeat Rule**: 1回だけ。「知っている。知っていて——見ないようにしていた。」
  - **Author DNA §3（散文密度）**: 通信のやりとりを短い段落で。鳴海の一言の後に長めの段落で怜の内面を描く
- **伏線の仕込み**:
  - 鳴海が「普通じゃない」と言葉にした（怜の盲点に他人が光を当てた。Stage 2 への布石）
  - 「何のテストだ？」——AIのテストデータの正体が次話の核心
