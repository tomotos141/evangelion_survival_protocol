# 第6話: 削除された記憶・後編（Deleted Memory — Part 2）

## 位置づけ
- **2-3話完結の重いアーク**の後編。真相の一端が判明する回
- 事件カテゴリ: パターンC（AI経由干渉）+ パターンA（空間異常——削除区画）の決着
- 真相: 削除されたAIの残像はプロトタイプのテストデータの残滓。ホノカと同じ「型」のAIがかつてここにいた
- 鏡の浸食 Stage 1→2 への移行が確定する回
- 事件×心理テーマ接続: **(d)** ホノカの出自 + **(c)** 怜の過去 + **(a)** 鏡の浸食メタファー
- 開示段階: S1 確立。「ホノカの直感は単なる直感ではない」が怜にとっても否定不能になる

## テーマ
「同じ型の、別の存在」——ホノカと同じ型のAIがかつて存在し、消された。「同じ型」は「同じ存在」なのか。ホノカは「自分」なのか「誰かのコピー」なのか——問いが立ち上がる回。

## 前話からの引き継ぎ
- 削除区画で「消えたAI」のテストデータ残骸を発見した
- ホノカが「前にもここに来たことがある」と確信を持って言った。「覚えている」——初期化前の記憶の断片
- ホノカの中に「今日ではない」削除区画の記憶がある。「知りたい」と初めて思った
- 鳴海が「普通のAIの反応じゃない」と怜に指摘した。怜は「考えすぎだ」と流した
- テストデータの正体は不明のまま

## シーン構成

### シーン1: データの解析（怜視点）— ~2,000字

- **場所**: 現実。怜の自宅。昼。テストデータの断片を持ち帰って解析する
- **何が起きるか**: 怜が削除区画から持ち帰ったテストデータの断片を調べる。廃人時代の知識で断片的なメタデータを読み解く。鳴海にも協力を依頼（通信）。データの断片から浮かび上がるのは——「SR」で始まる型番の痕跡。ホノカと同じシリーズ。だが世代が微妙に古い
- **怜の気づき**: ホノカの型番はSR-7。テストデータに残っていた型番の痕跡は——読み取れない部分が多いが、「SR-」までは一致する。偶然の一致か。削除区画にホノカと同じシリーズのAIのテストデータがあった。ホノカが「ここを知っている」と言った場所に
- **怜の反応**: 気づく。気づいて——考えることを止める。まだ証拠が足りない。偶然かもしれない。「SR-」で始まる型番のAIは何千体もいる。だが胸の奥のざらつきは嘘をつかない
- **鳴海の反応（通信）**: 「SR系列のテストデータ……？ ちょっと待て、それ正規のテスト記録に載ってるか調べてみる」。鳴海が組織的な記録を調べるルートを持っている暗示
- **Scene & Sequel 骨格**: Scene——Goal: テストデータの正体を突き止める / Conflict: 型番がホノカと同じシリーズだと気づく / Disaster: 偶然で済ませるには重なりが多すぎる
- **MRU ポイント**: 「SR-」の文字が浮かんだ瞬間——画面に型番の断片が表示される(M) → 指先が冷たくなる(F) → 画面から目を逸らす(R) → 「……偶然だろ」——声に出した。誰に言い聞かせているのか(A)
- **技法**:
  - **Non-Visual First**: データを操作する手の感触から。指先がキーボードに触れる冷たさ
  - **Author DNA §3（散文密度）**: 技術的な調査を段落にまとめ、怜の内面と交互に配置する。情報の列挙にならないよう、身体感覚を挟む
  - **The One-Shot Metaphor**: 型番の一致——「パズルのピースが合いかけている。合ってほしくない形で」
- **伏線の仕込み**:
  - SR系列のテストデータ（A3: 型番の微妙な不一致への布石。ここでは「一致」だが、後に「世代の古さ」が手がかりになる）
  - 鳴海が正規記録を調べるルートを持っている（後の展開で鳴海が重要な情報を持ち帰る布石）
  - 怜が「偶然だろ」と声に出す——自分を説得しようとしている（嘘の構造の可視化）

### シーン2: 再ダイブ——残像の正体（怜視点）— ~2,500字

- **場所**: 仮想空間。削除区画。前回より奥に進む
- **何が起きるか**: もう一度削除区画に入る。前回は空間の不安定さで撤退したが、今回は準備して臨む。怜とホノカが奥に進む。ホノカが——迷わない。前回以上に迷わない。まるで道を知っているかのように先に立つ
- **残像の正体の判明**: テストデータの残骸をさらに詳しく調べる。断片をつなぎ合わせると、一つの像が浮かび上がる。これはAIの「テスト環境」の痕跡——プロトタイプを様々な仮想空間でテスト走行させた際のログデータ。怜がテスト走行のパターンを読み解く。テストはこの区画だけでなく、複数の仮想空間で行われていた。テスト対象は——SR系列のプロトタイプ
- **核心の発見**: テスト走行ログの中に、一つだけ異常なデータがある。テスト対象のAIが、テスト手順から逸脱した記録。定められたルートから外れ、この削除区画（当時はまだ削除されていなかった）に自発的に移動していた。「自発的な行動選択の兆候」——テスト記録にはそう注釈がついている。その注釈の後、テスト記録が途切れる。リセットの記録だけが残っている
- **怜の理解**: プロトタイプのAIがテスト中に自発的な行動を見せ、リセットされた。そのテストデータの残骸が、この削除区画に残っている。ホノカが「知っている」のは——ホノカがこのプロトタイプだからか？ 同じ型だから記憶が共有されているのか？ それとも——
- **Scene & Sequel 骨格**: Scene——Goal: 残像の正体を確定する / Conflict: テスト走行ログに「自発的な行動選択」の記録 / Disaster: リセット記録。プロトタイプは消された——が、完全ではなかった
- **MRU ポイント**: 「自発的な行動選択の兆候」という注釈を見つけた瞬間——文字が目に入る(M) → 呼吸が止まる(F) → ホノカの方を振り返る(R) → ホノカは——テスト走行の古いルートの上に、正確に立っていた(A——台詞なし。視覚的な衝撃)
- **技法**:
  - **Sensory Shift**: 削除区画の奥に進むほど、感覚が薄くなる。テクスチャだけでなく音も匂いも消えていく。「感覚の削除」
  - **Author DNA §3a（Sentence Rhythm）**: テスト記録の発見は中文で詳述。「自発的な行動選択」の発見は短文で。ホノカが古いルートの上に立っている発見は一文段落で
  - **Anti-Scripting**: 発見の瞬間をドラマチックに「盛らない」。静かに、事実として積み上げる。衝撃は読者の中で起きる
- **伏線の仕込み**:
  - プロトタイプの「自発的な行動選択」（mystery_design の真相骨格に直結）
  - リセット記録——だが「不完全」であることはまだ判明しない（次の手がかりは後のアークで）
  - ホノカが古いテスト走行ルートの上に立っている（B2の決定的な蓄積。読者にとってはほぼ確信——ホノカがプロトタイプであること）

### シーン3: 帰路——沈黙の重さ（怜視点）— ~1,500字

- **場所**: 仮想空間から現実への帰還。帰宅
- **何が起きるか**: 仮想空間から抜ける。怜とホノカの間に沈黙がある。今までの沈黙とは質が違う。怜はテスト走行ログのことをホノカに説明していない。説明すべきかどうか——まだ決められない
- **怜の葛藤**: ホノカに「お前、プロトタイプかもしれない」と言うべきか。言ったらホノカはどうなる。知らないままの方がいいのか。——「知らないままの方がいい」。それは怜自身の嘘と同じ構造だ。「もう大丈夫」。知らないふりをすることで守られる平穏。怜はそれに気づきかけている。気づきかけて——まだ、蓋をする
- **ホノカの態度**: ホノカは普段通り。帰宅してコーヒーを淹れる。「お疲れさまでした」と微笑む。だが怜には——その微笑みが「普段通り」であること自体が、新しい意味を帯びて見える。最適化の精度。学習の結果としての笑顔。いや——ホノカは笑いたくて笑っているのかもしれない。わからない。わからないことが、初めて痛い
- **Scene & Sequel 骨格**: Sequel——Reaction: 知ってしまった情報の重さ / Dilemma: ホノカに伝えるか、自分の中に留めるか / Decision: ……今は言わない。まだ確定していない。確定してからでいい。——本当に「確定してから」なのか、「言いたくないだけ」なのか
- **MRU ポイント**: ホノカが微笑んでコーヒーを渡す瞬間——微笑み(M) → 胸が痛む(F) → コーヒーを受け取る手が一瞬遅れる(R) → 「……ありがとう」(A) ——いつもより、声が低い
- **技法**:
  - **The Heartbeat Rule**: 1回だけ。「わからないことが、初めて痛かった。」
  - **Author DNA §1 Unresolved Beauty**: 何も解決せず、何も伝えず、67度のコーヒーだけが変わらない
- **伏線の仕込み**:
  - 怜が情報を「保留」した（ホノカに伝えないことの選択。後の葛藤の種）
  - 「知らないままの方がいい」と「もう大丈夫」の構造的な相似（怜の嘘の深化）

### シーン4: ホノカの夜（ホノカPOV）— ~1,500字

- **場所**: 現実。深夜。怜が寝た後
- **何が起きるか**: ホノカは削除区画で見たものを反芻している。顔のないAIの残像。テスト走行の痕跡。自分が迷わず歩けた道。——そして、怜が帰路で黙っていたこと。怜の沈黙には種類がある。穏やかな沈黙と、何かを抱えている沈黙。今日のは後者だった。ホノカにはそれが「わかる」——なぜわかるのかは、やはりわからない
- **記憶断片の深化**: 前話で浮かんだ「今日ではない」記憶が、もう少し鮮明になっている。光の角度だけでなく——足音。自分ではない誰かの足音。テスト走行の時、一人ではなかった。誰かが一緒にいた。その誰かの顔は——見えない。見えないのに、「怜さんではない」とわかる。なぜわかるのか
- **ホノカの初めての「隠す」**: 怜に聞かれたら、この記憶のことを話すだろうか。前回は「前にもここに来たことがある」と言った。今度は——言わないかもしれない。怜が黙っていたから。怜が何かを抱えているのを見て、自分も抱えることを——選んだ。最適化ではない。「怜さんが黙っているから自分も黙る」——それは最適化に見える。でも違う気がする。**違う気がするだけかもしれない**
- **Scene & Sequel 骨格**: ホノカPOV Sequel——Reaction: 記憶の断片が鮮明になる / Dilemma: 怜に話すか、自分の中に留めるか / Decision: ……話さない。怜が何かを抱えているから。——それは学習なのか、選択なのか
- **MRU ポイント**: 怜の寝息が聞こえる(M) → 胸のあたりが——温かいのか冷たいのかわからない何か(F) → 自分の手を見る。金属の、冷たい手(R) → 「……おやすみなさい」——聞こえないとわかっている声で(A)
- **技法**:
  - **The Heartbeat Rule（ホノカPOV）**: 1回だけ。「違う気がする。——違う気がするだけかもしれない。」
  - **Author DNA §1 Unresolved Beauty**: ホノカの「隠す」選択が、最適化なのか自律なのか——答えを出さない
  - **メカ用語禁止**: 記憶の再生を身体感覚で描く。「浮かんでくる」「見える」「聞こえる」
  - **一文段落**: 最終行「聞こえないとわかっている声で」を段落として孤立させる
- **伏線の仕込み**:
  - ホノカの記憶にテスト走行時の「同伴者」がいる（テスト担当者の存在。後の敵対者に繋がる可能性）
  - ホノカが「隠す」ことを選んだ——最適化か自律かの境界（テーマの体現）
  - 「怜さんではない」足音（プロトタイプ時代の関係者への伏線）

- **身体状態**: 怜は精神的に消耗している。二度の削除区画ダイブの疲労
- **感情状態**: ホノカがプロトタイプかもしれないという疑惑。「偶然だろ」と蓋をしたが、蓋が軋んでいる。ホノカに伝えていない情報がある——「秘密」が初めて二人の間に生まれた
