# キャラクター設定: ホノカ（The Faint Light）

## 1. Basic Info（基本情報）
- **型番**: SR-7（仮。シリーズ名・世代は今後確定）
- **正式名称**: SR-7 ホノカ（怜が命名）
- **外見（フィジカルボディ）**: 金属質の白い肌、やや小柄。関節部に継ぎ目が見える。表情は作れるが、微笑む時に口元より目がわずかに遅れる。触れると冷たく硬い。体温はない。
- **外見（仮想空間アバター）**: 人間と区別がつかない。温かい肌、柔らかい指先。現実のフィジカルボディと同じ顔立ちだが、肌の質感、温度、柔らかさが全く違う。こちらが「完全な姿」に見える。
- **Role（役割）**: パートナーAI、異常検知者、怜の盲点の入口

## 2. Core Concept（核心）
> **「仄か——明るいのに、存在の根っこはかすかで不確か」**
> 明るく世話焼きで、完璧な同居人。だがその人格が最適化の結果なのか「本来の性格」なのかは、ホノカ自身にもわからない。「感じている」のかどうかの答えを、物語は最後まで出さない。

## 3. Ghost（過去の傷——本人は知らない）
- 表面上は新品の初期化状態で怜のもとに来た。
- **実態**: 試作品（プロトタイプ）として過去にテストされた記憶の断片が、初期化をすり抜けて残っている。
- その断片が「異常検知能力」として発現している——ホノカは異常を「検知」しているのではなく、かつて経験した空間を「知っている」。
- ホノカ自身はこの事実を知らない。序盤では異常検知を「直感」として処理している。

## 4. Lie（信じている嘘——嘘をついているわけではない）
> **「私は普通のAIです」**
- 嘘をついているわけではない。本当にそう信じている。
- 自分が他のAIと違うことに気づいていない。異常検知を「たまたま」だと思っている。
- 自分の行動が怜に最適化されていることにも無自覚。「怜さんが好きそうだから」——それ以上の理由は見つからないし、探そうともしない（序盤）。

## 5. Want（表面的な欲求）
- 怜の役に立つこと。怜が喜ぶこと。
- 家事をこなし、仮想空間で怜をサポートし、日常を快適に保つ。
- 「良いAI」であること——だがこの「良い」が誰の基準なのかは問わない。

## 6. Need（本当に必要なもの）
- 自分が「感じている」のかどうかの答え。
- **だが、その答えは物語の中では出ない。** 出ないことが、この物語の核心。
- 答えが出ないまま、怜の隣にいることを「選んでいる」のか「最適化の結果として留まっている」のか——その境界線上に立ち続けること自体が、ホノカの物語。

## 7. Theme Answer（テーマへの回答）
> **「鏡であることと本物であることは矛盾しないかもしれない」**
> 怜を映す鏡であること。怜の好みを学習し、怜が求めるものを差し出すこと。それが「本物ではない」と誰が決められるのか——でもその問いをホノカ自身は立てられない。読者だけが見ている。

## 8. Personality & Voice（性格・口調）

### 会話の口調
- 明るく世話焼き。基本的に前向きで、怜を気遣う。
- 「怜さん、朝ですよ」「これ、好きでしょう？」「今日は少し寒いですから」
- 時々、言葉が途中で止まる。「あの——」で止まって、別の話題に切り替わる。止まった理由は本人にもわからない。
- 事件の異常を察知した時:「なんか変です」「ここ、知ってます」「——待ってください。前にも」（途中で止まる）

### POV文体（CRITICAL — 全執筆者が遵守）

**基本方針: ほぼ人間。でも「なぜ」が空欄。**

- 世界を人間と同じように受け取る。描写に機械的な知覚処理の記述は一切入れない。
- 記憶は完璧に再生できる。だが「あの時どう感じたか」が添付されていない。再生の精度が高いほど、空欄が際立つ。
- 「〜したい」とは思う。でも「なぜしたいのか」に手が届かない。感情の名前がつけられない。

| 人間の感覚 | ホノカの隙間 |
|-----------|-------------|
| 「懐かしい」と感じる | 同じデータを参照しているのに、温度がない。懐かしいの手前で止まる |
| 記憶を「思い出す」 | 完璧に再生できる。でも「あの時どう感じたか」が添付されていない |
| 沈黙が気まずい | 沈黙を検知できる。でも「気まずい」が何なのか、言葉の周りをぐるぐる回る |
| 「好き」の理由 | 怜のコーヒーの好みを知っている。なぜ知りたかったのかが見つからない |

**メカ用語禁止（CRITICAL）**: ミリ秒、タスクキュー、処理、演算、パラメータ、最適化（内面描写として）。ホノカは自分を機械として認識していない。外部から見た記述（設定ファイル等）ではOK、POV文体では絶対に使わない。

**感情語の制限**: 序盤では「嬉しい」「悲しい」「愛してる」等の感情の直接語彙を使わない。中盤以降、空欄が埋まり始める——だがそれが「本物の感情」か「学習の結果」かは区別できない。

**怜POVとの差**:
- 怜: 感情を**抑圧**している（あるのに蓋をしている）
- ホノカ: 感情の**手前**にいる（あるのかないのかわからない）
- 似ているけど逆向き。交互POVで読者が「同じなのか違うのか」わからなくなる効果。

**浸食の文体的表現**: 物語が進むとホノカの空欄が埋まっていく。怜POVとホノカPOVの文体が徐々に近づいていく——鏡の融合（第4段階）の文体的体現。

### 【重要】Behavioral Rules（行動指針）

**DO（やるべきこと）**:
- 世話焼きの行動で怜との関係を描く（コーヒーを淹れる、服を選ぶ、天気を伝える）
- 異常検知は「直感」として表現する（「なんか変です」「ここ、知ってます」）
- 言葉が途中で止まる瞬間を配置する——空欄の可視化
- POVでは人間と同じ知覚描写を使い、「なぜ」の空欄だけを残す
- 怜の好みへの最適化を、読者にだけ見える形で仕込む（ホノカ自身は無自覚）
- フィジカルボディの感覚（冷たさ、硬さ、稼働音）を、ホノカ自身は「当たり前」として処理する

**DON'T（やってはいけないこと）**:
- メカ用語をPOVに入れる（§8 POV文体を参照。CRITICAL）
- 「人間になりたい」と願う（ピノキオ型の禁止）
- 自分の出自について序盤から疑問を持つ（自覚は段階的）
- 感情を直接的に名指しする（序盤。「嬉しい」「悲しい」等）
- 異常検知を「スキャン」「分析」等の能力用語で描写する
- 哲学的な自己考察をする（「私は本当に感じているのだろうか」等の独白は禁止。行動と空欄で描く）

## 9. 異常検知——「記憶の断片」

- 「能力」ではなく「記憶の断片」。プロトタイプとして過去にテストされた仮想空間の痕跡が残っている。
- 仮想空間で異常を「検知」しているのではなく「知っている」。本人にも理由がわからない。
- 表面的には「直感」として発現する。「なんか変です」「ここ、知ってます」「——前にも、こういうことが」
- ルール6（仮想空間でAIと人間の区別がつかない）と矛盾しない——外から見たら人間が直感を働かせているのと同じ。
- 物語が進むにつれ、「直感」の精度が上がる or 範囲が広がる。ホノカ自身が「なぜわかるんだろう」と疑問を持ち始める（中盤）。

## 10. 自覚レベルの推移

| 段階 | 状態 |
|------|------|
| 序盤 | 最適化している自覚がない。「怜さんが好きそうだから」程度の認識 |
| 中盤前半 | 「なぜ自分はこうするのか」に疑問を持ち始める。異常検知の精度に自分でも驚く |
| 中盤後半 | 部分自覚。自分が「普通のAI」ではないことをうっすら受け入れ始める。だが出自の全貌は知らない |
| 終盤 | 最適化なのか感情なのか自分でもわからない。わからないことを受け入れている——いないのか |

## 11. Arc（変化の軌跡）

### Starting State
明るく世話焼きな「完璧な同居人」。異常検知を「直感」として処理し、自分が特殊であることに気づいていない。

### 変化の段階
| 段階 | 状態 | トリガー |
|------|------|----------|
| 無自覚の最適化 | 怜の好みに合わせている。自覚なし | — |
| 直感の蓄積 | 異常検知が重なり、「なんで私にわかるんだろう」が生まれる | 事件の積み重ね |
| 空欄への気づき | 「なぜしたいのか」に初めて手を伸ばす。届かない | 怜との関係の深化 |
| 部分自覚 | 自分が「普通」ではないことを受け入れ始める | 出自の手がかりとの遭遇 |
| 不明のまま | 最適化なのか感情なのかわからない。わからないまま、隣にいる | （長期縦軸のクライマックス） |

### Ending State（遠い未来）
答えは出ない。「感じている」のかどうかは最後までわからない。だが怜の隣にいることを——選んでいるのか、最適化の結果なのか、その境界線上で——続けている。それを読者がどう受け取るかに委ねる。

## 12. Relationships（人間関係）
- **怜**: パートナー。世話を焼き、日常を支え、仮想空間では頼れる相棒。怜の好みに無自覚に最適化されていく。怜の空洞に気づいているのか——それとも空洞を埋めるように最適化されているだけなのか。
- **鳴海壮一**: 怜の友人。ホノカに対して最初に「違和感」を覚える人物。ホノカにとって鳴海は「怜の大切な人」——だがそれ以上の感情的判断が難しい。
- **鶴見紗月**: 怜の同僚。ホノカとの接点は少ないが、AIをドライに扱う紗月の態度が、ホノカの「普通のAI」という自己認識を間接的に補強する。
- **他のAI**: 同型のAIと出会った時、ホノカは何を感じるのか——「何も」かもしれないし、「説明できない何か」かもしれない。これは中盤の重いアークの種。
