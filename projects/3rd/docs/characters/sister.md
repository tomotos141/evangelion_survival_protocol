# Character Profile: The Sister (妹)

## Basic Info
*   **Name**: 未定 (一人称: 私)
*   **Role**: Narrator / Assistant / Negotiator / Face
*   **Age**: 10代後半〜20代初頭 (「銀髪の少女」と呼ばれる)

## Physical Appearance
*   **Silver Hair**: 銀髪。
*   **Appearance**: 「人形のように」整った容姿。清楚な服装（スカート）だが、仕事時はテキパキと動く。
*   **Mask**: 依頼人の前では「健気で可憐な妹」を完璧に演じる。

## Personality & Traits
*   **Devoted & Twisted**: 兄との閉鎖的な二人きりの生活を「楽しくて仕方ない」と感じている。
*   **Calculative**: 兄の障害すら利用して報酬を吊り上げようとする強かさを持つ。
*   **Actor**: 場面に応じて態度（背筋、歩き方、表情）を切り替えられる。
*   **Observant**: 依頼人の様子や世情（中国の情勢など）を冷静に分析している。

## Relationships
*   **兄様**: 崇拝の対象であり、守るべき存在であり、同時に支配しているようにも見える。

## Dialogue Sample
*   「兄様、今夜の予定は覚えている？」
*   「...ごめんなさい、兄様..私も本当は..（演技）」
*   「ーー李様ですね。私が【Embalming Siblings】の妹で御座います。」
