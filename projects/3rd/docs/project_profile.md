# Project Profile: 3rd (Embalming Siblings)

## Overview (概要)
**タイトル案**: Embalming Siblings (仮)
**ジャンル**: ゴシック・ミステリー, サイバーパンク, ダークファンタジー
**ターゲット**: 耽美的な世界観、共依存関係、少し歪んだ家族愛を好む層

### あらすじ
深い森の奥にある、元殺人現場の洋館。そこにひっそりと暮らす兄妹がいる。
足が不自由で皮肉屋の兄と、献身的に彼を支えつつも、その生活を楽しむ銀髪の妹。
彼らの裏の顔は、死者を美しく修復し保存する「エンバーミング（Embalming）」のスペシャリスト・チーム【Embalming Siblings】。
街を追われ、金に困った二人は、いわくつきの遺体や、表社会では扱えない「施術」を安価で引き受けている。
ある夜、経済大国となりテクノロジーが高度に発達した中国から、ある夫婦が訪れる。
彼らが持ち込んだ依頼は、単なる遺体の修復ではない、きな臭い「何か」を孕んでいた――。

## World View (世界観)
*   **Contrast**: 古めかしいゴシック様式の洋館と、アンドロイドやサイバー技術が発達した外界（特に中国）の対比。
*   **Atmosphere**: 常に薄暗く、静寂と死の匂いが漂うが、どこか美しい。
*   **The Mansion**: 「元殺人現場」として恐れられる孤独な館。兄妹の要塞であり、聖域。

## Specific Tone (この作品独自のトーン)
*   **Gothic & Decadent**: 退廃的で耽美。死を扱う職業だが、そこに恐怖よりも静謐な美しさを見出す。
*   **Performative**: 兄妹は依頼人の前で「健気な妹と不自由な兄」という役割を完璧に演じる。その演技性と本音のドライさのギャップ。
*   **Cynical Realism**: 金のためならプライド（兄の足へのコンプレックス）すら利用して報酬を吊り上げる強かさ。

## Keywords
*   **Embalming (エンバーミング)**: 遺体衛生保全。死化粧。
*   **Siblings (兄妹)**: 共依存、共犯関係、演技。
*   **China (中国)**: 強大なテクノロジー国家、富裕層、アンドロイド。
