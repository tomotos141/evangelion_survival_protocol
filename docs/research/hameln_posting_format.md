# Research Report: ハーメルン（syosetu.org）投稿フォーマット仕様

**Date**: 2026-02-16
**Type**: Subject
**Query**: ハーメルンの小説投稿フォーマット・記法・投稿設定の仕様調査

---

## Findings（調査結果）

### 1. テキストフォーマット

ハーメルンの本文入力はプレーンテキストベース。HTMLは使えない。独自の「特殊タグ」体系で装飾を行う。記法は二重山括弧 `《》` を使う独自形式で、なろう系サイト共通のルビ記法をベースに、大幅な拡張が施されている。

入力はブラウザ上のテキストエリアに直接書くか、外部エディタで書いたものをコピペする。「多機能フォーム」と「シンプルフォーム」の2種類の投稿フォームがあり、多機能フォームではリアルタイムプレビューが可能。

各話は「前書き」「本文」「後書き」の3フィールドに分かれている。ルビ・傍点・特殊タグは前書き・本文・後書き・あらすじ・活動報告で使用可能。

### 2. ルビの記法

なろう系共通の `|漢字《ふりがな》` 形式。

```
|永遠力暴風雪《えたーなるふぉーすぶりざーど》
```

- `|`（パイプ）がルビ対象の開始位置を示す
- `《》` 内にふりがなを書く
- ルビ文字にはひらがな・カタカナ・記号・漢字・英数字が使える
- ルビは最大20文字（半角英数の場合は60文字）
- 漢字が連続する場合、`|` を省略すると直前の漢字列全体にルビがかかる
  - 例: `永遠力暴風雪《えたーなるふぉーすぶりざーど》` — 漢字5字全体にルビ
  - 例: `今日は良い|永遠力暴風雪《えたーなるふぉーすぶりざーど》日和ですね` — `|` で開始位置を明示

### 3. 傍点の記法

二重の二重山括弧 `《《》》` で囲む。

```
これは《《重要な》》ことだ
```

囲まれた文字列の各文字の上に傍点（・）が表示される。

### 4. 改行・空行の扱い

- テキストエリア上の改行がそのまま反映される（HTMLの `<br>` に変換）
- 空行（連続改行）もそのまま表示に反映される
- 読者側の閲覧設定に「空行挿入」「空行圧縮」オプションがある。投稿者がどう書いても、読者の設定で空行の幅が変わる可能性がある
- Pixivと同様、プレーンテキストの改行が直接反映される方式

### 5. シーン区切り

ハーメルンには **なろうのような公式の水平線記法は存在しない**。シーン区切りの一般的な方法:

- テキストとして `＊＊＊` や `***` を空行で挟んで書く（最も一般的）
- 特殊タグを駆使して装飾的な区切り線を作る作者もいる
- `《center》＊＊＊《/center》` のように中央寄せと組み合わせる方法もある
- なろうの `[newpage]` に相当するページ区切り機能はない（1話=1ページ）

### 6. 特殊タグ（装飾記法）一覧

ハーメルンの最大の特徴。他サイトに比べて圧倒的に装飾の自由度が高い。全て `《タグ名》...《/タグ名》` の形式。

#### テキスト装飾
| 記法 | 効果 |
|------|------|
| `《b》テキスト《/b》` | **太字** |
| `《big》テキスト《/big》` | 文字を大きく |
| `《small》テキスト《/small》` | 文字を小さく |
| `《s数値》テキスト《/s》` | フォントサイズ指定（例: `《s3.9》`） |
| `《font数値》テキスト《/font》` | フォント番号指定（例: `《font104》`） |
| `《sup》テキスト《/sup》` | 上付き文字 |
| `《sub》テキスト《/sub》` | 下付き文字 |

#### 文字色・装飾色
| 記法 | 効果 |
|------|------|
| `《color:色名》テキスト《/color》` | 文字色（色名 or #カラーコード） |
| `《edge:#カラーコード》テキスト《/edge》` | 文字の縁取り |

使用可能な色名: white, gray, darkgray, black, brown, darkbrown, red, darkred, gold, orange, darkorange, green, darkgreen, blue, darkblue, purple, pink。6桁/3桁の16進カラーコード指定も可。

#### 配置・レイアウト
| 記法 | 効果 |
|------|------|
| `《center》テキスト《/center》` | 中央寄せ |
| `《right》テキスト《/right》` | 右寄せ |
| `《left》テキスト《/left》` | 左寄せ |
| `《lh数値》テキスト《/lh》` | 行間（line-height）指定 |

#### 背景・ボックス
| 記法 | 効果 |
|------|------|
| `《bgcolor:#コード》...《/bgcolor》` | 背景色 |
| `《bo#コード》...《/bo》` | 枠線 |
| `《r-数値》...《/r》` | 角丸 |
| `《box:オプション》...《/box》` | ボックス（w, h, bg, p, overhidden等） |

#### アニメーション・エフェクト
| 記法 | 効果 |
|------|------|
| `《marquee》テキスト《/marquee》` | スクロール |
| `《blink》テキスト《/blink》` | 点滅 |
| `《fade》テキスト《/fade》` | 緩やかな点滅 |
| `《shake》テキスト《/shake》` | 揺れ |
| `《vib》テキスト《/vib》` | 振動 |
| `《opacity:数値》...《/opacity》` | 透明度指定 |
| `《blur:数値》...《/blur》` | ぼかし |

#### テーブル
`《table》` タグで表が作成可能。行は `[[`、セルは `[` で区切る。ヘッダセルは `_`、中央揃えは `=`、右揃えは `>` 等のオプションあり。

#### その他
- TeX変換: 数式や表の組版が可能
- 麻雀牌画像変換
- 挿絵（画像）挿入: 事前アップロード → 運営チェック（通常2日以内）→ 画像タグで挿入
- 縦書き表示にも対応

### 7. 文字数制限

| 項目 | 制限 |
|------|------|
| 1話あたり最低文字数 | **1,000文字**（システム上の下限） |
| 推奨最低文字数 | **2,500文字**（FAQ記載の推奨値） |
| 1話あたり最大文字数 | 明確な公式発表なし。実運用上、数万字の投稿が存在する |
| 平均的な投稿文字数 | 連載作品の平均は約4,000文字/話 |
| 高評価帯の平均 | 約7,500文字/話の作品が最も評価が高い傾向 |

### 8. 投稿時の設定項目

#### 小説情報（必須）
- **タイトル**: 小説のタイトル
- **原作名**: 二次創作の場合は原作の正式名称を記入。サイトTOPの「原作カテゴリ」から選択。一次創作の場合は「オリジナル作品」と記入
- **あらすじ**: 検索結果や小説トップに表示される。画像挿入不可、ルビ・傍点は使用可
- **タグ**: 半角カンマ区切りで任意設定。検索に使われる

#### 警告タグ（必須チェック）
以下12種から該当するものを選択:
1. R-15
2. R-18
3. ボーイズラブ
4. ガールズラブ
5. オリ主（オリジナル主人公）
6. 神様転生
7. 残酷な描写
8. アンチ・ヘイト
9. 転生
10. 憑依
11. 性転換
12. クロスオーバー

警告タグは目次や検索結果で赤色タグとして表示され、読者が地雷を踏む前に回避できる設計。

#### 投稿形式
- **短編**: 1話完結
- **連載**: 2話以上。各話に「サブタイトル」（=エピソードタイトル）を設定

#### 公開設定
- 通常公開
- **チラシの裏**: 感想・評価を制限した非公開的な公開。ランキングや検索に表示されない
- 完全非公開

#### その他
- 感想欄の開閉設定
- 評価の受付設定

### 9. シリーズ/連載の設定

- **章管理機能**: 「投稿済み小説」→ 小説名 → 「章管理」から設定。章名は目次ページに表示される
- 各話に「サブタイトル」を設定可能（目次に表示される）
- 章の中に複数話を格納する階層構造（部 > 章 > 話）
- **前作/続編のリンク機能**: 明確な「シリーズ」機能は未確認。タグや説明文で関連付ける運用が一般的
- 連載の「完結」設定が可能（検索フィルタに影響）

### 10. Pixivテキストとの主な違い

| 項目 | Pixiv小説 | ハーメルン |
|------|-----------|------------|
| **基本フォーマット** | プレーンテキスト | プレーンテキスト + 独自特殊タグ |
| **ルビ** | `[[rb: 漢字 > ふりがな]]` | `\|漢字《ふりがな》` |
| **傍点** | `[[rb: 文字 > ・]]` で疑似的に | `《《文字》》` 専用記法あり |
| **シーン区切り** | `[newpage]` でページ分割 | なし。テキスト `＊＊＊` 等で代用 |
| **太字** | なし | `《b》テキスト《/b》` |
| **文字色** | なし | `《color:色名》テキスト《/color》` |
| **中央寄せ** | なし | `《center》テキスト《/center》` |
| **文字サイズ** | なし | `《big》` / `《small》` / `《s数値》` |
| **アニメーション** | なし | marquee, blink, shake 等多数 |
| **画像** | 挿絵機能あり（即時） | 挿絵機能あり（運営事前チェック要） |
| **章立て** | シリーズ機能で管理 | 章管理機能 + サブタイトル |
| **文字数下限** | なし | 1,000文字 |
| **装飾の自由度** | 低い（ほぼプレーンテキスト） | 極めて高い |
| **連載管理** | シリーズ内に個別作品を並べる | 1作品内で章・話で管理 |
| **読者の表示設定** | 限定的 | 空行圧縮/挿入、フォント、背景色等を読者が変更可 |
| **R-18** | あり（年齢制限設定） | あり（警告タグ + 年齢認証） |

#### Pixivからの変換時の注意点
- ルビ記法の変換: `[[rb: 漢字 > ふりがな]]` → `|漢字《ふりがな》`
- `[newpage]` の除去（ハーメルンには対応記法なし。必要なら `＊＊＊` に変換）
- `[chapter: タイトル]` → ハーメルンでは章管理機能で別途設定
- Pixivの本文にはほぼ装飾がないため、ハーメルンへの移植時に太字や中央寄せを追加する余地がある（ただし小説本文での装飾多用は読みにくさに繋がるため注意）

## Implications（本プロジェクトへの示唆）

- 現在の `dist/pixiv/` テキストは全角 `＊＊＊` でシーン区切りを行い、ルビは使用していない。ハーメルン用に変換する場合、ルビ記法の変換と `[newpage]` の除去が主な作業になる
- ハーメルンの読者は閲覧設定で空行幅を変更できるため、空行に依存した演出（Author DNA の余白の厳選）は意図通りに表示されない可能性がある
- ハーメルンの平均7,500字/話が高評価帯という数値は、Author DNA の目標文字数（7,000-10,000字）と合致する
- 警告タグ12種は二次創作特有の地雷回避システム。battousai は「残酷な描写」「R-15」が該当する可能性がある
- ハーメルンの特殊タグは極めて豊富だが、本プロジェクトの美学（文体で語る・装飾に頼らない）からすれば、ルビと傍点以外の装飾タグを使う場面は限られる

## 注意事項

ハーメルン公式サイト（syosetu.org）はスクレイピング/外部フェッチに対して403を返すため、公式ヘルプの直接閲覧ができなかった。本レポートの情報はWebSearch結果のスニペット、二次ソース（ニコニコ大百科、あにまん掲示板、note記事等）、および検索結果のサマリーから構成されている。正確性の担保のため、実際の投稿前にハーメルン公式ヘルプ（https://syosetu.org/readme.html）をブラウザで直接確認することを推奨する。特に以下の項目は公式確認が望ましい:
- 1話あたりの最大文字数（上限値）
- 特殊タグの最新の追加・変更
- シリーズ/前作リンク機能の有無
