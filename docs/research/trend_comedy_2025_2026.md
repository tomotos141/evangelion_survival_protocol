# Research Report: Web小説 コメディ・お気楽系トレンド 2025-2026

**Date**: 2026-02-11
**Type**: Trend
**Query**: 2025-2026年のWeb小説市場におけるコメディ・お気楽・愉快系ジャンルの動向、人気タグ、新テンプレ、読者反応、SNSバズ

---

## Findings（調査結果）

### 1. 今バズっているジャンル・タグ（コメディ・お気楽系）

**カクヨム 2025年人気新作TOP10の傾向**:
- 1位『小物貴族が性に合うようです』（スパ郎）――「小物」を自称する貴族が意図せず大事を成す構造。勘違い/無自覚系の亜種
- 2位『規格外素人のプロ野球人生』（Jaja）――現代スポーツもの。なろう/カクヨムでは珍しいジャンルが上位に
- 3位『じゃあ俺だけネトゲのキャラ使うわ』（藍敦）――ゲーム要素×異世界自由行動。お気楽トーンの最強系
- 4位『騎士団の落とし物係』（鈴木竜一）――窓際部署×転生騎士×無自覚無双。「有能なのに左遷」テンプレの変奏
- 5位以下もダンジョン系・レベル上げ系・追放悪役令息ものが並ぶ

カクヨムの2025年TOP10は「ファンタジー+コメディ」「無自覚無双」「現代ダンジョン」の3軸に集中。純粋なギャグ単体よりも、ファンタジーやアクションの骨格にコメディ味を載せる構造が強い。

**なろう（小説家になろう）の動向**:
- 恋愛ジャンルが全体の38%に急上昇（2025年末〜2026年初で過去最高）。「異世界恋愛」が首位奪還
- 「転生」はタイトルの約24%に含まれ、もはや設定ではなくインフラ
- 「ダンジョン」がファンタジー内で急伸。特に「現代ダンジョン」「ダンジョン配信」の掛け合わせが目立つ
- 「スローライフ」「領地経営」「もふもふ」はピークを過ぎたが安定枠として残存

**人気急上昇中のタグ・ジャンル**:
| タグ/ジャンル | プラットフォーム | 状態 |
|---|---|---|
| 勘違いコメディ / 無自覚最強 | カクヨム・なろう・アルファポリス | 成長中。カクヨムでは30,000スター超の作品あり |
| 現代ダンジョン × 配信者 | カクヨム・なろう | 急成長。VTuber文化との合流地点 |
| ラブコメ（学園・日常系） | カクヨム | このラノ2026文庫TOP4がラブコメ独占 |
| グルメ × 異世界 / ダンジョン | 全プラットフォーム | VTuber要素との融合も（『推しにささげるダンジョングルメ』） |
| おじさん主人公 / サラリーマン主人公 | なろう | 読者年齢層35.2歳との共鳴。テンプレ少年主人公の対抗軸 |
| TS転生 × コメディ | カクヨム・なろう | ニッチだが根強い。「男に戻るためにTS姿でダンジョン配信」等 |
| 美形インフレもの | なろう | 新ジャンル。『美形インフレ世界で化物令嬢と恋がしたい！』が代表 |

### 2. 新しいテンプレ・フォーマット（追放/悪役令嬢の次の波）

**「追放」「悪役令嬢」の現在**:
- 追放系: ピークアウト。「追放」タグだけではランキングに入れない段階。KADOKAWA系レーベルでも「追放ものの乱発は控える動き」が出始めている。ただしコミカライズのストック消化は2026年まで継続
- 悪役令嬢: 完全には死んでいないが新規参入が減少。「悪役令嬢 + ループ」「悪役令嬢 + 暗躍（本当に悪役として振る舞う）」が生き残りパターン

**2025-2026年の新テンプレ/フォーマット**:

1. **勘違い/無自覚最強系**: 「陰の実力者になりたくて！」の成功以降、勘違いコメディが一つのジャンルとして定着。主人公が状況を誤解している（あるいは周囲が主人公を誤解している）構造で、読者は「全知視点で笑う」快感を得る。『底辺領主の勘違い英雄譚』、カクヨムの勘違い系タグで30,000スター超の作品が複数存在

2. **現代ダンジョン × 配信/VTuber**: 異世界転生に代わる「現代を舞台にしたファンタジー」の受け皿。配信者がダンジョンを攻略する設定は、VTuber文化に親しんだ読者層と直結する。『底辺配信者だけどダンジョンで人気探索者を助けたら、なぜかやべぇ女として大バズりしてみんなから怖がられている』等のタイトルが象徴的

3. **ボードゲーム/趣味特化ラブコメ**: このラノ2026三冠『あそびのかんけい』（葵せきな）が象徴。ボードゲームカフェを舞台に、全員が秘密を抱えたブラフ（嘘・ごまかし）のすれ違いラブコメ。「趣味の場」を舞台にした閉じた人間関係の中でのすれ違いが新しいフォーマットとして浮上

4. **「同居/隣人」系ラブコメの深化**: 『お隣の天使様にいつの間にか駄目人間にされていた件』がこのラノ2026文庫2位。『義妹生活』系の「日常の隣にいる異性」テンプレが書籍化・アニメ化の王道ルートとして定着。Web小説発→ラノベ文庫→アニメ化のパイプラインが最も太いジャンル

5. **「テンプレのメタ化/自己パロディ」**: テンプレそのままでは売れない → テンプレを「加工」する方向。「美形インフレもの」（転生したら美形だが世界全体が美形）のように設定自体を自己言及的にパロディ化する。復讐テンプレを反転させたメタ作品、追放された側にも正当な理由がある展開など

### 3. カクヨム/なろうのランキング傾向（コメディ・日常系）

**このラノ2026 文庫部門TOP10**:
1. 『あそびのかんけい』 ← **ラブコメ**（三冠達成）
2. 『お隣の天使様にいつの間にか駄目人間にされていた件』 ← **ラブコメ**
3. 『負けヒロインが多すぎる！』 ← **ラブコメ**
4. 『時々ボソッとロシア語でデレる隣のアーリャさん』 ← **ラブコメ**
5. 『転生程度で胸の穴は埋まらない』
6. 『デルタとガンマの理学部ノート』
7. 『ミドルノートにさよなら』
8. 『こちら、終末停滞委員会。』
9. 『薬屋のひとりごと』
10. 『ダンジョンに出会いを求めるのは間違っているだろうか』

TOP4がラブコメ独占。文庫ラノベ市場では「ラブコメ＝王様」の状態が2025-2026年に確立。

**カクヨムの特徴**:
- なろうと比較して「ラブコメ」「現代もの」の比率が高い
- カクヨムコンテスト11（2025年12月〜2026年2月）が10部門を設置。新文芸・文芸部門があり、テンプレ外作品の書籍化チャンスが広い
- GA×カクヨムコラボで「学園ミステリー」「学園ホラー」の2部門を新設（大賞100万円+3巻書籍化+コミカライズ確約）
- カクヨム発→書籍化のパイプラインが電撃文庫、富士見ファンタジア文庫、MF文庫J、GA文庫に拡大中

**なろうの特徴**:
- 日間ランキングは依然として異世界ファンタジー+最強系が支配的
- ただしブックマーク重み付けの調整（2024年）により、序盤テンプレのみの作品の優位性がやや低下
- コメディ/ギャグ単独での上位入りは困難。「ファンタジー/恋愛 + コメディ要素」の掛け合わせが必須
- 年間・累計ランキングでは文芸寄りの作品（『無職転生』『本好きの下剋上』）も上位に入る

**アルファポリスの特徴**:
- 女性向けファンタジーが他プラットフォームより強い
- 勘違いコメディ系の作品が一定数存在。「誤解と妄想で突き進むほのぼのコメディ」等
- 第9回キャラ文芸大賞（2026年1月）でテーマ別賞を新設

### 4. 読者の反応が良い要素（軽め作品で機能するもの）

**構造レベル**:
- **全知読者の快感**: 勘違い系で読者だけが真実を知っている構造。主人公の言動と周囲の解釈のギャップが笑いを生む。読者は「優越的な立場から見下ろして笑える」安心感を得る
- **秘密のすれ違い**: 『あそびのかんけい』型。複数キャラがそれぞれ秘密を抱え、互いの嘘が絡み合って錯綜する。「いつバレるか」のサスペンスがページめくりを駆動する
- **ストレスフリー展開**: 「ざまぁ」の快感は残しつつ、悪意や陰湿さを排除した「カラッとした」テンポ。嫌味のないギャグ、ストレスを感じずに読み進められるトーン

**キャラクターレベル**:
- **ド天然/無自覚ヒロイン**: 『ド天然令嬢アリア』型。持ち前の天然さで周囲のやっかみを無自覚に躱す。読者はそのズレ自体に萌える
- **ギャップ萌え**: 「見た目は怖い/冷たいが中身は優しい」「強そうだが実はポンコツ」等の二面性。キャラの内面と外面のギャップがコメディとロマンスの両方を駆動
- **スパダリ（スーパーダーリン）婚約者**: 女性向けで根強い人気。「溺愛」タグとセットで機能する

**テンポ・文体レベル**:
- **高速テンポの掛け合い**: ボケとツッコミのリズムが速い。ラノベ的な軽い文体で、1話あたりの文字数は2,000〜4,000字程度が主流（なろう日間ランキング上位のコメディ作品の場合）
- **タイトル芸**: 長文タイトルが内容を要約し、読者が「何を読むか」を即座に判断できる。『底辺配信者だけどダンジョンで人気探索者を助けたら、なぜかやべぇ女として大バズりしてみんなから怖がられている』が典型
- **1話完結的エピソード構造**: 日常系/コメディ系では、各話が独立したエピソードとして機能しつつ緩やかに人間関係が進展する構造が好まれる

### 5. SNS（X/Twitter）で話題になっている小説系ネタ

**Twitter文学の成熟**:
- 麻布競馬場が「Twitter文学」のジャンルを確立。ツイート1本で14万いいねを獲得した実績。短編集『この部屋から東京タワーは永遠に見えない』はAmazon文芸売上1位を記録。2025年8月に新作『5分後に、虚しい人生。』（集英社文庫）を刊行
- 「Twitter → 書籍化」のルートが確立。SNSで言葉のセンスを示す → 出版社からオファーの流れ
- 特徴的なのは、ファンタジーではなく**現代日本の「中流の悲しみ」「東京と地方」**をテーマにした短編がバズること。Web小説市場の主流（異世界ファンタジー）と真逆のポジション

**SNS経由のバズパターン**:
- **スクショ小説**: メモアプリに長文を書いてスクリーンショットで投稿する形式。Twitterの文字数制限を回避しつつ、画像としてのインパクトで拡散される
- **概念系ツイート → 小説化**: 「〇〇な世界」「もし〇〇だったら」という概念ツイートがバズ → それを膨らませて小説に → カクヨムやなろうで連載開始、の流れ
- **ニコニコ漫画との連動**: SNSで話題になったラブコメ漫画がニコニコ漫画の上半期ランキング上位を席巻（KADOKAWA 2025年データ）。小説→漫画→SNSバズの三角循環が機能している

**2025-2026年に話題になった作品・概念**:
- 『あそびのかんけい』がSNSで拡散 → このラノ三冠。ボドゲカフェという現実的な舞台設定がSNSユーザーの共感を呼んだ
- 『負けヒロインが多すぎる！』がアニメ化でSNSを席巻。「負けヒロイン」概念自体がミーム化
- 「現代ダンジョン配信もの」はVTuber文化圏とWeb小説文化圏の合流点として、両方のSNSコミュニティで話題になりやすい

## Implications（本プロジェクトへの示唆）

### Author DNA との接点と衝突

Author DNA の美学（脆さ、沈黙、代償、未解決の余韻）は、コメディ・お気楽系の主流とほぼ**全面的に対立する**。コメディ市場が求めるのは「ストレスフリー」「高速テンポ」「カラッとした解決」であり、Author DNA が求めるのは「代償」「沈黙」「余白」。

ただし、接続可能なポイントは存在する:

- **「勘違い/すれ違い」構造**: 『あそびのかんけい』型の「全員が秘密を抱えている」構造は、Author DNA の「Silence as Dialogue」「Subtext of Silence」と共鳴しうる。コメディとして表面は軽いが、沈黙の裏に本音がある構造を暗くすれば Author DNA と直結する
- **「日常の聖性」**: Author DNA §5 の「日常の聖性」は、スローライフ/日常系の「何気ない幸福を描く」方向と接点がある。ただし Author DNA では「死を知る者にとっての奇跡」として描くため、トーンは根本的に異なる
- **villainess プロジェクトとの接続**: 悪役令嬢テンプレの「善人でした/溺愛エンド」を裏切る Author DNA の方向性は、市場の飽和に対する差別化として機能する。2025-2026年の生き残りパターン「悪役令嬢 + 暗躍」「悪役令嬢 + ループ」と方向が近い

### コメディ系に参入する場合の選択肢

Author DNA を保持したまま「軽い」作品を書く場合、以下の市場ポジションが考えられる:

1. **「すれ違いラブコメ」だが沈黙が重い**: 『あそびのかんけい』型の構造を借りつつ、秘密の質を深くする。笑えるが、ふと切ない瞬間が差し込まれる文体
2. **「勘違いコメディ」だが代償がある**: 勘違い/無自覚最強の外殻の中に、Author DNA の「力を振るうことの代償」を仕込む
3. **「おじさん主人公」の再起もの**: 読者年齢35.2歳との共鳴。コメディタッチだが人生の苦さがベースにある。市場にはまだ供給が薄い

### プラットフォーム選択

- **カクヨム**: コメディ・ラブコメ市場で最も幅が広い。コンテストの部門が多く、テンプレ外でも書籍化チャンスがある。「新文芸」「文芸」部門は Author DNA の文体密度と相性がよい
- **なろう**: コメディ単独での上位入りは困難。「ファンタジー + コメディ」の掛け合わせが必須。ただし読者母数が最大
- **アルファポリス**: 女性向けほのぼのコメディの場として機能。villainess プロジェクトの並行投稿先として有効
