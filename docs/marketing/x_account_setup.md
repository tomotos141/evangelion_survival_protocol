# X（Twitter）アカウント セットアップガイド

> 濁刃（だくじん）プロジェクト用。上から順に実行すれば、完成したアカウントが出来上がる。

---

## 1. アカウント作成

1. [x.com](https://x.com) にアクセスし「アカウントを作成」を選択
2. メールアドレスまたは電話番号で登録する
   - メールアドレス推奨（電話番号は後から追加できる）
3. 生年月日を入力（非公開設定にする）

### ID（@ハンドル）の選び方

- **作者名ベースにする**。作品名ではなく、ペンネームで取る
  - 理由: 作品は終わるが、ペンネームは次の作品でも使い続ける
- 15文字以内。短いほど良い
- アンダースコア `_` やドット `.` は避ける（タイプしにくく、口頭で伝えにくい）
- 数字の羅列も避ける（スパムアカウントに見える）

例: `@momonga` `@penname` のようなシンプルな形が理想。

### 表示名

```
[ペンネーム]@濁刃 連載中
```

連載の進行に合わせて更新する:

| 状態 | 表示名 |
|------|--------|
| 連載中 | `[ペンネーム]@濁刃 連載中` |
| 全話公開後 | `[ペンネーム]@濁刃 全10話` |
| 完結宣言後 | `[ペンネーム]@濁刃 完結` |
| 次回作開始時 | `[ペンネーム]@[次回作名] 連載中` |

## 2. プロフィール設定

### プロフィール文（160文字以内）

```
剣が冴えるほど人間が消える——
幕末剣劇『濁刃（だくじん）』連載中。るろうに剣心 追憶編を下敷きにした全10話。
```

- 1行目がフック。検索結果やフォロー通知で最初に目に入る部分
- 「るろうに剣心」「追憶編」をプロフィール文に入れることで、プロフィール検索にもヒットする
- AI生成であることはプロフィールに書かない（Pixiv側でAIフラグを設定済みのため十分）

### URL

PixivシリーズページのURLを設定する。

```
https://www.pixiv.net/novel/series/XXXXXXX
```

個別エピソードではなく、シリーズ一覧ページを貼ること。

### アイコン画像

- サイズ: **400x400px**（正方形）
- 円形にトリミングされるため、四隅には重要な要素を置かない
- 作品の世界観に合った画像（刀、血飛沫、鉄錆の質感など）
- ComfyUIで生成する場合、出力を400x400にリサイズしてからアップロード

### ヘッダー画像

- サイズ: **1500x500px**（横長 3:1）
- スマホ表示では上下約60pxずつトリミングされる。重要な要素は中央380pxの帯に収める
- 作品タイトルやキャッチコピーを画像に焼き込むのも有効
- ComfyUIで生成する場合、横長構図で出力してからトリミング

## 3. 固定ポスト

アカウント作成後、**最初に以下のポストを投稿して固定する**。

```
剣が冴えるほど人間が消える。

幕末の京都。長州の影の刃として名前のない仕事を重ねる少年。振るうほど鋭くなる刀——けれど、掌から鉄錆の匂いだけが消えない。

るろうに剣心 追憶編を下敷きにした幕末剣劇『濁刃（だくじん）』全10話・連載中。

[PixivシリーズURL]

#るろうに剣心 #二次創作小説
```

### 手順

1. 上記テキストをポストする
2. 表紙画像を添付する（横長推奨。ヘッダー画像と同じものでも可）
3. 投稿後、自分のプロフィール画面を開く
4. 該当ポストの右上「…」メニュー →「プロフィールに固定する」を選択

固定ポストはプロフィールを訪れた人が最初に見るポスト。シリーズの入口として機能させる。

## 4. 初期フォロー戦略

### 検索キーワード

以下のキーワードでX検索し、創作者や読者を見つける:

- `るろうに剣心 二次創作`
- `追憶編 小説`
- `るろ剣 SS`
- `るろ剣 二次`
- `抜刀斎 小説`

### フォロー対象（10〜20人目安）

優先度の高い順:

1. **るろ剣の二次創作小説を書いている人** — 相互認知の可能性が最も高い
2. **るろ剣のイラストを描いている人** — 作品のビジュアル拡散に繋がる
3. **追憶編の感想や考察を書いている人** — 濁刃のターゲット読者層と一致する

### フォロー後のアクション

- 相手のPixiv作品をブックマークする → プロフィール閲覧を誘発する
- 相手の作品への感想ポストをいいね or リポストする
- 自分の作品に関連する話題のポストに自然な形でいいねする
- **直接リプライで自作品の宣伝をしない**（マナー違反。嫌われるだけで逆効果）

### 認知を広げるための行動

- 自分自身も作品の感想や考察をポストする（宣伝ではなく、るろ剣ファンとしての発言）
- 他の創作者の新作に反応する（いいね、ブックマーク、感想）
- 相互認知が生まれてから、初めて自然な流れで作品の話になる
