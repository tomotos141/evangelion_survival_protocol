## 1. タグ設計

### battousai（濁刃）推奨タグ（8個）

```
るろうに剣心 / 緋村剣心 / 雪代巴 / 抜刀斎 / 追憶編 / シリアス / 幕末 / 長編
```

**設計意図:**
- `るろうに剣心`: 作品名。最大の検索流入源
- `緋村剣心` `雪代巴`: キャラ名。ファンが直接検索する
- `抜刀斎`: 時代を限定するキーワード。追憶編ファン直撃
- `追憶編`: 原作の中でも特に人気の高いエピソード。ここに刺さる層が本作のターゲット
- `シリアス`: ジャンル属性。コメディ・ギャグを除外するフィルタ
- `幕末`: 世界観タグ。歴史好き層へのリーチ
- `長編`: 読みごたえを求める読者を引く
- **残り2枠は読者によるタグ追加に開放**

### angel_return 推奨タグ（8個）

```
エヴァンゲリオン / 新世紀エヴァンゲリオン / 碇シンジ / ループもの / シリアス / SF / 長編 / 完結済み
```

**設計意図:**
- `エヴァンゲリオン` `新世紀エヴァンゲリオン`: 両方入れる。検索ワードが分散しているため
- `碇シンジ`: 主人公タグ
- `ループもの`: ジャンル。時間ループ好きの読者に届く
- `完結済み`: 全15話完結は大きな強み。完結済みで検索する読者は多い
- **残り2枠は読者によるタグ追加に開放**

## 2. キャプション冒頭78文字の最適化

> Pixiv検索結果に表示されるのは冒頭約78文字。ここで興味を引けなければクリックされない。

### 現状の問題
- 「タイトル：〇〇 English Title」で13〜16文字消費している
- タイトルはPixivの作品タイトル欄に入れるため、キャプションでの重複は無駄

### 改善案: battousai

**第1話（現行）:**
> タイトル：夜雨 Night Rain⏎⏎雨の京都――人斬りが刀を振るうたび、鉄錆の匂いが深くなる。

**第1話（改善案）:**
> 雨の京都――人斬りが刀を振るうたび、鉄錆の匂いが深くなる。「新時代のために」。大義の言葉が、今夜もまた、胸に届くまでに少しだけ時間がかかった。

→ タイトル行を削除。78文字すべてを世界観に使う。

**第2話（改善案）:**
> 四日後――次の名前が来た。前より格上の相手。前より速い剣。身体が先に動き、意識が追いつかない。双龍閃が完璧に決まった瞬間、指が震えていた。

**第3話（改善案）:**
> 血と煙と政治の匂いに沈む京都。清里の仇を探す女の懐には、白梅の香りがまだ残っていた。夜の路地裏で、血に濡れた男を見た。刀を拭う手が、震えていた。

### 改善案: angel_return

**現行:**
> [作品タイトル]⏎Evangelion: Survival Protocol⏎⏎[シリーズ共通あらすじ]⏎「逃げちゃダメだ」なんて...

**改善案（シリーズ紹介）:**
> 「逃げちゃダメだ」なんて、もう言わない。逃げる場所なんて、最初からどこにもなかったのだから。――記憶と経験を引き継いだまま、再び14歳に戻った碇シンジ。

→ `[作品タイトル]` `[シリーズ共通あらすじ]` などのラベル行を削除。冒頭からフックを叩きつける。

**第1話（現行）:**
> タイトル：使徒、再来⏎⏎目覚めると、そこは赤い海のほとりだった。

**第1話（改善案）:**
> 目覚めると、そこは赤い海のほとりだった。絶望の記憶を宿したまま、再び14歳として「選ばれた」碇シンジ。彼は知っている。この先に待つ痛みを。

## 3. シリーズ紹介文

### battousai（濁刃）シリーズ紹介文

```
剣が冴えるほど人間が消える。

幕末の京都。長州の影の刃として、名前のない仕事を重ねる少年がいた。
振るえば振るうほど鋭くなる刀——けれど、拭い終えた掌から鉄錆の匂いだけが消えない。

「剣の冴えと引き換えに、何を失っているのか」

血の匂いに侵されていく人斬りと、白梅の香りを懐に隠した女。
二つの沈黙が交わるとき、刀の外にある何かが軋み始める。

るろうに剣心 追憶編を下敷きにした幕末剣劇。全10話・3幕構成。
```

```
「逃げちゃダメだ」なんて、もう言わない。
逃げる場所なんて、最初からどこにもなかったのだから。

記憶と経験を引き継いだまま、再び14歳に戻った碇シンジ。
しかし彼を待っていたのは「無双」ができるイージーモードではなく、世界そのものが敵対的に進化した「ハードモード」だった。

傷ついた生存本能だけを頼りに、二度目の地獄を歩き始める。
これは、ただのループではない。断絶された未来に残された、最後の「悪あがき」の物語。

新世紀エヴァンゲリオン二次創作。全15話・4幕構成・完結済み。
```

## 3.5 表紙画像

シリーズ表紙にComfyUIで生成した雰囲気画像を使用する。詳細は `cover_art_guide.md` を参照。

- 表紙画像は1200×1600（縦長）で生成し、Pixiv側でリサイズさせる
- キャラクターは描かない。風景・小物・テクスチャで「染み鉄」の世界観を視覚化する
- タイトル文字を筆書き風フォントで重ねる
