# Phase 1: SNS初動スケジュール（2週間）

> アカウント開設から定常運用への移行まで。焦らず、1〜2日おきに告知を出して「宣伝botではなく創作者」として認知される。

## 基本方針

- 23:00投稿（30代男性読者のピーク時間帯）
- 告知は1〜2日おき（一気に6連投しない。新規アカウントがタイムラインを自分のツイートで埋めると「宣伝bot」と判断される）
- 告知しない日は「交流の日」（他の創作者の作品にいいね・ブックマーク）
- 創作進捗ツイートはPhase 1では不要（フォロワーが少ないうちは効果が薄い）
- テンプレートは `docs/marketing/sns_announcement_guide.md` を使用

## スケジュール

| Day | 曜日目安 | 時間帯 | アクション | 備考 |
|-----|----------|--------|------------|------|

| 0 | - | 23:00 | 固定ポスト投稿（シリーズ紹介 + 表紙画像） | 投稿後「固定する」を忘れずに |

| 2 | - | -- | 交流の日。他の人のポストにいいね | 投稿しない |
| 3 | - | 23:00 | 第2話「残心」告知 | |
| 3 | - | 随時 | 追加フォロー5人 | |
| 4 | - | -- | 交流の日 | |
| 5 | - | 23:00 | 第3話「白梅」告知 | |
| 6 | - | -- | 交流の日 | |
| 7 | - | 23:00 | 第4話「同居」告知 | |
| 7 | - | 随時 | 追加フォロー5人 | 計15人前後 |
| 8 | - | -- | 交流の日 | |

## Phase 1 完了後

- 6話分の告知が完了したら Phase 2（定常運用）に移行
- 定常運用の内容:
  - 新話公開時のみ告知（23時投稿 → 30分以内にX告知）
  - 創作進捗の小出し（ネタバレなし。「今日は7話目の戦闘シーンで刀が鳴る音の表現に悩んだ」程度）
  - 継続的な交流（ブックマーク・感想・いいね）
