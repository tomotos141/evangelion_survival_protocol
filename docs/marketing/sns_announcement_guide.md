# SNS告知ガイド

> 投稿テンプレートとハッシュタグ戦略。作品の世界観を漂わせるトーンで統一する。

---

## 基本ルール

- **トーン**: キャプションと同じ文体。作品の一文を切り取ったような告知
- **プラットフォーム**: X（旧Twitter）
- **投稿タイミング**: 作品公開から **30〜120分以内**
- **画像**: 表紙画像を添付。生成ガイドは `cover_art_guide.md` 参照
- **頻度**: 新話投稿時のみ。日常的な宣伝はしない
- **固定ポスト**: プロフィールの固定ポストにシリーズのPixivリンクを常時掲載

---

## テンプレート構造

```
[作品からの一文 or フック（1〜2行）]

[シリーズ名] [話数タイトル]
[Pixiv URL]

[ハッシュタグ 2〜3個]
```

## 運用メモ

- **反応が少なくても連投しない**。作品の質で届ける
- **他の創作者の作品をブックマーク・感想する**ことで相互認知が生まれる
- **投稿後24時間の反応を見てPixiv側のタグを微調整**する
