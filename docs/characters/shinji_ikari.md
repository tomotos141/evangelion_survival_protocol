# キャラクター設定: 碇シンジ (ハードモード・ループ)

## 精神状態: 崩壊と再構築の狭間
- **PTSD**: LCLの海、量産機の笑い声、アスカの悲鳴、ミサトの死、カヲルの死の記憶が常に鮮明にある。
- **解離**: 「今の自分」と「目の前の現実」がうまく噛み合わず、現実感を喪失している。痛みだけが現実を繋ぎ止めるアンカー。
- **罪悪感**: 世界を一度滅ぼし、全人類をＬＣＬにしたという罪の意識が、救済への願望よりも「罰を受けたい」という自虐的な衝動に繋がっていることがある。

## 能力・スキルの呪縛
- **エヴァ操縦技術**: 確かに高いが、初号機に乗ること自体が「母の胎内への回帰」と「人食いの魔物への搭乗」という二重のトラウマを刺激する。乗るたびに精神汚染が進むリスクがある。

    - 運命を変えようと行動した結果、バタフライエフェクトで逆に事態が悪化する（例：助けようとしたトウジが、もっと悲惨な死に方をするなど）。
