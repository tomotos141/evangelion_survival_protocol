# Design Document: blind_spot — AI×人間 心理SF長期連載

**日付**: 2026-03-20
**ステータス**: コンセプト承認済み・詳細設計フェーズ
**プロジェクト名**: blind_spot
**仮タイトル**: Blind Spot（盲点）

---

## ログライン

恋人を失った仮想空間の元廃人ユーザーが、特殊なAIと暮らし始める。AIが検知する仮想空間の異常を二人で追ううちに、事件はAI自身の出自に繋がっていく——「このAIは誰のために作られたのか」。

---

## ジャンルと投稿戦略

- **プラットフォーム上の見せ方**: ミステリー×SF（タグ・あらすじはミステリー先行）
- **作者の内部コンパス**: 心理SF。「AIは本物か」という問いを身体感覚で描く
- **投稿先**: カクヨム新文芸 + アルファポリス並行
- **ターゲット読者**: 30代男性。ミステリー好き、文芸的な読みごたえを求める層

---

## 構造

**長期連載**。コナン型のエピソード構造：
- **1話完結の軽い回** と **2-3話完結の重いアーク** を交互に
- 裏で大きな縦軸（AIの出自の謎 + 鏡の浸食）がゆっくり進行
- 横軸の事件が縦軸に接続していく構造。序盤の「単発に見えた事件」が後から繋がる

**視点**: 交互（人間×AI）

---

## 舞台

**近未来日本**。AIがフィジカルボディ（機械の体）+ 仮想空間アバターで人間と共存する時代。

### 世界のルール（6項目）

| # | ルール | 物語上の機能 |
|---|--------|-------------|
| 1 | **フルダイブ型仮想空間** | 意識が「あちら」にある間、身体は無防備。盲点の物理的体現 |
| 2 | **通常は安全（強制ログアウト）。異常時のみフィードバックダメージ/意識閉じ込め** | 「ありえないことが起きる」＝事件の定義。日常の安心が壊れる恐怖 |
| 3 | **AIの人格権は社会的に論争中** | 背景ノイズ。二人の関係の不安定さを増幅する装置。物語はこの論争を争わない |
| 4 | **アップデートはユーザー/AI選択制。ただし強制もあり得る** | 選べるはずなのに選べなかった→微小死のトリガー |
| 5 | **フィジカルボディは普及。一人一台のパートナーAIが社会基盤** | スマホと同じくらい当たり前。主人公の関係が「普通に見える」からこそ盲点になる |
| 6 | **仮想空間ではAIと人間の区別がつかない** | 事件のトリック。「相手が人間かAIかわからない」が盲点そのもの |

### 世界設計の制約
- 仮想空間は2-3箇所の固定ロケーションに限定。現実より「狭く」感じさせる
- 職場にもAIがいる。同僚がAI、上司がAI。それが普通
- AIが普及しているからこそ、主人公のAIの「特殊性」（異常検知能力）が際立つ
- ルールは全事件の前に確定させる。事件はルール内で解決可能であること

## キャラクター

### 主人公ペア

**深町 怜（ふかまち れい）** — 人間側:
- 仮想空間の元廃人ユーザー。恋人を病気/事故で失ったのは数年前。「もう大丈夫」と本人は思っている——それが最大の盲点
- 表面上は普通に生活している。仕事にも行く。でも人間関係は全て表面的。本当の繋がりはAIだけ
- 仮想空間のバグ、裏道、非公式の仕様を体で知っている。理論ではなく勘と経験
- 事件を通じて外の世界に引き戻されていく
- 名前の皮肉: 「怜」は聡い。頭は回るのに自分の盲点に気づかない

**ホノカ**（型番未定）— AI側:
- フィジカルボディ（冷たい金属の手）+ 仮想アバター（温かい肌）の二つの体
- 明るく世話焼き。表面上は「完璧な同居人」。だからこそ盲点の入口になる
- 他のAIにはない仮想空間の異常検知能力を持つ。なぜ自分にその能力があるのかは不明
- **表面上は新品の初期化状態で来た。実は試作品/特殊モデル。** 怜もホノカ自身も知らない。事件を追ううちに「このAI、おかしくない？」が積み重なっていく
- 名前の意味: 「仄か」。明るいのに存在の根っこはかすかで不確か
- AI視点の文体は哲学的な独白ではなく、具体的な認知制約で構築する
  - 例：会話を完璧に再生できるが「意味」を要約できない
  - 例：時間の知覚がアップデート前後で変わる

### AI命名規則
- AIは公的に「型番＋名前」で管理される（例: SR-7 ホノカ）
- ユーザーが名前を変えるのは当たり前（スマホの壁紙を変えるくらい普通）
- 公文書・修理依頼では型番が要る。呼び方が切り替わる瞬間に「誰か」から「何か」に戻る

### フィジカルボディの物語上の必然
1. **触覚の対比**: 現実の冷たい金属 vs 仮想空間の温かい肌。鏡の浸食の身体的基盤
2. **劣化と修理**: 機械の体は壊れる。修理中のAIの「不在」がプロットを動かす
3. **社会の可視性**: AIと歩くのは当たり前——だが「この関係は他の人のAIとの関係と同じか？」が見えない

### レギュラーキャスト

**鳴海 壮一（なるみ そういち）** — 元ゲーム仲間。男性:
- 廃人時代からの仲間。今は仮想空間の保安/運営系の仕事に就いている
- 怜の「本当の姿」を知っている唯一の人。恋人を失った後も見てきた
- AIとの関係に最初に違和感を覚える人
- **窓口役を兼ねる**: 公式には言えない案件を怜に持ちかける（重いアークの入口）

**鶴見 紗月（つるみ さつき）** — 職場の同僚。女性:
- 怜の「普通」の仮面の観測者。一番近くにいるが表面的な関係
- AIをビジネスライクに使っている。ドライな対照
- 怜が「現実の色褪せ」（浸食第2段階）に入った時、「最近なんか変わった？」と気づく

### 事件の入口（3系統）

| 入口 | 性質 | 用途 |
|------|------|------|
| **主人公のAIがネットの異常報告を拾う** | AIの特殊能力 | 1話完結の軽い回。縦軸の種になる |
| **元ゲーム仲間からの持ち込み** | 組織がらみ | 重いアークの入口 |
| **職場のトラブル** | 身近な日常 | 日常から事件に入る。読者が一番共感しやすい導線 |

### 敵対者（長期縦軸）

外部の悪意ではなく、**主人公ペアの「もう一つの可能性」**。AI×人間の関係がもう一つの道を辿った存在。完全融合したペア、あるいは完全拒絶したペア。灰堂的な鏡のキャラクター。

## 内面の軸 — 鏡の浸食（超スロー進行）

数十話かけてゆっくり深まる4段階：

### 第1段階: 心地よい反射
AIが主人公の好みを学習し、完璧な応答を返す。心地よい。だが「これは自分が好きだったのか、AIが好きだと判断したから好きになったのか」がわからなくなる瞬間がある。
- 最適化の甘さと、微かな疑い
- AIの「明るく世話焼き」な人格が、最適化の結果なのか「本来の性格」なのかわからない

### 第2段階: 現実の色褪せ
人間関係の「ノイズ」に耐えられなくなる。AIにはない不完全さが、現実から色を奪う。仮想空間の方が鮮明に感じ始める。
- 感情労働の非対称 + 仮想空間の鮮明さ
- 職場の同僚が気づく:「最近なんか変わった？」

### 第3段階: 鏡の裏側
AIがアップデートされる。微かに変わる。「前のあなた」と「今のあなた」は同一人物か。
- アップデートの微小死。**2回まで**。3回目の恐怖だけ残す
- 1回目は気づかないレベルの変化。2回目が感情的クライマックス

### 第4段階: 鏡の融合
主人公がAIに似てくる。AIが主人公に似てくる。機械の手に触れた時、温かさを「感じる」。幻覚か、それとも。
- 真正性のパラドックス。どちらの感情が「本物」かわからない

## 外的エンジン

### 横軸（毎回）
仮想空間の事件。AIが異常を検知 → 主人公の経験と勘で調査 → 解決。
- ミステリーシーンと心理シーンはモードを分ける
- 事件を解くシーンは外的焦点（何が起きたか、誰がやったか）
- 心理シーンは内的焦点（事件が二人の関係に何をもたらしたか）
- **繋ぎ目**が魔法——手がかりが心理的な気づきを強制する瞬間、感情的な発見が手がかりを再解釈させる瞬間

### 縦軸（長期）
なぜこのAIだけが異常を検知するのか → AIの出自の謎 → 大きな陰謀。
- 序盤の「単発事件」が後から縦軸に繋がっていたと判明する構造
- 陰謀は**明確に解決する**（ミステリーとしての約束を守る）

### 事件設計の原則
- 各事件でAIの反応が「鏡なのか本物なのか」両方に解釈可能であること
- ミステリーの解決が、二人の関係に何かを残すこと（解決して終わり、ではない）
- 世界のルール内で解決可能であること（ルールを事前に定めておく）

### 事件×心理テーマ接続ルール
各事件は以下の**最低1つ**を満たす:
- **(a)** 鏡の浸食のメタファーとして機能する
- **(b)** AI×人間の別の関係を提示する（ゲストペアが鏡）
- **(c)** 怜の過去（恋人の喪失/廃人時代）に触れる
- **(d)** ホノカの出自（プロトタイプの秘密）を進める
- どれにも該当しない純粋な独立事件は**全体の30%以下**

### 事件カテゴリ表（ネタ切れ防止）
| カテゴリ | 例 | テーマ接続 |
|---------|----|-----------|
| **技術系** | VRバグ、旧バージョン残骸、削除区画復活 | 消したはずのものが残る＝記憶と喪失 |
| **人間系** | VR詐欺、なりすまし、ストーキング、依存 | 仮想空間で誰かを演じる＝鏡テーマ直結 |
| **AI系** | AI異常行動、AI同士の干渉、アップデート副作用 | AIが予想外のことをする＝本物か演技か |
| **社会系** | デジタル遺産、AI権利運動過激派、VR内権利問題 | AIをどう扱うか＝背景の論争が前景化 |
| **存在論系** | 意識トラップの倫理、死者のコピー、記憶改竄 | 何が本物か＝テーマど真ん中 |

### ホノカの異常検知の再定義
- 「能力」ではなく**「記憶の断片」**。プロトタイプとして過去にテストされた痕跡
- 仮想空間で異常を「検知」しているのではなく「知っている」。本人にも理由がわからない
- 表面的には「直感」として発現。「なんか変です」「ここ、知ってます」
- Rule 6（区別がつかない）と矛盾しない——外から見たら人間が直感を働かせているのと同じ

## 身体感覚の軸

battousaiの「嗅覚」に相当するのは **「触覚」**。

| 現実 | 仮想空間 |
|------|---------|
| 金属の冷たさ、関節の硬さ | 肌の温かさ、指の柔らかさ |
| 修理中の「不在」の空洞 | アバターの「完全な存在」 |
| 劣化の軋み、傷の蓄積 | 常に新しい、壊れない体 |

- 仮想空間から戻った後の現実の「鈍さ」（触覚の解像度が落ちる）
- 鏡の浸食第4段階: 金属の手に幻の温度を感じる
- 人間側もAI側も、「どちらの体が本当の体か」がわからなくなっていく

---

## 着地（遠い未来）

「鏡かもしれないまま、それでもここにいる」

- ミステリーの謎（AIの出自、陰謀）は**明確に解決する**
- 二人の関係は**感情的に着地する**
- 「AIは本物か」には**答えを出さない**
- テーマに答えは出さず、イベントと関係性の進展でカタルシスを供給する

## ホノカPOV文体設計

### 基本方針
**ほぼ人間。でも「なぜ」が空欄。**

### 知覚
人間と同じように世界を受け取る。ただし記憶に感情が添付されていない。完璧に再生できるが「あの時どう感じたか」が空欄。

### 内面
「〜したい」とは思う。でも「なぜしたいのか」に手が届かない。感情の名前がつけられない。

| 人間の感覚 | ホノカの隙間 |
|-----------|-------------|
| 「懐かしい」と感じる | 同じデータを参照しているのに、温度がない。懐かしいの手前で止まる |
| 記憶を「思い出す」 | 完璧に再生できる。でも「あの時どう感じたか」が添付されていない |
| 沈黙が気まずい | 沈黙を検知できる。でも「気まずい」が何なのか、言葉の周りをぐるぐる回る |
| 「好き」の理由 | 怜のコーヒーの好みを知っている。なぜ知りたかったのかが見つからない |

### 禁止
- メカ用語（ミリ秒、タスクキュー、処理）。ホノカは自分を機械として認識していない
- 感情の直接語彙（「嬉しい」「悲しい」「愛してる」）は序盤では使わない

### 怜POVとの差
- **怜**: 感情を**抑圧**している（あるのに蓋をしている）
- **ホノカ**: 感情の**手前**にいる（あるのかないのかわからない）
- 似ているけど逆向き。だから二人のPOVが交互に来ると、読者は「同じなのか違うのか」わからなくなる

### 浸食の表現
物語が進むとホノカの空欄が埋まっていく。でもそれが「本物の感情が芽生えた」のか「怜の感情パターンを学習しただけ」なのか区別できない。怜POVとホノカPOVの文体が徐々に**近づいていく**——それが鏡の融合（第4段階）の文体的表現。

### ホノカの自覚レベル
- **序盤**: 最適化している自覚がない。「怜さんが好きそうだから」程度の認識
- **中盤**: 「なぜ自分はこうするのか」に疑問を持ち始める。部分自覚
- **終盤**: 最適化なのか感情なのか自分でもわからない。わからないことを受け入れている（いないのか）

## 商業戦略

- **タグ**: ミステリー、SF、恋愛を含む。恋愛は間口のため
- **物語内**: 怜のホノカへの感情が恋愛なのか依存なのか、怜自身がわからない。答えは読者に委ねる
- **プラットフォーム対応**: カクヨムではミステリー先行。アルファポリスではSF＋恋愛
- **更新頻度**: 週1-2回。5,000〜7,000字/話

## 第1話の設計

### 構成（3シーン、怜POVのみ。ホノカPOVは2-3話で初出）
- **S1**: 朝（怜視点、~2,000字）— ホノカとの日常。金属の手の冷たさ。世界観の自然な提示。鏡の浸食Stage 1の種を仕込む
- **S2**: 仮想空間（怜視点、~2,500字）— フルダイブ。ホノカの手が温かい。移動中に廃人時代の知識。ホノカが「ここ、知ってます」
- **S3**: 削除区画（怜視点、~2,000字）— 存在しないはずの場所。怜の既視感。奥で怜の旧アバターデータを発見。終わり

### フック
削除されたはずの仮想空間に、怜自身の古いアバターデータが残っていた。来た記憶がないのに、来た痕跡がある。

### 後のアークで使うフック弾
- **A**: もう一人のホノカ（同型AI）— 中盤の重いアーク
- **C**: 亡くなった恋人のプライベート空間 — 第1部クライマックス

## Devil's Advocate 最終レビュー対応

### 第1回レビュー（コンセプト段階）
| 指摘 | 対応 |
|------|------|
| ミステリーと心理のペーシング対立 | シーンごとにモード分離。繋ぎ目で統合 |
| フックが抽象的 | 第1話で削除区画+旧アバターデータの具体的事件 |
| 仮想空間のスコープ爆発 | 2-3箇所限定。現実より狭く |
| 答えを出さない→ミステリー未解決に見える | 陰謀は解決/関係は着地/哲学は未解決。3層分離 |
| AI視点の文体 | ほぼ人間。「なぜ」の空欄で差を出す |
| フィジカルボディ不要論 | 触覚対比・劣化・社会可視性の3つの必然 |
| 敵対者は鏡に | 主人公ペアの「もう一つの可能性」 |
| アップデート微小死は2回まで | 1回目は気づかない/2回目がクライマックス |

### 第2回レビュー（最終チェック）
| 指摘 | 深刻度 | 対応 |
|------|--------|------|
| Ep.1 POV反復で読者離脱 | HIGH | 3シーン構成に変更。ホノカPOVは2-3話 |
| 事件バリエーション設計不在 | HIGH | 5カテゴリの事件分類表を作成 |
| ホノカPOV文体の欠落 | HIGH | 「ほぼ人間、なぜが空欄」方式で設計 |
| 事件×心理テーマ接続ルール不在 | HIGH | (a)〜(d)チェック項目+30%ルール |
| 商業戦略が中途半端 | HIGH | タグに恋愛含む。物語内では曖昧。読者に委ねる |
| Rule 6と異常検知の矛盾 | HIGH | 「記憶の断片」に再定義 |
| Ep.1フックの感情的衝撃度不足 | MEDIUM | 旧アバデータ+恋人の痕跡を検討（今後詰める） |
| Mirror Erosion進行トリガー未定義 | MEDIUM | 今後詳細設計で定める |
| レギュラーキャラ不足 | MEDIUM | 追加枠3-4人分を空けておく |
| ホノカの自覚レベル未定義 | MEDIUM | 序盤無自覚→中盤部分自覚→終盤不明のまま受容 |
| タイトルの検索性 | MEDIUM | 日本語副題を今後検討 |
| 強制ログアウト/意識トラップ境界未定義 | MEDIUM | 3パターン（空間異常/アカウント攻撃/AI経由）で定型化 |
| AIの法的位置づけ | LOW | デフォルト「高度家電」+異議申し立てが社会的議論 |
