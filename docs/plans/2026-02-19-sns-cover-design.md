# SNS運用 + 表紙デザイン設計書

**Date**: 2026-02-19
**Scope**: battousai（濁刃）を皮切りに、創作活動全体のSNSプレゼンスと表紙ビジュアルを確立する

---

## 1. 表紙デザイン

### 方針

ComfyUI（Stable Diffusion）で**雰囲気画像**を生成する。キャラクターの描写は避け、風景・小物・テクスチャで「染み鉄（Stained Steel）」の世界観を視覚化する。

### キャラを描かない理由

- **技術面**: SDのアニメ系モデルは「AI特有の手癖」（目の光彩パターン、髪の光沢、肌の質感）が出やすく、見慣れた人には一目でAI生成と分かる。風景・小物・テクスチャ系はリアリスティックモデル（SDXL, Juggernaut等）が強く、AI生成と気づかれにくい
- **ブランディング面**: 顔が見えない、人物が写らない表紙は「不在感」を演出する。刀だけがそこにあって持ち主が見えない——物語のテーマ「剣の冴えと引き換えに何を失っているのか」と共鳴する
- **市場面**: Pixiv小説の表紙はキャラ絵・テキストのみ・雰囲気画像の3パターンが主流。キャラ絵がなくてもクリック率に大差はなく、フックはキャプション冒頭78文字が担う

### 生成する画像

| 用途 | サイズ | イメージ | 備考 |
|---|---|---|---|
| Pixivシリーズ表紙 | 1200×1600（縦長） | 雨に濡れた刀の柄、鉄錆のテクスチャ、タイトル文字を重ねる | Pixiv側でリサイズされる。600×800が最低推奨 |
| Xヘッダー | 1500×500（横長） | 雨の京都の通り、暗い色調、上に薄くタイトル | スマホでは上下がトリミングされるため重要要素は中央に |
| Xアイコン | 400×400（正方形） | 鍔（つば）のクローズアップ、または錆びた鉄のテクスチャ | 円形にトリミングされるため四隅に情報を置かない |

### 色彩設計

濁刃の「染み鉄」美学に準拠:
- **主色**: 鉄錆色（#8B4513系）、暗い灰（#2C2C2C系）
- **差し色**: 血の赤（#8B0000系）、白梅の白（控えめに）
- **テクスチャ**: 和紙、鋼の表面、雨滴

### 文字入れ

ComfyUI出力の画像に、Canva（無料）またはPhotopea（無料）でタイトル文字を載せる。

- フォント: 筆書き風（例: 衡山毛筆フォント、源界明朝）
- 「濁刃」を大きく、「だくじん」のルビを小さく
- 文字色は白 or 金系で背景から浮かせる

## 2. Xアカウント設計

### アカウント構成

| 項目 | 内容 |
|---|---|
| 表示名 | `[ペンネーム]@濁刃 連載中` |
| ID | 短く覚えやすいもの（作者名ベース） |
| アイコン | 表紙デザインと統一した画像 |
| ヘッダー | 濁刃の世界観を伝える横長画像 |
| 固定ポスト | シリーズ紹介 + Pixivリンク + 表紙画像 |

### プロフィール文

```
剣が冴えるほど人間が消える——
幕末剣劇『濁刃（だくじん）』連載中。るろうに剣心 追憶編を下敷きにした全10話。
[Pixivシリーズ URL]
```

**設計根拠**:
- 1行目: 作品テーマを一文で。フック。プロフィールを見た人が3秒で「何を書く人か」を理解できる
- 2行目: 作品名（読み方込み）、ジャンル、原作名、スケール感。検索にもかかる
- 「連載中」で今まさに動いている作品であることを示す

## 3. SNS運用フェーズ

### Phase 1: 初動（1週間）

- アカウント作成 + プロフィール・画像設定
- 既存6話を**1〜2日おきに1話ずつ**告知
  - 一気に6連投しない理由: 新規アカウントのタイムラインが自分のツイートだけで埋まり「宣伝bot」と判断される
  - テンプレは既存の `docs/marketing/sns_announcement_guide.md` を使用
- 同ジャンル（るろ剣二次創作）の創作者・読者を10〜20人フォロー
  - 創作者は拡散力を持つ。フォロー → 相手の作品をブックマーク → プロフィール閲覧 → 固定ポストから流入、のファネル

### Phase 2: 定常運用

- 新話公開: 23時投稿 → 30分以内にX告知
- 他の創作者の作品をブックマーク・感想して相互認知を育てる
- 創作進捗の小出し（ネタバレなし、手触りだけを伝える）
  - 例: 「今日は7話目の戦闘シーンを書いていた。刀が鳴る音の表現に悩んだ」
  - 投稿頻度を維持しつつ、読者に「作者が本気で書いている」と伝える
- 投稿後24時間の反応を見てPixiv側のタグを微調整

### Phase 3: 将来的な拡張

- angel_returnの告知も同じアカウントで開始
- villainess開始時にオリジナル作品用の戦略を別途設計

---

## 4. やらないこと

- 毎日の宣伝投稿（逆効果。作品の質で届ける）
- 作品と無関係な雑談投稿（フォロー解除の原因）
- AI活用を隠す（PixivではAI生成フラグを既に立てている。Xでも聞かれたら正直に答える。隠して後でバレる方がダメージが大きい）

---

## 5. AI活用のリスクと対策

### 現状

- 小説本文・表紙画像ともにAIを活用して制作している
- PixivのAI生成フラグは既に有効化済み。この方針を維持する

### リスク

- PixivのAI生成フィルタにより、AI生成作品を除外設定している読者には表示されない
- 二次創作コミュニティではAI制作物全般への忌避感がある。交流を避けられる可能性がある
- AI小説は「読む価値がない」と先入観で判断される場合がある

### 対策

- **質で勝負する**: AI生成フラグが立っていても読まれる作品は読まれる。フラグの有無より、キャプション冒頭78文字のフックと作品の完成度が決定的
- **表紙でキャラクターを描かない**: 絵師の領域を侵す印象を最小化し、反感のリスクを下げる
- **積極的に隠さないが、積極的にアピールもしない**: 「AI小説です！」と毎回宣言する必要はない。聞かれたら答える
- **コミュニティへの敬意を示す**: 他の創作者（手書き・AI問わず）の作品をブックマーク・感想することで、作品を通じた交流を築く
