# Evangelion: Survival Protocol

## 概要
『新世紀エヴァンゲリオン』の二次創作小説プロジェクト。
「強くてニューゲーム」の皮を被った、実存的不安の物語。主人公・碇シンジは2周目の知識を持つが、世界そのものが敵対的に進化している「ハードモード」の世界を描く。

## ストーリー
「逃げちゃダメだ」なんて、もう言わない。
逃げる場所なんて、最初からどこにもなかったのだから。

記憶と経験を引き継いだまま、再び14歳に戻った碇シンジ。
しかし、彼を待っていたのは「無双」ができるイージーモードではなく、世界そのものが敵対的に進化した「ハードモード」だった。

記憶の底に焼き付いた地獄のフラッシュバックに耐え、傷ついた生存本能（サバイバル・インスティンクト）だけを頼りに、彼は二度目の地獄を歩き始める。
これは、ただのループではない。断絶された未来に残された、最後の「悪あがき」の物語。

## ディレクトリ構成
- `.agent/skills/`: AIエージェント用のスキル定義ファイル (執筆支援、校正など)
- `.agent/workflows/`: 執筆ワークフロー定義
- `projects/angel_return/`:
    - `docs/`: 設定資料 (キャラクター、世界観、プロット)
    - `drafts/`: 執筆中の原稿 (Markdown形式)
    - `dist/pixiv/`: Pixiv投稿用フォーマット済みテキスト & 画像素材
