# Evangelion: Survival Protocol

## 概要
『新世紀エヴァンゲリオン』の二次創作小説プロジェクト。全15話・4幕構成。
「強くてニューゲーム」の皮を被った、アイデンティティの物語。

## ストーリー
「逃げちゃダメだ」なんて、もう言わない。
逃げる場所なんて、最初からどこにもなかったのだから。

記憶と経験を引き継いだまま、再び14歳に戻った碇シンジ。
しかし、彼を待っていたのは「無双」ができるイージーモードではなく、世界そのものが敵対的に進化した「ハードモード」だった。

偽りの記憶で世界を欺いてきた少年が、その記憶すら嘘だったと知り、
それでも「ここまで生きてきた自分は本物だ」と選び直すまでの物語。

## ディレクトリ構成
- `.claude/agents/`: AIエージェント定義 (Writer, Editor, Proofreader, Publisher)
- `.claude/skills/`: AIエージェント用スキル定義 (執筆、校正、チームオーケストレーション)
- `.agent/skills/`: 執筆支援スキル (小説執筆、整合性チェック、スタイルチェック等)
- `.agent/workflows/`: 執筆ワークフロー定義
- `projects/angel_return/`:
    - `docs/`: 設定資料 (キャラクター、世界観、プロット)
    - `drafts/`: 原稿 (Markdown形式)
    - `dist/pixiv/`: Pixiv投稿用フォーマット済みテキスト

## 執筆環境
本プロジェクトはClaude Codeのエージェントチーム機能を活用して執筆しています。
- **Writer**: プロットに基づく本文執筆
- **Editor**: 文体・没入度・AI臭の分析
- **Proofreader**: 設定整合性・キャラクター一貫性チェック
- **Publisher**: Pixiv投稿フォーマット変換・ドキュメント管理
